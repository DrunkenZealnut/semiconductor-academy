**기준**: Design §5.1 "COLUMN 600~1,200자"
**실측**: 범위 내 5개, **초과 4개**, 미달 0개 — col-9(1,591) · col-5(1,397) · col-8(1,373) · col-1(1,294)

### Gap-3 (Medium · 외부 정보 의존) — 판권 미확인 → **2026-08-09 종결 ✅**

**기준**: Design §7 D-1 · §8 DoD 마지막 항목("판권 확인 후 출처 표기 확정 — 게시 게이트")
**분석 시점 현황**: `attribution: '菊地正典(기쿠치 마사노리)'` · `publisher: '한국어판 판권 확인 중'`

**성격**: 구현 결함이 아니라 **원문 스캔본에 판권 페이지가 없어 생긴 외부 정보 부족**이었다. 참고문헌 8건 중 6건이 기쿠치 마사노리 저·감수(일본실업출판사)라는 간접 근거만 확보. 역자·출판사·발행연도 미상.

**종결 근거 (2026-08-09 사용자 결정)**: 이 사이트는 **개인 학습용**이며 middleware 로그인 게이트 뒤에서만 열람되는 **비공개 운영**이다. 따라서 게이트의 전제였던 "공개 배포"가 성립하지 않아 배포 판권 확인 자체가 불요하다. `license: 'fair-use'`는 개인 학습 목적 인용으로 유지된다.

**조치**: 미확인 정보를 표기하지 않도록 `publisher` 필드를 **제거**했다(optional 필드라 `SourceHeader`·`SourceModuleArticle`·`disclosureFor` 모두 없는 경우로 분기). 제거 후 렌더를 확인하니 `disclosureFor`의 no-publisher 분기가 처음 실행되며 바이라인이 `(菊地正典(기쿠치 마사노리))`로 **괄호 중첩**됐다 — 13개 자료원 중 publisher가 없는 첫 사례였다. 두 곳을 함께 정리했다: ① `attribution`을 괄호 없는 `'기쿠치 마사노리 菊地正典'`으로(한국어 사이트라 한글 독음 우선), ② no-publisher 분기를 `(${attribution} 지음)`으로. 최종 렌더는 `「처음 배우는 반도체」(기쿠치 마사노리 菊地正典 지음)`이며, 결정 근거는 `sources.ts` 해당 위치에 주석으로 남겼다.

**잔여 조건**: 이 종결은 **비공개 운영을 전제**로 한다. 향후 로그인 게이트를 해제해 공개 전환할 경우 판권 확인이 다시 게이트가 된다.

## 5. Match Rate

```text
검증 항목 50 = A13 + B5 + C8 + D5 + E10 + F6 + G3
그룹 소계    = A 13✅ + B 5✅ + C 6✅2⚠ + D 5✅ + E 10✅ + F 6✅ + G 3✅

최종  ✅ 48 · ⚠ 2 · ❌ 0  →  48 / 50 = 96.0%   (기준 90% 충족 ✅)
```

**측정 오류 정정 ④ (Match Rate 계산)**: 분석 시점에 `✅47 · ⚠2 · ❌1 → 94.0%`로 산출했으나 **그룹 소계와 맞지 않았다**. §1 매트릭스 50행 중 ❌ 판정을 받은 행은 하나도 없고(소계 합 = ✅48 + ⚠2 = 50), Gap-3(판권)은 §1에 검증 행이 없는 **Design §7 미확정 항목**이었다. 이를 50항목 안의 ❌로 세면서 ✅ 하나를 임의로 차감한 것이 오류다. 따라서 **분석 시점의 정확한 값도 96.0%**였고, Gap-3 종결은 Match Rate를 올린 것이 아니라 **§7 미확정 항목을 닫은 것**이다.

> 선례(hs-assembly-inspection)는 ⚠를 맥락 종결로 해소해 100%를 산출했으나, 이번 ⚠2건은 **수치 기준을 실제로 벗어난 것**이므로 상향 조정하지 않는다. **최종 Match Rate 96.0%**.
