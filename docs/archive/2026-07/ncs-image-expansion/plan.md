# Plan — NCS 전 모듈 확장 + 원문 도판 활용 재작성

> **Feature**: `ncs-image-expansion`
> **작성일**: 2026-07-13 · **Level**: Dynamic · **Cycle 유형**: 자료원 전량 확장 + 이미지 파이프라인 신설 + 기존 콘텐츠 보강
> **상속**: `ncs-semiconductor`(30모듈 재구성 체계·검증 게이트) · `ncs-semiconductor-dev-track.spec.md`(병렬 에이전트 재구성 스펙) · `chapters-source-fidelity`(ImageFigure·source-images 패턴)

## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem (문제)** | ① 기존 NCS 30모듈은 저작권 보수 정책으로 **이미지 0장** — 장비 구조·공정 흐름처럼 그림 없이는 이해가 어려운 내용이 텍스트로만 전달된다. ② 사용자가 `data/ncs/`에 marker 변환 md를 보완해 **개발 30·재료 22 모듈 전체 원문 + 도판 2,094장**이 확보됐지만, 사이트는 그중 30모듈만 커버(개발 19·재료 13·제조 7·장비 15 = **미커버 54모듈**). |
| **Solution (해법)** | 기존에 검증된 재구성 파이프라인(병렬 에이전트 + 구조 검증 + 원문 수치 대조)에 **이미지 선별 파이프라인**을 추가: 원문 도판 중 NCS 자체 저작(제3자 출처 미표기) 도판만 선별 → 리사이즈·압축 → `public/source-images/ncs/{module}/` → 기존 `ImageFigure` 컴포넌트로 캡션·출처와 함께 삽입. 이 파이프라인으로 **기존 30모듈 이미지 보강 + 신규 54모듈 작성**을 단계 확장한다. |
| **Function·UX Effect (기능·UX 효과)** | 모든 NCS 모듈에서 장비 사진·공정 도식·그래프를 원문 그림 번호·출처와 함께 열람(클릭 시 Lightbox 확대). `/sources/ncs-semi`가 30 → **84모듈**로 확장되어 NCS 반도체 4트랙(개발·제조·재료·장비)을 사실상 전량 커버. cross-link 연결망도 대폭 확대. |
| **Core Value (핵심 가치)** | "글로만 설명하던 현장"에 원문 도판이 붙어 고등학생 눈높이 이해도가 실질 상승. NCS 반도체 직무 표준의 **완전한 시각 자료원**이 되어 책(왜 위험한가)·OSHA(어떻게 안전하게)·NCS(현장 직무) 삼각 구도가 완성 단계에 도달. |

- 이미지 실측: 평균 55KB, 최대 320KB (jpeg). 파일명 `_page_{N}_{Figure|Picture}_{M}.jpeg`, md 본문에 `![](...)` 인라인 참조 + 인접 줄에 `[그림 X-X] 캡션` 존재 → **위치·캡션 매칭 가능**.
- 제조 md는 이미지 참조(`![...]` 23~115건/모듈)는 있으나 이미지 파일이 없음 → 원본 PDF에서 `marker_single`로 재추출 필요. 장비는 md 자체가 없어 marker 변환부터 필요 (`~/.local/bin/marker_single` 설치 확인됨).
- 장비 PDF 중 4개는 2-LM 합본(보드 설계 314+315, 유틸리티 SW 316+317, 시제품 성능평가 318+319, 품질관리 320+321) → 합본 1건 = 사이트 모듈 1개로 취급.
- macOS 한글 경로는 NFD 정규화 — 셸에서 경로 하드코딩 시 find 출력 경로를 그대로 사용할 것.

## 2. 저작권 — 정책 전환 (이번 사이클의 핵심 변경)

NCS 학습모듈 고지(원문): *"교육훈련기관에서 출처를 명시하고 교육적 목적으로 활용할 수 있습니다. 다만 국가(교육부)가 저작재산권 일체를 보유하지 않은 저작물(**출처가 표기된** 도표·사진·삽화·도면 등)은 원작자의 동의를 받아야 합니다."*

→ 기존 정책(이미지 전면 회피)에서 **"NCS 자체 저작 도판 선별 사용"** 으로 전환(사용자 지시). 선별 필터:

1. **제외**: 캡션·인접 본문에 제3자 출처 표기가 있는 도판(`[자료: ...]`, `(출처: 기업/보고서/서적)`, 외부 로고·워터마크 포함 이미지).
2. **제외**: 장비 제조사 카탈로그로 추정되는 실사 제품 사진 등 판단 애매 위험군 — **보수적으로 개념도·절차도·구조 도식 위주** 선별.
3. **제외**: 표지·NCS 보일러플레이트(활용 안내, 분류 체계도) 이미지.
4. **채택 상한**: 모듈당 3~6장 — 이해에 실질 기여하는 핵심 도판만 (전수 수록 아님).
5. **표기**: `ImageFigure`의 `caption`에 원문 그림 번호·제목, `source`에 `NCS 학습모듈 「{모듈명}」({LM코드}) · 교육부·한국산업인력공단`.
6. **푸터 갱신**: 이미지 포함 모듈은 기존 "원문 도표·사진은 싣지 않았습니다" → "원문 도판 일부를 출처 표기와 함께 실었으며, 제3자 저작 표기가 있는 도판은 제외했습니다"로 교체.

## 3. 목표 / 비목표

### 목표
- **이미지 파이프라인**: 선별(§2 필터) → 리사이즈·압축(`sips`, 최대폭 1200px, 장당 ≤200KB) → `public/source-images/ncs/{module-id}/` → MDX `ImageFigure` 삽입.

- 84섹션 인덱스 페이지 UI 재설계(그룹 접기 등) — 렌더 확인 후 필요 시 별도 사이클.

3. **기존 30모듈 처리**: ① 이미지 보강(본문 유지) ② 전면 재작성 — **권장 ①** (CodeRabbit 리뷰까지 통과한 본문 보존)
