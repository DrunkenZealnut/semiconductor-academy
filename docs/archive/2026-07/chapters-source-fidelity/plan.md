| **Function·UX Effect (기능·UX 효과)** | 각 챕터 페이지가 원문의 공정 원리·유해인자·연구 결과·표를 학생 눈높이(Easy)와 원문 충실(Deep/SourceQuote) 이중 구조로 완전 전달. `/quotes` 인용 인덱스 자동 확충(LE+SQ 증가). readingTime 실분량 반영. |

## 1. 배경 / 현재 상태

### 원문 자료 매핑 (루트 `data/`, 수정 금지)

| 추출 파일 | 챕터 | 분량 | 챕터 시작 행 |
|------|------|------|------|
| `20260526_185841_…_-_13.md` | ch1∼3 | 690줄/60KB | ch1: 248 · ch2: 384 · ch3: 609 |
| `20260526_215845_…_-_47.md` | ch4∼7 | 742줄/86KB | ch4: 6 · ch5: 160 · ch6: 381 · ch7: 600 |
| `20260527_132608_…_-811.md` | ch8∼11 | 1,445줄/151KB | ch8: 6 · ch9: 811 · ch10: 1129 · ch11: 1295 |
| `20260527_154313_…_-_toend.md` | ch12∼17 | 1,796줄/256KB | ch12: 6 · ch13: 104 · ch14: 775 · ch15: 1027 · ch16: 1397 · ch17: 1793 |

- 페이지 마커 `<!-- page: N -->`는 추출 배치 상대 번호. **책 페이지 = 마커 + 오프셋** (file4: +206, 책 자체 참조 "210쪽 [그림 12-2]"로 검증됨). 각 챕터 시작 책 페이지는 `chapters.json sourcePages[0]`이 진실.
- **ch17 원문 미추출**: file4는 ch17 제목 + 소개 문단 1개에서 끝남(추출 누락). → ch17은 이번 사이클 **제외**(현행 유지).
- OCR 노이즈 존재(헤딩 깨짐, 붙어쓰기) — 인용 시 명백한 오탈자만 최소 교정, 의미 변경 금지.

## 2. 목표 / 비목표

### 목표
1. **ch1∼ch16 (16개) 재작성** — 원문의 모든 주요 섹션(가나다 하위 절 포함)을 포괄, 표·수치·연구 결과·작용 기전을 정확 반영.
2. 기존 **3단 레이어 패턴 유지**: LayeredExplain(Hook/Easy/Deep) 1개 + 본문(Easy 톤) + SourceQuote(원문 직인용) 다수 + Callout.
3. 페이지 인용을 책 목차·`sourcePages` 기준으로 **교정** (마커+오프셋, 불확정 시 챕터 범위 내 단조 보간).
4. `chapters.json` readingTime 재산정 (hasFullBody 정합화 포함).
5. 파일럿(ch12) → 템플릿 확정 → 15개 병렬 → 검증 게이트 통과.

### 비목표
- `/process/*` 공정 페이지 재작성 (별도 사이클).
- cross-link 통제 어휘 확장, `_book-links.json` 변경.
- 원본 `data/` 이미지의 대량 신규 큐레이션 (기존 `public/source-images/` 자산 유지; 검증된 경우에 한해 소수 추가 허용).
- OSHA 콘텐츠·컴포넌트·라우팅 코드 변경 (콘텐츠 전용 사이클, 코어 무수정).
- ch17 재작성 (원문 미추출).

## 5. 실행 방식

1. **파일럿**: ch12 CMP 직접 재작성 → extract:quotes 검증 → 프롬프트 템플릿 확정.
2. **병렬**: 챕터별 서브에이전트 15개 (ch1∼11, 13∼16), 동일 템플릿 + 챕터별 원문 행 범위 지정.
3. **검증 게이트**: quotes/cross-link/typecheck/lint/build + LE/SQ 개수 비교 + 스팟 리뷰(무작위 3개 챕터 원문 대조).
4. **마감**: chapters.json 갱신 → PDCA analysis/report → 사용자에게 커밋 여부 확인.
