## 5. QA 라운드 (렌더 실측 + 원문 대조 감사, 커밋 후 수행)

### 5.1 렌더 실측 (Playwright, 데스크톱 1280 / 모바일 390)
- **hydration 오류 (전역)** — 여러 줄 `<p className="text-xs …">` 각주 블록 안에 마크다운 문단(`<p>`)이 중첩돼 SSR HTML에서 `<p>`-in-`<p>` 발생. 각주 8챕터 19곳을 `<div>`로 전환 → 정적 HTML 중첩 0.
- **모바일 표 오버플로** — 폭 넓은 표(예: ch1 9열, ch14 5열)가 뷰포트를 넘겨 페이지 body가 가로 스크롤됨. `mdx-components.tsx`에 `table` 매핑 추가(표를 `overflow-x-auto` div로 래핑) → 표 자체만 스크롤, body overflow-x 해소. **NFR-4(코어 무수정)의 유일한 예외** — 콘텐츠 표 밀도 증가로 드러난 전역 버그라 정당한 수정으로 판단.
- **인라인 ChemicalCard 4건** (ch5 1, ch8 3) — 문단 텍스트와 같은 줄에 블록 컴포넌트가 놓여 `<p>` 안에 카드 `<div>`가 중첩. 독립 블록으로 분리.
