## 2. 이 사이클이 실제로 한 일

### 2.1 ★Design이 착수 전에 Plan을 무너뜨렸다

Plan은 이 사이클의 숫자를 **G-5**(*"셀 수만으로는 못 보는 1건이 있다"*)에 걸었다. 셋을 쟀다:

| 잰 것 | 결과 |
|---|---|
| 후보 신호 ① 홀수 백틱 | 정당한 `\`` 에 **거짓 경보** · 합성 결함엔 **조용**(패리티가 우연히 맞았다) |
| 후보 신호 ② 원문 패리티 | 실물 결함에 **조용** · 이중 백틱에 거짓 경보 · 전량에서 **0건** |
| ★표적 자체 | **표 밖에서 파싱해도 완전히 동일** |

**그것은 표 결함이 아니었다** — 코드 스팬 안에는 이스케이프가 없어서(CommonMark) 백틱이
첫 짝에서 닫히는 저작 실수다. **G-5 폐기.**

> *신호를 세우기 전에, 그 신호가 겨누는 것이 정말 그 자리에 있는지 먼저 잰다.*

### 2.2 ★가장 값진 것 — **습관을 구조로**

1차 판독이 짚은 것: 새로 적은 상한 3줄·우회로 3줄·`파일:줄`이 **전부 무대조군**.
2차가 짚은 것: **그것을 고치는 커밋이 같은 병을 한 번 더 냈다**(상한을 두 줄로 적고 한 줄만 걸었다).

**아홉 번째였다.** 그래서 손 목록을 **유도**로 바꿨다.

```text
상한 줄 삭제        → 19줄인데 선언은 20이다        (손 목록은 조용했다)
상한 줄 추가        → 21줄인데 선언은 20이다        (다음 사람의 실수를 미리 막는다)
유도기가 빈 목록     → 유도가 0줄을 냈다             (처음엔 조용 → 쓰는 자리에서 다시 세게 고침)
유도를 () => /a/    → 패턴이 너무 짧다              (처음엔 조용)
소스엔 있는데 안 찍힘 → D-02가 운다                  (유도가 «소스»가 아니라 «출력»을 본다)
```

> **재는 대신 못 쓰게 만든다.** 상한 줄을 더하면서 대조군을 잊는 것이 **불가능하다.**

### 2.3 ★한쪽만 고치는 병

3차 판독: 1차가 짚은 *"우회로가 무대조군"* 을 **표 쪽만 덮고 링크 쪽 쌍둥이 6줄을 남겼다.**
그 6줄은 *"allow 파일이 없다 — 우회로가 공짜다"* 라는 주장의 **유일한 구현**이다.
→ `failureFileLines()` 유도로 닫았다.

그리고 같은 병이 **연쇄로** 나왔다:

| 자리 | 한쪽만 고친 것 |
|---|---|
| 죽은 docs 경로 | *"4건 → 0건"* 이 `.mjs`/`.py` 범위에서만 참 — **`.ts`에 7 참조**가 살아 있었다 |
| `F-31` | 유도기가 둘이 됐는데 상한은 **하나만** 적혀 있었다 |
| 위반 **건수** | 표·링크 둘 다 아무도 안 봤다 |
| `D-30` | 쌍둥이 `D-27`은 줄 번호 값을 거는데 여기만 없었다 |

> **한쪽만 고치는 병을 고치려고 만든 장치가, 그 병의 새 서식지가 된다.**

### 2.4 실측이 뒤집은 «처방» 둘

| 적혀 있던 것 | 실측 |
|---|---|
| *"이중 백틱도 표 우회로다"* | **거짓** — 홑백틱 4셀 · **이중백틱 4셀** · `\|` 2셀. F-29(코드 스팬)의 처방을 이 병에 적었다 |
| *"`treeOf`는 단일 원천 — 이음매가 없다"* | **거짓 문장** — 판정 셋이 `PROC.parse`를 직접 불렀다. 고쳤고, **오늘은 배선이 관측 불가**임을 상한으로 적었다 |

## 3. ★범위 — 이 사이클은 «앱 코드 무변경»을 쓸 수 없다

선행 세 사이클이 전부 *"앱 코드 무변경"* 을 성과로 적었다. **이번엔 못 적는다.**

```text
git diff -U0 src/  →  7파일 · 추가 줄 7 · 그중 주석 7  ·  실행 코드 0
  - * Design: docs/02-design/features/…design.md
  + * Design: docs/archive/…/design.md
```

**정당한 확장인 근거 셋**(4차 판독의 판정):

1. **Plan §6이 금지하지 않는다** — 범위 밖 목록에 `src/`가 없다.
2. **원인이 이 사이클 안에서 발견됐다** — 2차가 *"관문이 `.md`/`.mdx` 밖을 못 본다"* 를 열고
   *"4건 → 0건"* 이라 닫았는데, 그 닫힘이 **반쪽**임을 3차가 실측했다.
   **자기가 낸 거짓 문장을 자기 사이클에서 참으로 만드는 일** — 침범이 아니라 **부채 상환**이다.
3. **위험 0** — 주석만 바뀌면 런타임·타입·번들 어디에도 영향이 없다(`typecheck` 통과).

> ★**선을 긋는다**: 이 확장은 *"사각을 실측했더니 밖에도 있었다"* 는 **구체적 실측**이 있어서
> 정당하다. 근거 없이 `src/`를 만지면 선행 세 사이클의 그 문장이 무의미해진다.

## 4. 상한 — 안 재는 것

| 자리 | 성질 |
|---|---|
| **HTML `<table>` · JSX 표** | 파서가 `html` 노드로 준다 — 셀을 못 센다 |
| **코드 펜스 안의 표** | 파서가 표로 안 본다 — **그것이 우회로다**(의도된 상한) |
| ★**헤더 행·구분자 행 자체가 깨진 경우** | GFM이 **표로 인식조차 안 한다** — 이 병의 **더 나쁜 형태**인데 완전히 조용하다(실물 0건 → **F-30**) |
| **`.mdx`의 JSX 여는 태그 바로 다음 줄부터의 표** | `remark-mdx`를 안 써서 `html`에 삼켜진다(실물 0건) |
| **데이터 행이 0인 표** | 검사할 행이 없다 |
| ★**`.md`/`.mdx` 밖** | `.ts`·`.mjs`·`.py` 주석의 `docs/…` 경로는 사각이다 — **실측으로 죽은 것이 있었다** |
| ★**유도의 «내용»** | 개수는 재는데 내용은 못 잰다 — 유도기 **둘 다**(**F-31**) |
| ★**실패 출력 7줄** | 유도가 아니라 **손 목록**이 지킨다 — 한 줄 더하면 **열 번째 재발**(**F-32**) |

**성공 출력이 이 목록을 스스로 말하고, `D-31`이 그 말을 관측한다.**

## 5. 왜 89%에서 닫나

4차 판독의 근거를 그대로 옮긴다 — **곡선이 꺾였다.**

| 판독 | 찾은 것의 깊이 |
|:--:|---|
| 1차 83 | 장치가 아예 없다 (구조) |
| 2차 87 | **고치는 커밋이 병을 재현한다** (구조) |
| 3차 88 | 표만 덮고 쌍둥이를 남겼다 · 문장 셋이 거짓 (절반 구조) |
| **4차 89** | **새 구조적 결함 0건** — 같은 문서 안 다른 칸의 수 셋 + 얇은 무대조군 넷 (표류) |

*한 겹 아래로 못 내려가고 **옆칸**으로 갔다.* 남은 셋은 이 사이클의 도구로 안 닫힌다:
**F-32**는 설계 변경(분기마다 fixture가 다르다) · **F-31**·**F-33**은 *재는 자를 재는 자*의 되돌이다.
선행 `doc-link-route-resolvers`가 85%에서 *"억지 대조군으로 수를 만들지 않는다"* 고 판단한 것과
**같은 지점**이다.

## 7. 남기는 문장

> **습관은 아홉 번 깨진다.** *"출력 줄을 더하면 같은 커밋에서 `wantReason`도 더한다"* 는
> 옳은 습관이었고, 아홉 번 지켜지지 않았다. **재는 대신 못 쓰게 만들고 나서야 멈췄다.**
>
> **한쪽만 고치는 병을 고치려고 만든 장치가, 그 병의 새 서식지가 된다.**
> `failureFileLines()`는 쌍둥이를 닫았고, 그 자신이 F-31에 이름이 없는 쌍둥이가 됐다.
>
> **«4건 → 0건»처럼 범위를 좁혀 놓고 «밖은 사각이다»라고 적으면, 사각의 크기를 모른 채 적는 것이다.**
> `.mjs`·`.py`만 보고 닫았는데 `.ts`에 7 참조가 있었다.
