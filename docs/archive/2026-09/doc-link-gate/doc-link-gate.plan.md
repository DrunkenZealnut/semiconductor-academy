# 문서 링크를 재는 자 — Plan

> **선행**: `render-gate-self-test-denominator`(91%, 2026-09-01 아카이브) 파생 **F-10**
> **한 줄**: 링크를 고친 사이클이 *"0건"* 이라고 적었고, **그 문장이 4건을 만들었다.**

---

## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 도해에는 관문이 다섯 겹인데 **문서 링크는 무방비**다. 직전 PR에서 CodeRabbit이 죽은 링크 **1건**을 짚었는데 세어 보니 **21건**이었고, 성질이 넷으로 갈렸다. 고친 뒤 *"저장소 전체 0건"* 이라고 적었는데 **그 문장을 쓴 표가 곧바로 4건을 만들었다**(가상 경로 예시). 그리고 전수 측정에서 **살아 있는 콘텐츠 페이지의 사고 링크 1건**이 나왔다 — 그 규칙은 2026-07 설계서에 적혀 있었다. **적어 두는 것으로는 안 막혔다.** |
| **Solution** | 마크다운 링크를 **파서로** 해석하고 대상이 실재하는지 본다. 어긋나면 `exit`. **정규식이 아니다** — 실측: 사고 링크 후보 4건 중 파서가 인정한 것은 **1건**이고, 나머지 셋은 목적지에 공백이 있어 CommonMark상 링크가 아니다(**거짓 경보 75%**). |
| **Function · UX Effect** | 독자에게는 **깨진 링크가 사라진다**. 사고 링크(`1[H](헨리)`)는 지금 실제로 하이퍼링크로 **렌더된다** — 그것이 없어진다. |
| **Core Value** | *"링크를 다 고쳤다"* 와 *"다 고쳤다는 말이 참이다"* 는 다른 주장이다. 선행 사이클이 관문의 **분모**에 대해 세운 결론이 여기서는 **문서**에 적용된다. |

## 1. 착수 전 실측

> 이 절의 수는 전부 이번에 **직접 재서** 얻었다. 하나도 문서에서 옮겨오지 않았다.
>
> ⚠️ ★**§1.2·§1.6은 Design §0.0에서 뒤집혔다** — 정규식 스캐너로 잰 값이라, 파서에 물으니
> 결과가 달라졌다. **수는 그쪽에 있다**(여기 옮겨 적지 않는다 — 두 곳에 적으면 한 곳만 고친다).
> 이 절은 *착수 시점에 무엇을 알았나*의 기록으로 남긴다.

### 1.1 지금 무엇이 있나

```text
.md 224 · .mdx 342 = 566개
마크다운 링크        151건 (remark-parse) / 146건 (정규식)   ← 파서가 5건 더 본다
```

| 갈래 | 건수 | 판정 가능? |
|---|:--:|---|
| 구체 경로 · **해석 성공** | 116 | ✅ |
| 구체 경로 · **해석 실패** | **2** | ✅ ★아래 §1.2 |
| **사이트 라우트**(`/process/wafer/`) | 24 | ⚠️ 파일이 아니다 — 별도 판정 |
| **모양**(글로브·예시 `[^'"]+`·`...`) | 4 | ❌ 검사 불가 |

### 1.2 ★해석 실패 2건은 **깨진 링크가 아니다**

둘 다 **사고로 만들어진 링크**다 — 파일을 가리키려던 것이 아니다.

| 자리 | 원문 | 성질 |
|---|---|---|
| `src/content/sources/hs-basic-tech-1/electronic-devices.mdx:111` | `1[H](헨리)의` | ★**살아 있는 페이지** — "H"가 하이퍼링크로 렌더된다 |
| `docs/archive/2026-07/chapters-source-fidelity/design.md:125` | `` `[…](…)` `` | 링크 **문법을 설명하는** 자리 |

**둘째가 첫째의 규칙을 적어 놓은 그 문서다.**

```text
7. 대괄호 직후 여는 괄호 `[…](…)`는 링크 문법 — 의도치 않게 만들지 말 것
   (원문의 "[그림 N-M]" 인용 시 대괄호 제거 권장).
```

**적혀 있었고, 지켜지지 않았고, 아무도 몰랐다.** 이 저장소가 반복해 배운 그것이다.

### 1.3 ★정규식으로는 안 된다 — 실측

단위 대괄호 뒤 여는 괄호를 정규식으로 찾으면 **4건**이 나온다. 파서에 물으면 **1건**이다.

| 원문 | 정규식 | **파서** |
|---|:--:|:--:|
| `1[H](헨리)의` | ❗ | ❗ **링크다** |
| `760[mmHg](수은주 높이)와` | ❗ | 안전 |
| `10.336[mAq](Aq는 물을 뜻하는 Aqua의 줄임말)와` | ❗ | 안전 |
| `60[Hz](지역에 따라 다름), 미국은` | ❗ | 안전 |

목적지에 **공백**이 있으면 CommonMark는 링크로 안 본다. 눈으로는 넷이 똑같다.
**거짓 경보 75%짜리 관문은 곧 무시된다.**

### 1.4 인라인 코드의 경로 언급은 **검사 대상이 아니다**

```text
`docs/…` · `src/…` · `scripts/…` 꼴 인라인 코드   1295건 · 해석 실패 256건
```

실패 256건의 대부분은 **아카이브된 문서가 과거를 기술한 것**이다 —
`src/components/layout/BookHero.tsx`(이후 `PlatformHero`로 개명) · `src/components/ui/Button.tsx`(삭제) 등.
**그때는 참이었다.** 이것을 관문이 울리면 역사 기록을 고치라고 요구하게 된다.

→ 이 갈래는 **범위 밖**이다. 다만 *"왜 안 보나"* 를 관문이 스스로 말해야 한다(선행 사이클의 규약).

### 1.5 비용과 재료

| | |
|---|---|
| 566개 전량 파싱 | **1.12초** — `verify:diagram`(1.7초)과 같은 급, 상시 관문으로 쓸 수 있다 |
| 파서 | `remark-parse`·`unified`·`unist-util-visit`가 **전이 의존**으로 이미 있다. **직접 의존은 `remark-gfm` 하나뿐** |

### 1.6 지금 조용한 것

```text
사고 링크 1건이 살아 있는 페이지에 있다 · 아무도 안 운다
"저장소 전체 0건"이라 적힌 문장 곁에 예시 4건이 있다 · 아무도 안 운다
```

**이것이 F-10이다.**

## 2. 열린 문제 — Design이 정한다

| # | 문제 |
|:--:|---|
| **A** | **파서인가 정규식인가.** 파서는 §1.3의 거짓 경보 75%를 없애지만 **전이 의존에 기댄다**(직접 의존은 `remark-gfm`뿐). 올릴 것인가, 아니면 `remark-gfm`을 통해 닿을 것인가, 아니면 정규식 + 상한 선언인가. 이 저장소의 정적 관문은 **의존이 없다** |
| **B** | **사이트 라우트 24건을 볼 것인가.** 파일이 아니다. `generateStaticParams`가 전개하는 실제 라우트와 대조하면 **가치가 크다**(죽은 내부 링크를 잡는다). 그러나 라우트 유도는 관문이 앱을 알아야 한다는 뜻이다 |
| **C** | **예시를 어떻게 가르나.** 실측으로 두 종류가 확인됐다 — ① 가상 경로 예시(`x.plan.md`) ② 문법 설명(`[…](…)`). 도해 관문에는 선례가 있다(`docs/02-design/features/diagram-check-allow.json`). allow 파일인가, 표기 규약인가, 모양 자동 판별인가 |
| **D** | **사고 링크를 이 관문이 볼 것인가.** 실측상 **구체 실패 2건이 전부 이것**이라, 사실상 이 관문의 주 수확이다. 그러나 *"링크가 해석되나"* 와 *"이것이 링크일 의도였나"* 는 다른 판정이다 |
| **E** | **종료 코드.** 도해 관문의 계약(`0`/`1` 콘텐츠 위반/`2` 검사기가 자기 범위를 주장할 수 없음)을 그대로 쓸 것인가. 그렇다면 `2`의 조건은 무엇인가(파서 부재 · 파일 0개 · 자체검사 실패) |
| **F** | **분모를 어떻게 지키나.** 선행 사이클의 결론을 그대로 적용한다 — 대조군 수를 **코드가 선언하고 실행 집계와 대조**한다. 그런데 **감사(`audit:wiring`)까지 만들 것인가**는 별개다 |

## 5. 착수 순서

```text
① 선행 사이클이 남긴 거짓 문장부터 정정한다
   — docs/archive/2026-09/_INDEX.md의 "재스캔 0건"이 자기 예시 4건을 안 센다
② 판정을 순수 함수로 — 파싱 · 분류(구체/라우트/모양/예시) · 해석
③ 대조군 + 개수 선언
④ 되돌림: G-4 · G-5 · G-6 · G-7
⑤ FR-6 사고 링크 수정 → 관문이 초록이 되는 것으로 확인
⑥ CLAUDE.md · Check
```

**①이 먼저인 이유** — 이 사이클은 *"고쳤다는 말이 참인가"* 를 다루는데,
착수 시점에 저장소가 그 말을 거짓으로 들고 있다.
