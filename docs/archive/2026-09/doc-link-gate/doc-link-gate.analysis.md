# 문서 링크를 재는 자 — Check

> ※ 이 문서의 `파일:줄` 인용과 **수치는 Check 시점의 스냅숏이다** — 코드가 진실이고
> 실행이 자기 수를 찍는다. 여기 적힌 수는 *그때 무엇을 봤나*의 기록이지 현재값이 아니다.
>
> Plan: [doc-link-gate.plan.md](./doc-link-gate.plan.md)
> Design: [doc-link-gate.design.md](./doc-link-gate.design.md)
> (인라인 코드가 아니라 **링크**로 적는다 — 그래야 이 관문이 자기 사이클 문서를 지킨다. F-22)
> **한 줄**: 관문이 **재는 것**은 코드가 지켰고, 관문이 **말하는 것**은 네 판독 내내 무대조군이었다.

## 1. 일곱 판독이 매번 같은 자리를 짚었다

| 판독 | 무대조군이던 것 |
|:--:|---|
| 1차 | 성공 출력의 *"안 보는 것"* 3줄 · `remarkGfm` · `dieOnCrash` · exit-2 분기 넷 · 이름 가드 |
| 2차 | `resolvePublic` **배선**(순수 함수는 덮었는데 부르는 자리는 안 덮었다) |
| 3차 | 다중행 JSX **형태**(덮는 것의 70%) · `href` 추출 · `ASSET`의 `'src'` 성분 |
| 4차 | `settled` 삼항(**손으로 지은 짝**) · `SKIP_DIRS`의 `data/` · 홑따옴표 상한 |
| 5차 | ★**홑따옴표 상한을 적은 그 문구** · 대조군 **식별자** 유일성 · 상한 개수(다섯→여섯) |
| 6차 | `seenNames` **배선** · `/보는 것:/`의 **공허** · 상한이 한 주석 안에서 세 목소리 |
| 7차 | **설계서**가 구현과 반대 · `동적 라우트:` 줄 · 상한이 실제로는 **열**(다섯 번째 오답) |

**같은 병이 일곱 번, 매번 한 겹 아래에서.** 순수 함수를 뽑으면 **부르는 자리**가 무대조군이 되고,
장치를 세우면 **그 장치**가 무대조군이 되고, 문구를 적으면 **그 문구**가 무대조군이 된다.

## 2. ★가장 값진 것 — 판독이 틀린 것을 실측이 뒤집었다

4차가 *"다중행 줄 번호 대조군(현 `J-27`)은 판별력 0"* 이라고 단정했다. 근거는 **원문의 들여쓰기**였다 —
`  src="…"` 처럼 들여쓰면 `\s`가 개행이 아니라 공백이라 옛 식도 맞다는 것.

되돌려 재 보니 **아니었다.**

```text
옛 식 m.index                  실제 파일 41  (원문 42)  ❌   → J-27이 운다
현재  m.index + m[0].length     실제 파일 42            ✅
판독 제안 m.index + 1           실제 파일 42            ✅
```

**remark가 `html` 노드 값에서 들여쓰기를 벗긴다** — `"<ImageFigure\nsrc=…"`. 원문만 보면 옛 식도
맞아 보이는데 **파서가 주는 값은 다르다.** 판독은 원문으로 추론했고, 관문은 노드 값을 본다.

> **판독자도 재지 않으면 틀린다.** 그래서 처방을 받을 때마다 넣고 **재 봤다** — 이 사이클에서
> 세 번 그렇게 했고, 세 번 다 무언가가 뒤집혔다.

다만 판독이 제안한 `m.index + 1`은 **URL 값 안의 개행을 안 세어** 더 안전하므로 채택했다.
*틀린 진단에서 나온 옳은 처방*이다.

## 4. 되돌림 실측

**1차 Act 이후**(7건) — 파일 링크 깸 → `1` · 라우트 깸 → `1` · **코드 스팬 예시 추가 → `0`** ·
**공백 목적지 추가 → `0`** · **해석기 없는 동적 라우트 → `2`** · 대조군 삭제 → `2` · 선언 훼손 → `2`

**2차 Act 이후**(6건) — "안 보는 것" 3줄 삭제 · 소요 출력 삭제 · `gfm` 제거 · 이미지 추출 제거 ·
`route.*` 제거 · `empty` 처분 제거 → **각각 지목한 대조군이 운다**

**4차 Act 이후**(5건)

| 되돌림 | 결과 |
|---|---|
| ★`settled` 삼항 **뒤집기** | `exit 2` — 대조군 **7건**이 운다(라벨과 처분이 함께 간다) |
| ★`settled` **삭제** | `exit 2` — 3건 |
| ★`SKIP_DIRS`에서 `'data'` 제거 | `exit 2` — 4건 |
| ★홑따옴표까지 넓히기 | `exit 2` — 상한 대조군이 운다 |
| ★미등록 템플릿 출력 삭제 | `exit 2` — *정상 트리* 대조군이 운다 |

**5차 Act 이후**(2건)

| 되돌림 | 결과 |
|---|---|
| 식별자를 무리 **안**에서 겹친다(`J-02`→`J-01`) | `exit 2` — *식별자가 겹친다 — J-01* |
| 식별자를 무리 **간**에서 겹친다(`D-01`→`J-01`) | `exit 2` — 실제로 났던 충돌 모양이다 |

> ★그 단언은 **처음엔 공허했다** — 이름 *전체*를 비교하니 `J-01 외부…`와 `J-01 mailto…`가
> 서로 달라 통과했다. 실제 충돌(`㉙ 홑따옴표` vs `㉙ 정상 트리`)도 못 잡았을 것이다.
> **식별자만 보게** 고치고 두 모양으로 재서 확인했다. *가드를 세웠다고 가드가 아니다.*

**6차 Act 이후**(3건)

| 되돌림 | 결과 |
|---|---|
| ★`record`의 `push` 삭제 | `exit 2` — *판정 0건인데 선언은 29이다* |
| "보는 것" 3줄 삭제 | `exit 2` — `D-01`이 운다 |
| "출처:" 줄 삭제 | `exit 2` — `D-01`이 운다 |

> ★첫 것은 **판독의 처방대로 헬퍼로 묶었을 때는 안 물었다**(실측 `exit 0`).
> *묶는다고 하나가 되는 것이 아니다* — **원천이 하나**여야 한다.

**7차 Act 이후**(3건)

| 되돌림 | 결과 |
|---|---|
| `동적 라우트:` 줄 삭제 | `exit 2` — `D-01`이 운다 |
| 판정 식별자를 `D-*`로 | `exit 2` — 유일성이 먼저 운다 |
| 판정에 `D-90` 하나 | `exit 2` — *식별자가 무리와 안 맞는다 — 판정:D-90* |

## 5. 상한 — 무엇을 안 재는지

| 자리 | 왜 |
|---|---|
| ★**대조군을 만들 수 없는 자리들**(수를 안 적는다) | `dieOnCrash` · 무리 이름 가드 · `!(kind in tally)` · `!(node in byNode)` · `CONTROLS`/`seen` 단언 · 식별자 **유일성** · 식별자 **모양·무리** · `runSelfTest` 예외 catch · `--self-test` 실패 · ★**본 검사 앞 게이트**(그 배선이 죽으면 대조군 전부가 장식이 된다). **소스를 훼손해야** 관측되는데 감사가 없다(D-4) → **F-12**. ★이 수는 넷→다섯→여섯→일곱으로 **다섯 번 틀렸다** — 그래서 세지 않고 열거만 한다 |
| 외부 URL | 네트워크가 필요하다 |
| 앵커(`#heading`)의 실재 | 실측 1건뿐이라 값이 없다 |
| 인라인 코드의 경로 언급 | 256건 중 대부분이 아카이브 문서의 **정당한 역사 기술**이다 |
| 홑따옴표·빈 속성값·`src={표현식}` | 실측 0건. 상한을 **대조군이 고정**한다 |
| `.mdx`의 JSX 여는 태그 다음 줄 | HTML 블록에 삼켜진다 |
| `data/` | 원문 자료(수정 금지) — 배선을 대조군이 잰다 |
| **대소문자** | macOS `existsSync`가 안 가린다 — GitHub에서는 깨질 수 있다 |

이 표는 성공 출력을 **요약**한 것이다(출력에는 `참조 링크`가 더 있고, 이 표의 *"대조군 다섯"* 은
출력에 없다 — 그것은 헤더 주석에 있다). **출력의 각 줄을 `D-01`(정상 트리)이 사유 정규식으로
관측한다**(6차에 4/9, 7차에 `동적 라우트:` 한 줄이 더 붙었다) — 5차 시점에는 4줄뿐이었고, *"안 보는 것을 말한다"* 를 고치려고 새로 적은 줄이
다시 무대조군이었다. **이 사이클이 다섯 번 겪은 자리다.**

## 7. 이 사이클이 남기는 문장

> **관문이 재는 것은 코드가 지키고, 관문이 말하는 것은 아무도 안 지킨다.**
> 일곱 판독이 매번 그 자리를 짚었다 — 출력의 문구 · 상한의 개수 · 근거로 든 형태 · 내역의 라벨.
> **말도 재야 한다.**

그리고 하나 더 —

> **판독자도 재지 않으면 틀린다.** 처방을 받을 때마다 넣고 재 봤고, 세 번 무언가가 뒤집혔다.
> 두 번은 내가 틀렸고 한 번은 판독이 틀렸다. **어느 쪽인지는 재 봐야 안다.**
