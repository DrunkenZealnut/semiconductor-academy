- **대상**: `render-gate-self-test` (C-2 해소 — `verify:render`에 자체검사가 0건이었다)

- **방법**: gap-detector 1회(범위 4항목) + 주장별 직접 재현

## 0. Do가 "7/7 충족"이라고 적었다. 대조군이 무엇을 고정하는지는 몰랐다.

Do는 게이트 7개를 다 채우고 되돌림 6종을 확인했다. 그런데 gap-detector가 물은 것은 다른 질문이었다.

> **자체검사가 통과하면서 본 검사가 깨진 상태를 만들 수 있나?**

**8가지 있었다.** 그중 둘을 직접 재현했고 둘 다 실재했다.

### A-3 — 대조군 ④가 4.5라는 선에 대해 아무것도 말하지 않았다

```js
const faint = tok('slate-100');
... fill="${faint}"/>          // 배경
... fill="${faint}">묻힌다     // 글자  ← 같은 토큰
```

같은 색이면 대비 비율이 **정확히 1.00**이다. `r < minContrast`는 `minContrast > 1.0`이면 무조건 참이다.

```text
MIN_CONTRAST 4.5 → 1.05  →  자체검사 11/11 통과
```

실제 사건의 **1.44**는 이제 안 잡힌다. **문턱을 한쪽 끝에서만 보면 문턱이 고정되지 않는다.**

### A-1 — 처분이 아니라 감지만 증명했다

`figures === 0` 가드를 **통째로 지워도** 11/11이 통과했다. 대조군 ⑨는 `measureInPage`의 **카운터**만 보고, 그 뒤 본 검사 루프가 `exit 2`를 내는지는 `--self-test` 경로가 **한 줄도 실행하지 않는다.**

> **지난 사이클 C-20과 정확히 같은 모양이다.** 정적 관문이 종료 코드 대조군 8건을 만들며 배운 구분(*"처분은 감지와 다른 주장이다"*, usage §2.1.1f)이 렌더 쪽에는 없었다.

### 1.1 FR-7 — ①이 "안 깨졌다"고 나온 이유는 판정이 아니라 되돌림이었다

`out.figures += 1;`(137행) 뒤에 `out.small.push({ …, cap })`을 넣었는데 **`cap`은 138행에서 선언된다.**
TDZ로 `page.evaluate`가 통째로 터져 `❌ 실패` 줄이 **하나도** 안 나왔다. 앵커를 `cap` 뒤로 옮기니 ①만 깨졌다.

> *"되돌렸는데 아무것도 안 깨졌다"* 는 **두 가지**를 뜻한다 — 대조군이 공허하거나, **되돌림이 틀렸거나.**
> 구분하는 법: 대조군이 공허하면 **그 하나만** 조용하고, 되돌림이 틀리면 **전부** 조용해진다.

## 3. 구현 중 두 번 걸렸다 — 둘 다 이미 겪은 함정

⑫를 만들며:

1. **`spawnSync`가 부모의 이벤트 루프를 막아** 스텁 서버가 응답을 못 했다. 자식은 *"연결할 수 없다"* 로 죽었다 — 종료 코드는 2로 맞았지만 **이유가 달랐다.** 비동기 `spawn`으로 바꿨다.
2. **자식이 자체검사를 또 돌려 무한 재귀**(10분 타임아웃). **두 사이클 전 `--assert-only`와 같은 함정**이다. `DGM_RENDER_CHILD` 가드로 끊었다.

> **재귀 회피는 매번 새로 설계해야 한다.** 앞선 사이클이 *"재귀 회피는 인자에 붙는 성질이지 코드베이스에 붙는 성질이 아니다"* 를 적어 놨는데, 새 대조군이 새 인자(이번엔 인자 없이)를 쓰자 그대로 되살아났다.

## 5. 교훈

1. **문턱은 한쪽 끝에서만 보면 고정되지 않는다.** 대조군 ④는 "잡는다"를 증명했지만 "**4.5에서** 잡는다"는 증명하지 않았다 — 같은 색을 써서 비율이 1.00이었기 때문이다.
2. **"처분은 감지와 다른 주장이다"가 여기서도 그대로다.** 정적 관문이 두 사이클 전에 배운 것을 렌더 쪽에서 다시 배웠다. 규약을 적어 놓아도 **새 검사기에는 자동으로 옮겨지지 않는다.**
3. **재귀 회피는 매번 새로 설계해야 한다.** 세 번째다.
4. **fixture는 실제 형상을 흉내 내야 한다.** 11건 전부가 `frameBg.a > 0` 갈래를 지났고, 값이 우연히 같아 결과가 안 갈렸을 뿐이다.
5. **"게이트 7/7 충족"과 "대조군이 무엇을 고정하는지 안다"는 다른 문장이다.** Do는 앞의 것을, Check는 뒤의 것을 물었다.
