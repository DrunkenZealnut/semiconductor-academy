## 1. 문제

`diagram-label-legibility` Check가 C-2로 남긴 것:

> 106건 거짓 경보를 낸 실제 결함을 고쳤는데 `verify:render`에는 자체검사 하네스가 없다. 이 저장소의 규약은 "검사기를 고치면 대조군을 남긴다"인데 이번만 예외다. **되돌아가도 아무도 모른다.**

그 결함은 배경 후보에 `defs`·`mask` 안의 도형이 섞여 마스크 구멍(`fill="black"`)이 **가장 작은 포함 사각형**으로 뽑히던 것이다. 한 줄(`.filter((r) => !r.closest(NOT_PAINTED))`)을 지우면 그대로 돌아온다.

### 1.1 착수 전 실측 — 비대칭이 심하다

| | `verify:diagram` | `verify:render` |
|---|:--:|:--:|
| 자체검사 대조군 | **69건** | **0건** |
| 자체검사 실패 시 | 본 검사 미실행 · `exit 2` | (없음) |
| 판정 종류 | C-1~C-20 | **6종** — 가로 넘침 · 글자 축소 · 대비 · 글리프 구멍 · 마커 미해결 · 마커 중복 |
| 줄 수 | 약 2,100 | 323 |

**판정 6종 중 어느 것도 "이 검사가 실제로 잡는가"를 증명한 적이 없다.**

### 1.2 서버도 자격증명도 필요 없다 (실측)

`verify:render`가 상시 관문이 아닌 이유는 *"서버와 자격 증명이 필요하고 92페이지 × 2뷰포트가 약 3분"* 이다(스크립트 머리말). **자체검사에는 그중 어느 것도 필요 없다.**

`measureInPage`는 `.toString()`으로 직렬화돼 `page.evaluate`에 들어간다 — **아무 페이지 내용에나 먹일 수 있다.** `page.setContent()`로 만든 도해면 충분하다.

시제품 실측:

```text
✅ 대비 미달을 잡는가 (흰 바탕에 흰 글자)
✅ 글자 축소를 잡는가 (실효 5px)
✅ 마커 미해결을 잡는가
✅ 음성 — 정상 도해에 거짓 경보를 내지 않는가
✅ 글리프 구멍 — 마스크 없음
✅ 글리프 구멍 — 구멍이 안 덮음

6/6 · 판정 36ms · 브라우저 기동 237ms
```

**약 0.3초다.** `verify:render` 본체(106초)와 견줄 비용이 아니다.

## 2. 결정

### D-1 · 하네스는 **`page.setContent()`** 로 만든다

서버를 띄우면 자체검사가 앱 상태에 묶인다 — 콘텐츠가 바뀌면 대조군이 흔들린다. `setContent`는 **입력이 대조군 안에 있다.**

### D-2 · 자체검사는 **별도 인자**로도 돌 수 있어야 한다

`verify:render --self-test`가 **Chrome만으로** 돌면, 서버·자격증명 없는 자리(다른 사람의 기계, 빠른 확인)에서도 검사기의 건강을 볼 수 있다.

### D-3 · 본 검사 앞에서 **먼저** 돌고, 실패하면 본 검사를 안 돌린다

`verify:diagram`이 이미 그 모양이다(`❌ 자기 검사 실패 — 스크립트가 오류를 놓친다. 본 검사를 실행하지 않는다.` · `exit 2`). 같은 계약을 준다 — **검사기가 눈먼 채로 "전 항목 통과"를 내지 않게.**

## 3. 열린 문제 (Design에서 정한다)

| # | 문제 |
|:--:|---|
| **A** | **대비 판정은 실제 색을 읽는다.** 시제품은 `#fefefe` 같은 리터럴을 썼는데, 본 검사는 Tailwind oklch를 canvas로 읽는다. 대조군이 리터럴만 쓰면 **그 경로를 증명하지 못한다.** 토큰 색을 어떻게 대조군에 넣을 것인가 |
| **B** | **`figures === 0` → `exit 2`** 는 선행 사이클이 넣은 중요한 가드다(아무 도해도 못 봤는데 통과하는 경로가 있었다). 자체검사에서 이것을 어떻게 겨눌 것인가 — `setContent`로는 항상 도해가 있다 |
| **C** | **판정 6종 전부에 양성·음성을 둘 것인가**, 아니면 이번엔 일부만인가. 전부면 12건 + 회귀 대조군 |
| **D** | **106건을 낸 그 결함**을 직접 겨누는 대조군의 형태 — `NOT_PAINTED` 필터를 지우면 깨지는 것을 어떻게 고정하나 |
