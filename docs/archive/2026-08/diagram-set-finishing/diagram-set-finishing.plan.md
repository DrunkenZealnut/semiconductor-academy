## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 직전 사이클이 도해 12종을 만들고 97모듈에 적용했으나 **미완 6건**을 남겼다. 그중 둘은 단순 부채가 아니라 **확대 전에 반드시 정해야 하는 계약**이다 — 글자 크기 단위와 `altTable` 방침을 나중에 바꾸면 도해가 붙은 모든 모듈을 다시 손봐야 한다. 도해 미적용 자료원이 **13개·213모듈 + 책 17장** 남아 있어, 지금 정하지 않으면 같은 부채가 자료원마다 복제된다. |
| **Solution** | 6건을 성격별로 갈라 처리한다 — **계약 확정 2건**(글자 크기·`altTable`)은 방침을 정해 Design에 명문화하고, **구현 2건**(`LayerStack` band 모드·`<desc>`)은 채우고, **정리 2건**(`Timeline.span`·tokens 우회)은 덜어 낸다. 실측 결과 `Timeline.span`은 사용처가 0이라 **구현이 아니라 삭제**가 맞고, band 모드는 007·008이 에너지 축을 재료 단면 톤으로 그리고 있어 **부정확 교정**이 걸려 있다. |
| **Function UX Effect** | 본문 글자 크기를 키우면 **도해 라벨도 함께 커진다**(현재는 도해만 그대로여서 비율이 어긋난다). 에너지 밴드 도해가 재료 단면과 **구분되어 보인다**. 스크린리더가 `<title>`에 더해 `<desc>`로 도해 내용을 읽는다. 독자가 체감하는 변화는 작지만, 어긋나 있던 것들이 맞춰진다. |
| **Core Value** | 12종은 **13개 자료원 213모듈로 확대될 공용 자산**이다. 이 사이클은 그 확대에 앞서 **계약을 고정**하는 일 — 지금 6건을 닫는 비용은 하루지만, 확대 후에 닫으면 모듈 수만큼 곱해진다. |

## 1. 배경

`diagram-component-set`(2026-08-10) 완주 시 Match Rate 93.6%로 게이트를 통과했으나 잔존 Gap을 백로그로 넘겼다. 그중 **G-1·G-3 육안 확인**은 로그인 게이트 뒤라 사람만 가능해 이번 범위에서 제외하고, **나머지 6건**을 닫는다.

### 1.1 왜 확대보다 먼저인가

도해 미적용 자료원은 **13개 213모듈 + 책 17장**이다.

| 자료원 | 모듈 | 도해 |
|---|:--:|:--:|
| first-semiconductor | 97 | **97** |
| ncs-semi | 84 | 0 |
| hs-* 계열 **8종** | **96** | 0 |
| cert-equip-maintenance | 13 | 0 |
| daegu-hs-process · osha-scs | 20 | 0 |
| **미적용 소계** | **213** | |

검산: 84 + 96 + 13 + 20 = **213** (책 17장은 별도). 확대 후 도해 보유 모듈은 97 + 213 = **310**이 된다.

6건 중 **글자 크기 단위**와 **`altTable` 방침**은 도해가 붙은 모든 모듈에 영향을 준다. 확대 후에 바꾸면 손봐야 할 모듈이 97에서 310으로 늘어난다.

## 3. 확정이 필요한 계약 2건

Design에서 확정하되, Plan 단계에서 선택지와 무게를 기록해 둔다.

### 3.1 글자 크기 (F-3)

| 안 | 내용 | 대가 |
|---|---|---|
| **A. `em` 전환** | SVG `<text>`를 상대 단위로 바꿔 `FontSizeToggle`에 연동 | viewBox 좌표계 안에서 `em`은 CSS px로 해석돼 **도해 폭과 글자가 따로 논다**. 라벨이 도형을 넘칠 수 있어 12종을 전부 재검증해야 한다 |
| **B. 절대값 확정** | 현행 유지 + Design §3.2를 "도해는 이미지 성격이라 본문 토글과 독립" 으로 정정 | 접근성 관점에서 글자 확대가 필요한 사용자에게 도해만 작게 남는다 |
| **C. 절충** | 절대값 유지 + 도해 컨테이너에 브라우저 확대(ctrl+±) 대응만 보장 | 토글 연동은 포기하되 확대 수단은 남는다 |

선행 사이클이 B를 **묵시적으로** 택했으나 기록하지 않은 것이 Gap의 실체다. 어느 쪽이든 **결정을 문서에 남기는 것**이 이 항목의 핵심이다.

### 3.2 `altTable` (F-4)

| 안 | 내용 | 대가 |
|---|---|---|
| **A. 표 병치를 대안 이행으로 명문화** | 현행 유지. FR-8을 "표 병치 또는 `altTable` 중 하나"로 재정의하고 §5.1 자수 예외의 근거 문장도 "표 병치"로 정정 | 도해와 표가 나란히 보여 지면이 길어진다 |
| **B. `altTable` 전량 채우기** | 131개 도해에 `altTable` 추가하고 본문 표 제거 | 작업량 큼. 표를 지우면 자수가 줄어 하한 근접 6모듈이 §5.1 보정에 걸린다 |
