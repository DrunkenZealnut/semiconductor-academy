## 0. 요약

```text
┌──────────────────────────────────────────────────────────────┐
│  1차 측정  Match Rate 84.0%  (45 검증항목 중 37.80)           │
│  Check 중 즉시 수정 7건 반영 → 97.3%  (48 항목 중 46.70)      │
│  Gap: High 1 → 0 · Medium 4 → 0 · Low 6 → 2                  │
└──────────────────────────────────────────────────────────────┘
```

이 사이클은 **미완 6건을 닫는 마감 작업**이었는데, Check가 **마감 자체의 미완 7건**을 다시 찾아냈다. 전부 즉시 수정 가능한 범위여서 Act 없이 Check 안에서 닫았다.

가장 뼈아픈 것은 **G-7 실패**다. Do 단계에서 내가 돌린 자체 검증 스크립트가 "불일치 0"을 냈으나, `gap-detector`가 실제로는 **7행이 어긋나 있음**을 밝혔다 — 내 스크립트가 optional prop만 얕게 훑고 제외 목록이 과도했다. **자기 검증이 통과했다고 해서 통과한 것이 아니다**는 것이 이 사이클의 교훈이다(선행 사이클도 자기 검증이 4번 틀렸다).

## 5. 교훈

**자기 검증 스크립트를 믿지 말 것.** Do 단계에서 내가 돌린 G-7 대조 스크립트는 "불일치 0"을 냈지만 실제로는 7행이 어긋나 있었다 — optional prop만 정규식으로 훑고 제외 목록(`at`·`to`·`label`…)이 과도해 대부분을 건너뛰었다. 선행 사이클 `first-semiconductor-primer`도 자기 검증이 4번 틀렸고, 그때 남긴 백로그가 **"Gap 판정 스크립트에 양성 대조군"**이었다. 이번에 그 백로그가 왜 필요한지 다시 증명됐다.

→ **후속 백로그에 유지**하고, 다음에 판정 스크립트를 쓸 때는 **의도적으로 틀린 입력을 함께 넣어 스크립트 자체를 먼저 검증**한다.
