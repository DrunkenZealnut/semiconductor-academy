## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem (문제)** | 반도체고 학생의 실질 목표인 **반도체설비보전기능사** 자격 취득을 돕는 자료가 사이트에 없다. 원문 수험서(에듀크라운, OCR 17,860줄·518쪽)가 `data/`에 추출돼 있으나 미반영. 기존 12개 자료원(책·OSHA·NCS·교과서 9권)에 시험 준비 관점의 진입점이 없다. |
| **Solution (해법)** | 수험서를 **독립 자료원**(신규 kind `exam-prep`, accent `standard`=직무 관점)으로 등록. 이론편 Part 01~10을 13개 모듈로 재구성(문제편은 재작성 제외)하고, 각 모듈에 ① 3단 레이어 ② **출제기준 연결 "시험 포인트"** ③ 기존 11개 자료원으로의 **인라인 커멘트(SourceRef/ChapterRef) 최대 연결** ④ cross-link 태깅을 넣는다. |
| **Function·UX Effect** | 홈 "직무" 관점 클러스터에 수험서 카드가 생기고, `/sources/cert-equip-maintenance/`에서 시험 과목 순서 그대로 학습한다. 각 모듈이 "이 개념은 어느 교과서 몇 단원, 어느 챕터에서 더 쉽게/깊게 배우는지"를 커멘트로 안내 — 수험서가 **전체 사이트의 허브 색인** 역할을 한다. |
| **Core Value (핵심 가치)** | 학교 교과(원리) → 유해인자(위험) → OSHA(안전) → NCS(직무)로 흩어진 학습을 **자격증 취득이라는 단일 목표**로 꿰는 동선 완성. |

## 1. 원문 인벤토리

- 경로: `data/반도체설비보전기능사/iPhone_15_-_반도체설비보전기능사/` (gitignore, 메인 체크아웃에만 실존, 파일명 한글 NFD — glob/find로 접근)
- 「반도체설비보전기능사 필기시험문제」 김종주 공저, 에듀크라운(국가자격시험문제 전문출판). 표지 "새 출제기준에 따른 최신판", 수록 출제기준 적용기간 **2024.1.1~2028.12.31**. 발행연도 OCR 미확인 → `year` 생략.
- 구성: **출제기준(필기)** → **제1편 이론편 Part 01~10**(Part 10 안전관리는 제1~4장: 산업안전/전기설비/화공설비/환경) → **Part별 출제예상문제**(책 402~502쪽) → **기출 2014·2015** → **실전모의고사**. 총 518 스캔 페이지, 이미지 571장.
- OCR 품질: 헤더 오식 다수("Part 19 국유의 일반"=Part 09 공유압 등). 본문은 대체로 양호. 이미지 전면 미사용(저작권 원칙).

## 2. 목표 / 비목표

### 목표
- 이론편 전체(Part 01~10, 13모듈)를 3단 레이어로 전면 재작성해 자료원 등록.
- **커멘트 최대화**(사용자 핵심 요청): 모듈당 인라인 SourceRef/ChapterRef 4개 이상 + "더 알아보기" Callout — 관련 개념을 다른 자료원에서 쉽게/깊게 이어 배우도록 안내.
- **시험 포인트**: 모듈당 2~4개, 출제기준 주요항목(공개 자료)과 예상문제 빈출 개념을 **자기 문장으로** 연결(지문·선지 재현 금지).
- cross-link 태깅으로 자동 상호 연결(역방향: 기존 모듈들의 관련자료 박스에도 수험서 노출).

### 비목표
- 예상문제·기출문제·실전모의고사의 문제은행화(저작권 + daegu 선례상 제외 — 빈출 **개념 파악용**으로만 참조).
- 출제기준 개편 추적, 실기시험 대비 콘텐츠, 원문 이미지 대체 일러스트 대량 제작.
- 기존 코어 페이지 수정(자동 편입 외 0건).
