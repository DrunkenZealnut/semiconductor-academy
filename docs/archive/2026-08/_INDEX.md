- **`--wave w4` 단독 호출이 `_coverage: 'selective'`를 놓친다** — C-1 74건을 낸다(`--all`은 정상). HEAD에서도 동일한 기존 문제. 웨이브 단독 실행과 `--all`이 다른 판정을 내는 것 자체가 결함이다.
- **`verify:render`에 다크 모드 (선행 R-2 유지)** — `colorScheme: 'light'` 고정.
