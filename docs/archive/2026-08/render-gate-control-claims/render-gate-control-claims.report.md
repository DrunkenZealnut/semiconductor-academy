## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 판정을 순수 함수로 뽑아 대조군을 싸게 얻었는데 **그 함수를 부르는 자리**는 아무도 안 봤다. 착수 전 실측: 호출부 인자 **11자리 중 5자리를 망가뜨려도 자체검사가 종료 0**. 사용자가 지목한 B-1은 그중 하나였고, `scopeStatic` 전체(브라우저 앞 판정 γ·ε·α₀·σ)가 사실상 무대조군이었다. |
| **Solution** | 자식 대조군을 **저장소에서 떼어 낸다.** 임시 cwd에 심링크 대신 **가짜 도해 트리**(컴포넌트 + 배럴 + MDX)를 심으면 γ·ε·α₀·σ·β를 **직접 유발**할 수 있어 배선 5자리가 한 기계로 덮이고, 자식이 저장소와 무관해져 **B-5도 사라진다.** 그리고 그것을 재는 `npm run audit:wiring`을 만들었다. |
| **Function · UX Effect** | **독자에게 보이는 변화는 없다.** 검사기가 자기 배선을 증명하는 사이클이다. |
| **Core Value** | *"대조군이 있다"* 와 *"그 판정이 본 검사에서 살아 있다"* 는 다른 주장이다. **배선 감사 6/11 → 11/11** — 그리고 그 분수 자체가 참인지를 다시 검사한다. |

## 1. 무엇을 만들었나

### 1.1 가짜 도해 트리 (자식의 격리)

```text
임시 cwd/
  node_modules -> 심링크        ← 유일하게 빌린다 (검사 대상이 아니라 실행 수단)
  src/data/chapters.json        ← 직접 쓴다
  src/components/diagram/       ← 직접 만든다 (Alpha.tsx · Extra.tsx · index.ts)
  src/content/…                 ← 직접 만든다
```

자식이 트리를 **소유**하므로 상태를 마음대로 만든다 — 배럴에만 있는 `Ghost`(γ) · 파일만 있는 `Extra`(ε) · 아무도 안 쓰는 `Lonely`(α₀) · URL 규칙 밖 `topics/`(σ) · 없는 종을 그리는 스텁(β).

**⑳ 하나만 실제 트리를 쓴다** — 전부 가짜면 *"유도 규칙이 실제에서 도는가"* 를 아무도 안 보게 되고, **그것이 이 사이클이 고치는 병과 같은 모양**이기 때문이다(Design D-4). *다만 그 전제는 Check에서 거짓으로 판명됐다 — §5 B-8.*

### 1.2 배선 감사 (`npm run audit:wiring`)

호출부 인자를 **하나씩** 훼손하고 자체검사가 잡는지 센다. 관문이 아니라 **관문을 재는 자**다(약 2.5분).

```text
⏭ 감사 밖: return scopeStatic({ — 자체검사가 저장소 상태를 재는 자리다 …
   호출부 인자 11개 · CASES 11개 — 대조 일치
✅ 잡힘   scopeStatic  svg  α₀  종료 2 · ㉔
…
덮인 배선 **11/11**
```

세 겹으로 자신을 지킨다 — 호출부에서 **인자를 유도해 대조**(분모) · **주장 대조군**`wantBroken`이 실제로 깨지는지(분자) · `Ctrl-C`·`SIGTERM`에도 **원복**.

### 1.3 대조군 (29 → 33)

| 무리 | 수단 | 수 |
|---|---|---:|
| 판정 | `page.setContent()` | 14 |
| 범위 | **순수 함수**(브라우저·서버 없음) | 10 |
| 처분 | **자식 프로세스 + 임시 cwd** | 9 |

신설 넷: **㉔**(정적 4종을 한 자식에 겹쳐) · **㉕**(β · 선행 B-1) · **㉖**(음성 — 과잉 발화를 잡는다) · **㉗**(판정 순서).

## 8. 교훈

1. **재는 자도 재어야 한다.** *"재는 자를 먼저 만들지 않으면 무엇이 늘었는지 말할 수 없다"* 를 옳게 적고 그대로 했는데, **그 자의 눈금이 하나 빠져 있었다**(11/12).
2. **분모와 분자를 모두 붙잡아야 지표다.** `covered/CASES.length`에서 분모가 손목록이면 100%는 *"내가 세기로 한 것을 다 셌다"* 는 뜻이고(C-1), 분자가 종료 코드면 **부수 피해로 초록**이 된다(C-3).
3. **덮을 것이 없는 자리와 안 덮인 자리는 다르다.** 11/11을 만들려고 억지 대조군을 붙이는 것이 아니라 **훼손을 관측 가능한 형태로 바꾸는 것**이 맞다.
4. **미러는 자리를 옮겨 다시 나타난다.** 목록 → 문자열 → 정규식 → 경로 → **훼손 목록**. 다섯 번째다.
5. **"적어도 이것"과 "정확히 이것"은 다르다.** 판정 fixture는 `offTarget`, 순수 함수는 개수로 이미 양쪽을 보고 있었는데 **처분 무리만 빠져 있었다.**
6. **면책은 증거로 한다.** *"이 대조군의 잘못이 아니다"* 를 출력 문구로 판단했더니 거짓 면책이 떴다.
7. **소스를 고치는 도구는 `Ctrl-C`를 견뎌야 한다.** `finally`는 SIGINT에서 안 돈다.
8. **수치는 실행 단위로 적는다.** 같은 코드가 아니면 같은 수치가 나올 수 없다 — 뭉개면 어느 쪽이 참인지 알 수 없어진다.
