## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem (문제)** | `data/처음배우는반도체/`에 일본 입문서 번역본 원문(4,379줄 / 9장 **88항목** + COLUMN 9)이 추출됐으나 미반영이다. 이 책의 절반인 **3~5장(로직·메모리·IC 설계, 30항목)과 9장(최첨단기술, 11항목)은 사이트 12개 자료원 어디에도 없는 공백 영역**이다. 반면 원서는 견개(2쪽)당 1항목·그림 위주 구성이라 **실질 텍스트가 항목당 22줄**뿐이고 내용의 절반을 담은 이미지 336개는 저작권상 쓸 수 없다 — 원문을 그대로 옮기는 방식으로는 페이지가 성립하지 않는다. |
| **Solution (해법)** | 원서 견개 구조를 **1항목 = 1페이지(88모듈) + COLUMN 9모듈 = 총 97모듈**로 1:1 재현하되, 얇은 원문을 3단 레이어(Hook→Easy→Deep)로 **확장 재서술**한다. 그림이 담던 정보는 캡션·라벨 OCR을 근거로 텍스트·자체 다이어그램으로 되살리고, Deep 레이어의 밀도 부족은 **이전 자료(책 17장·NCS·교과서 9권)로 잇는 cross-link**가 메운다 — "얇은 입문서가 두꺼운 자료들의 색인 역할을 한다"는 것이 이 자료원의 포지션이다. 미보유 영역을 잇기 위해 통제 어휘에 설계·회로 축 topic 5종을 신설한다. |
| **Function·UX Effect (기능·UX 효과)** | 홈에 13번째 독립 자료원 카드 추가. `/sources/first-semiconductor/`에서 9트랙(기초→소자→로직→메모리→설계→웨이퍼→전공정→후공정→최첨단) 97페이지를 원서 목차 순서 그대로 탐색하고, 각 페이지는 이전/다음 내비 + cross-link로 책·NCS·교과서의 심화 서술로 이어진다. 학습자는 **"한 항목 2분 읽기 → 궁금하면 심화 자료로 점프"** 동선을 얻는다. |
| **Core Value (핵심 가치)** | 사이트가 유해인자·공정 축으로만 두꺼웠던 상태에서 **소자→회로→메모리→설계라는 반도체 이해의 나머지 절반**이 채워진다. 동시에 97개 얇은 진입점이 기존 12자료원 전체에 크로스링크를 뿌려, PRODUCT-DIRECTION의 북극성인 **크로스링크 그래프의 노드 밀도**가 사이클 한 번으로 최대폭 증가한다. |

### 1.3 이 자료 특유의 이슈

**① 원문 밀도가 사이트 최저 — 재구성이 아니라 "확장 서술"이 필요**

기존 교과서 권 모듈은 원문 84~1,182줄을 **압축·재구성**했다. 이 책은 항목당 22줄로, 기존 최소 모듈의 **1/4**이다. 원서가 "왼쪽 쪽 해설 + 오른쪽 쪽 그림"이라는 견개 편집이라 정보의 절반 이상이 그림에 있고, 그 336개는 저작권상 전면 미사용이다.

→ 대응 3종(§4.2): ⓐ 그림 캡션·라벨 OCR을 근거로 한 **텍스트 재서술**(캡션·축 라벨·구성요소명은 md에 남아 있음), ⓑ 필요 시 **자체 다이어그램**(기존 `ProcessDiagram` 패턴), ⓒ Deep 레이어를 **cross-link 심화 동선**으로 대체 — 원문이 얇으면 두꺼운 자료로 보낸다.

**② 사이트 자산과의 관계가 장마다 정반대**

3~5·9장(41항목)은 **공백 채우기**, 1~2·6~8장(47항목)은 **대량 중복**이다. 중복 영역은 daegu 선례(§4.3)대로 "각도 차별화 + cross-link 상호 연결"로 처리하되, 이 책의 각도는 **"반도체 전체 지도에서 이 공정이 어디쯤인지"** 라는 조감(鳥瞰) 시점이다 — 교과서는 실습·장비, 책은 유해인자, 이 책은 전체 흐름.

**③ 제품 정체성과의 거리 (정직한 기록)**

`PRODUCT-DIRECTION.md`의 북극성은 "KO 학술서 ↔ EN OSHA 규제자료를 유해인자로 잇는 다리"다. 이 책의 3~5장(30항목)은 유해인자와 **무관한** 회로·설계 영역이고, 통제 어휘 확장(§3.3)은 쐐기를 넓히는 방향이다. 다만 ⓐ 사이트는 이미 NCS 설계 트랙(84모듈)을 품어 어휘 축을 넓힌 선례가 있고, ⓑ 6~8장 47항목은 유해인자 자료와 정면 교차하며, ⓒ 97개 진입점이 기존 자료 전체의 크로스링크 밀도를 올린다 — **다리를 넓히는 것이지 흐리는 것은 아니라는 판단**으로 진행한다. 이 판단은 Report에서 실측(신설 topic의 실제 연결 건수)으로 재평가한다.

## 3. IA 설계

### 3.1 자료원 배치 — ✅ 독립 자료원 확정 (2026-08-08, 사용자 선택)

```ts
// src/lib/sources.ts — order 13, category 미지정
{
  id: 'first-semiconductor',           // URL: /sources/first-semiconductor/
  kind: 'book',                        // 단행본 입문서 (교과서 아님)
  order: 13,
  accent: 'book',                      // ✅ Design §2.1 확정 — EPI 책과 같은 원리 설명형 단행본
  license: 'fair-use',
  // category 없음 — 책·OSHA·NCS와 같은 독립 카드
}
```

- 기각: `hs-textbook` 편입(고교 인정교과서가 아니라 분류 부정확), 신규 `primer` 카테고리(권 1개로는 그룹 섹션이 성립하지 않음 — 유사 입문서가 2권 이상 쌓이면 그때 신설).
- `kind`는 `'book'` 제안 — 단행본이라는 점에서 EPI 책과 동류. `SourceKind` 확장 불필요.

### 3.2 모듈 체계 — ✅ 항목 단위 88모듈 확정 (2026-08-08, 사용자 선택)

- **트랙(`group`) = 원서 9개 장**, **모듈 = 항목 1개**, 순서 = 원서 목차 순서 = 이전/다음 내비 순서.
- COLUMN 9개는 해당 장 트랙의 **마지막 모듈**로 배치(장별 마무리 읽을거리) → 총 **97모듈**.
- 슬러그: `{3자리 번호}-{의미 슬러그}` (예: `001-what-is-semiconductor`, `043-dram`). COLUMN은 `col-{장번호}-{슬러그}` (예: `col-1-oxide-organic`).
  - 번호 접두 이유: 97개 규모에서 목차 순서·원문 매핑 추적이 슬러그만으로는 불가능. NCS(84모듈)에서 순서 추적이 어려웠던 선례 반영.
- 기각: 장 단위 9모듈(3장 18항목이 초장문), 항목 그룹 20모듈(원서 견개 구조 훼손).

## 4. 콘텐츠 전략

### 4.1 3단 레이어 표준 (이 자료원용 변형)

| 레이어 | 기존 자료원 | **이 자료원** |
|---|---|---|
| **Hook** | 한 줄 흥미 유발 | 동일 — "이 항목이 왜 필요한가" 1~2문장 |
| **Easy** | 비유·일러스트 | **주력** — 원문 22줄을 비유·맥락으로 확장, 그림이 담던 구조를 말로 풀어냄 |
| **Deep** | 원본 학술 표현 | **정의·수치·용어 보존** + **심화 자료 동선**(책 ch·NCS 모듈로 SourceRef) — 원문이 얇으므로 "더 깊이 볼 곳"을 명시 |

- 페이지당 목표 분량: **본문 1,200~2,000자** (원문 22줄 → 확장). 기존 교과서 모듈(3,000~6,000자)보다 의도적으로 짧게 — 견개 1항목의 "2분 읽기" 성격 유지.

  > ✏️ **2026-08-09 Check 이후 현행화**: 완성본 97모듈 전수 실측 결과 **미달 0 / 상한 초과 항목 15·COLUMN 4**로, 상한을 **항목 1,200~2,300 · COLUMN 600~1,600**으로 갱신했다(코드는 무수정 승인). 또한 Easy를 "주력"으로 본 위 표의 전제가 실제와 달랐다 — 실물은 `LayeredExplain`이 도입부, 그 아래 `##` 본문 섹션이 주력이다. 후속 자료원이 참조할 기준은 이 표가 아니라 Design §5.1(현행화판)이다. 상세: `first-semiconductor-primer.design.md` §0 V-6 · §5.1. FR-3의 "1,200~2,000자"도 같은 정정 대상.
- 전 페이지 하단 출처 표기: `참고: 「처음 배우는 반도체」 ({역자·출판사 — §9-5 확정 후 기입})`.

### 4.2 얇은 원문 대응 3종

- **ⓐ 그림 → 텍스트 재서술**: OCR에 캡션(`그림 1 …`)·축 라벨·구성요소명이 남아 있다. 이를 근거로 구조·동작을 서술한다. 원문 이미지 자체는 미사용.
- **ⓑ 자체 다이어그램**: 텍스트만으로 성립하지 않는 항목(논리 게이트 진리표, 메모리셀 구조, CZ 성장법 등)에 한해 기존 컴포넌트로 제작. **전량 제작 아님** — 파일럿에서 필요 최소 기준을 정한다.
- **ⓒ cross-link 심화 동선**: Deep 레이어 말미에 "더 깊이" 블록으로 책·NCS·교과서 대응 섹션 링크. 이 자료원의 정체성이자 밀도 부족의 구조적 해법.

### 4.3 중복 영역(1~2·6~8장, 47항목) 차별화

| 자료원 | 각도 |
|---|---|
| 책(EPI) | 이 공정에서 **무엇이 몸에 해로운가** |
| 교과서 9권 | 이 장비를 **어떻게 다루는가**(실습·운용) |
| NCS | 이 직무에서 **무엇을 해내야 하는가** |
| **이 책** | 전체 흐름에서 **이 단계가 어디쯤이고 왜 필요한가** (조감) |

원문 문장·구조 재사용 금지, 개념·수치·절차만 근거로 재작성(daegu 원칙 승계).

### 4.4 저작권

- 일본 원서의 한국어 번역본 — **이용허락 미확인**. daegu 최보수 원칙 일괄 적용: 전면 재작성 + 원문 이미지 0 + 원저자 표기.
- **운영 형태 (2026-08-09 확정)**: 이 사이트는 middleware 로그인 게이트 뒤에서만 열람되는 **비공개 개인 학습용**이다. 공개 배포가 없으므로 판권 확인을 게이트로 두지 않는다. `license: 'fair-use'`는 개인 학습 목적 인용으로 유지하며, 미확인 정보(역자·출판사·발행연도)는 표기하지 않는다.
- **잔여 조건**: 로그인 게이트를 해제해 공개 전환하면 판권 확인이 다시 공개 전 게이트가 된다.
