## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 입문서 자료원 97모듈에 **시각 요소가 0개**다. 원문 도판 336개를 저작권상 전면 미사용하기로 했고, 그 공백을 표(95/97 모듈·909행)로만 메웠다. pn접합·MOS 동작·적층 단면·공정 흐름처럼 **그림이 있어야 성립하는 개념**이 전부 글로만 남아 있어, "알기 쉽게 풀어쓴" 이라는 이 자료원의 존재 이유가 가장 약해지는 지점이다. |
| **Solution** | 원문 도판을 베끼지 않고 **자체 제작 도해 컴포넌트 8종**(LayerStack·FlowSteps·CompareCards·TruthTable·ValueBars·ScaleRuler·CircuitSchematic·LabeledFigure)을 만들어, MDX는 **데이터만 넘기고** 그림은 컴포넌트가 그린다. 전원 **서버 컴포넌트 정적 SVG**라 JS 번들이 늘지 않고, 색·다크모드·접근성이 한 곳에서 통제된다. 파일럿 게이트로 시각 언어를 먼저 고정한 뒤 97모듈로 확대한다. |
| **Function UX Effect** | 독자는 `##` 본문 섹션을 읽기 전에 **구조를 한 장으로 먼저 본다**. 소자 단면은 층으로, 공정은 화살표 흐름으로, 대조 개념은 나란히, 논리 게이트는 입력→출력 색으로 구분되어 보인다. 97모듈 어디를 열어도 **같은 시각 언어**가 반복되므로, 트랙을 옮겨도 그림 읽는 법을 다시 배울 필요가 없다. |
| **Core Value** | 컴포넌트는 이 자료원 전용이 아니라 **사이트 공용 자산**이다. 지금까지 13개 자료원 425개 이미지가 전부 원문 스캔이었고 자체 제작 도해는 하나도 없었다 — 이 사이클은 그 **첫 번째 시각 어휘를 세우는 일**이며, 이후 교과서·NCS·OSHA 자료원도 같은 8종을 그대로 쓴다. |

## 4. 기술 방침

- **서버 컴포넌트**: `'use client'` 없음. SVG를 서버에서 렌더 → JS 번들 무증가, 인쇄·SEO 모두 안전.
  > ✏️ **2026-08-09 사실 정정**: 초판은 "정적 export"를 근거로 들었으나 `next.config.mjs`에 **`output: 'export'`가 없다** — 이 저장소는 Vercel 배포로 옮겼고 루트 `CLAUDE.md`의 GitHub Pages·정적 export 기술이 현행과 다르다(design-validator L-9). 서버 컴포넌트 SVG는 어느 쪽이든 안전하므로 **설계 결론은 그대로**이고 근거 문장만 정정한다.
- **다크모드**: SVG 요소에 Tailwind 유틸(`fill-slate-200 dark:fill-slate-700`) 적용. 색 토큰은 `tokens.ts` 한 곳.
- **접근성**: `role="img"` + `<title>`/`<desc>`, 그리고 도해 아래 **`<details>` 표 대체 텍스트**. 도해 안 글자는 SVG `<text>`로 넣어 선택·검색 가능하게.
- **반응형**: `viewBox` + `width:100%`. 모바일 세로에서 깨지지 않도록 `FlowSteps`는 `orientation` 전환.
- **MDX 배치 주의**: 도해는 블록 요소다. MDX에서 문단과 **빈 줄로 분리**하지 않으면 `<p>` 안에 블록이 들어가 hydration 오류가 난다 (이 저장소에서 이미 겪은 함정).
- **분량**: 도해 마크업은 Design §5.1 측정 기준(공백·마크업 제외)에서 제외되므로 기존 자수 기준은 그대로 유효하다. 다만 **RT(읽기 시간) 표기**는 Design에서 재검토.

## 5. 구현 범위 / 단계

### 5.1 Step 0 — 배치 전수 매핑 (Design 첫 관문, 선행 필수)

97모듈 × 8종의 **배치표**를 만든다: 모듈별로 ⓐ 어떤 컴포넌트를 ⓑ 어떤 데이터로 ⓒ 왜 넣는지. 여기서 8종으로 커버 안 되는 모듈이 드러나면 `LabeledFigure` 대상 또는 컴포넌트 스펙 조정으로 처리한다. **커버율 100%를 Design 완료 조건으로 삼는다.**

### 5.2 Step 1 — 1차 4종 + 파일럿 게이트

`tokens.ts` + `LayerStack`·`FlowSteps`·`CompareCards`·`TruthTable` 제작 후 대표 4모듈에 적용:

| `029-or-gate` | `TruthTable` — 기존 표를 도해로 **대체**하는 첫 사례 |
