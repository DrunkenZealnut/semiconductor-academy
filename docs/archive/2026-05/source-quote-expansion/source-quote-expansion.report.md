### 1.3 Value Delivered (4-Perspective)

| 관점 | 결과 |
|------|------|
| **Problem (문제)** | 학술 원본 보기를 열어도 "원본 자료에서 해당 페이지를 참고하세요." 한 줄만 나오는 챕터가 17/17이었고, SourceQuote도 챕터당 1~3개로 부족했음. 추가로 기존 SourceQuote 중 26개가 책 원문이 아닌 의역이었던 사실이 분석 과정에서 발견됨. |
| **Solution (해결)** | (1) `LayeredExplain` fallback 제거 — quote 없으면 Disclosure 자체를 미렌더, (2) 17개 챕터 LayeredExplain의 `deep.quote` 전부 채움 (100~180자 책 원문), (3) SourceQuote 74개 추가/보강, (4) 의역 26개 → 책 원문으로 교체, (5) 책의 열거 구조(첫째~넷째, 4원칙, 7단계 등) 46개 완결성있게 표시. |
| **Function UX Effect (기능 효과)** | (1) 17챕터 모든 "학술 원본 보기" 클릭 시 실제 책 원문 표시 (placeholder 박스 사라짐), (2) 쉬운 설명(amber 박스) ↔ 책 원문(disclosure blockquote)을 같은 카드에서 비교 학습 가능, (3) 본문 중간 SourceQuote가 정의·표·결론을 원문으로 확인 가능, (4) Disclosure 기본 닫힘 — 처음엔 쉬운 설명, 원할 때 펼쳐 깊이 학습, (5) 출처 표기 (`— 「반도체 산업의 유해인자」 p.X`) 표준화. |
| **Core Value (핵심 가치)** | **"쉽게 풀어쓴 설명 + 책 원문 병독"** — 사이트의 핵심 가치 회복. 학술서를 통째 읽기 어려운 사용자가 친절한 해설을 따라가다 원하는 지점에서 원문을 클릭 한 번으로 정확히 확인 가능. **"공부하는 사람을 위한 진짜 학습 도구"** 정체성 확립. Plan 목표를 충실히 달성했을 뿐만 아니라, 의역 26개 교체와 완결성 46개 보강이라는 **Plan에 명시되지 않은 추가 가치까지 실현**. |

## 5. 주요 학습 사항 (Lessons Learned)

### 5.1 잘 된 점

| 항목 | 내용 |

| 단계적 진행 | Ch.1 먼저 완료 → 사용자 확인 → 16개 순차 진행 (안전한 학습 곡선) |

| 열거 구조 완결 | 단순 인용을 넘어 책의 "첫째~넷째", "4원칙", "8단계" 구조까지 완결 |
| 사용자 피드백 반영 | Ch.1 "4가지 특성 첫째만 인용" 지적 → 즉시 완결성 보강 |

### 5.2 발견 및 개선

| 항목 | 내용 |
|------|------|
| 의역 SourceQuote 발견 | Plan 단계에서 알 수 없었던 **기존 26개가 의역**임을 작업 중 발견 → 모두 책 원문으로 교체 |
| MDX `~` 파싱 이슈 | 한 줄 내 `~` 두 번 연속 시 strikethrough로 인식 → `∼`(U+223C)로 변환하여 10건 해결 |
| LayeredExplain 카운트 누락 | Plan은 SourceQuote만 카운트했지만 **LayeredExplain quote도 원문 인용** → AC-3 평가 시 합산해야 정확 |

### 5.3 향후 활용 가능한 패턴

| 패턴 | 설명 |
|------|------|
| 책 원문 발췌 워크플로우 | `data/*/*.md` OCR 텍스트 → grep → 직접 인용 (의역 회피) |
| 열거 구조 완결성 | 책의 "첫째~넷째", "N가지 원칙", "N단계 흐름"은 SourceQuote 1개에 묶어 완결 |
| MDX 안전 문자 | 숫자 범위 표현 시 `~` 대신 `∼` 또는 `-` 사용 |
