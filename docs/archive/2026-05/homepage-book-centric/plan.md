| **Function UX Effect (기능 효과)** | (1) 첫 방문자가 "아, 이 사이트는 책 한 권을 쉽게 풀어둔 곳이구나" 즉시 인식 (2) 17 챕터 진입 동선이 메인 hero 직후로 단축 — 책 정독 사용자 동선 강화 (3) 빠른 참조(공정/유해물질) 사용자는 특별 섹션을 통해 한 번에 진입 — 두 사용자 페르소나(정독러 vs 참조러) 동시 충족 (4) 책 정체성을 명시함으로써 SourceQuote·페이지 인용·이미지 fair use의 학술적 맥락이 자연스러워짐 (5) 공정·유해물질 섹션의 시각적 분리는 책의 학술 구조(공정 vs 화학물질 vs 직업병)를 사이트에서도 그대로 재현. |
| **Core Value (핵심 가치)** | **책 정체성의 완성** — 17 챕터 풀 깊이 완료(매치율 평균 96%) 직후, 메인 페이지가 그 정체성을 명시함으로써 사이트 전체가 "원서를 쉽게 풀어둔 단일 자료"라는 일관된 메시지를 제공. 알 권리의 민주화라는 프로젝트 핵심 미션이 첫 화면에서부터 명확해진다. |

## 2. 배경 및 동기

### 2.1 현재 메인 페이지 분석

`src/app/page.tsx` 현재 구조:

| 순서 | 섹션 | 비중 | 책 정체성 |
|------|------|------|----------|
| 1 | Hero ("어려운 반도체 이야기, 쉽게 풀어드려요") | 큼 | 약함 — 일반적 톤 |
| 2 | 반도체 제조 9단계 (ProcessDiagram) | 큼 | 없음 — 책과 분리된 인터랙티브 |
| 3 | ChaptersHero (책 차례 1줄 배너) | 작음 | 있음 — 그러나 배너 1줄 |
| 4 | 3 Pillars (학습 가이드/유해물질/직업병) | 중간 | 약함 — 책 외부 페이지 강조 |
| 5 | CTA "처음부터 시작하기" → /what-is-semiconductor/ | 작음 | 없음 |

**문제점**:
1. Hero가 "반도체 아카데미"로 일반화되어 "유해인자 책 사이트" 정체성 부재
2. 책 차례(17 챕터)가 4번째 자리, 그것도 1줄 배너로 축소 노출
3. ProcessDiagram이 2번째 핵심 자리 차지 — 인터랙티브하지만 책과 직접 연결되지 않음
4. 유해물질·직업병이 3 pillar 중 하나로 묻혀 "특별함" 없음
5. 책 원서명·저자·페이지 수 등 책 정체성 정보 전무

### 2.2 사용자 요청의 핵심

> "이 사이트는 반도체유해인자 책을 쉽게 풀어서 볼 수 있게 하는 것이므로 메인의 구성도 이게 걸맞게 바뀌어야 합니다. 반도체공정이나 유해물질 정보등은 특별한 섹션으로 구성해주세요"

**해석**:
- **(A) 메인 = 책 중심** — 책을 풀어서 보여주는 정체성을 메인 구성이 반영해야 함
- **(B) 공정 = 특별 섹션** — 일반 카드가 아니라 "특별한" 섹션으로 분리
- **(C) 유해물질 정보 = 특별 섹션** — 마찬가지로 별도 특별 섹션

### 2.3 왜 지금인가

- 17 챕터 풀 깊이 완성 (`ch3-to-ch17-batch` 96% 완료, 2026-05-29 archived)
- 책 정체성을 받칠 콘텐츠 인프라(SourceQuote, 페이지 이미지, Callout, 자체 표)가 모두 갖춰짐
- 메인이 정체성을 명시하지 않으면 첫 방문자는 사이트의 학술적 토대를 인식하지 못함

## 3. 목표 (Goals) & 비목표 (Non-Goals)

### 3.1 목표

- [G1] Hero에 책 정체성 명시 — 원서 제목, 저자(7인), "쉽게 풀어드립니다" 메시지
- [G2] 17 챕터 책 차례를 Hero 바로 다음 핵심 섹션으로 승격 — 4 카테고리 카드 미리보기
- [G3] **공정 특별 섹션** — 시각적으로 구별되는 박스/배경 + ProcessDiagram + Ch.3~13 진입
- [G4] **유해물질·직업병 특별 섹션** — 시각적으로 구별되는 박스/배경 + 화학물질 사전 진입 + Ch.14~16 진입
- [G5] 부수 페이지(/start, /about)는 메인에서 작은 링크로 축소 (or 푸터 영역으로 이동)
- [G6] Lighthouse ≥ 90, 모바일 반응형 유지
- [G7] 책 정체성을 받치는 메타데이터 텍스트(원서명, 저자, 페이지 수, ISBN 등) 노출

### 3.2 비목표 (이번 사이클 제외)

- 챕터 본문 수정 (이미 17 챕터 완성)
- ProcessDiagram 컴포넌트 자체 수정 (메인에서의 배치만 변경)
- 화학물질 사전 컴포넌트(`ChemicalSearch`, `ChemicalCard`) 수정
- 새로운 라우트 생성 (메인 페이지만 재구성)
- 다국어 지원, 다크모드 신규 컬러 시스템

## 4. 사용자 시나리오

### 4.1 페르소나 A — 정독러 (책을 처음부터 끝까지 읽고 싶은 사람)

1. 메인 접속 → Hero에서 "이건 책 한 권을 풀어둔 사이트구나" 인지
2. 직후 17 챕터 책 차례 노출 — 4 카테고리(도입/공정/유해/성찰) 한눈에 확인
3. "도입(foundation)" 카테고리 → Ch.1부터 정독 시작
4. 정독 동선: 메인 → 책 차례 → Ch.1 → Ch.2 → ... → Ch.17

### 4.2 페르소나 B — 빠른 참조러 (특정 정보만 찾고 싶은 사람)

1. 메인 접속 → "공정 정보가 필요한데" → **공정 특별 섹션** 으로 직행
2. ProcessDiagram 클릭 → 해당 공정 페이지 또는 챕터로 이동
3. 또는 **유해물질 특별 섹션** → 화학물질 사전 → 검색
4. 참조 동선: 메인 → 특별 섹션 → 원하는 페이지

### 4.3 페르소나 C — 호기심 방문자 (반도체 산업에 관심만 있는 사람)

1. Hero의 "쉽게 풀어드립니다" 메시지에 끌림
2. 책 차례 카테고리 카드 중 흥미로운 것 클릭 (예: "성찰" → Ch.17)
3. 마음에 들면 정독러로 전환, 아니면 특별 섹션 둘러봄

### 5.2 시각 차별화 전략 — "특별 섹션"이 특별해 보이게

| 일반 섹션 | 특별 섹션 |
|----------|----------|
| 배경 흰색, 테두리 없음 | 배경 톤다운 컬러 (slate-50, amber-50 등) + rounded-3xl 큰 박스 |
| 일반 폰트 크기 | 상단 칩 라벨 (`✨ 특별 섹션`) + 큰 제목 |
| 단순 그리드 | 좌우 분할 or 강조 카드 + 내부 내부 패딩 충분 |
| 단일 CTA | 메인 CTA + 보조 링크(카테고리 챕터 보기) |

## 6. 기술 접근

### 6.1 수정 파일

| 파일 | 변경 |
|------|------|
| `src/app/page.tsx` | **전면 재구성** — 신규 IA 적용 |
| `src/components/chapter/ChaptersHero.tsx` | 폐기 or 보조 컴포넌트로 활용 (deprecate or repurpose) |
| `src/components/layout/BookHero.tsx` (신규) | 책 정체성 hero |
| `src/components/layout/BookTOCPreview.tsx` (신규) | 4 카테고리 카드 그리드 |
| `src/components/layout/SpecialSection.tsx` (신규) | 특별 섹션 래퍼 (공통) |

### 6.2 신규 컴포넌트 설계

#### `BookHero`
- props: 없음 (서버 컴포넌트, 정적 메타데이터 직접 포함)
- 구성: 원서명 큰 글씨 + 저자 7인 한 줄 + 슬로건 + 2개 CTA + 보조 메타(챕터 수·시간)
- 디자인 톤: 깨끗한 흰 배경 + 책 아이콘(BookOpen) + brand 색 강조

#### `BookTOCPreview`
- props: 없음 (서버 컴포넌트, `getChaptersByCategory()` 직접 호출)
- 구성: 4 카테고리 카드 그리드 (md:grid-cols-2 lg:grid-cols-4)
- 각 카드: 이모지 + 카테고리명 + 챕터 수 + 1줄 설명 + "보기" 화살표
- 클릭 시: `/chapters/#{category}` or `/chapters/?cat={category}` (현 페이지가 카테고리 앵커/필터 지원 여부 확인 필요)

#### `SpecialSection`
- props: `{ icon, label, title, description, children, tone: 'process' | 'hazard' }`
- 구성: `✨ 특별 섹션` 칩 + 아이콘 + 제목 + 설명 + children + 보조 링크 슬롯
- tone에 따라 배경/테두리 색상 변경 (process: slate/blue, hazard: amber/red)
- 충분한 패딩 (sm:p-10) + rounded-3xl

### 6.3 라우팅·필터 검토 사항

- `BookTOCPreview` 카테고리 카드가 `/chapters/?cat=foundation` 같은 필터 URL로 갈지, `/chapters/#foundation` 앵커로 갈지 확인 필요 → 현재 `/chapters/` 페이지는 카테고리별 섹션이 있으므로 **앵커 방식** 채택 (예: `<section id="process">`).

### 6.4 기존 동선 보존
