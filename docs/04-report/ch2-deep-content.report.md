2. **신규 컴포넌트 0개** — `ImageFigure`, `Lightbox`, `FontSizeToggle`, `SourceQuote`, `Callout`, `LayeredExplain`, `Term`, `ChapterRef` 모두 그대로 재사용.
3. **1장과의 사상적 연결** — 무어/황의 법칙 Callout이 "**1장에서 본 '짧은 역사, 빠른 변화'의 위험과 직결된다**"고 명시. 책 전체의 narrative thread가 사이트에 살아남.
4. **반도체 역사 연표** — 11 사건(1947~2020s)을 책에 없는 자체 제작 표로 정리. 책+사이트 양쪽의 학습 가치 모두 누림.
5. **저작권 정책 일관 적용** — SourceQuote 3개 각 80/75/110자, 책 표는 출처 명시, 책 이미지는 maxWidth 600px + credits.json. About 페이지 정책과 일치.
6. **유기/무기 비교 표 추가** — Design 외 보너스. §2가 가독성 향상.

## 7. 학습 사항 (Lessons Learned)

1. **패턴 확립의 가치** — Ch.1의 ImageFigure + 표 + SourceQuote 구조가 명확히 정의돼 Ch.2 작업이 "콘텐츠만 추가"로 단순화. 첫 구축 시간(Ch.1 ~3h) > 확산 시간(Ch.2 ~1.5h).
2. **Design 문서를 구현 후 sync** — Ch.2에서 자체 표 4개로 늘어났지만 Design은 3개로 명시됨. Design을 살아있는 문서로 보고 구현 후 +1 sync가 자연스러움.
3. **이미지 캡션 안전망** — "일반적 묘사" 형태 캡션이 OCR 추정의 불확실성을 가려줌. 책의 정확한 그림 번호 매칭이 안 돼도 사용자 경험에 큰 차이 없음.
4. **챕터 간 사상적 연결** — Callout 안에서 "1장에서 본 ... 위험과 직결돼요" 같은 cross-reference가 사이트의 narrative cohesion을 만듦.
5. **자체 제작 표 = 저작권 자유** — 도체/부도체 비교, 도펀트 표, 역사 연표 — 모두 자체 제작이라 저작권 무관, 학습 가치 큼. 패턴화 가능.
