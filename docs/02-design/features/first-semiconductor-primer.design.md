## 1. Step 0 산출물 — 97항목 전수 매핑 (Plan §5.1 완료)

### 1.1 매핑 방법과 신뢰도

원문의 페이지 마커(`<!-- page: N -->`, 214개)와 원서 쪽수 사이에 **오프셋 −4가 전 구간 일정**함을 6개 지점(002·024·031·034·043·086)에서 검증했다 → `원서 쪽 = 마커 + 4`. 목차 파싱(83/88 성공)의 손상 구간은 본문 마커·헤딩 대조로 복원했다.

- **97개 전수 확정**(88항목 + COLUMN 9), 누락·중복 0.
- 제목 OCR 소실 **2건**: `057`(목차·본문 모두 소실 — 내용 기준 제목 부여), `062`(본문 소실 → 목차에서 복원).
- 원문 라인 분포: 평균 41.8줄 / 최소 22줄(col-2) / 최대 79줄(031). **빈 줄·이미지 참조 포함 수치**이며, 실질 텍스트는 항목당 약 22줄(Plan §1.1).

### 2.1 `kind`·`accent` 결정 — ✏️ Do 단계 정정 반영 (§0 V-4·V-5)

| 필드 | 최초 판단 | **확정값** | 이유 |

- `kind`와 `accent`는 별개 축이다 — 유형은 입문서(`primer`), 관점은 원리(`school`).

### 5.1 3단 레이어 구성 (항목 모듈)

<LayeredExplain
