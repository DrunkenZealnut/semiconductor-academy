## 2. 배경 및 동기

### 2.1 원본 자료

- **자료**: 「반도체 산업의 유해인자 (Hazards in Semiconductor Industry)」, 윤충식·김승원·박동욱·정지연·최상준·하권철·함승헌
- **위치**: `data/20260526_185841_반도체산업의유해인자_에피스테메_-_13/`
- **분량**: markdown 690줄 + 페이지 이미지 40여 장
- **수준**: 산업보건학 전공 서적 (산업의학·환경공학·화학 배경 필요)

### 2.2 원본의 한계

1. **어휘 장벽**: "에틸렌글리콜류 생식독성", "극저주파 자기장 노출수준", "포토레지스트 PR 박리" 등 전공 용어 다수
2. **공정 이해 전제**: 8대 공정(클리닝→확산→포토리소그래피→식각→증착→이온주입→CMP→칩조립)의 흐름을 모르면 유해인자 설명을 이해 불가
3. **시각적 보조 부족**: 책의 그림은 흑백 도식 위주, 인터랙티브하지 않음
4. **검색·참조 어려움**: 인쇄 매체라 "벤젠이 어느 공정에 나오지?" 같은 빠른 참조 불가

### 2.3 왜 지금인가

- 반도체 산업은 18~24개월마다 새 물질·새 공정이 도입(황의 법칙) → 정보 격차가 빠르게 벌어짐
- 국내외 반도체 직업병 이슈 지속(생식 질환, 백혈병, 림프종 등) → 일반인 이해도 제고 필요
- 사전주의 원칙(precautionary principle)을 실천하려면 시민·노동자의 위험 이해가 선행되어야 함

### 5.1 3단 레이어 구조

각 챕터는 다음 3개 레이어로 재구성:

```
┌─ Layer 1: 한 줄 요약 (Hook) ─────────────┐
│  "반도체는 전기가 반만 흐르는 물질이에요"   │
├─ Layer 2: 비유 + 일러스트 (Easy) ──────────┤
│  수도꼭지 비유 + 인터랙티브 그림             │
├─ Layer 3: 원본 인용 (Deep) ────────────────┤
│  접기/펼치기로 학술 원문 그대로 제공         │
└──────────────────────────────────────────┘
```

## 6. 핵심 기능 (선택 확정 사항)

### 6.1 공정 인터랙티브 다이어그램 (P0)

- **위치**: 홈 + `/process-overview`
- **동작**: 8단계 공정 박스를 호버 → 핵심 유해인자 툴팁, 클릭 → 상세 페이지 이동
- **기술**: React 컴포넌트 + SVG, 모바일 터치 지원
- **데이터 소스**: 원본 3장 + 각 공정 챕터에서 추출

### 6.2 유해물질 사전/검색 (P0)

- **위치**: `/chemicals`
- **데이터 구조**:
  ```ts
  type Chemical = {
    id: string;           // "benzene"
    nameKo: string;       // "벤젠"
    nameEn: string;       // "Benzene"
    formula: string;      // "C6H6"
    casNo: string;        // "71-43-2"
    category: 'solvent' | 'gas' | 'metal' | 'photoresist' | ...;
    usedIn: ProcessId[];  // ['cleaning', 'photolithography']
    hazards: string[];    // ['발암성 1군', '생식독성', ...]
    easyExplain: string;  // 비유 기반 쉬운 설명
    sourceRef: string;    // 원본 페이지 인용
  };
  ```
- **검색**: 이름(한/영), 분류, 공정으로 필터링 (클라이언트 사이드)

### 6.3 쉬운 설명 + 비유/일러스트 (P0)

- 모든 학술 용어에 인라인 툴팁 (마우스 호버/모바일 탭) 제공
- 각 챕터마다 도입부에 핵심 비유 1개 + 일러스트 1장
- 원본 인용은 별도 토글로 분리 — 학습자가 자기 페이스로 진입
