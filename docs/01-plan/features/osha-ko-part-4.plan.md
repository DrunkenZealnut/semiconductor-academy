## Executive Summary

|------|------|
| **Problem (문제)** | OSHA SCS Part 4 "Hazardous Gas Systems and Controls"는 극저온 실린더·압축가스 물리적 위험·NFPA 등급·12단계 유해 가스 통제 시스템·비상 정지(EMO) 절차를 다루는 SCS 커리큘럼의 **마지막 강의**이나 영문 transcript뿐이었다. |

| **Core Value (핵심 가치)** | **OSHA SCS 5 Part(1A/1B/2/3/4) 한글화 완주** — 반도체 화학물질 안전 교육 전 과정을 모국어로 제공. |

## 1. 배경 / 현재 상태

| 항목 | 현황 |
|------|------|
| 토글 메커니즘 | ✅ 완성 — 변경 불필요 |
| `koLoaders` 현황 | part-1a/1b/2/3 등록 (part-4만 미등록 → 영문 단독, 이번 사이클로 완주) |
| 번역 대상 | `part-4.mdx` — 영문 182줄, 헤딩 23개, 표 4개, 목록 항목 51개 |
| Part 4 구조 | 개요/학습목표(6개) → 불활성 가스 → 극저온 실린더(듀어) → 압축가스 실린더 위험 → 가스 범주화(7종, Part 1∼3과 재사용) → 일반 통제 수단(NFPA·MAQ) → 12단계 통제 시스템 → 비상 절차(EMO) → 요약("SCS 커리큘럼 전체를 마치면…") |
| 안전 수치 | 산소 결핍 4단계(23.5∼19.5%/19.5∼10%/10∼6%/6% 미만), 액체질소 팽창계수 700배, 듀어 용량 160∼230리터, 최대 방출량 161,000리터(230×700 정합 확인), 실린더 압력 2,000 PSI, 핀홀 누출 임계 100 PSI, NFPA 0∼4등급 |
| 화학물질 3종 | 압축질소(N₂), 아르곤(Ar), 육불화황(SF₆) — 전부 chemicals.json/기존 번역과 무관한 신규지만 표준 명칭 |
| 용어 재사용 | "불활성 가스"(Part 1B 기 확립), 7개 가스 범주 명칭(Part 3과 완전 동일 재사용: 인화성·자연발화성·산화성·부식성·독성 수소화물·고에너지 물질), "NFPA(미국방화협회)"(Part 1B 기 확립) |

**확정 결정** (기존 사이클 계승): Claude 초벌 작성 후 사람 검수.

## 2. 목표 / 비목표

### 목표
- `part-4.ko.mdx`를 영문과 헤딩·목록·표 1:1 구조로 작성.
- `koLoaders`에 `'part-4'` 등록 → 토글 자동 노출 → **OSHA 5 Part 전체 한글화 완주**.
- 안전 수치(농도·배율·용량·압력·등급) 직역 정확성 확보. 특히 극저온 팽창(160∼230리터 → 최대 161,000리터)의 내적 정합성(230×700=161,000) 유지.
- 가스 범주 7종 명칭을 Part 3과 완전히 동일하게 재사용.
- 코어(컴포넌트/page) 무수정.

### 비목표
- 다른 자료원 확장 (OSHA SCS는 5 Part로 완결).
- 토글 컴포넌트·로더 시그니처·page 로직 변경.
- `quotes.json` 한글 인덱싱 (영문 기준 유지).
