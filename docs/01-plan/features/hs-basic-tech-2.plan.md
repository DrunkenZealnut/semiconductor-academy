| **Problem (문제)** | 「반도체기초기술2」(크리아트출판사, 정예원 외 4인, 충청북도교육감 인정교과서, 6,243줄 OCR) 원문이 `data/school-text/`에 있으나 사이트에 미반영이다. hs-basic-tech-1(이하 book1)과 달리 원문 페이지 순환 배치는 없으나(재검증 완료, §1.3), 5대단원 15중단원 중 **Ⅳ장(반도체장비 공유압기술)이 전체의 38%(2,370줄)를 차지**하고 그중 다수가 목표·재료·안전·방법·정리·평가로 구조가 반복되는 실습 워크시트라 그대로 재현하면 정보 밀도가 과잉된다. 또한 Ⅲ장에 AutoCAD 명령어 튜토리얼(사이트에 없던 소프트웨어 매뉴얼형 콘텐츠)이 처음 등장한다. |
| **Solution (해법)** | `hs-basic-tech-1`이 확장한 카테고리 인프라(스키마·공용 라우트·통합 로더)를 그대로 재사용해 신규 자료원 `hs-basic-tech-2`를 등록한다. 목차 재검증 결과 순환 배치가 없어 목차 순서 = 파일 순서 = 재구성 순서로 바로 진행할 수 있다(book1식 역산 불필요). 5대단원 15중단원 전량을 daegu 원칙(재작성·이미지 0·출처 표기)으로 재구성하되, **반복 실습은 "대표 예시 상세 + 변형 표"로 압축**하고 **안전 유의사항은 예외적으로 매 실습 보존**하며, **CAD 파트는 명령어 나열이 아닌 개념·워크플로우 중심**으로 재구성한다. |
| **Function·UX Effect (기능·UX 효과)** | "반도체 고등학교 교과서" 그룹에 4번째 권 카드(order 7) 추가. `/sources/hs-basic-tech-2/`에서 5대단원 트랙(전기·전자 기초→기계 가공 기술→반도체장비 설계→반도체장비 공유압기술→프로그래밍)으로 탐색한다. 대부분 모듈이 book1의 대응 모듈과 "기초→응용" 관계로 `SourceRef` 연결되고(교류/디지털회로↔전자소자/직류회로, CAD↔제도규격, 마이크로프로세서/아두이노↔C언어), NCS 반도체장비 트랙 — 특히 유지보수 3종·시스템소프트웨어·보드설계 — 와 신규로 교차한다. |
| **Core Value (핵심 가치)** | book1이 "장비를 설계·조립·구동하려면 무엇을 알아야 하는가"의 **기초**를 놓았다면, 이 권은 그 기초를 **응용 회로·CAD 실무·임베디드 프로그래밍·실습 기반 유지보수**로 완성한다 — 반도체 장비 기술자 양성 교육의 "이론에서 실무로" 전환점. 실습 중심 콘텐츠라 "안전 및 유의 사항"이 원문에 반복적으로 등장하는데, 이는 사이트 정체성(유해인자 교육)과 가장 밀접한 실습 안전 콘텐츠가 처음으로 대량 편입됨을 뜻한다. |

### 1.3 원문 순환 배치 재검증 — 이번 권은 이슈 없음

book1은 표지·목차·챕터Ⅰ 도입부가 파일 끝(4501~4666행)에, 챕터Ⅰ 중후반부가 파일 시작(1~655행)에 오는 순환 배치가 있었다. **이번 권은 그런 문제가 없다**: OCR 물리 페이지 마커(`<!-- page: N -->`)가 1→232로 단조 증가할 뿐 아니라, 콘텐츠 흐름 자체도 목차(3쪽)→Ⅰ~Ⅴ 본문(정순)→참고문헌(231쪽)→집필/검토/심의위원·판권(232쪽)으로 자연스럽다. 대단원 러닝 헤더 등장 순서(전기·전자 기초 → 기계 가공 기술 → Ⅲ 설계 → Ⅳ 공유압기술 → Ⅴ 프로그래밍)가 목차 순서와 정확히 일치함을 확인했다. → **목차 순서 = 파일 라인 순서 = 재구성 순서**, book1식 라인 단위 역산이 불필요하다.

- **book1 SourceRef 연결망**(§1.4 매핑 적용): Ⅰ(교류·디지털회로)→`electronic-devices`/`dc-circuits`, Ⅲ(CAD 등)→`drafting-standards`/`drawing-methods`/`sectional-views`, Ⅴ(마이크로프로세서·아두이노)→`c-basics`/`c-programming`. Deep 레이어에서 연결하되 본문 서술은 "응용·심화" 각도로 book1과 명확히 차별화(중복 재작성 금지, R-5).
- **CAD 파트 재구성 원칙**: 원문의 "NEW/OPEN/SAVE" 등 AutoCAD 메뉴·아이콘·명령어 단계별 나열을 그대로 옮기지 않는다. 대신 "왜 이 순서로 도면을 그리는가", "손 제도와 CAD가 다른 점", "좌표계·도면층(레이어) 개념" 등 특정 소프트웨어 UI에 종속되지 않는 이식 가능한 개념 중심으로 재구성.
- **반복 실습 압축 전략**(Ⅳ장 "3. 공압 실습 과제"·"5. 유압 실습 과제" 중심): 원문은 유사한 회로 실습(목표→재료→안전→방법→정리→평가 구조)이 실습별로 7~8건 반복된다. 실습 전건을 1:1로 재현하지 않고, **대표 실습 1~2건은 상세 재구성**(목표→회로 원리→절차→평가 기준) + **나머지는 "실습 변형 비교표"**(제어 대상·회로 차이·핵심 포인트)로 압축한다.
- **안전 유의사항 예외 보존**(신규 원칙): 위 압축 대상에서 "다. 안전 및 유의 사항"만은 제외한다 — 압축하지 않고 실습마다 Callout(주의)으로 유지·강조. 사이트 정체성(반도체 산업 유해인자 교육)과 가장 직접 맞닿는 대목이기 때문.
- **단위 표기**: book1과 동일 원칙(원문 단위 kgf/cm² 등 유지 + 괄호로 SI 환산값 병기) — Ⅳ장 공압·유압 전 모듈에 동일 적용.

## 9. 결정 사항 — 제안(book1 원칙 승계 중심, 이견 있으면 Design 착수 전 조정)

book1과 카테고리·저자·발행처·정책이 완전히 동일한 자매편이라, 대부분은 book1에서 이미 사용자 확정된 원칙을 그대로 승계하는 것으로 제안한다. 신규 판단이 필요한 항목만 별도 표시.

1. **범위**: 5대단원 15중단원 **전량 편입** — book1 "로드맵 일관성 우선" 원칙 승계, 축소 없음 (Ⅱ장처럼 반도체 정체성이 낮은 대단원도 포함).
2. **파일럿 모듈**: 목차 순서대로 "**1. 교류 회로**" — 순환 배치가 없어 즉시 착수 가능(book1의 "1.전자 소자" 자연스러운 후속점).
3. **CAD 파트 재구성 밀도** *(신규 판단)*: 명령어 단계별 재현이 아닌 **개념·워크플로우 중심 압축**(§4, §8 R-2 근거).
4. **반복 실습 압축 전략** *(신규 판단)*: **대표 실습 상세 + 변형 표** 방식, **안전 유의사항은 예외적으로 전건 보존**(§4, §8 R-1 근거).
5. **단위계 표기**: book1과 동일 — 원문 단위(kgf/cm² 등) 유지 + SI 병기.

> 1·2·5는 book1 선례를 그대로 승계, 3·4는 이 권에서 새로 판단한 원칙. 이견이 없으면 이 제안대로 Design에 반영한다.
