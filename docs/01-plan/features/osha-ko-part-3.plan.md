## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem (문제)** | OSHA SCS Part 3 "Extremely Hazardous Chemicals"는 반도체 공정의 극도로 위험한 화학물질 9개 범주(독성 수소화물·부식성/산화성/자연발화성 가스·실란·인화성 가스·고에너지 물질·부식성 액체·유해 부산물)와 비상 대응을 다루는 핵심 강의이나 영문 transcript뿐이었다. |
| **Solution (해법)** | 검증된 토글 메커니즘과 Part 2 번역 템플릿을 그대로 재사용해 `part-3.ko.mdx`를 추가하고 `koLoaders`에 1줄 등록한다. |
| **Function·UX Effect (기능·UX 효과)** | `/sources/osha-scs/part-3`에서 `[한국어] [EN]` 토글 자동 노출. 9개 화학물질 범주·실란 폭발 기전·비상 대응 절차가 한글로 1:1 렌더. |
| **Core Value (핵심 가치)** | 극도로 위험한 화학물질 취급·비상 대응 지식을 모국어로 전달. OSHA 5 Part 중 4개(1A/1B/2/3) 한글화. |

## 1. 배경 / 현재 상태

| 항목 | 현황 |
|------|------|
| 토글 메커니즘 | ✅ 완성 — 변경 불필요 |
| `koLoaders` 현황 | part-1a/1b/2 등록 (part-3/4 미등록 → 영문 단독) |
| 번역 대상 | `part-3.mdx` — 영문 234줄, 헤딩 35개(H2 11 + H3 24), 표 2개, 목록 항목 79개 |
| Part 3 구조 | 개요/학습목표 → 9개 범주 개요표 → 범주 1∼9(각 화학물질 목록+핵심 위험) → 비상 대응 → 요약 |
| 안전 수치 8개 | 100°F/38°C(디보레인 자연발화 임계), 5ppm/2.5ppm(오존 IDLH·감지기 설정값), 9배(실란 폭발=TNT 9배 에너지), 25%(LEL 경보 설정), 2%(고에너지 물질 불안정 임계), 100%(공정 효율) |
| 화학물질 35종(화학식 병기) | 아르신·디보레인·저메인·셀렌화수소·황화수소·포스핀·암모니아·삼염화붕소·브롬화수소·염화수소·육불화텅스텐·염소·삼불화염소·불소·일산화질소·이산화질소·오존·실란·디실란·아세틸렌·일산화탄소·수소·메탄·프로판·디에틸아연·트리메틸알루미늄/갈륨/인듐·염산·불산·황산·질산·인산 등 |

**확정 결정** (기존 사이클 계승): 범위는 Part 3만(4는 후속), 번역은 Claude 초벌 작성 후 사람 검수.

### 목표
- `part-3.ko.mdx`를 영문과 헤딩·목록·표 1:1 구조로 작성.
- `koLoaders`에 `'part-3'` 등록 → 토글 자동 노출.

- 화학물질 한글명을 `chemicals.json`·Part 1A/1B/2 번역과 일관 유지.
- 코어(컴포넌트/page) 무수정.

- Part 4 한글 번역 (후속 사이클).

- `quotes.json` 한글 인덱싱 (영문 기준 유지, `.ko.mdx` 스캔 비대상).
