## 1. 배경 / 현재 상태

### 원문 자료 인벤토리 (`data/school-text/daegu/20260415_200404_반도체공정기초_렛유인_/`, 수정 금지 — 원본, `.gitignore`로 워크트리 비추적)

### 저작권 (매우 중요 — 이번 사이클 최대 리스크)

- NCS(`ncs-semiconductor.plan.md` §1)는 "출처 명시 시 교육목적 활용 가능"이라는 **명문 고지**가 있었지만, 이 교과서는 **그런 고지를 찾지 못했다**(판권 페이지 OCR 손상, 발행처가 사설 상업 교육기업).
- 기존 `EPI_BOOK`(윤충식 외, 에피스테메 발행 정식 학술서)도 `license: 'fair-use'`로 등록되어 있으나, 이는 **원문 발췌 인용 + 전면 재작성 + 출처 명시**를 전제로 한 것이며 대량 원문 복제가 아니다.
- 렛유인 교재는 정식 출판사 학술서보다 **저작권 리스크가 높다고 봐야 한다**: (1) 상업적 사설교육 콘텐츠, (2) 이용허락 고지 미확인, (3) 도표·그림 244개는 자체 제작 도판일 가능성이 높아 **원문 이미지 사용은 전면 배제**해야 한다(NCS와 동일 원칙, 더 보수적으로 적용).
- → **결론(제안)**: 원문을 "학습 로드맵·정확도 검증용 비공개 참고자료"로만 취급하고, 사이트에 게재되는 문장은 **전면 재작성**(원문 문장 구조·표현 재사용 금지) + 필요시 짧은 개념 정의만 최소 인용 + 출처 표기("대구반도체고 교과서 「반도체 공정기초」참고" 수준으로 표기, 원저자명 병기 여부는 §9에서 확인). 이 자세도 최종적으로는 **사용자 확인이 필요한 결정 사항**(§9-1)이다.

### 현재 아키텍처와의 관계

## 2. 목표 / 비목표

### 목표
- 대구반도체고 교과서 원문을 **정확도 검증·콘텐츠 보강의 근거 자료**로 활용해, 사이트의 공정 설명(현재 9개 Process 페이지 + 필요 시 신규 페이지)을 기술적으로 더 탄탄하게 만든다.
- 원문에는 있지만 사이트에 없는 주제(공정설비/진공/플라즈마 개론, 금속배선 상세 공정)를 새 콘텐츠로 채운다.
- 전 구간 **저작권 안전 원칙** 적용: 원문 이미지 미사용, 문장 전면 재작성, 출처 명시.
- cross-link로 책(유해인자)·NCS(직무)와 자동 연결해 "원리 → 위험 → 직무"의 학습 동선을 완성한다.
- 용어는 `terms.json`·책과 일관 유지.

### 비목표 (이번 사이클 제외)
- 원문 224p·이미지 244개의 전량 큐레이션/자체 일러스트 대량 제작 (별도 디자인 사이클).
- 원문 그대로의 "확인문제" 은행화(정답 텍스트가 원문에 없어 자체 제작 필요 — 별도 검토).
- 부록 "반도체 용어" 전체를 별도 용어사전 페이지로 이관 (기존 `terms.json` 확장 여부만 이번엔 검토).
- 대구반도체고 실제 수업 커리큘럼(진도표·평가계획) 연동.

## 3. 정보구조(IA) 설계 — ✅ A안 확정 (2026-07-14, 사용자 선택)

### 확정: **A안 — NCS 선례를 따라 신규 Source(`daegu-hs-process`) 추가**

`/sources/daegu-hs-process`로 노출, **대단원 3개를 트랙으로 그룹핑**(NCS의 4트랙 패턴과 동일한 `SourceSection.group` 재사용), 중단원 10개를 모듈로 등록한다. 라우팅·MDX 로더는 NCS 패턴(`ncsMdx.tsx` → `daeguMdx.tsx`, `[module]` 라우트 복제)을 그대로 재사용해 구현 비용이 낮다.

| 트랙 (대단원) | 모듈 (중단원) |
|---|---|
| 반도체 공정 개념 | 공정 개요 · 공정 설비와 파라미터(진공·플라즈마) |
| 반도체 공정 Ⅰ | 포토 · 식각 · 박막 · 금속 배선 |
| 반도체 공정 Ⅱ | 산화 · 도핑 · CMP · 세정 |

- 장점: "대구반도체고 교과서"가 자료원 카드로 명확히 노출 — 학생이 자기 교과서와 1:1 대응 가능(핵심 가치 직결). NCS 인프라 재사용으로 코어 무수정 확장.
- 검토했던 단점과 대응: 기존 Process 9개와 내용이 겹치는 문제 → **cross-link로 상호 연결**하고, 대구 모듈은 "교과서 단원 흐름(학습목표→개념→핵심정리)" 각도로, 기존 Process는 "공정 한눈에 보기" 각도로 차별화한다. 저작권 노출 면적 증가 → 전면 재작성 원칙(§4)으로 상쇄, 원문 문장·이미지 미사용 재확인.

### 기각된 대안 (기록용)

- **B안** — 기존 Process 페이지 Deep 레이어 보강 + 갭만 신규 페이지: 중복은 없지만 교과서의 존재감이 사라지고 attribution을 걸 표준 위치가 없음. 사용자 선택으로 기각.
- **C안** — 전부 기존 페이지에 흡수: 구현량 최소지만 공정설비·진공·플라즈마를 특정 공정에 끼워 넣기 애매. 기각.

## 4. 콘텐츠 재구성 전략

### 재구성 원칙 (원문 직역 아님 — "쉽게 다시 쓰기", `ncs-semiconductor` 선례와 동일)
- 원문 문장을 그대로 옮기지 않고, 개념·수치·절차만 근거로 삼아 **전면 재작성**.
- 3단 레이어(Hook 한 줄 → Easy 비유/일러스트 → Deep 원본 학술 표현) 패턴 유지. Deep 레이어에 원문 근거를 짧게 인용(`SourceQuote`)할 경우 출처 명시.
- 기존 Process 페이지의 기존 문단을 삭제하지 않고, **없던 세부만 추가**하는 방식으로 보강(코어 콘텐츠 무손실 원칙).

### 용어·수치 정확성
- 8대 공정(Photo/Etch/CVD/Metal/Diffusion/Implant/CMP/Clean) 분류, FEOL/MOL/BEOL 정의, CZ/FZ 웨이퍼 성장법, 클린룸 class 정의(1ft³당 0.5μm 이상 입자 수 기준) 등은 원문 표현이 정확하므로 **수치·정의는 보존**하되 문장은 새로 쓴다.
- 기존 `terms.json`과 용어 충돌 시 기존 용어 우선, 신규 용어만 추가.

### 저작권 처리 (§1 결론 반영)
- 원문 이미지(244개) 전면 미사용. 필요한 다이어그램은 자체 제작.
- 문장 전면 재작성 + 페이지 하단에 "참고: 대구반도체고 교과서 「반도체 공정기초」" 형태로 출처 표기(구체적 표기 문구·저자명 병기 여부는 §9-1 확정 후 적용).
- 확인문제는 원문 그대로 사용하지 않음(별도 자체 제작 검토 — 비목표).

## 5. 구현 범위(파일) · 단계 — A안(확정) 기준

### 단계 (파일럿 우선, ✅ 책 목차 순서대로 작업 — 2026-07-14 변경)
1. **파일럿 — "반도체 공정 개요" 모듈 1개**(교과서 1번 모듈): Source 인프라(레지스트리·라우트·로더) 신설 + 공정 개요(8대 공정·전/후공정·웨이퍼공정·클린룸) 재구성 → 저작권 표기·재구성 품질·cross-link 실증.
2. **검증 게이트** → 나머지 모듈을 **교과서 목차 순서 그대로** 확대: 공정 설비와 파라미터(진공·플라즈마) → 공정 Ⅰ(포토→식각→박막→금속배선) → 공정 Ⅱ(산화→도핑→CMP→세정). 겹치는 주제는 기존 Process·책 챕터와 cross-link 필수.

> 사이트 노출 순서도 동일하게 교과서 목차 순서를 따른다(`SOURCES` 섹션 등록 순서 = 목차 순서).
