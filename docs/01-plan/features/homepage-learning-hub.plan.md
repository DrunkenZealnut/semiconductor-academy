> **상속**: `multi-source-learning-platform`(Source 레지스트리) · `ncs-semiconductor`·`daegu-hs-textbook`(자료원 확장 완료 상태)

## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem (문제)** | 사이트 콘텐츠는 이미 **4개 자료원·116개 학습 단위**(책 17챕터 + OSHA 5파트 + NCS 84모듈 + 대구 교과서 10단원)에 공정 9페이지·화학물질 사전 30종·인용 검색까지 갖춘 멀티소스 플랫폼인데, **홈·SEO·히어로는 여전히 "책 한 권을 풀어드립니다"라는 단일 학술서 중심 아이덴티티**에 머물러 있다. 첫 화면만 보면 유해인자 책 소개 사이트로 보여, NCS(직무)·교과서(공정 원리)·OSHA(안전) 자료를 찾는 학습자가 자신에게 맞는 콘텐츠가 있는지 알기 어렵다. |
| **Solution (해법)** | 홈을 **"다양한 반도체 자료를 학습하는 허브"** 로 재구성: 히어로를 플랫폼 메시지로 교체하고, 4개 자료원 선택(SourcePicker)을 첫 시선 흐름으로 승격, 학습자 유형·주제별 탐색 동선을 추가한다. SEO 기본 문구·홈 메타도 플랫폼 아이덴티티로 갱신. 기존 콘텐츠 페이지·URL은 무수정. |
| **Function·UX Effect (기능·UX 효과)** | 첫 화면에서 "무엇을 배울 수 있는 곳인지"가 4개 자료원 카드로 즉시 드러나고, "공정 원리 → 위험 → 안전 → 직무"라는 사이트 고유의 학습 삼각형+1이 탐색 동선으로 노출된다. 책 중심 섹션(BookHero·BookTOCPreview)은 자료원의 하나로 강등·재배치. |
| **Core Value (핵심 가치)** | 사이트의 실체(멀티소스 학습 플랫폼)와 첫인상(책 소개 페이지)의 불일치를 해소 — 고등학생·교사·일반인 각자가 자기 목적(진로·수업·안전·교양)에 맞는 자료로 30초 안에 도달하는 **반도체 학습 관문**으로 전환. |

## 1. 배경 / 현재 상태

### 콘텐츠 인벤토리 (2026-07-14, PR #12 머지 기준)

| 자료원 | 규모 | 관점 |
|---|---|---|
| 책 「반도체 산업의 유해인자」 | 17챕터 | 왜 위험한가 (학술) |
| OSHA Semiconductor Chemical Safety | 5파트 (영/한 토글) | 어떻게 안전하게 (실무 수칙) |
| NCS 반도체 학습모듈 | 84모듈 · 4트랙 | 현장에서 무슨 일을 (직무·진로) |
| 대구반도체고 교과서 「반도체 공정기초」 | 10단원 · 3트랙 | 공정이 어떻게 동작 (원리) |
| 부가 기능 | 공정 다이어그램 9단계 · 화학물질 사전 30종 · 용어 15종 · 인용 검색 214건 | 횡단 도구 |

### 현재 홈 구조 (`src/app/page.tsx`, 127줄)

1. `BookHero` — "책 한 권을 풀어드립니다 / 반도체 산업의 유해인자, 쉽게 풀어드려요" + CTA "책 처음부터 읽기"·"책 차례 보기"
2. `SourcePicker` — 4개 자료원 카드 (2번째 섹션으로 밀림)
3. `BookTOCPreview` — 책 17챕터 카테고리별 미리보기
4. `SpecialSection`(공정) — ProcessDiagram 9단계
5. `SpecialSection`(유해물질·직업병) — 화학물질 사전·직업병 카드
6. `FooterLinks` — 시작 가이드·소개·반도체란 + **원서 표기**

### 아이덴티티 불일치 지점 (코드 확인)

| 위치 | 현재 문구/구성 | 문제 |
|---|---|---|
| `BookHero` | "책 한 권을 풀어드립니다", 저자 7인 나열, CTA 2개 모두 책 | 첫 화면 전체가 단일 책 소개 |
| `page.tsx` metadata | "반도체 산업의 유해인자, 쉽게 풀어드려요" | 홈 타이틀이 책 제목 |
| `seo.ts` `DEFAULT_DESCRIPTION` | "반도체 산업과 유해인자를 …" | 전 페이지 기본 설명이 유해인자 한정 |
| `Header` 네비 | 책 차례·공정·유해물질·인용·직업병·소개 — **자료원(sources) 진입점 없음** | NCS·교과서·OSHA는 홈 카드로만 도달 가능 |
| `SourcePicker` 문구 | "국내 학술서와 OSHA 교육 프로그램 등 자료원별로…" | 4개 자료원 반영 안 된 구식 문구 |
| `FooterLinks` | 원서 1종만 표기 | 4개 자료원 시대와 불일치 |

- 사이트명 "반도체 아카데미"(`seo.ts` SITE_NAME, Header 로고)는 이미 플랫폼형 네이밍 — **유지**.

## 2. 목표 / 비목표

### 목표
- 홈 첫 화면(above the fold)이 **"4개 자료원으로 반도체를 배우는 곳"** 임을 즉시 전달.
- 자료원 선택을 히어로 직후(또는 히어로 내부)로 승격, 문구를 4자료원 기준으로 갱신.
- 학습 동선 노출: 관점 축(원리→위험→안전→직무) 또는 학습자 유형(학생/교사/일반인) 기반 탐색 섹션.
- 책 전용 섹션(BookHero·BookTOCPreview)은 축소·재배치하되 **책 콘텐츠의 접근성은 유지**.
- `seo.ts` 기본 문구·홈 metadata·Header 네비(자료원 진입점)·FooterLinks를 플랫폼 아이덴티티로 갱신.
- 횡단 도구(공정 다이어그램·화학물질 사전·인용 검색)는 "도구" 성격으로 유지 노출.

### 비목표 (이번 사이클 제외)
- URL·라우팅 구조 변경 (기존 모든 경로 유지 — SEO·북마크 보존).
- 자료원 상세/콘텐츠 페이지(`/chapter/*`, `/sources/*`, `/process/*` 등) 수정.
- 사이트명·로고 교체 ("반도체 아카데미" 유지, 로고 아이콘 교체는 Design에서 검토 가능한 소품목).
- 신규 콘텐츠 집필, 검색 기능 신설, 다국어(영문) 홈.

## 3. IA 설계 — 권장안 + 대안

### 권장: **A안 — "학습 허브" 재구성 (허브 히어로 + 자료원 승격 + 관점 탐색)**

```
1. PlatformHero (신규, BookHero 대체)
   "반도체, 네 가지 관점으로 배우다" — 원리·위험·안전·직무
   CTA: [자료원 둘러보기(앵커)] [학습 시작 가이드(/start/)]
   신뢰 지표: 4개 자료원 · 116개 학습 단위 · 무료 공개

2. SourcePicker (승격·문구 갱신)
   4개 자료원 카드 + 각 카드에 관점 뱃지(원리/위험/안전/직무)

3. LearningPathSection (신규)
   "이렇게 시작해 보세요" — 목적별 추천 동선 3~4개
   (예: 진로 탐색→NCS / 수업 보조→교과서 / 안전 교육→책+OSHA)

4. SpecialSection(공정 다이어그램) — 유지 (횡단 도구)
5. SpecialSection(유해물질·직업병) — 유지 (횡단 도구)
6. BookTOCPreview — 제거 또는 축소형으로 하단 이동 (책 인덱스는 /chapters/가 담당)
7. FooterLinks — 4개 자료원 출처 표기로 갱신
+ Header 네비에 "자료원" 항목 추가, seo.ts DEFAULT_DESCRIPTION 갱신
```

- 장점: 실체와 첫인상 일치, 신규 자료원(NCS·교과서)의 발견성 극대화, 변경 범위가 홈+메타에 국한.
- 단점: BookTOCPreview 강등으로 책 중심 기존 사용자의 동선 한 단계 증가 (완화: Header "책 차례" 유지).

### 대안 B: 최소 변경 — 히어로 문구만 플랫폼화
BookHero의 카피·CTA만 바꾸고 섹션 순서 유지. 위험은 최소지만 BookTOCPreview가 자료원 카드보다 크게 남아 "책 사이트" 인상이 잔존 — 전향 취지 미달.

### 대안 C: 학습자 유형 중심 — "당신은 누구인가요?" 분기형 홈
고등학생/교사/일반인 선택 → 맞춤 추천. 몰입감은 높지만 첫 화면에서 콘텐츠 실체가 안 보이고, 정적 사이트에서 개인화 없는 분기는 클릭 부담만 추가. 권장안의 LearningPathSection으로 취지만 흡수.

**→ A안을 기본 골격으로 제안**, BookTOCPreview 처리(제거 vs 축소 하단 유지)는 §9에서 확인.

## 4. 카피/브랜딩 방향 (Plan 수준 초안 — Design에서 확정)

- 히어로 헤드라인 후보: "반도체, 네 가지 관점으로 배우다" / "반도체 학습의 모든 길이 여기에" — Design에서 2~3안 비교.
- 관점 라벨(자료원 카드 뱃지): 원리(교과서)·위험(책)·안전(OSHA)·직무(NCS) — 기존 보고서들의 "학습 삼각형+1" 서사 재사용.
- `DEFAULT_DESCRIPTION` 초안: "학술서·OSHA·NCS·고교 교과서 4개 자료원으로 배우는 반도체 — 공정 원리부터 유해인자·안전·직무까지, 중·고등학생 눈높이로."
- 어조: 기존 사이트 톤(해요체, 비유 중심) 유지.
