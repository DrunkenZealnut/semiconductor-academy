### 1.3 핵심 리스크 — 원문 페이지 순환(rotation) 배치 (신규 발견, 이번 사이클 최대 이슈)

OCR 물리 페이지 마커(`<!-- page: N -->`)는 파일 전체에서 1→172로 **단조 증가**하지만(재배열·중복 없음), 그 페이지 순서 자체가 책의 자연스러운 앞→뒤 흐름과 다르다. 실제 인쇄 편집상 표지·판권·목차가 본문보다 **뒤쪽 물리 페이지(164~172쪽)** 에 스캔되어 있고, 진짜 챕터 Ⅰ 도입부(학습목표→R,L,C 도입)가 그 뒤에 이어진다.

**검증**: 파일 끝(4666행)이 "인덕터 특성 1)~3)" 항목으로 끊기고, 파일 시작(1행)이 "4) 공진하는 성질이 있다"로 시작 — 인덕터 특성 리스트 1~4번이 파일 끝→파일 시작으로 정확히 이어짐을 확인. 챕터 Ⅱ~Ⅴ(656~4343행)는 내부적으로 정순이며 챕터 전환도 자연스럽다(예: 621행 "마. 평가"→656행 "Ⅱ. 기계 가공 기술" 챕터 시작).

**재구성 시 읽기 순서** (Do 단계에서 그대로 적용):

```text
① 4501~4666행 (물리 165~172쪽: 목차 이후 표지·학습안내·학습목표·1 R,L,C 도입~인덕터 특성 1~3)
② 1~655행     (물리 1~163쪽 전반: 인덕터 특성 4~다이오드~BJT/FET~전자소자 실습~2.직류회로~평가)
③ 656~1683행  (Ⅱ. 기계 가공 기술 — 정순)
④ 1684~2409행 (Ⅲ. 반도체장비 설계 — 정순)
⑤ 2410~3366행 (Ⅳ. 반도체장비 공유압기술 — 정순)
⑥ 3367~4343행 (Ⅴ. 프로그래밍 — 정순, 4343행 "단원 정리"로 종료)
⑦ 4365~4453행 (참고문헌·판권 — 재구성 대상 아님, 출처 메타로만 사용)
```

챕터 Ⅰ만 ①+② 조합이 필요하고, 챕터 Ⅱ~Ⅴ는 daegu·반도체기초와 동일하게 순차 읽기로 충분하다.

### 1.4 콘텐츠 성격 — 예상과의 괴리 (Plan 수립 시 반드시 고려)

`hs-textbook-collection.plan.md` 인벤토리는 이 권을 "전기·전자 기초(원자모형·반도체 재료·PN접합·다이오드·전자소자·측정)"로 요약했으나, 실제로는 **반도체 장비 기술자 양성을 위한 5과목 묶음 실무 교재**다.

| 대단원 | 반도체 정체성 | 기존 사이트와의 관계 | 비고 |
|---|:---:|---|---|
| Ⅰ. 전기·전자 기초 | 중간 | **`hs-semicon-basics`의 passive-components·diode·bjt와 개념 중복** | 이 책은 실습(납땜)·공식 중심, 반도체기초는 개념·소자원리 중심 — 각도 차별화 필요 |
| Ⅱ. 기계 가공 기술 | **낮음** | 사이트에 없음(신규) | 버니어캘리퍼스·밀링머신은 범용 기계공작 기초 — 반도체 특정성 약함 |
| Ⅲ. 반도체장비 설계 | 높음 | NCS `equipment-concept-design`·`equipment-main-design`·`equipment-board-design` 등과 신규 연결 | 제목에 "반도체장비" 명시, KS 제도 규격은 장비 설계 실무의 기초 |
| Ⅳ. 반도체장비 공유압기술 | **높음** | 사이트에 없음(신규), NCS `vacuum-plasma-maintenance`·`chemical-gas-maintenance`와 개념적 인접 | fab 장비 밸브·실린더 구동 원리 — cross-link `gas-safety`/`compressed-gas` 어휘와 결합 가능 |
| Ⅴ. 프로그래밍 | **낮음** | NCS `equipment-system-software`·`firmware-development`와 느슨한 연결 | 아스키코드·연산자 등 범용 C 튜토리얼, 반도체 문맥 거의 없음 |

→ 5개 대단원을 **동일한 우선순위로 다룰 근거가 약하다.** §9에서 범위·순서를 사용자에게 확인한다.

### 1.5 저작권 (hs-textbook-collection 확정 원칙 적용 — 재확인)

`hs-textbook-collection.plan.md` §9-4에서 **전 권 daegu 최보수 원칙 일괄 적용**이 이미 확정됐다. 이 권도 예외 없이 적용:

## 2. 목표 / 비목표

### 목표
- 원문 페이지 순환 배치를 해소한 정확한 재구성 순서 확정(§1.3 — 완료).

- 챕터 Ⅲ·Ⅳ(설계제도·공유압)를 NCS 장비 트랙과 cross-link로 연결해 "원리→직무" 학습 동선에 신규 축 추가.

### 비목표 (이번 사이클 제외)
- 실습(납땜·밀링 가공) 절차의 안전 수칙 심층 확장(별도 안전 보강 사이클 후보 — daegu의 `daegu-safety-enrichment` 선례처럼 향후 검토).
- 원문 도판 244개+ 규모의 자체 일러스트 대량 제작.
- C프로그래밍 실습 코드의 온라인 실행 환경 제공(정적 사이트 원칙상 범위 밖).
- 확인문제·단원평가 문제은행화(기존 daegu·반도체기초와 동일 원칙으로 배제).

## 4. 콘텐츠 재구성 전략 (daegu·반도체기초 원칙 승계 + 이 권 특유 보정)

### 공통 원칙 (변경 없음)
- 3단 레이어(Hook→Easy→Deep), 원문 이미지 미사용, 문장 전면 재작성, 수치·정의·법칙(보일의 법칙·키르히호프 법칙 등)은 보존.
- 페이지 하단 출처 표기: "「반도체기초기술1」(정예원 외 4인 지음, 크리아트출판사)".

### 이 권 특유 보정
- **챕터 Ⅰ 차별화 각도**: `hs-semicon-basics`의 passive-components·diode·bjt 모듈은 "개념·물리적 원리" 중심으로 이미 구성되어 있으므로, 이 권의 챕터 Ⅰ은 **"회로를 실제로 어떻게 만들고 측정하는가"**(저항 색띠 읽기, 납땜 실습, 임피던스 계산, 완성품 평가 기준) 각도로 재구성해 중복이 아닌 보완 관계를 만든다. Deep 레이어에서 `hs-semicon-basics` 해당 모듈로 `SourceRef` 연결.
- **재구성 순서**: §1.3의 읽기 순서(①→②)를 그대로 따라 원문을 정독한 뒤 Hook/Easy/Deep로 재작성 — 파일 내 라인 순서가 아니라 재구성한 논리적 순서를 기준으로 작업.
- **단위·법칙 표기**: 이 권은 공학 단위(kgf/cm², mmHg, at 등 옛 단위계)가 많이 등장 — SI 단위 병기 여부를 Design에서 결정.
