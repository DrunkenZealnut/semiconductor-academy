| **Problem (문제)** | 「반도체 포토·에칭」(박기주 외 4인, 에이치앤지, 충청북도교육청 인정, 7,242줄 OCR) 원문이 사이트에 미반영이다. 15중단원 중 **5개가 특정 상용 장비 모델(니콘 NSR-2205i11D 스테퍼·MARK-7 트랙·TE8500 에처)의 구조·조작·유지보수 매뉴얼형**이라 그대로 재현하면 단종 모델 조작법 나열이 되고 저작권·실효성 리스크가 크다. 또한 포토·에칭 주제는 daegu(공정 개론)·기존 Process 페이지(유해인자)·책 챕터와 사이트 안에서 가장 많이 겹치는 영역이다. |
| **Solution (해법)** | 검증된 카테고리 인프라에 `hs-photo-etch`(order 8)를 등록하고 5대단원 15중단원 전량을 재구성하되, 이 권의 각도를 **"장비 기술자의 눈"**(공정 원리→장비 구조→운용→예방정비)으로 잡아 기존 콘텐츠와 차별화한다. 장비 모델 콘텐츠에는 book2 CAD 특칙의 확장판을 적용 — 모델 조작 시퀀스 재현 금지, **장비 유형(트랙/스테퍼/에처)의 일반 구조·운용 원리** 중심, 모델명은 대표 사례로만. 실습 2개 중단원은 book2 압축 전략(대표 상세+변형표, 안전 전건 보존) 재사용. |
| **Function·UX Effect (기능·UX 효과)** | "반도체 고등학교 교과서" 그룹 5번째 권 카드. `/sources/hs-photo-etch/`에서 5트랙(포토 공정→포토 장비 구조→포토 장비 운용→에칭 공정·장비→에칭 장비 운용) 탐색. **daegu photo·etch, 기존 Process photolithography·etching, 책 챕터, OSHA(화학물질), NCS 유지보수 트랙과 cross-link 최다 교차** — 감광액·HMDS·에칭 가스(CF₄·SF₆·Cl₂·HBr)·플라스마·클린룸이 본문에 직접 등장해 통제 어휘 태깅이 교과서 시리즈 중 가장 풍부해진다. |
| **Core Value (핵심 가치)** | 사이트의 심장부인 포토·에칭 주제에 **세 번째 관점**이 완성된다: 책·Process가 "무엇이 위험한가"(유해인자), daegu가 "어떻게 만드는가"(공정 원리)를 다뤘다면, 이 권은 **"그 장비를 어떻게 다루고 지키는가"**(장비 구조·운용·PM). 유해인자 교육과 장비 직무 교육이 같은 공정 위에서 처음으로 3중 연결된다. |

### 1.3 콘텐츠 성격 — 이 권 특유 이슈 2가지

**① 상용 장비 모델 매뉴얼형 콘텐츠 (15중단원 중 5개, 이번 사이클 최대 이슈)**

Ⅱ.3(NSR 구조)·Ⅲ.1(MARK-7 운용)·Ⅲ.2(NSR 운용)·Ⅴ.1(TE8500 구조)·Ⅴ.2(TE8500 PM)가 특정 상용 장비 — 니콘 NSR-2205i11D 스테퍼, MARK-7 트랙(코터/디벨로퍼), TE8500 에처 — 의 구성도·조작 절차·화면 메뉴·PM 체크리스트를 다룬다. 그대로 재현하면 ⑴ 원문(및 장비 제조사 매뉴얼)의 표현 재사용 위험, ⑵ 특정 단종 모델에 종속된 낮은 학습 실효성, ⑶ 정보 밀도 과잉. → **book2 CAD 특칙의 확장 적용**(§4): 조작 시퀀스·화면 메뉴 재현 금지, "트랙/스테퍼/에처라는 장비 유형의 일반 구조와 운용 개념(레시피·인터록·알람 대응·PM 주기)" 중심으로 재구성, 모델명은 대표 사례로 언급.

**② 기존 콘텐츠와의 최다 중복 — 그러나 관점이 다르다**

| 기존 콘텐츠 | 관점 | 이 권과의 관계 |
|---|---|---|
| 책 ch·기존 Process `photolithography`/`etching` | 유해인자 — 무엇이 위험한가 | 감광액·에칭 가스의 위험을 다루는 페이지와 상호 보완 |
| daegu `photo`/`etch` | 공정 원리 개론 — 어떻게 새기는가 | 같은 공정의 원리 요약 — 이 권은 그 다음 단계(장비) |
| NCS 장비 트랙(`vacuum-plasma-maintenance` 등) | 직무 — 유지보수라는 일 | 이 권의 Ⅴ.2(PM)가 학문적 기초 제공 |

이 권의 각도 = **"장비 기술자의 눈"** — 공정 원리는 리마인더+SourceRef로 압축하고, 장비 구조·운용·예방정비에 본문을 집중해 중복이 아닌 3중 연결을 만든다.

### 1.4 유해인자 접점 — 시리즈 중 최다 (사이트 정체성 정면 교차)

감광액(포토레지스트) 177회, HMDS 17회, CF₄·SF₆·Cl₂·HBr 에칭 가스, 플라스마, FAB 클린룸·에어샤워·방진복(Ⅰ.4) 등 통제 어휘·화학물질 DB와 직접 겹치는 소재가 본문 전반에 등장한다. cross-link 태깅이 book1(공압 2모듈)·book2(공압 3모듈)와 달리 **다수 모듈에서 자연스럽게 가능** — `photolithography`·`etching`·`gas-safety`·`liquid-chemicals`·`cleanroom`·`engineering-controls`·`ppe` topics + chemical id 태깅(Design에서 chemicals.json 대조 확정).

### 1.5 저작권 (확정 원칙 재확인)

daegu 최보수 원칙 일괄 적용(카테고리 공통 확정): 원문 이미지 전면 미사용(도판 규모 大 — 장비 구성도·공정 순서도 다수), 문장 전면 재작성, 원저자(박기주 외 4인)·발행처(에이치앤지) 명시. "충청북도교육청 인정"은 이용허락과 무관. **추가**: 장비 모델 관련 서술은 원문뿐 아니라 제조사 매뉴얼 표현의 간접 재사용 가능성도 있으므로 §4 특칙으로 이중 방어.

## 4. 콘텐츠 재구성 전략 (시리즈 원칙 승계 + 이 권 특유 보정)

### 공통 원칙 (변경 없음)
- 3단 레이어(Hook→Easy→Deep), 원문 이미지 미사용, 문장 전면 재작성, 수치·정의·공정 조건은 보존.

### 이 권 특유 보정
- **장비 모델 일반화 특칙**(§1.3-①): 특정 모델의 버튼·화면 메뉴·조작 스텝 시퀀스는 재현하지 않는다. 재구성 축 — ⑴ 장비 유형의 보편 구조(트랙: 코터·디벨로퍼·베이크 모듈과 웨이퍼 반송 / 스테퍼: 광원·레티클·투영렌즈·스테이지 / 에처: 챔버·RF·진공·가스 계통), ⑵ 소프트웨어 불문 운용 개념(레시피, 인터록, 알람 대응, 로트 흐름), ⑶ PM의 사고방식(일/주/월 주기, 소모품, 안전 절차). 모델명(NSR-2205i11D·MARK-7·TE8500)은 "이런 유형의 대표 사례" 수준으로 언급 — 제목이 모델명인 중단원도 페이지 제목은 유지하되 본문은 일반 원리 중심.
- **"장비 기술자의 눈" 차별화**: 공정 원리(포토·에칭의 화학·물리)는 1~2문장 리마인더 + `SourceRef`(daegu photo/etch, 기존 Process, 책)로 압축. 본문은 장비가 그 원리를 "어떻게 구현하고, 무엇이 틀어질 수 있고, 어떻게 지키는가"에 집중.
- **실습 압축**(Ⅲ.3·Ⅴ.3): book2 규칙 그대로 — 대표 실습 1~2건 상세 + 변형 비교표 전건 커버, 안전 유의사항 전건 보존(대표 개별 + 통합 warning Callout, 고유 항목 없으면 통합 단독 허용).
- **유해인자 연결 우선**: 감광액·HMDS·에칭 가스·플라스마·클린룸 대목에서 기존 유해인자 페이지로 SourceRef를 적극 연결 — 이 권이 3중 관점의 다리가 되도록.
- **Ⅳ.1 에칭 공정(~1,000줄, 최대 중단원)**: 습식/건식·플라스마 원리·가스별 특성 등 밀도가 높다 — 내부 구성을 Design에서 정밀 설계(분할은 하지 않되 GFM 표 적극 활용).

## 9. 결정 사항 — 제안 (시리즈 확정 원칙 승계 중심, 이견 있으면 Design 착수 전 조정)

2. **파일럿 모듈**: 목차 순서 "**1. 반도체 공정의 개요**" — 분량이 가볍고(6~11쪽) 책·daegu와의 연결 각도를 첫 모듈에서 실증하기 좋다(승계).
3. **장비 모델 일반화 특칙** *(신규 판단)*: §4 원칙 — 조작 시퀀스 재현 금지, 장비 유형 일반 원리 중심, 모델명은 사례 언급(제목은 원문 유지).
4. **차별화 각도** *(신규 판단)*: "장비 기술자의 눈" — 공정 원리는 daegu·Process·책으로 SourceRef 압축, 본문은 장비 구조·운용·PM 집중.
5. **실습 압축·안전 보존**: book2 확정 규칙 그대로(승계).
