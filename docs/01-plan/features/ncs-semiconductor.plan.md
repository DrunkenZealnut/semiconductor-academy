# Plan — NCS 반도체 학습모듈 교육자료 카테고리 추가

> **Feature**: `ncs-semiconductor`
> **작성일**: 2026-07-12 · **Level**: Dynamic · **Cycle 유형**: 신규 자료원 + 콘텐츠 재구성
> **상속**: `multi-source-learning-platform`(Source 레지스트리·라우팅) · `cross-link-system`(통제 어휘) · `ch3-to-ch17-batch`(3단 레이어 재구성 패턴) · `osha-bilingual-toggle`(로더 레지스트리 패턴)
>
> **상태 갱신 (2026-07-13)**: 본문은 파일럿(제조 3개) 기준의 초기 계획 기록으로 보존한다. 이후 §5의 단계적 확대 경로대로 **장비 2 → 개발 8 → 재료 4가 순차 완료되어 4트랙 17모듈 전체가 완성**되었다(PR #6). `SourceLicense` 신규 값(`ncs-open`)·트랙 그룹 렌더·`[module]` 라우트는 파일럿에서 반영 완료. 확장 배치의 재구성 스펙은 `docs/02-design/features/ncs-semiconductor-dev-track.spec.md` 참조.

## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem (문제)** | 국가직무능력표준(NCS) 반도체 학습모듈 17개(`data/ncs/`)는 특성화고~대학 직무훈련용으로 만들어져 **전문적·실무적**이라, 사이트의 목표 독자인 **고등학생·일반인에게는 진입 장벽이 높다**. 원문 그대로는 교육 자료로 쓸 수 없고, 사이트에 통합할 카테고리도 없다. |
| **Solution (해법)** | NCS를 책·OSHA와 나란한 **새 자료원(Source)** 으로 추가하고(기존 multi-source 아키텍처 재사용), 각 학습모듈을 **고등학생 눈높이로 전면 재구성**(기존 책 챕터의 3단 레이어 Hook→비유→원문 방식). 원문은 근거·인용으로만 쓰고, 저작권 있는 도표·사진은 회피한다. |
| **Function·UX Effect (기능·UX 효과)** | `/sources/ncs-semi`에 NCS 카테고리가 노출되고, 4개 세분류(개발·제조·재료·장비) 트랙으로 학습모듈을 탐색. 각 모듈은 "빛으로 회로 그리기: 노광장비는 무슨 일을 할까?" 식으로 재구성. cross-link로 책·OSHA와 자동 연결(예: NCS Photo장비 ↔ 책 8장 포토리소그래피 ↔ OSHA 화학안전). |
| **Core Value (핵심 가치)** | 학술서(왜 위험한가)·OSHA(어떻게 안전하게)에 이어 **NCS(현장에서 무슨 일을 하나 = 직무·진로)** 관점을 더해 반도체 교육 삼각형 완성. 고등학생이 "반도체 산업에서 어떤 일을 하는지"를 자기 눈높이로 이해. |

## 1. 배경 / 현재 상태

### NCS 자료 인벤토리 (`data/ncs/`, 수정 금지 — 원본)

마크다운으로 변환된 학습모듈은 **17개**(+ 능력단위 정의서 report 3개). 4개 세분류:

| 세분류 (트랙) | 모듈 수 | 학습모듈 |
|---|:---:|---|
| **반도체개발** | 8 | 반도체 제품 기획 · 아키텍처 설계 · 디지털 회로 설계(수정요청) · 패키지 제품설계 · 펌웨어 개발 · 시스템 반도체 제조 공정 개발 · 커스텀 레이아웃 검증 · 플립 패키지 개발 |
| **반도체제조** | 3 | Photo 장비운영 · 반도체 품질관리 · 반도체 생산성 향상 |
| **반도체재료** | 4 | 재료 안전관리 · CMP 재료 제조 · 세정 공정 재료 제조 · 플립칩 재료 제조 |
| **반도체장비** | 2 | 장비 기구 조립 검증 · 장비 주변부 기구 설계 |

- 각 모듈 구조: NCS 소개 보일러플레이트(앞 ~10p, 학습내용 아님) → 학습모듈 개요 → **학습 1·2·3…** 각각 `필요 지식`(이론) → `수행 내용`(실습 절차) → `교수·학습 방법` → `평가`.
- 분량: 모듈당 1,500∼4,800줄(원문). 전문 용어·표·절차 밀도 높음.
- `report/` 3개(제조·장비·재료): 능력단위 정의서(수행준거·지식·기술·태도) — OCR 표 손상 심함, **재구성 참고 자료로만** 활용.

### 저작권 (중요)

NCS 학습모듈 고지: "교육훈련기관에서 **출처를 명시하고 교육적 목적으로 활용 가능**. 단 출처가 표기된 도표·사진·삽화 등은 원작자 동의 필요."

→ **텍스트 재구성은 자유**(공개 교육 표준, 출처 명시). **원문 이미지는 사용 회피** — 자체 도식/일러스트로 대체하거나 무이미지 구성. (책=fair-use, OSHA=us-gov와 다른 제3의 라이선스 상황)

### 현재 아키텍처 (재사용 가능 — 확장 부담 낮음)

| 요소 | 현황 | NCS 적용 |
|---|---|---|
| `SOURCES` 레지스트리 (`sources.ts`) | `[EPI_BOOK, OSHA_SCS]` | `NCS_SEMI` 1개 추가 |
| `SourceKind` (`types.ts`) | `'book'\|'training-program'\|'standard'\|'guide'\|'paper'` | **`'standard'` 이미 존재** |
| `accent` | `'book'\|'osha'\|'standard'` | **`'standard'` 이미 존재** (색상 토큰만 확인) |
| `SourceLicense` | fair-use / us-gov / cc-by(sa) / public-domain | NCS용 신규 값 1개 추가 필요(§5) |
| 라우팅 | `/sources/[source]`, `/sources/osha-scs/[part]` | `/sources/ncs-semi/[module]` 신규(OSHA 라우트 복제) |
| MDX 로더 레지스트리 | `oshaMdx.tsx` | `ncsMdx.tsx` 신규(동일 패턴) |
| cross-link 통제 어휘 | Topic/Hazard/Chemical | NCS 섹션 태깅으로 책·OSHA 자동 연결 |
| 3단 레이어 컴포넌트 | `LayeredExplain`, `SourceQuote`, `Callout` 등 | 그대로 재사용 |

## 2. 목표 / 비목표

### 목표
- NCS를 **새 Source(`ncs-semi`)** 로 등록 → `/sources`에 책·OSHA와 나란히 노출.
- 4개 세분류를 **트랙(그룹)** 으로 묶어 학습모듈 탐색 (SourceSection 그룹핑 확장).
- 각 학습모듈을 **고등학생 눈높이 MDX로 재구성** — 3단 레이어(Hook→비유·일러스트→원문 표현/인용). 원문 직역·복붙 금지.
- 전문 용어를 `terms.json`·책과 일관 유지, 필요 시 신규 용어 추가.
- cross-link 통제 어휘로 태깅 → 책·OSHA와 상호 연결.
- **저작권 준수**: 텍스트 재구성 + 출처 명시, 원문 이미지 회피.
- 코어(기존 컴포넌트·책·OSHA 페이지) 무수정 확장 실증.

### 비목표 (이번 사이클 제외)
- NCS 원문 이미지의 대량 큐레이션/자체 일러스트 제작 (별도 디자인 사이클).
- report(능력단위 정의서) 3개의 별도 페이지화.
- 17개 전체 일괄 완성 (범위는 §5 단계적 접근).
- 사이트 전역 IA 재편, 기존 자료원 카드 디자인 변경.

## 3. 정보구조(IA) 설계 — 권장안 + 대안

### 권장: **1개 자료원 + 4트랙**
- `NCS_SEMI` 하나의 Source. `sections[]`에 17개 모듈, 각 섹션에 `group`(세분류) 메타.
- `SourceSection`에 `group?: string` 필드 추가 → `SourceSectionList`가 세분류 헤더로 그룹 렌더.
- **장점**: 기존 카드 UI에 카드 1장만 추가(폭발 방지), 세분류는 자료원 내부에서 구조화. multi-source 아키텍처와 자연스러움.

### 대안 A: 세분류별 4개 자료원
- 개발/제조/재료/장비를 각각 독립 Source로. **단점**: `/sources` 카드가 6장으로 늘고, 4개가 사실상 한 출처(NCS)라 중복감.

### 대안 B: 직무/진로 중심 재편
- NCS 원 분류를 버리고 "설계자·공정엔지니어·재료개발자" 진로 관점으로 재구성. **장점**: 고등학생 흥미 최적. **단점**: 설계 부담 크고 원자료 추적성 약화. → 후속 고려.

> **결정 필요(§9)**: 위 3안 중 택1. 본 계획은 **권장안(1자료원+4트랙)** 기준으로 이후 전개.

## 4. 콘텐츠 재구성 전략

### 재구성 원칙 (원문 직역 아님 — "쉽게 다시 쓰기")
- **Hook**: 한 줄로 "이 모듈이 답하는 질문" (예: "빛으로 회로를 그리는 노광장비, 셋업이 왜 그렇게 까다로울까?").
- **Easy**: 비유·그림으로 핵심 개념 (예: 노광 = 사진 인화, CD = 붓의 굵기, PR = 감광 필름).
- **Deep/SourceQuote**: NCS 원문의 핵심 정의·수치를 근거로 인용(출처 명시). 원문 표(광원 파장 g/i/KrF/ArF/EUV 등)는 정확 재현.
- 직무 관점 유지: "현장에서 이걸 왜/어떻게 하는가"를 살려 진로 이해로 연결.
- 원문의 방대한 실습 절차(수행 내용)·평가는 **고등학생에게 필요한 만큼만 요약**, 전문 절차 나열 지양.

### 용어·수치 정확성
- 전문 용어 첫 등장 시 한글 풀이 + 영문 병기. `terms.json`에 없는 것은 추가 검토.
- 수치·화학식·표는 원문 그대로(노광 광원 파장, CD 단위 등).
- **OCR 오탈자 예외**: 원본 `data/ncs/`는 OCR 변환 자료라 오탈자가 있다. ① 명백한 오류(숫자 0↔문자 O 오인식, 통용 화학식·통용 기술값과 상충하는 표기 등)는 최소한으로 교정하되 해당 표·인용의 출처 각주에 보정 사실을 명시한다. ② 판단이 애매한 수치·화학식은 원문을 유지하고 사람 검수 항목으로 기록한다. ③ 표 구조가 깨져 확신이 없는 내용은 추측 복원 없이 배제한다.

### 저작권 처리
- 텍스트: 재구성 + 각 모듈 하단 "출처: NCS 학습모듈 {코드} {명칭}, 교육부·한국산업인력공단" 명시.
- 이미지: 원문 도표·사진 **미사용**. 필요 시 기존 사이트 자체 자산(`ProcessDiagram` 등) 재활용 또는 무이미지.
- `Source.license`: NCS 실태에 맞는 신규 값(§5).

## 5. 구현 범위 (파일) · 단계

### 단계 (권장: 파일럿 우선)
1. **파일럿 — 반도체제조 트랙 3개**(Photo 장비운영·품질관리·생산성 향상). 선정 이유: 책 공정 지식과 겹쳐 **cross-link 즉시 검증** 가능(Photo↔책 8장 포토), 3개로 트랙 완결성·재구성 품질 확인.
2. **검증 게이트** → 3단 레이어 품질·저작권·빌드 확인 후, 나머지 세분류(개발 8 → 재료 4 → 장비 2) 순차 확대.

### 파일럿 파일 목록

| 구분 | 파일 | 작업 |
|------|------|------|
| 수정 | `src/lib/types.ts` | `SourceLicense`에 NCS 값 1개 + `SOURCE_LICENSE_LABELS` / `SourceSection.group?` 필드 추가 |
| 수정 | `src/lib/sources.ts` | `NCS_SEMI` Source 추가 + `SOURCES` 배열 등록 |
| 신규 | `src/lib/ncsMdx.tsx` | 모듈 MDX 로더 레지스트리 (oshaMdx 패턴) |
| 신규 | `src/app/sources/ncs-semi/[module]/page.tsx` | 모듈 동적 라우트 (osha `[part]` 복제) |
| 신규 | `src/content/sources/ncs-semi/*.mdx` | 파일럿 3개 재구성 MDX |
| 수정(선택) | `src/components/sources/SourceSectionList.tsx` | 트랙 그룹 헤더 렌더 (group 필드 사용) |
| 수정(선택) | `src/data/cross-link.json` 원천(`_links.json`) | NCS 섹션 통제 어휘 태깅 |
| 수정(선택) | `tailwind.config` / 색상 | `accent: 'standard'` 색상 토큰 확인·보강 |

> 기존 책·OSHA 페이지·컴포넌트 무수정. 빌드 산출물 직접 수정 금지.
