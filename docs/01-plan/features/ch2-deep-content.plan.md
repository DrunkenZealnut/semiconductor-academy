| **Core Value (핵심 가치)** | **패턴 확산 검증** — Ch.1에서 만든 ImageFigure + 표 + SourceQuote 구조가 Ch.2에 그대로 적용되며, 16챕터 전체로 확산할 수 있는 템플릿임을 실증. 새 컴포넌트 0개, 새 인프라 0개로 콘텐츠 깊이만 추가 — **콘텐츠 작업 속도가 1.5배 빨라짐**. |

## 4. 콘텐츠 재구성 전략 (Ch.1 패턴 그대로)

### 4.1 본문 구조 (Ch.1 패턴 그대로)

```
[LayeredExplain Hero — 수도꼭지 비유 유지]
[ImageFigure 2장 표지]

## 1. 반도체의 기초 — 도체, 부도체, 반도체
  본문 + 표(도체/부도체/반도체) + ImageFigure(전류/전자 흐름) + Term 툴팁

## 2. 반도체의 분류
  ### 가. 유기 반도체와 무기 반도체
    본문 (실리콘 vs 유기 반도체) + 분류 표
  ### 나. 진성 반도체와 불순물 반도체
    본문 (도핑의 의의) + Callout(도핑) + SourceQuote
    + ImageFigure(에너지 밴드 또는 진성/불순물)

## 3. 모스트랜지스터 (MOSFET)
  본문 + ImageFigure(MOS 구조) + Callout(스위치 비유) + SourceQuote

## 4. 전자소자와 반도체
  본문 (전자소자에서 반도체의 역할)

## 5. 집적회로의 발전
  ### 가. 다이오드
    본문 + ImageFigure
  ### 나. 트랜지스터
    본문 + ImageFigure(단면) + 표 2-3 + Callout
  ### 다. 집적회로
    본문 + ImageFigure(IC) + Callout(무어의 법칙)

## 6. 반도체의 역사
  연대표 + SourceQuote (역사 결론)

[ChapterRef order={3}] 다음 챕터
```

### 4.2 저작권 정책 (R1, R2 — Ch.1과 동일)

- SourceQuote ≤ 3개, 각 ≤ 150자 직접 인용
- 표는 학술 표 fair use (출처 명시)
- 책 페이지 이미지: 작은 크기 (maxWidth 600px) + 출처 명시
- 본문 대부분은 책 흐름을 따르되 **재구성** — 직접 베끼기 금지
