## 1. CPU를 칩 하나로

컴퓨터 안에서 연산과 데이터 처리를 맡는 심장부가 <strong>CPU</strong>(중앙연산처리
장치)예요. 이 기능을 하나의 칩에 담아 낸 LSI가 <strong>MPU</strong>, 흔히 말하는
마이크로프로세서죠.

이 압축이 왜 중요했냐면 — CPU가 칩 하나가 되는 순간 컴퓨터의 크기와 값이 함께 무너져
내렸기 때문이에요. 방 하나를 차지하던 기계가 책상 위로, 다시 손바닥 위로 내려온
출발점이 여기예요.

## 2. 두 갈래 설계 철학 — CISC와 RISC

MPU의 기본 설계사양을 <strong>아키텍처</strong>라고 해요. 크게 두 갈래예요.

| | CISC (복합 명령 세트) | RISC (축소 명령 세트) |
|------|------|------|
| 지향 | 기능 중시 | 고속성 중시 |
| 명령 세트 | 다기능·다양함 | 기본적이고 개수가 적음 |
| 명령 길이 | 가변 | 고정 |
| 하드웨어 | 복잡 (부담 큼) | 간단 (부담 작음) |
| 소프트웨어 | 부담 작음 | 부담 큼 |
| 개발 | 어렵고 기간이 긺 | 쉽고 기간이 짧음 |
| 주 무대 | 개인용 컴퓨터의 규격형 MPU | 워크스테이션·서버·게임기 |

핵심은 <strong>부담을 어디로 넘기느냐</strong>예요. CISC는 고급 언어로 쓴 구문 하나를
명령 하나로 처리하려 하니 하드웨어가 복잡해지는 대신 소프트웨어가 편해져요. RISC는
1기계 사이클에 끝나는 단순한 명령만 갖춰 두고 여러 단계로 나눠 처리하니, 하드웨어는
간단해지지만 그만큼 소프트웨어(컴파일러)가 일을 더 해야 하죠.

MPU는 CISC로 시작했고 1980년대부터 RISC가 등장했어요. 개인용 컴퓨터에서는 CISC가
주류를 유지했지만, 서버·워크스테이션·게임기로 RISC가 넓혀 갔어요.

## 3. "몇 비트"가 뜻하는 것

MPU 성능을 말할 때 붙는 비트수는 <strong>한 번에 다루는 데이터의 폭</strong>이에요.
4비트에서 시작해 8·16·32·64·128비트로 넓어졌고, 폭이 넓을수록 한 번에 처리하는 양이
많아져요.

용도에 따라 필요한 폭이 달라요. 가전제품처럼 단순한 제어에는 4비트로 충분했고,
컴퓨터·서버·게임기 같은 고성능 영역에서 32~128비트가 쓰여요. 성능을 재는 다른 지표로는{' '}
<strong>MIPS</strong>(1초에 실행하는 명령 수)가 있어요.

## 4. 속도만으로는 안 되는 시대

한동안은 동작 주파수를 올리는 것이 곧 성능 향상이었어요. 그런데 빨라질수록 소비전력과
발열이 함께 치솟아 한계에 부딪혔죠. 그래서 방향이 바뀌었어요 —{' '}
<strong>소비전력을 억제하면서 속도를 얻는 방법</strong>, 즉 여러 개의 처리 단위를
나란히 두는 멀티칩·멀티코어 구성이 등장했어요.

MPU는 컴퓨터만의 부품이 아니에요. 휴대폰, 디지털 TV, 레코더, 디지털 카메라, 프린터까지
계산이 필요한 거의 모든 기기에 들어가 있어요.
