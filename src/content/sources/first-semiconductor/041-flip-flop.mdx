## 1. D형 플립플롭의 진리값표

단자는 넷이에요 — 입력 D, 클럭 CLK, 출력 Q와 그 반대값 Q̄.

| 입력 D | 클럭 CLK | 출력 Q | 출력 Q̄ |
|:---:|:---:|:---:|:---:|
| 0 | ↑ (0→1) | 0 | 1 |
| 1 | ↑ (0→1) | 1 | 0 |
| X (무관) | 0 | Q₀ (이전 상태) | Q̄₀ |

세 번째 줄이 핵심이에요. 클럭이 기동하지 않는 동안에는 <strong>입력 D가 무엇이든
상관없이</strong>(표에서 X) 출력이 이전 값을 그대로 유지해요. 이게 바로 '기억'이죠.

동작을 <strong>상태 전이</strong>로 쓰면 이렇게 정리돼요.

- <strong>클럭 상승 에지에서만</strong> → Q ← D
- <strong>그 밖의 모든 구간</strong>(High 유지·Low 유지·하강 에지) → Q ← Q₀ (이전 값 유지)

원서는 이를 <strong>Q = CLK·D + C̄L̄K̄·Q₀</strong>라는 논리식으로 적었어요. 뜻은 통하지만
엄밀히 읽으면 "CLK이 1인 <strong>동안 계속</strong> D를 따른다"가 되어, 에지에서 한 번만
받아들이는 플립플롭이 아니라 <strong>레벨 민감 D 래치</strong>를 기술하게 돼요. 실제 에지
트리거 D-FF에서는 클럭이 High를 유지하는 동안 D가 바뀌어도(홀드 타임 이후) 출력이 따라가지
않아요. 그래서 이 항목에서는 위의 상태 전이 표현을 기준으로 삼아요.

## 2. 타이밍으로 보면 더 분명해요

클럭이 기동하는 시점을 t₁, t₂, t₃, t₄라고 해봐요.

- t₁~t₂ 사이, t₂~t₃ 사이에 D가 바뀌었다면 → 출력 Q는{' '}
  <strong>t₂와 t₃ 시점에</strong> 따라 바뀌어요. 값이 변한 순간이 아니라 클럭이 온
  순간에 반영되는 거죠.
- t₃~t₄ 사이에 D가 그대로였다면 → t₄에서도 Q는 바뀌지 않아요.

이 "정해진 순간에만 반영"이라는 성질이 왜 중요할까요? 회로 안의 신호는 경로마다 도달
시간이 조금씩 달라요. 만약 값이 변할 때마다 즉시 반응한다면 순서가 뒤엉켜 엉뚱한 결과가
나오죠. 클럭이라는 <strong>공통 신호</strong>로 모든 회로의 박자를 맞추는 것 — 디지털
회로가 안정하게 동작하는 비결이에요.

## 3. 여러 개를 나란히 두면 레지스터

데이터를 잠시 담아 두는 회로를 <strong>레지스터</strong>라고 해요. 만드는 방법은
간단해요 — <strong>D-FF를 n개 늘어놓고 클럭선을 공유</strong>하면 돼요.

1. 각 플립플롭의 입력 D₁~Dₙ에 데이터를 걸어 둬요.
2. 클럭이 기동하면 n개 값이 <strong>동시에</strong> 각 플립플롭에 들어가요.
3. 다음 클럭까지 그대로 보존되고, 출력 Q₁~Qₙ에서 꺼낼 수 있어요.

여기에 <strong>CLR</strong>(클리어) 신호를 1로 주면 이전에 무엇이 들어 있었든 전부
0으로 리셋돼요. 전원을 켠 직후처럼 상태를 확정해야 할 때 쓰는 장치예요.

## 4. 메모리 장의 출발점

레지스터는 용량이 아주 작아요(수십 비트 수준). 대신 프로세서 안에서 <strong>가장
빠르게</strong> 접근하는 저장 공간이에요. 이 장에서 앞으로 볼 DRAM·SRAM·플래시는 같은
"기억"을 훨씬 큰 용량으로, 대신 다른 방식과 다른 대가로 구현한 것들이에요.

특히 <strong>SRAM은 메모리셀 자체가 플립플롭</strong>이에요(044). 그래서 전원이 켜져 있는
한 리프레시 없이 데이터를 지키죠. 이 항목이 4장 맨 앞에 놓인 이유예요.
