## 1. 한 칩 안에 다 들어 있다

MCU 칩 하나에 담기는 것들을 8비트 제품 기준으로 늘어놓으면 이래요.

| 블록 | 역할 |
|------|------|
| CPU | 계산과 판단 |
| RAM / ROM | 데이터 임시 보관 / 프로그램 저장 |
| A/D · D/A 변환기 | 현실의 아날로그 신호 ↔ 디지털 값 |
| 타이머 (TM·WD·WT) | 시간 재기, 멈춤 감시(워치독) |
| 직렬 인터페이스 | 다른 기기와 통신 |
| 끼어들기 (INT) | 급한 일이 생기면 하던 일을 멈추고 처리 |
| 곱하기·나누기 (MULDIV) | 연산 보조 |

프로그램과 데이터를 담는 메모리에는 <strong>용도에 맞게 맞춤 제작된 정보</strong>가
들어가요. 같은 MCU 칩이라도 안에 무엇을 써 넣느냐에 따라 전자레인지도 되고 리모컨도
되는 셈이죠.

## 2. MPU와의 갈림길

MCU에 들어가는 CPU는 034에서 본 MPU보다 기능도 성능도 떨어져요. 그런데도 쓰는 이유는{' '}
<strong>한 칩으로 끝나기 때문</strong>이에요. 부품 수가 줄고, 기판이 작아지고, 값이
싸지고, 고장 날 곳도 줄죠.

그래서 두 칩은 경쟁 관계가 아니에요. MCU는 소규모 기기의 두뇌로 혼자 일하기도 하고,
MPU가 들어간 고성능 기기 안에서 <strong>각종 제어를 도맡는 조수</strong> 노릇을 하기도
해요. 컴퓨터 한 대 안에도 MPU 하나에 MCU 여럿이 들어 있는 게 보통이에요.

## 3. 비트수와 쓰임새

MCU도 MPU처럼 4·8·16·32·64비트로 나뉘고, 비트수가 클수록 복잡한 기능을 감당해요.

| 비트 | 가전·생활 | 산업 | 자동차 |
|:---:|------|------|------|
| 4 | 리모컨, 전자레인지 | — | — |
| 8 | 오디오, TV, 카메라 | 마우스, POS 단말 | 에어백, 도어 제어 |
| 16 | 에어컨 | 자동판매기, 인버터 제어 | 파워 스티어링, 차량용 에어컨 |
| 32 | 휴대폰, 레코더, 디지털 카메라, IC 카드 | 프린터, 승강기 제어, 자동 발매기 | 엔진 제어, ABS |
| 64 | 고성능 디지털 가전 | — | 차량 제어용 |

## 4. 프로그램은 어떻게 넣나

MCU를 쓰려면 안에 넣을 프로그램을 만들어야 해요. 4비트급처럼 아주 단순한 제품에는{' '}
<strong>어셈블러</strong>(명령을 하나씩 기계어로 옮기는 도구)를 쓰지만, 8비트 이상에서는
개발 효율 때문에 <strong>컴파일러</strong>(사람이 읽기 쉬운 고급 언어를 한꺼번에 번역)를
써요.

기계어는 컴퓨터가 직접 읽는 2진수 나열이고, 고급 언어는 영어 단어에 가까운 형태예요.
그 사이를 번역해 주는 도구가 있어야 사람이 감당할 수 있는 규모의 프로그램을 만들 수
있죠.
