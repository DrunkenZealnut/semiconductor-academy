## 1. 왜 계층으로 나누나

3장 025에서 봤듯 칩 하나에 들어가는 소자 수는 계속 늘어요. 사람이 소자 하나하나를
그리는 방식으로는 감당이 불가능하죠.

그래서 <strong>계층 설계</strong>(탑다운 설계)를 써요. 설계 공정을 <strong>전체에서 부분,
위에서 아래로</strong> 층층이 나누고, 각 층에서 CAD 툴이 다음 층을 만들어 내는 방식이에요.

핵심 원칙이 하나 있어요 — <strong>'설계'에는 늘 합성(synthesis)과 검증(verification)이
함께 들어가요</strong>. 만드는 것과 확인하는 것이 한 쌍이죠. 자동 툴이 만든 결과가
의도대로인지 매 층에서 확인하지 않으면, 아래로 내려갈수록 오류가 걷잡을 수 없이 커져요.

## 2. 네 개의 층

<strong>① 시스템 설계</strong>

가장 위층이에요. 여기서 가장 중요한 것은 <strong>아키텍처 설계</strong> —{' '}
<strong>하드웨어와 소프트웨어의 분담</strong>을 정하는 일이에요. 어떤 기능을 회로로 만들고
어떤 기능을 프로그램으로 처리할지 나누는 거죠.

주로 <strong>C언어</strong>를 쓰고, <strong>하드·소프트 협조 시뮬레이션</strong>으로 동작과
인터페이스의 정합성을 확인해요.

<strong>② 기능 설계</strong>

<strong>HDL</strong>(하드웨어 서술 언어)로 기능을 써 내려가요 — <strong>Verilog</strong>나{' '}
<strong>VHDL</strong>이 대표적이죠.

다만 아무렇게나 쓰면 안 돼요. 논리 합성 툴이 다룰 수 있도록 <strong>RTL</strong>
(Register Transfer Level) 수준으로 써야 해요. RTL은 회로 동작을{' '}
<strong>플립플롭 등 레지스터 사이의 신호 흐름 + 논리 연산 조합</strong>으로 기술하는
방식이에요(4장 041의 플립플롭이 여기 나와요).

그리고 작성한 RTL이 기대대로 동작하는지 <strong>기능 검증</strong>을 해요.

<strong>③ 논리 설계</strong>

여기서는 세 종류의 도구가 각자 다른 일을 해요. 원서는 이를 '논리 시뮬레이터'로 뭉뚱그려
적었지만, 실제 EDA 흐름에서는 역할이 나뉘어 있어요.

| 도구 | 입력 | 하는 일 |
|---|---|---|
| <strong>논리 합성</strong> | RTL + 속도·전력·면적 제약 | <strong>게이트 레벨 넷리스트</strong> 생성 |
| <strong>STA</strong> (정적 타이밍 분석) | 넷리스트 + 셀 라이브러리 + 제약 | <strong>타이밍 검증</strong> |
| <strong>시뮬레이터</strong> | 넷리스트 + 테스트벤치 | <strong>기능 동작</strong> 검증 |

합성이 3장 028~030의 게이트들을 실제로 골라 배치하고, STA가 "신호가 제때 도착하는가"를
따지고, 시뮬레이션이 "결과가 의도대로인가"를 봐요. 신호가 정해진 시각에 도착하지 못하면
논리가 아무리 맞아도 오동작하니 두 검증이 모두 필요하죠.

<strong>④ 레이아웃 설계</strong>

게이트 레벨 회로도를 바탕으로 <strong>기능 블록을 배치하고 상호 배선</strong>을 정해요.
여기서 처음으로 "칩 위의 실제 위치"가 정해지죠.

검증은 두 가지예요 — <strong>DRC</strong>(설계법칙 체크)로 050의 설계 기준을 어기지
않았는지 보고, 신호가 지나는 경로를 세밀하게 확인해요.

## 3. 피드백 — 아래에서 위로 되돌아가기

탑다운이라고 해서 한 방향으로만 흐르지 않아요. 아래층에서 문제가 발견되면{' '}
<strong>위층 설계로 피드백</strong>해 전체를 다시 최적화해요.

예를 들어 레이아웃에서 타이밍이 안 맞으면 논리 설계로 돌아가고, 그래도 안 되면 기능
설계나 아키텍처까지 거슬러 올라가기도 하죠. 그래서 실제 설계는 여러 번의 왕복으로

## 4. 칩 안쪽만이 아니다

레이아웃 설계에서 배치하는 것은 회로만이 아니에요. 칩 주변부에도 여러 요소가 들어가요.

| 요소 | 역할 |
|---|---|
| <strong>전극 패드</strong> | 외부와 연결하는 접점 (8장 073의 와이어 본딩이 여기 붙어요) |
| <strong>절단선</strong> | 웨이퍼에서 칩을 잘라 낼 선 (8장 071의 다이싱) |
| <strong>노광용 위치조정 마크</strong> | 여러 층을 정확히 겹치기 위한 정렬 기준 (7장 064) |
| <strong>체크 패턴</strong> | 기초 특성 측정용 |

설계가 이후 공정 전체를 미리 고려한다는 뜻이에요 — 이 항목이 5장 한가운데 놓인 이유죠.
