## 1. 흔한 원소, 그러나 순수하지 않은 상태로

1장 003에서 봤듯 실리콘의 <strong>클라크수는 25.8%</strong>로 산소(49.5%) 다음이에요.
지각의 4분의 1이 실리콘인 셈이죠.

그런데 문제가 있어요. 실리콘은 <strong>홀로 존재하지 않아요</strong>. 산소와 화합한{' '}
<strong>규석</strong>(SiO_x) 형태로 지각에 널리 퍼져 있죠. 흔히 보는 모래와 돌이 그거예요.

그래서 반도체용 실리콘을 얻는 첫 단계는 이렇게 돼요.

1. 땅속에서 <strong>규석을 캐낸다</strong>
2. <strong>환원한다</strong> — 즉 산소를 떼어 낸다
3. 실리콘을 분리한다

이 과정의 구체적인 내용이 다음 항목(054)이에요.

## 2. 재료로서의 실리콘

| 구분 | 항목 | 값 |
|---|---|---|
| 일반 | 분류 | <strong>반금속</strong> |
| 일반 | 밀도 | 2,330 kg/m³ |
| 일반 | 색 | 암회색 |
| 원자 | 원자번호 / 원자량 | 14 / 28.0855u |
| 원자 | 원자 반지름 | 111×10⁻¹² m |
| 원자 | 결정 구조 | <strong>다이아몬드 구조</strong>(면심 입방) |
| 물리 | 융점 | <strong>1,414℃</strong> |
| 물리 | 열전도율 | 148 W·m⁻¹·K⁻¹ |
| 물리 | 비열용량 | 700 J·kg⁻¹·K⁻¹ |
| 기타 | 클라크수 / 전기 음성도 | 25.8% / 1.9 |

'반금속'이라는 분류가 눈에 띄어요 — 금속도 비금속도 아닌 중간이죠. 1장 001에서 본
"도체와 절연체의 중간"이라는 성격이 원소 분류에도 그대로 나타나요.

높은 융점(1,414℃)과 좋은 열전도율은 반도체 공정에 유리한 조건이에요. 7장에서 볼 고온
공정들을 견뎌야 하고, 칩이 작동하며 내는 열을 빼내야 하니까요.
