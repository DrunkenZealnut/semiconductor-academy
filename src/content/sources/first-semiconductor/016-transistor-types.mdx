## 1. 트랜지스터가 하는 두 가지 일

- <strong>증폭</strong> — 작은 신호를 큰 신호로 키워요.
- <strong>스위치</strong> — 전류를 켜고 끊어요.

1947년 미국 벨 연구소에서 처음 발명된 뒤 다양한 형태로 개발·개량돼 왔어요(그 발명
이야기는 2장 COLUMN에 있어요). 3장부터 나오는 논리회로는 트랜지스터의{' '}
<strong>스위치</strong> 기능만 쓰고, 아날로그 회로는 <strong>증폭</strong> 기능을 주로 써요.

## 2. 첫 번째 축 — 캐리어가 몇 종류인가

| | 유니폴라(단극)형 | 바이폴라(2극)형 |
|---|---|---|
| 관여하는 캐리어 | <strong>한 종류</strong>(전자 또는 양공) | <strong>두 종류 모두</strong> |
| 무엇으로 동작 | <strong>전압</strong>(전기장) | <strong>전류</strong> |
| 다른 이름 | <strong>FET</strong>(전기장 효과 트랜지스터) | 바이폴라 트랜지스터 |
| 종류 | MOSFET, JFET, MESFET | p-n-p형, n-p-n형 |

'유니(uni-)'와 '바이(bi-)'는 각각 하나와 둘을 뜻해요. 이름에 캐리어 종류 수가 들어 있는
셈이죠.

FET이라는 이름은 <strong>전기장(Field)의 효과(Effect)로 동작</strong>한다는 뜻이에요.
게이트에 전압을 걸면 전기장이 생기고, 그 전기장이 채널을 만들거나 없애요 — 게이트가 채널에{' '}
<strong>직접 닿지 않는다</strong>는 점이 특징이에요(011의 MOS 용량 구조를 떠올리면 돼요).

## 3. 두 번째 축 — 게이트를 무엇으로 만드나

FET은 게이트 구조에 따라 셋으로 갈려요.

| 종류 | 게이트 구조 | 다루는 항목 |
|---|---|---|
| <strong>MOSFET</strong> | 금속(또는 다결정 실리콘) - 산화막 - 반도체 | 017·018 |
| <strong>JFET</strong> | p-n 접합을 게이트로 | 020 |
| <strong>MESFET</strong> | 금속-반도체 접합(쇼트키)을 게이트로 | 021 |

가장 널리 쓰이는 것은 MOSFET이에요. 3장 025에서 "가장 대표적인 IC는 MOS-IC"라고 했던
그 MOS죠.

## 4. 세 번째 축 — 채널 극성과 동작 모드

<strong>채널 극성</strong> — 전류를 나르는 캐리어가 무엇인가로 갈려요.

- <strong>n채널형</strong> — 전자가 운반자 (017)
- <strong>p채널형</strong> — 양공이 운반자 (018)

<strong>동작 모드</strong> — 게이트 전압이 없을 때 어떤 상태인가로 갈려요.

| 모드 | 게이트 전압 0V일 때 | 비유 |
|---|---|---|
| <strong>증강형</strong> | 전류가 <strong>흐르지 않음</strong> | 평소 닫힌 밸브 |
| <strong>고갈형</strong> | 전류가 <strong>흐름</strong> | 평소 열린 밸브 |

MOSFET과 MESFET에는 두 모드가 다 있지만, <strong>JFET은 고갈형만</strong> 있어요 — 구조상
게이트 전압 없이도 채널이 이미 존재하니까요(020에서 이유를 봐요).
