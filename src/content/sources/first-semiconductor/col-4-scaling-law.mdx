  해야 하는지를 정해 주는 규칙이 있어요.

## 그냥 작게 만들면 안 된다

MOS 트랜지스터를 미세화할 때의 기본 원리를 <strong>스케일링 법칙</strong> 또는{' '}
<strong>비례 축소의 법칙</strong>이라고 해요.

도면을 축소 복사하듯 가로세로만 줄이면 문제가 생겨요. 치수는 작아졌는데 전압이 그대로면
소자 내부의 <strong>전기장이 급격히 세지기</strong> 때문이에요. 전기장이 세지면 절연막이
버티지 못하고, 캐리어가 과도하게 가속돼 소자를 늙게 만들죠.

그래서 가장 기본이 되는 방식이 <strong>정전기장(constant field) 조건</strong>이에요.
치수를 줄이는 만큼 <strong>전원 전압도 함께 비례해서 줄여</strong> 각 부분에 걸리는
전기장을 일정하게 유지하며 축소하는 것이죠.

## 무엇을 얼마나 줄이나

전원 전압을 1/k로 낮추려면 아래 값들을 함께 맞춰야 해요.

| 파라미터 | 스케일링 |
|------|:---:|
| **소자 구조** | |
| 게이트 길이 (L) | 1/k |
| 채널 폭 (W) | 1/k |
| 게이트 절연막 두께 (T_OX) | 1/k |
| p-n 접합 깊이 (X_j) | 1/k |
| 실리콘 기판 불순물 농도 (N_d) | **k배** |
| **회로 특성** | |
| 전기장 (E) | 1 (일정) |
| 전압 (V) | 1/k |
| 용량 (C) | 1/k |
| 지연 시간 (d = VC/I) | 1/k |
| 소비전력 (P = IV) | **1/k²** |

표에서 두 줄이 눈에 띄어요.

**불순물 농도만 반대 방향** — 다른 건 다 줄이는데 기판 불순물 농도는 k배로{' '}
<strong>늘려요</strong>. 소자가 작아지면 소스·드레인의 공핍영역이 채널을 침범하기
쉬워지는데, 농도를 높이면 공핍영역이 좁아져 그 침범을 막을 수 있거든요.

**전기장은 1** — 이게 이 방식의 목표예요. 크기와 전압을 같은 비율로 줄이면 전기장은
변하지 않아요. 그래서 소자가 작아져도 동작 조건이 유지되죠.

## 축소가 성능이 되는 이유

이 규칙을 지키면 크기만 줄어드는 게 아니에요.

- <strong>지연 시간이 1/k</strong> → 그만큼 빨라져요.
- <strong>소비전력이 1/k²</strong> → 훨씬 덜 먹어요.

즉 <strong>작아지고, 빨라지고, 전력을 덜 쓰는 일이 동시에</strong> 일어나요. 3장 023에서
"네 가지가 한꺼번에 좋아졌다"고 했던 것, 그리고 반도체 산업이 반세기 동안 같은 방향으로만
달려온 이유가 이 표 한 장에 들어 있어요.

물론 현실은 이 이상적인 표대로 흘러가지 않았어요. 전압을 무한정 낮출 수는 없고(문턱값
전압이 있으니까요), 절연막을 계속 얇게 하면 터널링으로 전류가 새기 시작해요. 그 벽에
부딪힌 뒤의 이야기가 9장의 주제예요 — 신재료, 3차원 구조, 새로운 공정으로 돌파구를
찾는 시도들이죠.
