## 1. 메모리 IC — 맡아 두었다 꺼내 주는 칩

정보를 기억했다가 필요할 때 내주는 반도체예요. 가장 큰 갈림길은{' '}
<strong>전원을 끄면 잊는가</strong>예요.

| | 종류 | 성격 |
|------|------|------|
| 휘발성 | DRAM | 기억 보존 동작(리프레시)이 필요한 읽기·쓰기 메모리 |
| 휘발성 | SRAM | 보존 동작이 불필요한 읽기·쓰기 메모리 |
| 비휘발성 | MROM | 제조 단계에서 내용이 정해지는 읽기 전용 메모리 |
| 비휘발성 | 플래시 메모리 | 쓰기·삭제가 가능한 비휘발성 메모리 |

## 2. 마이콤 IC — 계산하고 지시하는 칩

컴퓨터의 중앙 연산처리를 맡는 갈래예요. 연산이 주 임무인{' '}
<strong>MPU</strong>(초소형 연산처리 장치), 제어가 주 임무인{' '}
<strong>MCU</strong>(초소형 제어 장치), 그리고 입출력 등 주변 기기를 다루는 주변 회로가
여기 들어가요.

## 3. ASIC — 특정 용도를 위한 주문형

메모리와 마이콤이 시장에서 사 오는 <strong>규격품</strong>이라면, ASIC은 특정 용도를
위해 <strong>주문 제작</strong>하는 IC예요. 안쪽 갈래가 좀 복잡한데, 두 번의 갈림길로
정리하면 쉬워요.

<strong>첫 번째 갈림길 — 누구를 위한 것인가</strong>

- <strong>USIC</strong> : 특정 고객만을 위한 IC
- <strong>ASSP</strong> : 특정 용도를 위해 만들되 여러 고객에게 파는 표준품

<strong>두 번째 갈림길 — USIC을 얼마나 처음부터 만드나</strong>

- <strong>전주문형</strong> : 바닥부터 전부 설계
- <strong>반주문형</strong> : 미리 준비된 구조를 활용해 설계 기간을 줄임
  - <strong>GA</strong>(게이트 어레이) — 가장 간편한 주문 방식
  - <strong>CB-IC / SCA</strong>(셀 베이스) — 검증된 블록을 쌓아 올리는 빌딩블록 방식
  - <strong>ECA</strong>(내장형 셀 어레이) — 게이트 어레이에 메모리 셀을 더한 형태
  - <strong>PLD·FPGA</strong> — 완성된 뒤에도 사용자가 기능을 프로그램할 수 있는 규격형 로직

## 4. 시스템 IC — 한 칩에 시스템 전체를

CPU, 메모리, 로직, 주변 회로를 <strong>한 칩에 모두</strong> 담은 것이 시스템 IC예요.
기판 위에 여러 칩을 늘어놓던 것을 칩 하나로 압축한 셈이니, 023에서 본 "조립을 안쪽으로
가져오기"가 시스템 수준에서 다시 한번 일어난 것이라고 볼 수 있어요.
