## 1. 장비 셋업 — 반입에서 성능 검증까지 6단계

새 장비가 팹에 도착해 첫 웨이퍼를 만나기까지는 순서가 정해져 있어요.

| 단계 | 하는 일 |
|:-:|---|
| ① 장비 반입 | 도착 일정을 확인하고 이송 경로를 계획한다. 포장재 손상을 점검하고 청정실 기준에 안 맞는 목재 포장재를 제거한 뒤, 에어 샤워나 패스 박스를 거쳐 청정실로 들여온다 |
| ② 위치 설정 | 레이아웃 도면대로 설치 위치를 확인하고 바닥 수평도를 측정한다. 진동 방지 패드·댐퍼를 설치하고 정밀 수준기로 0.1mm 이하 정확도까지 수평을 맞춘 뒤 앵커 볼트로 고정한다 |
| ③ 유틸리티 연결 | 사양에 맞는 전력과 무정전 전원 공급 장치(UPS)를 연결하고, 공정용 가스를 연결해 누출 검사를 한다. 냉각수·진공·압축 공기도 각각 사양대로 연결해 확인한다 |
| ④ 기능 점검 | 전기 회로의 절연 저항을 측정하고 센서·액추에이터의 작동을 확인한다. 제어 시스템의 작동을 점검하고, 비상 정지·가스 누출 감지 등 안전 시스템을 검증한다 |
| ⑤ 초기 설정 | 제어 소프트웨어를 설치하고 네트워크를 연결한다. 공정 파라미터와 표준 레시피를 설정하고, 알람 상·하한값과 인터로크 조건을 확인한다 |
| ⑥ 성능 검증 | 실제 웨이퍼나 테스트 기판으로 위치·온도·압력 정확도를 측정하고 재현성을 검증한다. 처리량을 측정해 생산성을 확인한 뒤, 제조업체와 공동으로 성능 인증서를 발급한다 |

<strong>유틸리티</strong>란 장비를 돌리는 데 필요한 전력·냉각수·압축
공기·진공·질소 같은 기반 설비를 통틀어 부르는 말이에요. 전력은 보통
380V/220V, 냉각수는 15~25°C, 압축 공기는 5~7bar(약 500~700kPa) 수준의
조건을 맞춰야 해요. 그리고 초기 설정에서 확인하는{' '}
<strong>인터로크(interlock)</strong>는 두 개 이상의 장치가 특정 조건에서만
함께 움직이거나 아예 멈추도록 서로 맞물려 놓은 안전 장치예요 — 도어를
열면 장비가 자동으로 멈추는 것도, 가스가 새면 밸브가 자동으로 잠기는
것도 인터로크가 하는 일이에요.

## 2. 장비 검수 — 계약대로 만들어졌는가, 6단계

검수는 셋업이 끝난 장비가 계약서에 적힌 사양과 성능대로 만들어졌는지
철저히 확인하는 과정이에요. 여기서 놓친 문제는 나중에 수율 저하로
되돌아오기 때문에, 생산 투입 전 마지막 관문이라 할 수 있어요.

| 단계 | 확인하는 것 |
|:-:|---|
| ① 외관 검사 | 손상·변형·부식·오염 여부, 용접 부위와 표면 마감의 파티클 발생 가능성, 안전 라벨 부착 상태, 계약된 부속품 포함 여부 |
| ② 기능 시험 | 전기 시스템과 구동 장치의 정상 작동, 로봇 암 등 기계적 구동부의 소음·진동, 제어 시스템과 통신 상태, 도어 개방 시 정지 등 안전 인터로크 기능 |
| ③ 성능 측정 | 위치·온도·압력·유량 제어의 정확도와 재현성, 시간당 웨이퍼 처리량(WPH; Wafers Per Hour), 진동·소음·파티클 수준, 웨이퍼 내·웨이퍼 간 공정 균일도 |
| ④ 안전 점검 | SEMI S2·S8 기준 준수 여부, 접지·절연 저항, 가스 감지기·비상 배기·자동 차단 밸브, 안전 가드·라이트 커튼, 인체 공학적 설계 |
| ⑤ 문서 확인 | 사양서·도면·배선도 같은 기술 문서, 조작 매뉴얼과 예방 정비 계획서, 안전 데이터 시트(SDS)와 공장 승인 시험(FAT) 결과서, 소프트웨어 사양서 |
| ⑥ 인수인계 | 최종 검수 보고서와 성능 보증서, 운영·유지 보수 담당자 교육, 예비 부품·소모품 인수, 자산 관리 시스템 등록 |

성능 측정 단계에서 나오는 <strong>WPH(Wafers Per Hour)</strong>는 장비가
한 시간에 웨이퍼를 몇 장 처리하는지를 나타내는 생산성 지표예요. 안전
점검 단계는 앞 절에서 살펴본 SEMI S2·S8 표준을 실전 장비에 그대로
적용해 보는 자리이기도 해요.

<Callout type="info" title="FAT(Factory Acceptance Test), 출하 전의 마지막 시험">
  FAT는 장비 제조업체의 공장에서 미리 치르는 사전 검수예요. 구매자가 직접
  방문해 성능을 확인하고, 이 시험을 통과해야만 장비가 팹으로 출하될 수
  있어요. 그러니 이 절의 6단계 검수는 사실 FAT를 한 번 더 팹 현장에서
  확인하는 절차인 셈이에요.
</Callout>

## 3. 운영 중 유지 보수 — 매일의 돌봄, 6단계

장비가 생산에 투입된 뒤에도 돌봄은 끝나지 않아요. 24시간 365일 돌아가는
반도체 팹에서는 가동률 95% 이상을 지켜야 경쟁력을 유지할 수 있고, 단
몇 시간의 예기치 않은 정지도 수십억 원의 손실로 이어지기 때문이에요.

| 단계 | 핵심 활동 |
|:-:|---|
| ① 일상 점검 | 오일 누유·부품 파손 등 시각 점검, 이상음 청취 점검, 진동계·적외선 온도계로 이상 부위 확인, 계기 지시값·소모품 상태·안전장치 작동 확인 |
| ② 예방 보전 | 제조업체 권고와 운영 경험에 따라 계획적으로 청소·점검, 윤활유 공급과 소모품 교체, 센서 교정, 진동·열화상 분석으로 고장 예측 |
| ③ 고장 대응 | 비상 정지·전원 차단으로 2차 피해 방지, 알람 이력 분석으로 원인 진단, 부품·인력 확보 후 수리, 완료 후 단계별 재확인 |
| ④ 부품 교체 | 정확한 품번·사양 확인 후 공인 업체에서 조달, 정전기 방지 대책 아래 교체, 토크 사양·결선도에 맞춰 설치, 교체 내역 기록 |
| ⑤ 성능 복원 | 처리 속도·정확도·재현성을 기준값과 비교, 실제 웨이퍼로 공정 품질 검증, 안전장치·인터로크 재확인, 필요시 센서 재교정 |
| ⑥ 기록 관리 | 작업 일시·담당자·부품·소요 시간 기록, 고장 원인과 조치를 데이터베이스로 축적, 열화 패턴 파악과 비용 분석, 정기 보고 |

<Callout type="warning" title="고장 대응, 첫 동작은 언제나 안전 확보">
  고장이 나면 가장 먼저 하는 일은 수리가 아니라 <strong>안전
  확보</strong>예요. 비상 정지와 전원 차단으로 2차 피해부터 막아요.
  산업 현장에서는 이 전원 차단·잠금 절차를 흔히{' '}
  <strong>LOTO(Lock Out, Tag Out)</strong>라고 불러요 — 수리 중에 누군가
  실수로 전원을 켜는 일을 막기 위한 잠금과 표시죠.
</Callout>

일상 점검에서 이상음으로 의심하는 <strong>펌프 캐비테이션</strong>은
펌프 안에서 압력이 낮은 지점에 생긴 기포가 수압 변화로 터지며 나는
현상이고, 예방 보전에서 교정하는 <strong>유량 센서</strong>는 배관
속을 흐르는 액체·기체의 양을 재는 장치예요. 이런 마모·저하가 쌓이는
경향을 <strong>열화 패턴</strong>이라 부르는데, 체임버 내벽의 에칭이나
O-링의 탄성 저하처럼 장비마다 정해진 패턴을 분석하면 부품 교체 시기를
미리 알 수 있어요.

## 4. 디지털 트윈 — 가상 공간에서 미리 보는 장비

최근에는 실제 장비를 가상 공간에 그대로 옮겨 놓은{' '}
<strong>디지털 트윈</strong>(digital twin)이 운영 중 유지 보수에
활용되고 있어요. 장비에 붙은 수백 개 센서가 실시간으로 보내는 데이터로
가상 장비를 움직이면, 진짜 장비의 상태를 정확히 파악하고 미래까지
내다볼 수 있어요. 활용 분야는 크게 네 가지예요.

| 활용 분야 | 내용 |
|:-:|---|
| 고장 예측 | AI가 진동·온도·전류 패턴을 분석해 부품 고장을 2~3주 전에 미리 예측한다 |
| 공정 최적화 | 가상 공간에서 다양한 레시피를 시뮬레이션해 최적 조건을 찾는다 |
| 원격 진단 | 해외 전문가가 디지털 트윈을 통해 실시간으로 장비 문제를 진단한다 |
| 교육 훈련 | 실제 장비 없이도 가상 공간에서 운영·유지 보수 교육을 진행한다 |

국내 기업들도 디지털 트윈을 적극 들이고 있어요. 삼성전자는 평택
공장에 디지털 트윈을 구축해 장비 가동률을 5% 높였고, SK하이닉스는
이천 공장에서 디지털 트윈으로 에너지 사용량을 15% 절감했어요.
