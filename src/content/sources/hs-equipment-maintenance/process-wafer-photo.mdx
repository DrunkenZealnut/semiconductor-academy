단원에서 장비 산업 전체의 지도를 그렸다면, 이제는 그 지도 위의 장비를
하나씩 열어 볼 차례예요. 첫 두 정거장은 웨이퍼가 태어나는 <strong>웨이퍼
제조 장비</strong>와, 그 위에 회로의 첫 그림을 찍는 <strong>포토리소그래피
장비</strong>예요. 두 공정의 화학과 원리는 이미 책 <ChapterRef order={5} />와
<ChapterRef order={8} />에서 다뤘으니, 여기서는 그 원리를 실제로 돌리는
<strong>장비의 몸</strong>에 집중해요.

## 1. 실리콘을 키우는 장비 — 초크랄스키(CZ)와 플로트존(FZ)

실리콘 웨이퍼의 출발점은 원기둥 모양의 잉곳이에요. 잉곳을 키우는 방법은
두 가지이고, 장비 구조부터 서로 달라요.

<CompareCards
  caption="실리콘을 키우는 두 장비"
  columns={[{ title: '초크랄스키(CZ)', tone: 'accent' }, { title: '플로트존(FZ)' }]}
  rows={[
    { aspect: '원리', values: ['도가니에서 녹인 실리콘에 시드를 담가 끌어올린다', 'RF 코일로 부분 가열하며 이동시켜 재결정화'] },
    { aspect: '순도', values: ['도가니 접촉으로 한계가 있다', '도가니를 쓰지 않아 고순도'] },
    { aspect: '지름', values: ['대구경화에 유리', '키우기 어렵다'] },

| 구분 | 초크랄스키(CZ)법 | 플로트존(FZ)법 |
|---|---|---|
| 도가니 | 금속 도가니에 원료를 녹여 사용 | 도가니 없이 열선(RF 코일)으로 일부만 녹임 |
| 가열 방식 | 도가니 전체를 약 1,500℃로 가열 | 잉곳 아래부터 폭 약 1.5cm만 녹여 올림 |
| 속도 | 성장 속도 0.5~3mm/min, 회전 속도 20~120rpm | 녹는 구간만 서서히 이동시키며 성장 |
| 분위기 | 아르곤(Ar) 분위기 | 아르곤(Ar) 보호가스 |
| 강점 | 대량 양산에 적합한 표준 방식 | 도가니 오염이 없어 고순도, 주로 소구경에 사용 |

CZ법은 종자(seed) 결정을 녹은 실리콘에 담근 뒤 도가니와 반대 방향으로
서서히 돌리면서 끌어 올려 원기둥 잉곳을 만들어요. FZ법은 도가니 접촉
자체가 없어 불순물이 섞일 통로가 적고, 그만큼 더 순도 높은 결정을 얻을 수
있어요. 정비 기술자에게는 이 차이가 곧 점검 포인트의 차이예요 — CZ 장비는
도가니·회전축·인상 기구를, FZ 장비는 RF 코일과 정밀 이송 기구를 주로
들여다봐요.

## 2. 잉곳을 웨이퍼로 — 가공 장비 5종

잉곳 하나를 500~700㎛ 두께로 낱장 절단해 웨이퍼로 만드는 과정을
웨이퍼링(wafering)이라고 해요. 이 과정에 쓰이는 장비 다섯 가지를 순서대로
보면 다음과 같아요.

| 순서 | 장비 | 하는 일 |
|---|---|---|
| 1 | 다이아몬드 연삭기 | 잉곳 표면을 매끄럽게 갈고, 결정 방향을 표시하는 기준면을 만듦 |
| 2 | 와이어 톱 | 잉곳을 낱장 웨이퍼로 절단하고, 가장자리를 매끄럽게 래핑 |
| 3 | 식각조 | 절단 과정에서 생긴 표면 손상을 약 10㎛ 깊이로 제거 |
| 4 | CMP 장비 | 화학적 연마제와 기계적 마찰로 표면을 평탄화 |
| 5 | 웨이퍼 검사기 | 세정 후 결함·이물질·형상·평탄도를 최종 확인 |

정비 기술자가 가장 자주 갈아 끼우는 소모품은 다이아몬드 연삭기의
<strong>다이아몬드 숫돌</strong>과 와이어 톱의 <strong>와이어</strong>예요.
숫돌이 무뎌지면 기준면 가공 정밀도가 떨어지고, 와이어가 끊어지면 웨이퍼
한 장이 통째로 못 쓰게 돼요. 3단계 식각조는 불산(HF)-질산-초산을 섞은
식각액으로 표면을 깎는데, 이 화학 처리 이후에는 반드시 CMP·검사 단계로
이어져요.

## 3. 웨이퍼 품질검사 — 무엇을, 어떻게 재나

가공이 끝난 웨이퍼는 반도체 전공정에 들어가기 전 여러 항목을 검사받아요.
대표적인 검사 항목은 다음과 같아요.

| 검사 항목 | 사용 장비 |
|---|---|
| 표면 결함 | 육안·광학 검사 |
| 평탄도 | 레이저·광학 측정 장비 |
| 두께 | 엘립소미터·프로파일러 |
| 부유 입자(파티클) | 파티클 카운터 |
| 결정 방향·구조 | XRD |
| 전기적 특성 | 면저항 측정기 |

여기서 걸러내지 못한 결함은 이후 여러 전공정을 다 거친 뒤에야 드러나기
때문에, 웨이퍼 단계의 검사는 손실을 가장 싸게 막는 지점이에요. 웨이퍼는
품질에 따라 <strong>프라임</strong>(실제 양산에 투입), <strong>테스트</strong>
(공정 이상 유무를 미리 점검), <strong>더미</strong>(프라임 웨이퍼를 앞뒤로
보호), <strong>재생</strong>(폐기 웨이퍼를 재생) 네 등급으로 나뉘어요. 이 중
테스트·더미 웨이퍼는 정비 기술자가 장비 이상 유무를 점검하거나 새 레시피를
시험할 때 먼저 태우는 웨이퍼예요.

## 4. 포토 공정 장비 둘 — 트랙과 노광기

포토 공정은 감광액 도포 → 노광 → 현상 → 검사 순으로 진행돼요. 이 흐름을
두 종류의 장비가 나눠 맡아요.

### 트랙 장비 — 코팅과 현상을 한 몸에

| 구성부 | 역할 |
|---|---|
| 스핀부 | 감광액 코팅과 현상 처리 |
| 베이크부 | 핫플레이트로 열처리(소프트베이크 약 100℃·30초, 하드베이크 120~150℃·10~20분) |
| 냉각 처리부 | 베이크 후 웨이퍼 온도를 낮춤 |
| 필터·노즐부 | 보조 약액과 초순수를 공급 |
| 로봇부 | 웨이퍼를 이송·수납 |
| 카세트 색인부 | 웨이퍼 카세트를 입출고 |

감광액을 입히기 전, 웨이퍼 표면에는 HMDS(헥사메틸디실라젠) 증기를 살짝
씌워요. 웨이퍼와 감광막 사이의 접착력을 높이는 처리인데, 이 처리를
건너뛰면 감광막이 쉽게 벗겨져 다음 공정에서 문제가 생겨요.

### 노광 장비 — 빛으로 패턴을 옮기다

노광 장비는 광원·렌즈·조리개로 이루어진 <strong>조명계</strong>, 마스크를
장착하는 <strong>레티클 스테이지부</strong>, 웨이퍼를 올리는
<strong>웨이퍼 스테이지부</strong>, 정렬 상태를 확인하는 <strong>측정부</strong>로
구성돼요. 방식에 따라 이름이 갈려요.

| 종류 | 특징 |
|---|---|
| 스테퍼(stepper) | 사진기처럼 레티클 단위로 한 장씩 노광 |
| 스캐너(scanner) | 복사기처럼 레티클을 훑으며 연속 노광 |
| 마스크 얼라이너 | 웨이퍼와 레티클의 위치를 정밀 정렬 |

노광에 쓰는 빛의 파장은 계속 짧아져 왔어요 — 365nm의 I-line에서 248nm의
KrF, 193nm의 ArF를 거쳐 지금은 13.5nm의 EUV(극자외선)까지 쓰여요. 파장이
짧을수록 더 미세한 회로를 그릴 수 있어요. 노광 장비 내부의 광학계·정렬
구조를 더 깊이 들여다보려면
<SourceRef source="hs-photo-etch" section="exposure-equipment" label="「반도체 포토·에칭」 노광 장비의 개요" />를,
트랙 장비의 웨이퍼 반송 흐름은
<SourceRef source="hs-photo-etch" section="track-equipment" label="「반도체 포토·에칭」 트랙 장비의 구조와 기능" />를
참고하세요.
