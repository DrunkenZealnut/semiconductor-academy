설계</strong>를 다뤄요. 둘 다 아직 부품 하나 조립되지 않은 단계지만, 여기서 내리는 결정이 장비의
성능·신뢰성·유지 보수성 대부분을 사실상 정해 버려요. 그래서 이 단원은 화면을 조작하는 법이 아니라
<strong>"무엇을 어디에, 왜 그렇게 놓는가"</strong>라는 결정의 논리를 따라가요.

## 1. 장비가 태어나는 네 단계 — 콘셉트에서 양산까지

이 교과서 Ⅳ단원은 장비 한 대가 세상에 나오기까지의 과정을 <strong>콘셉트 → 설계 → 조립·평가 →
양산</strong>이라는 네 단계로 그려요.

<SourceRef source="hs-equipment-maintenance" section="industry-trend" label="「반도체 장비 유지 보수」 반도체 장비 산업과 개발 직무" />에서 이미 장비 개발을 사양 검토 → 설계 개발 → 조립 제작 → 검증 → 설치·유지 보수라는 5단계로 본 적이 있는데, 이번 네 단계는 그중 앞부분(사양 검토·설계 개발)을 훨씬 촘촘하게 들여다보면서 뒷부분(조립 제작 이후)까지 프로젝트 하나의 흐름으로 다시 훑는 버전이에요.

| 단계 | 하는 일 |
|:-:|---|
| ① 콘셉트 설계 | 고객 요구 파악 → 장비 사양 미팅 → 장비 콘셉트 수립. 이 모듈 앞부분의 주제예요 |
| ② 장비 설계 | 전체 레이아웃 결정 → 분야별(기구·전장·소프트웨어) 모듈 설계 → 상세 설계. 기구 설계가 이 단계를 다뤄요 |
| ③ 조립·평가 | 부품 검수 → 기구·전장 조립 → 모듈 평가·통합 → 연동 테스트 |
| ④ 양산 | 설치·셋업 → 가동·테스트 → 유지 보수 대응 |

①과 ②(특히 기구 설계 부분)가 이 모듈의 주제이고, ③과 ④는 각각 Ⅲ 요소 기술 단원과 Ⅴ 장비 관리
단원에서 더 자세히 다룰 내용이라 여기서는 큰 흐름만 짚을게요.

<strong>조립·평가</strong> 단계는 입고된 부품을 도면과 <strong>BOM(Bill of Materials, 자재 명세표
— 무엇을 몇 개, 어떤 규격으로 쓸지 정의하는 문서)</strong>에 따라 검수하는 데서 시작해요. 검수를
통과한 부품은 기구 조립(프레임·체임버·로봇·진공/가스/냉각 유닛)과 전장 조립(전원 공급 장치·제어
박스·센서·액추에이터·배선)으로 나뉘어 조립되고, 기능 단위 모듈로 평가받은 뒤 이송 모듈(TM)과 공정
모듈(PM) 단위로 통합돼요. 마지막으로 진공·가스·공압·전기 유틸리티를 모두 연결해 연동 테스트를
거쳐요.

<strong>양산</strong> 단계는 완성된 장비를 고객사에 들여보내는 과정이에요. 지정된 위치로 옮겨
프레임과 모듈을 정렬하고 전력·가스·진공·냉각수를 연결하는 <strong>훅업(hook-up)</strong> 작업을
거친 뒤, 장비의 초기 상태와 파라미터를 복원하는 <strong>백업(B/U; Back Up)</strong> 절차를 밟고
시험 가동으로 성능을 검증해요. 가동이 시작된 뒤에는 정해진 주기로 점검·부품을 교체하는{' '}
<strong>예방 정비(PM; Preventive Maintenance)</strong>와, 문제가 생겼을 때 즉시 수리하는{' '}
<strong>사고 정비(BM; Breakdown Maintenance)</strong>로 장비를 지켜요 — 이 둘은 뒤에 나올 Ⅴ 장비
관리 단원의 핵심 주제예요.

## 2. 콘셉트 설계 — 고객의 말을 장비의 사양으로

콘셉트 설계는 세 걸음으로 진행돼요.

- <strong>고객 요구 사항 파악</strong> — 영업팀과 공정팀이 고객사와 미팅해 공정 사양·특이 사항 같은
  요구를 파악해요. 여기서 확보하는 정보는 공정 조건, 성능 목표, 설치 환경, 운영상 제약 등이에요.
  교과서는 이 고객의 요구를 <strong>프로세스 랭귀지(process language)</strong> — 공정 사양과
  조건을 표현하는, 고객사가 제안한 공정 내용 — 라고 불러요.
- <strong>장비 사양 미팅</strong> — 장비 개발자들이 모여 그 공정 조건을 하드웨어 관점으로 옮겨요.
  이렇게 만들어지는 게 <strong>하드웨어 랭귀지(hardware language)</strong> — 고객 요구를 구현할
  장비 구조와 부품 사양을 표현한 설계 내용이에요. 구조·기능·주요 모듈 구성·부품 사양·안전성·유지
  보수성까지 함께 검토해요.
- <strong>장비 콘셉트 설계</strong> — 앞의 내용을 종합해 장비의 기본 구조와 레이아웃, 핵심 기능
  구현 방법을 제시해요. 이게 이후 상세 설계 단계의 기준이 돼요.

콘셉트 설계 전체를 한마디로 줄이면 <strong>"고객의 말(프로세스 랭귀지)을 장비의 설계 언어(하드웨어
랭귀지)로 번역하는 일"</strong>이에요. 이 번역이 실제로 어떻게 이뤄지는지 조금 더 들여다볼게요.

<strong>공정 요구 사항 분석</strong>에서는 고객과의 협의 내용을 프로세스 랭귀지로 정리해요 — 필요한
가스 종류와 흐름, 에너지 공급 방식(열·플라스마), 반응 조건, 생성되는 박막의 종류(실리콘막·산화막·질화막·금속막
등), 부산물 처리 방식 같은 것들이에요. 이로부터 장비가 갖춰야 할 기능적 요구 사항 네 가지를
뽑아내요.

| 기능 요구 사항 | 내용 |
|---|---|
| 반응 환경 조성 | 온도·압력·가스 분위기를 제어한다 |
| 에너지 공급 | 열·플라스마·이온 빔 등 공정별 에너지를 제공한다 |
| 물질 이송 | 반응물을 공급하고 생성물·부산물을 배출한다 |
| 반응 제어 | 공정 시간·순서·조건 변화를 관리한다 |

이어지는 <strong>장비 하드웨어 사양 정의</strong>에서는 이 기능들을 실제 구성 요소로 바꿔요 —
프로세스 체임버 구조, 가스 주입 장치(샤워 헤드), 플라스마 발생 장치(RF 파워), 웨이퍼 가열 장치,
압력 제어, 배기 라인 같은 것들이에요. 그리고 기구·전장·소프트웨어 세 분야의 엔지니어가 모여 이
기능들을 어떤 부품과 방식으로 구현할지 나눠 맡아요.

| 분야 | 맡는 일 |
|---|---|
| 기구 | 물리적 구조, 가스·유체 흐름, 열 관리 |
| 전장 | 전원 공급, 센서 신호 처리, 액추에이터 제어 |
| 소프트웨어 | 시퀀스 제어, 파라미터 관리, 안전 로직 |

이렇게 만들어진 하드웨어 랭귀지가 실제로 어떤 모습인지, 교과서에 실린 PE-CVD(플라스마 화학 기상
증착) 장비 한 대의 예시 사양표를 볼게요. PE-CVD는 「반도체 산업의 유해인자」<ChapterRef order={10} />가 다루는 증착 공정 가운데, 플라스마의 도움으로 비교적 낮은 온도에서도 막을 입히는 방식이에요. 아래 표는 어디까지나 교과서에 실린 하나의 예시 사양일 뿐이라는 점을 기억해 두세요 — 실제 장비마다 세부 값은 다르게 정해져요.

| 구분 | 항목 | 사양 |
|---|---|---|
| 적용 대상 | 공정 / 웨이퍼 | PE-CVD / 6인치(150 mm) |
| 장비 규격 | 크기 / 무게 | 680×845×2040 mm / 300 kg |
| 장비 사양 | 플라스마 발생 방식 | CCP(용량 결합형) |
| 장비 사양 | 플라스마 밀도 | 약 10¹⁰개/cm³ (전자 에너지 1~3 eV) |
| 장비 사양 | 고주파 발생기 / 정합기 | 13.56 MHz·300 W / Auto(VVC, P-Type) |
| 장비 사양 | RF 케이블 | RG214(N-Type) |
| 제어 사양 | 제어용 컴퓨터 / PLC / HMI | 산업용 PC / 산업용 PLC / 터치패널 HMI |
| 부대 사양 | 전원 | 220 V·20 A·1상·60 Hz |
| 부대 사양 | 공압 | 2~7 bar, Φ8 튜브, 23 L/min |
| 부대 사양 | 진공 | -100~100 Pa, NW25 플랜지 |
| 부대 사양 | 가스 | O₂/N₂ 0~500 sccm, 레귤레이터 1차 4 bar → 2차 2 bar |

이 표 하나가 "고객이 원하는 막을 만들려면 이런 방전 방식, 이런 전력, 이런 진공도, 이런 유틸리티가
필요하다"는 하드웨어 랭귀지의 실제 얼굴이에요. 프로세스 랭귀지가 "이런 막을 만들어 주세요"라는 한
문장이라면, 하드웨어 랭귀지는 이렇게 숫자로 못 박힌 사양표예요.

## 3. 콘셉트를 고르는 법 — 아이디어에서 최종 선정까지

같은 요구 사항이라도 하드웨어 사양이 하나로만 정해지는 건 아니에요. 여러 콘셉트로 풀 수 있어서,
그중 가장 나은 하나를 고르는 절차가 필요해요.

<strong>기술 동향 분석</strong>은 두 방향으로 진행돼요. 공정 로드맵과 장비 기술 로드맵을 분석해
앞으로 어떤 기능·성능이 발전할지 살피고(특허·논문·산업 보고서 조사, 타사 기술 수준·장비 사양
벤치마킹 포함), 반도체 시장의 기술 발전 방향과 고객사들의 미래 요구 사항도 함께 조사해요.{' '}
<strong>로드맵(road map)</strong>이란 기술·제품이 앞으로 어떤 방향으로 발전·변화할지 단계별로
정리한 계획을 말해요.

이렇게 모은 정보로 <strong>콘셉트를 도출</strong>해요. 공정 엔지니어와 기구·전장·소프트웨어
엔지니어가 함께 모여 <strong>브레인스토밍(brainstorming)</strong> — 비판 없이 자유롭게 아이디어를
내는 기법 — 으로 요구 기능과 구현 방법을 논의하고, 고객 요구와 비교해 기술적·기능적 적합성을
검토해요. 이 과정에서 나온 아이디어들을 구체화해 여러 개의 콘셉트 대안으로 발전시켜요.

대안들은 두 가지 잣대로 <strong>평가</strong>받아요.

| 평가 | 보는 것 |
|---|---|
| 기술성 평가 | 기술적으로 실현 가능한가 |
| 경제성 평가 | 영업팀·경영진 회의에서 제작 가능성, 납기 준수, 원가 경쟁력, 유지 보수성, 회사 수익성 기여도를 검토한다 |

기술적 요구와 사업성을 모두 충족한 콘셉트가 <strong>최종 선정</strong>되면, 이 결과가 이후 상세
설계의 기준이 돼요. 콘셉트를 도출하고 평가하는 과정을 몇 번이고 반복하며 피드백을 주고받을수록
콘셉트의 완성도가 높아지고, 이는 최종 장비의 성능·경쟁력과 곧바로 연결돼요.

## 4. 콘셉트를 그림으로 — 스케매틱에서 시뮬레이션까지

확정된 콘셉트는 아직 문장과 사양표일 뿐이에요. 이걸 실제로 만들 수 있는 도면과 모델로 바꾸는 절차가
이어져요.

<strong>스케매틱(schematics) 작성</strong> — 확정된 장비 사양을 바탕으로 개략도를 그려요.
스케매틱은 장비의 주요 구성 요소, 전원·신호 흐름, 제어 로직, 유틸리티 연결 구조를 개략적인 기호와
선으로 나타낸 도면으로, 장비의 기능적 관계와 작동 원리를 한눈에 보여주는 이후 설계의 참조 기준이
돼요.

<strong>3차원 모델링(3D modeling)</strong> — 스케매틱을 바탕으로 장비의 전체 레이아웃을 설계해요.
모듈 배치, 부품 간 간섭 여부, 배선·배관 경로, 유지 보수 공간 확보 같은 것들을 검토하며 3D CAD를
수행하고, 이렇게 만들어진 3D 모델은 실제 제작 시의 형태·구조를 미리 보여주면서 제작 가능성과 설치
용이성을 사전에 확인하게 해줘요.

<Callout type="info" title="3D CAD 자체의 개념이 궁금하다면">
  좌표계, 도면층, 스케치 기반 형상 명령·참조 요소 기반 명령 같은 3D CAD의 공통 개념은 <SourceRef source="hs-basic-tech-2" section="cad-drafting" label="「반도체기초기술2」 컴퓨터를 이용한 제도" />에서 다뤘어요. 손 스케치가 좌표값을 가진 도면으로, 그 도면이 다시 여기서 본 3D 모델로 확장되는 과정이 바로 이 흐름이에요.
</Callout>

<strong>기능 시뮬레이션(function simulation)</strong> — 3D 모델이 완성되면 상세 설계에 앞서 가상
환경에서 장비의 동작·성능을 검증해요. 분야마다 보는 것이 달라요.

| 분야 | 시뮬레이션 내용 |
|---|---|
| 기구 설계 | 구조 강도 해석, 열 해석, 진동 해석 |
| 전장 설계 | 전원 안정성, 전자파 간섭(EMI), 인터로크 회로 동작 |
| 소프트웨어 | 제어 시퀀스, 동작 시나리오, 안전 로직 시험 |

이 단계에서 설계 결함을 조기에 발견할수록 나중에 드는 수정 비용과 시간을 아낄 수 있어요.

<strong>설계 최적화(design optimize)</strong> — 모델링·시뮬레이션에서 드러난 문제점을 상세 설계로
넘어가기 전에 미리 보완해요. 이 반복이 장비의 완성도를 높이고 개발 중 위험 요소를 줄여줘요.

## 5. 기구 설계란 — "어디에 무엇을 놓을지" 정하는 일

여기부터는 <strong>기구 설계</strong> — 콘셉트와 사양으로 정해진 내용을 실제 공간에 배치하는
일이에요. 기구 설계는 장비의 성능과 신뢰성을 결정짓는 핵심 단계로, 장비 레이아웃·모듈 배치·배선과
배관 경로 같은 요소를 공간 효율성과 구조 안정성이 함께 높아지도록 배치해야 해요. 순서대로 보면 팹
안에서 장비가 놓일 자리, 장비 안에서 웨이퍼가 지나가는 길, 장비를 돌리는 숨은 시스템, 그 모든 걸
지지하는 뼈대 순으로 좁혀 들어가요.

## 6. 팹 안의 자리 — 클린룸과 상하부 플레넘

반도체 제조 장비는 <strong>팹(Fab; Fabrication)</strong> — 웨이퍼 가공 장비가 설치된 공장 —
안에서 효율적인 생산과 유지 보수를 위해 체계적으로 배치돼요. 장비 레이아웃은 클린룸 환경 유지,
유틸리티 공급 최적화, 작업자 접근성, 안전성을 모두 고려해 설계되는데, 메인 장비가 놓인 클린룸을
중심으로 상하부 <strong>플레넘(plenum)</strong>과 외부 배출 시스템이 유기적으로 연결되는 구조를
가져요.

| 공간 | 위치 | 놓이는 것 |
|:-:|---|---|
| 클린룸 | 중심 | 실제 공정이 이뤄지는 메인 장비. ISO Class 1~5 수준의 극청정 환경, 온도·습도·진동·전자기 환경을 엄격히 제어하고 필수 공정 장비만 배치해요 |
| 2층 플레넘 | 클린룸 상부 | 주전원 분배반(MPD)의 전력 공급, 칠러·열 교환기의 냉각수 시스템 등 유틸리티 분배 장비 |
| 1층 플레넘 | 클린룸 하부 | 진공 펌프류, 1차 스크러버, 가스 공급 장치, 배기 처리 설비 — 소음·진동이 큰 장비들 |
| 배기 시스템 | 옥외 | 메인 스크러버와 메인 덕트를 거쳐 배기가스를 안전하게 배출 |

플레넘은 클린룸의 "뒷받침 공간"이에요 — 전기·냉각수·가스 같은 유틸리티를 공급하거나 소음·진동이 큰
장비를 격리해서, 클린룸이 깨끗하고 조용하게 유지되도록 돕는 숨은 설비 공간이에요. 클린룸 안에
극청정 환경이 필요한 이유는 <strong>파티클(particle)</strong> — 웨이퍼 위에 떨어져 회로 결함을
유발하는 아주 미세한 먼지·이물질 — 때문이에요.

## 7. 웨이퍼의 길 — 이송 모듈

이송 모듈(TM; Transfer Module)은 웨이퍼를 각 공정 모듈로 빠르고 정확하게 전달하는 장치로, 장비
레이아웃 설계의 중심축이에요. 가장 널리 쓰이는 배치는 <strong>중앙 집중형 방식(cluster type
layout)</strong>이에요 — 이송 모듈에서 각 공정 모듈까지 접근 거리를 균등하게 유지해 웨이퍼 이송
시간을 최소화하고 로봇 팔의 동작 범위를 최적화하는 구조로, 보통 6개 이하의 공정 모듈이 이송 모듈
주변에 방사형으로 배치돼요. 이 구조를 구현한 것이 <strong>클러스터 툴 시스템(cluster tool
system)</strong>이에요.

웨이퍼는 이 시스템 안에서 다음 순서로 이동해요.

1. <strong>장비 전단 모듈(EFEM; Equipment Front End Module)</strong>이 풉(FOUP)을{' '}
   <strong>로드 포트 모듈(LPM)</strong>에 자동으로 도킹·언로딩해요.
2. EFEM 내부의 <strong>대기압 이송 로봇(ATR)</strong>이 웨이퍼를 <strong>얼라이너(aligner)</strong>로
   옮겨 평탄부(flat)나 노치(notch)를 기준으로 위치·방향을 맞춰요.
3. ATR이 웨이퍼를 <strong>로드 로크(L/L; Load Lock)</strong>로 옮기면, 로드 로크가 대기압과 진공
   사이 압력을 단계적으로 맞춰 완충해요. 처리량을 높이려고 보통 2개 이상을 설치해요.
4. <strong>진공 이송 모듈(VTM; Vacuum Transfer Module)</strong> 내부의 <strong>진공 이송
   로봇(VTR, 문헌에 따라 VDA·VR로도 표기)</strong>이 웨이퍼를 각 공정 모듈(PM)로 반송해요.

EFEM은 <strong>팬 필터 유닛(FFU; Fan Filter Unit)</strong>과 퍼지 가스로 청정 환경을 유지하고,
매핑·정렬 기능과 안전 인터로크(interlock)를 갖춰요. VTM은 이송 모듈 중앙부에서 로봇 팔의 회전·신축
동작 공간을 확보하고, 전용 진공 펌프와 직접 연결돼 독립적인 진공 환경을 유지해요. 클러스터 구조는
싱글 클러스터·트윈 클러스터·인라인 탠덤처럼 몇 가지 형태로 나뉘는데, 웨이퍼 처리량과 설치 공간에
따라 골라 써요.

## 8. 공정이 일어나는 곳 — 공정 모듈과 플라스마 체임버

공정 모듈(PM; Process Module)은 웨이퍼에 실제 반도체 공정을 수행하는 핵심 장치로,{' '}
<strong>플라스마 체임버(plasma chamber)</strong>를 중심에 두고 여러 서브 시스템이 기능적으로
배치돼요. 상부와 하부가 맡는 역할이 뚜렷이 나뉘어요.

| 위치 | 구성 | 역할 |
|:-:|---|---|
| 상부 | 상부 전극(샤워 헤드) + RF 매칭 박스 + 가스 공급 장치 | 공정 가스를 균일하게 분사하고 RF 전원을 인가해 플라스마를 형성한다 |
| 하부 | 하부 전극(정전 척, ESC or Heater) + 터보 분자 펌프(TMP) + 드라이 펌프 | 웨이퍼를 정전력으로 고정·가열하고, 체임버 내부를 고진공으로 유지한다 |

<strong>정전 척(ESC; Electrostatic Chuck)</strong>은 정전력으로 웨이퍼를 붙잡는 동시에 히터로 열을
공급하고 냉각 가스로 온도를 조절하는, 웨이퍼와 가장 가까이 붙어 있는 부품이에요. 진공 시스템은
터보 분자 펌프를 체임버 바로 아래에 직결해 컨덕턴스(기체가 흐르는 능력)를 최대화하고, 드라이 펌프는
PM 바깥 하단에 따로 둬서 소음·진동을 체임버에서 떼어놔요. 압력은 대기압 근처부터 낮은 진공까지는{' '}
<strong>컨벡트론 게이지</strong>로, 더 정밀한 저·중진공 영역은 <strong>바라트론 게이지</strong>(약
10⁻⁴ Torr까지 측정하는 정전 용량 다이어프램 방식 센서)로 나눠 측정해요.

가스는 <strong>가스 매니폴드</strong>를 중심으로 좌우에 <strong>질량 유량 제어기(MFC; Mass Flow
Controller)</strong> 뱅크를 대칭 배치해 여러 가스를 정밀하게 섞고 나눠요. 밸브와 MFC를 한데 묶어
이상 발생 시 자동으로 차단하는 블록을 <strong>IGS 블록</strong>이라고 불러요.

플라스마를 만들려면 전력도 필요해요. <strong>고주파 전원 시스템(RF power system)</strong>은
발생기(RF generator)·정합기(matcher)·센서·필터·케이블로 구성되는데, 발생기가 만든 전력은 동축
케이블을 타고 매칭 박스로 가고, 매칭 박스는 <strong>임피던스 정합(impedance matching)</strong>으로
반사 전력을 최소화한 뒤 상·하부 전극에 전력을 흘려보내요. 전원과 부하의 임피던스가 어긋나면 전력
일부가 튕겨 나와(반사 전력) 플라스마가 불안정해지고 장비가 상할 수 있어서, 매칭 박스가 가변
커패시터·인덕터로 이 값을 실시간으로 맞춰줘요. 교과서는 HF 발생기(13.56 MHz·3 kW)와 LF
발생기(370 kHz·1 kW)를 각각 케이블(RG393, RG214)로 매칭 박스에 연결하는 예를 들어요 — RF 발생기는
보통 PM 하부에, 매칭 박스는 체임버 측면 상부에 둬서 케이블 길이를 최소화하고 전송 손실을 줄여요.

## 9. 장비를 돌리는 숨은 시스템 — 유틸리티

<strong>유틸리티(utility)</strong>는 장비가 정상 작동하는 데 필요한 모든 보조 시스템을 통틀어요 —
전력, 가스, 냉각수, 진공, 압축 공기 같은 자원을 안정적으로 공급하는 역할이에요. 장비로 들어오는{' '}
<strong>공급 매체</strong>와 장비 밖으로 나가는 <strong>배출 매체</strong>로 나눠 볼 수 있어요.

공급 시스템은 네 가지예요.

- <strong>가스 공급 시스템(gas delivery system)</strong> — 공정 가스·퍼지 가스·캐리어 가스를 정밀
  제어해 공급해요. 가스 캐비닛에서 고압가스 실린더를 안전하게 보관하고 1차 압력 조정을 하며, 설비
  단에서는 가스 박스와 통합 가스 시스템을 둬요.
- <strong>케미컬 공급 시스템(chemical supply system)</strong> — 세정 등 약액 공정에 쓰는 화학
  약품을 공급해요. <strong>화학 중앙 공급 시스템(CCSS; Chemical Central Supply
  System)</strong>이 산·알칼리·솔벤트 같은 고순도 화학 물질을 중앙에서 저장·공급·회수·정화해요.
- <strong>공압 시스템(CDA; Clean Dry Air)</strong> — 먼지·수분·오일을 제거한 압축 공기로, 밸브와
  액추에이터를 구동해요.
- <strong>물 공급 시스템</strong> — 웨이퍼 세정에 쓰는 초순수(DIW; De-Ionized Water)와, 장비
  과열을 막는 공정 냉각수(PCW; Process Cooling Water)로 나뉘어요.

처리 시스템 세 가지는 반대 방향으로 흘러요 — <strong>진공 장치</strong>(공정 진공·하우스 진공),{' '}
<strong>배기 장치</strong>(잔류 가스·폐가스를 규제치 이하로 처리해 대기로 배출),{' '}
<strong>배수 장치</strong>(폐수 배출)예요.

실제로 어떤 자원이 오가는지 교과서의 분류표를 간추리면 이래요.

| 구분 | 종류 | 예 | 쓰임새 |
|---|---|---|---|
| 가스 | 벌크 가스 | N₂, CDA | 체임버 퍼지, 밸브 구동 |
| 가스 | 공정 가스 | 공정마다 다른 반응 가스(예: HCl, He, SF₆, PH₃, H₂, O₂, CO₂ 등) | 반도체 공정별 화학 반응 |
| 가스 | 퍼지 가스 | Ar, N₂ | 공정 중 산화 방지 |
| 화학 물질 | 유기계 / 무기계 | 시너·아세톤·IPA 등 / 산·알칼리 | 공정 반응·세정 |
| 진공 | 공정 진공 / 하우스 진공 | — | 공정용 진공 / 클린룸 청소용 진공 |
| 물 | 초순수(DIW) / 냉각수(PCW) / 공업용수 | — | 세정 / 장치 냉각 / 1차 스크러버 가스 용해 |
| 전원 | 일반 / 비상 | 220 V·380 V / UPS | 정상 공급 / 정전 대비 |
| 배기·배수 | 배기(열·유기·독성 가스 계열) / 배수(폐액·폐수 계열) | — | 규제치 이하로 처리한 뒤 배출 |

여기 나오는 공정 가스는 종류에 따라 성질이 완전히 달라요 — 이 가스들을 안전하게 저장·공급·차단하는
법은 Ⅲ 요소 기술 단원의 진공·가스 공급 기술 부분에서 자세히 다뤄요. 이 단원에서는 "장비 설계가 이런
자원들의 자리를 미리 마련해 둬야 한다"는 정도로만 기억해도 충분해요.

## 10. 뼈대를 세우다 — 프레임과 주변부 지원 시스템

주요부(이송 모듈·공정 모듈)가 정해졌다면, 이제 그걸 실제로 세울 뼈대와 그 주요부가 힘을 낼 수 있게
뒷받침하는 <strong>주변부</strong>가 필요해요.

<strong>체임버 프레임(chamber frame)</strong>은 장비의 기본 골격과 외관을 이루는 구조로,
공정·이송·전단 모듈 같은 모든 내부 시스템을 지지하고 보호해요. 알루미늄 압출재를 조립하는 방식으로
만들어지는데, 재질은 주로 알루미늄(AL6061, AL5083)이나 스틸(SS400, SUS304)을 써요. 메인 프레임이
각 모듈의 무게와 진동을 안정적으로 지지하고, <strong>브래킷(bracket)</strong> —
부품·모듈·배관·전장품을 정해진 위치에 고정하는 연결용 금속 지지대 — 이 내부 모듈들을 정확한 자리에
붙잡아 줘요. 프레임 바깥은 외부 커버가 감싸는데, 전면·측면·상부에 모듈별 정비 요구에 맞춘 다양한
크기의 도어를 두고, 작업자 안전을 위해 모든 도어에 <strong>안전 인터로크(safety
interlock)</strong>를 적용해요 — 문이 열려 있으면 장비가 위험한 동작을 하지 않도록 막는 장치예요.

주변부 설계는 전력 공급과 온도 제어를 책임져요.

<strong>전력 공급 시스템</strong>은 일반 전력과 제어 전력으로 나뉘어요. 일반 전력은 히터·펌프·RF
발생기·칠러·송풍 팬처럼 큰 동력을 쓰는 장치에 공급되는데, 3상 208 VAC·60 Hz·400 A를 중성선 없는
3선에 접지선 1개를 더한 4선으로 배선해요. 제어 전력은 제어·모니터링 시스템에 공급되며 1상
208 VAC·60 Hz·60 A에 노이즈 차단 변압기를 더해 전력 품질을 높이고, 정전 시에도 끊기지 않도록
<strong>무정전 전원 장치(UPS; Uninterruptible Power Supply)</strong>로 백업해요.

<strong>온도 제어 시스템</strong>은 운전 중 생기는 열을 없애거나 필요한 곳을 데워서 각 부품이 적정
온도에서 움직이게 해요. 가열 방식은 두 갈래로 나뉘어요.

| 방식 | 원리 | 특징 | 쓰이는 곳 |
|---|---|---|---|
| 직접 가열 | 히터 열선의 열이 부품(웨이퍼·체임버 전극 등)에 곧바로 전달 | 응답이 빠르고 고온 구현이 쉽지만, 균일한 온도 분포가 어렵고 열 충격으로 부품이 상할 수 있음 | PE-CVD, RTP(급속 열처리) 등 수백 ℃ 이상 고온 공정 |
| 간접 가열 | 냉각수·열매체를 칠러나 열 교환기로 순환시켜 간접 조절 | 온도 범위는 좁지만 안정적이고 균일함, 응답은 느리고 구성이 복잡함 | 퍼니스, 건식 식각, 트랙, CMP 등 |

냉각은 강제 순환 팬으로 자연 대류를 촉진하는 <strong>공랭</strong> 방식과, 공정 냉각수(PCW)로 발열
부품을 식히는 <strong>수랭</strong> 방식을 함께 써요.
