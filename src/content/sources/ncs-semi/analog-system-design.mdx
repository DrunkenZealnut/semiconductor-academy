## 한 줄 요약

아날로그 회로 시스템 설계 = 시뮬레이션으로만 검증됐던 회로를 실제 보드에 얹어 전원을 넣고 측정하고
(1·2단계), 그 결과를 데이터시트·기능 모델·타이밍 파일로 정리해 "제품"으로 포장하고(3단계 IP
디자인 모델 설계), 마지막으로 더 큰 칩(SoC) 안에 꽂아 넣어 정전기 보호와 양산 시험, 수율 관리까지
통과시키는(4단계 시스템 설계) 네 걸음의 여정이에요. 이미 만난 아날로그 3부작 — 아키텍처를
설계하고, 트랜지스터 크기를 정해 회로를 그리고, 소자 레벨까지 시뮬레이션하는 모듈들 — 이 "회로를
어떻게 그리고 컴퓨터로 검증할까"를 다뤘다면, 이 모듈은 **그렇게 완성된 회로가 실제로 작동하는지
확인하고, 다른 팀·다른 칩에서도 재사용할 수 있게 만들어 양산까지 내보내는 마지막 관문**을 다뤄요.

## 1. 검증 보드를 만든다 — 시험 계획서에서 PCB까지

### 가. 무엇을 확인할지부터 문서로 남긴다

<Term id="semiconductor">반도체</Term> 설계에서 만든 회로 블록을 IP(Intellectual
Property)라고 불러요. IP가 SoC(System on Chip)에서 제 역할을 하려면 먼저 클럭·리셋·데이터 같은
입력 신호와 인에이블·모드 셀렉트 같은 제어 신호를 어떤 값으로 넣었을 때 어떤 출력이 나와야
하는지를 시험 계획서로 미리 적어 둬야 해요.

<SourceQuote section="NCS 학습모듈 — 아날로그 회로 시스템 설계: 1-1. 검증 환경 준비 (설계 IP 검증의 중요성)">
  <p>
    설계 IP(Intellectual Property)는 SoC(System on Chip)에서 핵심적인 역할을 하며, 정확한 기능
    구현이 필수적이다. IP의 기능이 예상대로 동작하는지 확인하기 위해서는 검증을 해야 한다. 검증을
    통해 IP의 성능, 신뢰성, 안정성을 확인하여, 시스템 통합 시 문제를 방지할 수 있다.
  </p>
</SourceQuote>

### 나. 회로를 실제 보드 위에 앉히다

시험 계획서가 준비되면 OrCAD·Altium Designer·KiCAD 같은 도구로 검증용 보드의 스키매틱을 그리고,
신호 무결성·전력 분배·열 관리를 고려해 부품을 배치하고 배선하는 PCB 아트워크 설계로 넘어가요.
이때 제조 가능성(DFM)과 테스트 용이성(DFT)을 함께 검토하고, 나중에 문제를 진단할 수 있도록 테스트
포인트도 미리 심어 둬요.

<Callout type="info" title="보드 하나에도 '성능'이 걸려 있다">
  검증 보드를 아무렇게나 만들면 안 돼요. 트레이스 길이·폭으로 임피던스를 맞추고, 전력 분배
  네트워크(PDN)와 접지 플레인을 제대로 구성하지 않으면 보드 자체의 노이즈가 IP의 진짜 성능을
  가려 버려요. 보드 설계가 시험 IP의 성능 열화를 유발하지 않는지 검토하는 것도 이 단계의 중요한
  일이에요.
</Callout>

보드를 조립할 부품은 전압·전류·주파수 같은 전기적 사양을 분석해 고르고, 주요 부품이 품절될 경우를
대비한 대체 부품도 미리 확보해요. 조립이 끝나면 오실로스코프·로직 분석기·멀티미터·전력 분석기 같은
계측 장비를 갖추고, 접지·케이블·실드로 노이즈를 줄인 뒤 장비를 정기적으로 캘리브레이션해야 측정값을
믿을 수 있어요.

## 2. 전원을 넣고 진짜로 확인한다 — 아날로그 회로 성능 검증

### 가. 열리거나 붙어 있지는 않은지부터

보드에 처음 전원을 인가할 때는 설계 의도와 다르게 회로가 끊어진(Open) 곳이나 엉뚱하게 붙어버린
(Short) 곳이 없는지부터 확인해요. 멀티미터로 저항을 재 오픈·쇼트를 가려내고, 오실로스코프로 각
노드의 전압 파형을 봐서 비정상적인 신호가 없는지 살펴요.

### 나. 모드를 바꿔 가며 측정하고, 시뮬레이션과 맞춰 본다

이상이 없으면 시험 계획서에 적어 둔 대로 모드 셀렉트 신호를 바꿔 가며 각 모드의 출력을
오실로스코프·스펙트럼 분석기·전력 분석기로 계측해요. 측정값이 성능 기준에 못 미치면, 시뮬레이션
결과와 실제 측정 결과를 나란히 놓고 어느 블록에서 성능이 열화됐는지를 찾아내요.

<SourceQuote section="NCS 학습모듈 — 아날로그 회로 시스템 설계: 2-1. 아날로그 회로 성능 검증 (성능 열화 분석)">
  <p>
    시뮬레이션 결과와 측정 결과 간의 차이를 분석하여, 성능 열화의 원인을 파악한다. 이는 부품의
    노화, 온도 상승, 전원 변동 등에 의해 발생할 수 있다.
  </p>
</SourceQuote>

원인이 된 블록을 찾으면 트랜지스터 크기나 바이어스 전류를 다시 조정해 회로를 고치고, 고친 회로를
다시 시뮬레이션·재측정해 피드백이 실제로 반영됐는지 확인해요. 마지막으로 칩 한 개가 아니라 여러
개를 측정해 평균값과 표준 편차 같은 통계 지표로 칩 간 성능 편차가 양산해도 괜찮을 수준인지 점검해요.

## 3. IP를 "제품"으로 포장한다 — 디자인 키트

### 가. 다른 팀이 그대로 가져다 쓸 수 있어야 한다

검증까지 마친 IP를 SoC 설계자나 고객에게 넘기려면 IP 혼자가 아니라 여러 파일을 묶은 <strong>
디자인 키트(Design Kit)</strong>로 만들어야 해요. 공정 파라미터를 담은 Technology
File(.tf), 셀의 형상·전기 정보를 담은 Cell Library(.lef), 설계 규칙 위반을 점검하는
DRC(.drc), 레이아웃과 회로도가 일치하는지 보는 LVS(.lvs), 전기적 동작을 시뮬레이션하는 SPICE
모델(.sp)까지가 기본 구성이에요. 여기에 전압·전류·지연 시간·핀 배치 같은 정보를 정리한
데이터시트를 더해요.

### 나. 코드로 기능을 재현한다 — Verilog 모델

IP를 실제 회로도 그대로 넘기지 않고, 하드웨어 기술 언어(HDL)인 <strong>Verilog</strong>로 기능만
따로 모델링해서 넘기기도 해요. wire는 신호선을, reg는 값을 저장하는 레지스터를 나타내고, 특정
신호나 조건이 바뀔 때마다 실행되는 always 블록으로 동기·비동기 회로의 동작을 정의해요. 복잡한
동작은 상태(state)와 상태 전이를 정의하는 스테이트 머신(FSM)으로 표현하고, 완성된 모듈은
테스트벤치로 입력을 넣어 예상 출력과 실제 출력이 맞는지 ModelSim·Synopsys VCS 같은 도구로
시뮬레이션해 검증해요.

### 다. 속도를 숫자로 넘긴다 — .lib 타이밍 파일

<SourceQuote section="NCS 학습모듈 — 아날로그 회로 시스템 설계: 3-1. IP 디자인 모델 설계 (.lib 파일 기본 개념)">
  <p>클럭 신호와 부하 커패시턴스에 따른 타이밍 정보를 제공하는 파일이다.</p>
</SourceQuote>

.lib 파일은 library 키워드로 시작해 라이브러리 이름과 65nm·28nm 같은 기술 노드 정보를 담고,
cell·pin·timing 블록마다 신호가 얼마나 지연되는지(전파 지연), 클럭이 오기 전에 데이터가 얼마나
안정돼 있어야 하는지(셋업 타임), 클럭이 지난 후에도 얼마나 유지돼야 하는지(홀드 타임)를 부하
커패시턴스 조건별로 정의해요. 이렇게 만든 타이밍 정보는 PrimeTime·Tempus 같은 정적 타이밍 분석
(STA) 도구로 검증한 뒤, SoC 설계자와 파일 목록·전달 일정·버전 관리까지 협의해 넘겨요.

## 4. 큰 칩에 꽂아 넣고 양산까지 — 시스템 설계

### 가. 이웃 블록과 제대로 이어졌는지 확인한다

디자인 키트를 넘긴 뒤에도 끝이 아니에요. IP의 넷리스트가 개발 중인 칩의 이웃 블록과 올바른 신호로
연결됐는지 시뮬레이션으로 논리 기능을 확인하고, GDS 레이아웃에서는 전원·입력 패드와 충분히
가까운지, 신호 레이어의 폭이 충분한지, 이웃 블록의 잡음이 넘어오지 않는지를 도면으로 직접
검토해요.

### 나. 정전기 한 방에 무너지지 않게 — ESD·EOS 보호

<SourceQuote section="NCS 학습모듈 — 아날로그 회로 시스템 설계: 4-1. 시스템 설계 (ESD 및 EOS 보호 설계)">
  <p>
    정전기적으로 충전된 물체가 접지된 물체나 다른 전위가 있는 물체와 접촉하게 되면, 높은 전위차로
    인해 전하가 급격히 방전되어 ESD가 발생한다. ESD는 짧은 시간 동안 매우 높은 전압과 전류를
    발생시킬 수 있으며, 민감한 전자 소자에서는 미세한 회로를 손상시키거나 소자를 파괴할 수 있다.
  </p>
</SourceQuote>

입력·전원 핀 사이에 다이오드를 역방향으로 배치한 보호 회로를 넣어, 정전기 방전(ESD)이나 전기적
과부하(EOS)가 들어오면 전류를 안전하게 우회시켜요. 사람 모델(HBM)·기계 모델(MM)·충전 장치 모델
(CDM) 같은 방식으로 보호 회로가 실제로 버티는지 테스트하고, 보호 회로 때문에 정상 신호가 왜곡되지
않는지도 함께 확인해요.

### 다. 공장 라인에서도 같은 성능이 나오는지 — 양산 시험과 수율

시험 모드별 초기 세팅값, 전원·클럭 인가 방법을 정의한 뒤에는 대량 생산 제품을 검사할 양산 시험
계획을 세워요. 자동화된 테스트 장비(ATE)로 −40℃~125℃ 같은 온도 범위와 0.9V·1.2V·1.8V 같은 전원
전압 범위에서 모든 칩을 일괄 검사해요.

| 검사 항목 | 대표 조건(예시) |
|---|---|
| 온도 범위 | −40℃ ~ 125℃ |
| 전원 전압 범위 | 0.9V, 1.2V, 1.8V |
| 검사 장비 | 자동화된 테스트 장비(ATE) |
| 검사 종류 | 자동 광학 검사(AOI), 불량 분석(FA), 전기적 시험(ET), 기능적 시험(FT) |

<div className="text-xs italic text-slate-500">출처: NCS 학습모듈 아날로그 회로 시스템 설계 — 4-1. 시스템 설계 (양산 시험 계획 수립, 수율 분석 및 품질 관리)</div>

양산 중 수율이 갑자기 떨어지면 파레토 차트·히스토그램으로 불량 유형을 시각화해 전기적 결함인지,
물리적 손상인지, 온도·습도 같은 환경 요인 때문인지를 가려내요. 이 원인이 측정 환경의 문제인지
제조 공정의 문제인지 실험으로 확인하고, 통계적 공정 관리(SPC)로 공정이 안정적인 상태를 유지하고
있는지 계속 지켜봐요.

## 이 일을 하는 사람은

시험 보드를 설계하고 부품을 갖추는 사람을 **보드 설계 엔지니어**, 전원을 넣고 모드별로 측정해
성능 열화의 원인 블록을 찾는 사람을 **검증 엔지니어**, IP를 데이터시트·Verilog 모델·.lib
파일로 포장해 다른 팀에 넘기는 사람을 **IP 패키징 엔지니어**, 넷리스트·GDS를 검토하고 ESD·EOS
보호와 양산 시험까지 책임지는 사람을 **시스템 통합 엔지니어**라 불러요. 회로를 그리는 일과 달리
이 단계는 "숫자로 증명하는" 일이라, 측정 장비를 다루는 손기술과 데이터를 읽는 눈이 함께
필요해요.
