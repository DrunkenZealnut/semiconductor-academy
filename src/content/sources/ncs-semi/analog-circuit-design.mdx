## 한 줄 요약

아날로그 회로 설계 = <Term id="semiconductor">반도체</Term> 칩 안에서 소리·전압처럼 연속적으로
변하는 신호를 다루는 회로를, 트랜지스터 하나 단위로 손수 그리고(1단계) 블록으로 엮고(2단계)
컴퓨터로 미리 돌려보고(3단계) 실제 배선까지 반영해 다시 확인한 뒤(4단계) 시제품을 만들어
측정하는(5단계) 다섯 걸음의 여정이에요. 「반도체 산업의 유해인자」<ChapterRef order={2} />가
"반도체 칩이 무엇인가"를 설명한다면, 이 모듈은 **그 칩 안에서 아날로그 신호를 다루는 회로를
어떻게 설계하고 검증하는가**를 다뤄요.

## 1. 트랜지스터 하나, 회로의 최소 단위

### 가. P형과 N형이 만드는 스위치 — PMOS와 NMOS

실리콘(Si)은 원자와 전자의 수가 4개로 같아 원래는 전기적으로 중성이에요. 여기에 3가 원자(붕소,
알루미늄, 인듐, 갈륨)를 넣으면 P형, 5가 원자(인, 비소, 안티모니, 비스무트)를 넣으면 N형
반도체가 되는데, 이렇게 불순물을 일부러 주입하는 과정을 <Term id="doping">도핑</Term>이라고
불러요. N형 반도체 기반에 P형 반도체 단자 2개를 얹으면 PMOS, 반대로 P형 기반에 N형 단자를 얹으면
NMOS 트랜지스터가 돼요. 두 단자를 각각 드레인·소스라 부르고, 그 사이 흐름을 조절하는 부분을
게이트라고 해요.

<ImageFigure
  src="/source-images/ncs/analog-circuit-design/_page_15_Figure_3.jpeg"
  alt="N형 반도체 위에 두 P형 단자를 얹은 PMOS 트랜지스터의 단면 구조도"
  caption="[그림 1-1] PMOS 트랜지스터 구조"

/>

게이트에 전압이 걸리지 않으면 드레인과 소스 사이는 막혀 전류가 흐르지 않아요. 그런데 게이트
전압이 특정 값(**문턱 전압**)을 넘으면 그 사이에 반대 성질의 채널이 생기며 전류가 흐르기
시작해요. 채널의 길이가 짧을수록 같은 회로를 더 작은 면적에 넣을 수 있고, 게이트 옥사이드 두께도
얇아져 스위치 속도가 빨라지고 전력 소모도 줄어요. 그래서 2000년대 초 130nm 수준이던 반도체
최소 공정은 지금은 20nm 전후까지 미세해졌어요.

  <p>
    아날로그 회로 설계의 가장 기본이 되는 소자로써, 가장 일반적인 종류로는 접합형
    트랜지스터(BJTs: Bipolar Junction Transistors)와 전계 효과 트랜지스터(FETs: Field Effect
    Transistors)로 구분할 수 있다.
  </p>
</SourceQuote>

### 나. 회로를 그리기 전에 챙겨야 할 문서와 패키지

본격적으로 회로를 그리기 전에 세 가지 문서가 필요해요. 개발 목표와 성능 기준을 적은
**설계 규격서**, 트랜지스터·저항·커패시터 같은 소자들의 특성을 기술한 **모의실험 모델 특성
문서(Spice Model Parameter)**, 레이아웃 시 최소·최대 선폭 같은 제약을 정리한 **도면 설계
규칙서(Design Rule)**예요. 완성된 회로는 언젠가 하나의 <Term id="wafer">웨이퍼</Term> 위에서
칩으로 잘려 나오는데, 이 칩은 외부 충격에 매우 약해서 반드시 패키지로 감싸야 해요.

<ImageFigure
  src="/source-images/ncs/analog-circuit-design/_page_18_Picture_0.jpeg"
  alt="IC칩과 리드프레임, 패드가 PCB보드에 연결되는 패키지 구조 예시도"
  caption="[그림1-3] 패키지 기본 구조"
  source="NCS 학습모듈 「아날로그 회로 설계」(LM1903060103_14v3) · 교육부·한국산업인력공단"
/>

패키지는 완성된 집적회로(IC) 칩, 칩과 패키지 핀을 잇는 입출력(IO) 패드, 마지막으로 칩과
PCB 보드를 연결하는 리드 프레임으로 이루어져요. 리드 프레임과 본딩 와이어의 길이가 길어질수록
의도하지 않은 저항·리액턴스·커패시턴스 같은 **기생 성분**이 생기는데, 이걸 미리 모델링해 설계
조건에 반영해야 완성된 칩의 성능이 흔들리지 않아요.

<Callout type="info" title="정전기(ESD)와 싸우는 IO 패드">
  아날로그 회로 대부분은 3.3V나 1.0V 이하의 작은 전압에서 동작해요. 그런데 사람이나 장비에서
  순간적으로 발생하는 정전기가 회로에 인가되면 트랜지스터의 절연막이 파괴될 수 있어요. 그래서
  외부와 연결되는 입력·전원 핀에는 다이오드를 이용한 정전기 보호회로를 갖춘 IO 패드를 사용해요.
</Callout>

## 2. 큰 그림에서 작은 소자까지 — 계층적 설계

수억 개의 트랜지스터가 들어가는 칩을 처음부터 소자 하나하나로 그릴 수는 없어요. 그래서 대규모
설계는 큰 그림에서 작은 소자로 좁혀가는 세 단계로 나뉘어요.

    동일한 블록은 동일 이름을 사용) 해당 블랙박스의 포트를 결정한다.
  </p>
</SourceQuote>

블랙박스 단계에서 큰 방향을 잡았다면, 인버터·낸드·노어 같은 심볼로 논리를 표현하는
**게이트 수준 설계**를 거쳐, 마지막으로 트랜지스터의 폭(W)·길이(L)·핑거 수(m)까지 직접
입력하는 **트랜지스터 수준 설계**로 내려가요. 저항은 길이와 폭을, 커패시터는 겹치는 금속층의
면적을 조절해 값을 만들어요. 이때 중요한 게 **매칭**이에요. 마주보고 짝을 이루는 소자의 크기와
신호선 길이를 최대한 동일하게 맞춰야 잡음이 서로 상쇄되는데, 실제 제조 공정에서는 물질을 비스듬히
주입하기 때문에 대칭으로 보이는 두 소자도 도핑 농도가 미세하게 달라질 수 있어요. 그래서 중요한
소자 양옆에는 **더미(Dummy) 소자**를 배치해 이런 틀어짐을 미리 방지해요.

## 3. 진짜로 만들기 전에 컴퓨터 안에서 먼저 돌려본다 — 시뮬레이션

회로도를 문서 형태로 바꾼 것을 **네트리스트(Netlist)**라 불러요. 트랜지스터는 M, 다이오드는 D,
저항은 R, 커패시터는 C, 인덕터는 L로 시작하는 이름을 붙이고 뒤에 연결 노드와 크기를 적어요. 여기에
파운드리가 제공하는 **모델 파라미터**와 실험 조건을 적은 **테스트벤치**를 더하면 시뮬레이션을
돌릴 준비가 끝나요.

모델 파라미터는 공정 조건(Process)·전압(Voltage)·온도(Temperature), 줄여서 PVT 조건에 따라
소자 특성이 달라지는 걸 반영해요.

## 4. 레이아웃을 그린 뒤 다시 확인 — 포스트 시뮬레이션

회로도(Schematic)만으로 검증한 결과를 **프리 시뮬레이션**이라 불러요. 그런데 실제로 레이아웃을
그려 물리적인 배치와 배선까지 마치고 나면, 회로도에서는 보이지 않던 배선 저항·커패시턴스 같은
**기생 성분**이 새로 등장해요. 이렇게 물리적인 표준 셀 배치까지 반영해 뽑아낸 회로 정보를
**포스트 네트리스트**라 부르는데, 2차원 회로도였던 프리 네트리스트와 달리 3차원 배치를 기준으로
하기 때문에 기생 저항·커패시터 정보까지 함께 담겨요.

레이아웃 결과가 회로도와 실제로 일치하는지는 **LVS(Layout vs. Schematic)**로, 제조 공정의 규칙을
지켰는지는 **DRC(Design Rule Check)**로 확인해요. 그다음 **LPE(Layout Parasitic
Extraction)**로 기생 성분을 뽑아낸 포스트 네트리스트를 만들어 다시 시뮬레이션을 돌려요. 이
단계에서 가장 흔히 나타나는 문제는 차동(differential) 신호선의 왜곡과, 순간 전류가 몰리는
출력단의 전원 배선 폭 부족이에요. 실제로 흐르는 순간 전류량은 평균 전류량보다 3~4배 커질 수
있어서, 레이아웃 단계에서부터 여유 있게 배선 폭을 잡아 둬야 해요.

## 5. 시제품을 만들고 실제로 측정하기

설계와 시뮬레이션을 마쳤다고 끝이 아니에요. 완성된 칩을 패키지에 넣고, 이를 PCB 보드에 실장해
전원발생기·신호발생기·오실로스코프 같은 계측 장비로 실제 성능을 측정해요. 아날로그 패드와
디지털 패드는 각각 전원·그라운드·입력·출력 패드로 나뉘어 모두 8가지 종류로 구분할 수 있어요.

측정한 시료들의 결과는 두 가지 형태로 문제가 나타날 수 있어요. 평균값 자체가 성능 기준을
벗어나는 **평균 불량**은 즉시 개선이 필요한 신호예요.

    평균의 문제가 발생하는 경우는 샘플 시료의 측정값 평균이 성능 기준을 벗어나서 불량 시료가 다수
    발생하는 상황으로, 대 물량 양산 시 수율에 큰 영향을 미칠 수 있으므로 즉시 개선이 필요하다.
  </p>
</SourceQuote>

반대로 시료 대부분이 기준을 만족하지만 분포의 꼬리 쪽에서 불량이 나오는 **산포 불량**은 당장
재설계할 정도는 아니어도, 대량 생산 시 수율에 영향을 줄 수 있어 관리할지 재설계할지 판단해야
해요. 이런 통계적 판단을 위해 보통 30개 이상의 샘플을 무작위로 뽑아 평균과 산포 값을 확인해요.

## 이 일을 하는 사람은

트랜지스터 크기를 하나하나 조율해 회로도를 그리는 **아날로그 회로 설계자**, 그 회로를 물리적인
도면으로 옮기는 **레이아웃 설계자**, LVS·DRC로 결과를 검증하는 **검증 엔지니어**, 그리고 완성된
시제품을 PCB에 실장해 오실로스코프로 측정하는 **시험 엔지니어**까지, 여러 역할이 협업해야 칩
하나가 완성돼요. 반도체 공정 자체를 다루는 일은 아니지만, 자신이 그린 회로가 실제 웨이퍼 위에서
어떤 모습으로 구현되는지를 끊임없이 상상해야 하는 일이에요.
