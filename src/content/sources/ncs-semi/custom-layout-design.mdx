## 한 줄 요약

커스텀 레이아웃 설계 = 회로도를 물리적 도면으로 바꾸는 여러 방법 중, 자동화 툴에 맡기지 않고
설계자가 직접 트랜지스터·배선의 위치와 모양을 손으로 그려 넣는 실행 그 자체예요. 같은 시리즈의
다른 모듈이 "그리기 전에 무엇을 확인해야 하는가"(공정 분석)나 "다 그린 도면이 맞는가"(레이아웃
검증), "자동화 툴은 어떻게 대신 그리는가"(자동 배치 배선)를 다룬다면, 이 모듈은 그 사이에 있는
<strong>손으로 배치하고 배선하는 작업 그 자체</strong>를 다뤄요.

## 1. 기성복이냐 맞춤 정장이냐 — 레이아웃 설계 방법의 갈래

회로도가 완성되면 이걸 실제 칩으로 만들 물리적 도면, 즉 레이아웃으로 바꿔야 해요. 이때 쓸 수
있는 방법은 한 가지가 아니에요.

<SourceQuote section="NCS 학습모듈 — 커스텀 레이아웃 설계: 2-1. 레이아웃 방법 결정 (필요 지식 — 풀 커스텀 레이아웃 설계)">
  <p>정의: 모든 트랜지스터와 배선을 직접 설계하는 방법</p>
  <p className="mt-2">장점: 최대의 설계 유연성과 최적화 가능성, 최고의 성능과 최소의 전력 소모</p>
</SourceQuote>

표준 셀 레이아웃, 하프 커스텀 레이아웃, 아날로그 레이아웃, 혼합 신호 레이아웃까지 방법마다
정의와 장점이 달라요.

| 방법 | 정의 | 장점 |
|---|---|---|
| 표준 셀 레이아웃 | 기본적인 논리 게이트 및 플립플롭과 같은 디지털 회로의 표준 셀을 사용하여 설계 | 일관성 있는 설계, 빠른 설계 주기, 반복 가능한 성능 |
| 풀 커스텀 레이아웃 | 모든 트랜지스터와 배선을 직접 설계하는 방법 | 최대의 설계 유연성과 최적화 가능성, 최고의 성능과 최소의 전력 소모 |
| 하프 커스텀 레이아웃 | 표준 셀 레이아웃과 풀 커스텀 레이아웃의 혼합 형태 | 일부 모듈에서 커스텀 설계를 적용하면서도 표준 셀의 장점을 활용 |
| 아날로그 레이아웃 | 아날로그 회로의 특성을 고려한 레이아웃 설계 방법 | 높은 신호 무결성과 저 노이즈 특성 |
| 혼합 신호 레이아웃 | 디지털 및 아날로그 회로를 통합한 설계 방법 | 디지털과 아날로그 회로의 통합 설계 가능 |

이 중 자동화 EDA 툴에 배치·배선을 통째로 맡기는 방법은 따로 있고, 이 모듈은 설계자가 Cadence
Virtuoso 같은 레이아웃 편집기를 직접 열어 트랜지스터 레벨에서 배치·배선하는 풀 커스텀 방식을
중심으로 다뤄요.

## 2. 손으로 그리는 아홉 걸음 — 커스텀 레이아웃 수행

커스텀 레이아웃 수행은 아래 아홉 단계를 순서대로 밟아요.

**1. 공정 기술과 설계 규칙 파악** — 이 소자가 7nm·14nm·28nm 같은 어떤 공정에서 만들어질지 확인하고, 그 공정의 설계 규칙을 읽어요.

<SourceQuote section="NCS 학습모듈 — 커스텀 레이아웃 설계: 4-1. 커스텀 레이아웃 수행 (수행 순서 — 공정 기술 및 설계 규칙 파악)">
  <p>
    각 공정 기술마다 고유의 설계 규칙이 있다. 이러한 규칙은 배선 간격, 층간 두께, 최소 피치, 접촉
    크기, 트랜지스터 채널 길이 등과 관련된 규칙을 포함한다. 설계 규칙 책자(DRC: design rule
    check)를 참고하여 설계에 반영한다.
  </p>
</SourceQuote>

<Callout type="warning" title="규칙에는 마스크 정렬까지 포함돼요">
  공정 설계 규칙에는 배선 간격이나 크기뿐 아니라 <Term id="mask">마스크</Term> 정확성과
  오버레이(다른 층 간의 정렬 정확성)도 들어 있어요. 층마다 그린 도형이 조금이라도 어긋나면
  실제 칩에서는 층과 층이 맞지 않아 버려요.
</Callout>

**2. 소자 정의와 초기 배치** — NMOS·PMOS 트랜지스터, 커패시터, 저항 같은 소자의 종류를 정하고, 타이밍 요구 사항과 전력 분포를 고려해 대략적인 위치부터 잡아요.

<ImageFigure
  src="/source-images/ncs/custom-layout-design/_page_136_Figure_7.jpeg"
  alt="트랜지스터·커패시터 소자를 레이아웃 도면에 대략 배치한 초기 구상도"
  caption="[그림 4-1] 커스텀 레이아웃의 초기 소자 배치 개념도"
  source="NCS 학습모듈 「커스텀 레이아웃 설계」(LM1903060131_23v5) · 교육부·한국산업인력공단"
/>

**3. 레이아웃 설계** — 소자를 규칙에 맞춰 배치하고, 전력·그라운드 배선으로 안정적인 전원을 확보하고, 타이밍을 맞추는 클럭 신호 배선과 외부 신호를 잇는 입출력(IO) 배선까지 그려요.

**4. 설계 규칙 검사(DRC)** — 배선 간격·접촉 크기·층 간 간격이 규칙을 지켰는지 확인하고, 위반이 사라질 때까지 고쳐요.

**5. 레이아웃 최적화** — 면적을 줄이고, 신호 지연을 최소화하도록 배선 경로를 조정하고, 전력 게이팅 같은 저전력 기법으로 소모 전력을 낮춰요.

**6. 레벨 간 배선** — 층과 층 사이를 잇는 비아(via)를 설계하고, 여러 메탈 레이어를 나눠 쓰며 저항·용량을 고려해 신호 전송 경로를 최적화해요.

**7. 타이밍·신호 무결성 검토** — 정적 타이밍 분석(Static Timing Analysis, STA)으로 타이밍 요구 사항을 충족하는지, 전자기 방출 같은 간섭이 없는지 확인해요.

**8. 레이아웃 검증(LVS)** — 완성된 도면이 처음 그린 회로 스키매틱과 전기적으로 같은지 맞춰 봐요.

**9. 최종 검토와 테이프아웃 준비** — 모든 규칙·타이밍·전력 요구 사항이 충족됐는지 마지막으로 훑고, 제조 공정에 넘길 데이터를 준비해요.

DRC와 LVS를 통과하는 세세한 기준은 검증 단계에서 훨씬 깊게 다루니, 여기서는 손으로 도면을 그려
나가는 아홉 걸음 중 어느 지점에서 이 두 검문소를 지나는지만 기억해 두면 돼요.

## 3. 블록을 놓고 빈틈까지 채우는 감각

기능 블록이 여러 개라면 무작정 늘어놓을 수 없어요. 요구 사항을 분석해 블록을 식별하고, 관련
있는 블록끼리 묶은 뒤, 전원 공급과 열 배출을 고려해 배치 계획을 세워요.

<SourceQuote section="NCS 학습모듈 — 커스텀 레이아웃 설계: 4-1. 커스텀 레이아웃 수행 (수행 순서 — 기능 블록 배치)">
  <p>
    각 블록 그룹을 레이아웃상에 배치하는 계획을 수립한다. 이때 공정의 설계 규칙을 고려하여 각
    블록의 위치를 결정한다. 예를 들어, 전원 공급과 열 배출을 고려하여 블록들을 배치할 수 있다.
  </p>
</SourceQuote>

자투리 공간을 그냥 비워 두지 않고 효율적으로 활용하는 것도 배치 실력이에요.

실제로 잘 맞물려 동작하는지 확인한 뒤에야 배치를 확정해요.

## 4. 자를 정확히 맞추는 법 — 람다(λ) 눈금

트랜지스터 하나, 배선 하나를 손으로 그릴 때마다 설계자는 계속 규칙과 자를 맞춰 봐야 해요.

<ImageFigure
  src="/source-images/ncs/custom-layout-design/_page_155_Figure_0.jpeg"
  alt="설계 규칙 수치를 람다(λ) 단위 배수로 표시한 도면 예시"
  caption="[그림 4-5] 람다에 의한 디자인 룰 표시"
  source="NCS 학습모듈 「커스텀 레이아웃 설계」(LM1903060131_23v5) · 교육부·한국산업인력공단"
/>

규칙을 nm 같은 절대 수치 대신, 공정의 최소 크기를 기준으로 삼은 람다(λ) 단위 배수로 표시하는
방식이에요. 어떤 공정에서 만들어지든 도면 위 비율은 그대로 유지되니, 설계자는 이 눈금 하나로
여러 공정 세대에 걸쳐 같은 감각으로 도면을 그릴 수 있어요.

<Callout type="info" title="매개 변수가 흔들려도 특성은 그대로">
  금속 레이어의 두께, 절연물의 두께·유전율, 포토리소그래피의 노광량처럼 레이어마다 각기 다른
  공정 매개 변수가 있어요. 손으로 그린 레이아웃이 이 매개 변수 변화에도 전기적 특성이 흔들리지
  않도록, 설계자는 DRC를 반복해 걸고 자동 백업·롤백 기능으로 이전 상태로 되돌릴 안전판까지
  마련해 둬요.
</Callout>

## 이 일을 하는 사람은

낮은 복잡성의 회로는 회로 설계 엔지니어가 레이아웃까지 직접 맡기도 해요. 복잡도가 올라가면 회로
설계 엔지니어와 레이아웃 엔지니어가 나눠서 협업하고, 아주 복잡한 칩이라면 회로 설계·레이아웃
설계·시뮬레이션·제작 및 검증을 각각 담당하는 전문가들이 팀을 이뤄 움직여요. 레이아웃 편집기 앞에
앉아 있지만, 이들이 정하는 좌표 하나하나가 결국 마스크에 새겨져 <Term id="semiconductor">반도체
</Term> 소자의 크기와 성능을 결정해요. 규칙을 정확히 지키면서도 회로가 요구하는 최적의 형태를
찾아내는 감각은, 자동화 툴로는 아직 대신하기 어려운 사람의 몫이에요.

<Callout type="tip" title="함께 보면 좋아요">
  이 모듈이 "손으로 배치·배선하는 실행"을 다룬다면, 그리기 전 무엇을 확인해야 하는지는 공정 분석
  모듈이, 다 그린 도면이 맞는지는 레이아웃 검증 모듈이, 자동화 툴이 같은 일을 어떻게 대신하는지는
  자동 배치 배선 모듈이 다뤄요. <ChapterRef order={2} />는 여기서 배치하는 트랜지스터 같은 반도체
  소자의 기본 구조를 설명해요.
</Callout>
