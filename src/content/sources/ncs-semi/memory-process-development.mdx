## 한 줄 요약

메모리 반도체 제조 공정 개발 = 휘발성·비휘발성 메모리의 종류와 특성을 구분하고, 웰(well)과
격리 구조로 트랜지스터가 들어설 자리를 만들고, MOSFET·커패시터 같은 단위 소자를 완성해
DRAM·NAND 같은 실제 메모리 셀로 조립하고, 완성된 소자와 소재가 기준을 만족하는지 검증하는
네 단계의 여정이에요. 자매 모듈인 「시스템 반도체 제조 공정 개발」이 로직 회로를 세우는 순서를
다룬다면, 이 모듈은 **같은 웨이퍼·같은 트랜지스터로 어떻게 "기억하는" 셀을 만드는가**를
다뤄요. 「반도체 산업의 유해인자」<ChapterRef order={3} />가 반도체 공정의 큰 그림을 보여준다면,
이 모듈은 그 그림 중에서도 메모리 소자가 완성되는 순서에 집중해요.

## 1. 메모리는 다 같은 메모리가 아니에요 — 휘발성과 비휘발성

전원을 끄면 기억을 잃는지 아닌지에 따라 메모리는 크게 두 갈래로 나뉘어요.
<Term id="doping">도핑</Term>된 트랜지스터 하나로도 여러 방식의 기억 장치를 만들 수 있다는
점이 반도체 설계의 묘미예요.

### 가. 잠깐 기억하는 램 — DRAM과 SRAM

<Term id="semiconductor">반도체</Term> 메모리 중 **RAM(random access memory)**은 전원이
꺼지면 데이터가 사라지는 휘발성 메모리예요. 그중 **DRAM**은 트랜지스터와 커패시터로
구성되고, 커패시터에 담긴 전하가 시간이 지나면 조금씩 새기 때문에 주기적으로 재충전
(refresh)을 해 줘야 해요. **SRAM**은 플립플롭(flip-flop) 구조라 재충전이 필요 없고 더
빠르지만, 회로가 복잡해 더 비싸요. 그래서 DRAM은 컴퓨터의 메인 메모리로, SRAM은 캐시
메모리처럼 아주 빠른 속도가 필요한 곳에 쓰여요.

### 나. 전원이 꺼져도 기억하는 메모리 — ROM과 플래시

제조 단계에서 <Term id="mask">마스크</Term>에 새겨진 그대로 데이터가 고정되는 Mask ROM부터,
자외선으로 지우는 EPROM, 전기로 지우고 다시 쓰는 EEPROM까지 — ROM(read-only memory) 계열은
전원이 꺼져도 데이터가 남는 비휘발성 메모리예요. 그 뒤를 잇는 플래시 메모리(Flash Memory)는
블록 단위로 지우고 다시 쓸 수 있어서 용량은 크면서, 속도는 DRAM보다 느리지만 EEPROM보다는
빨라요. 플래시는 다시 읽기 속도가 빨라 코드 저장에 적합한 **NOR Flash**와, 저장 밀도가 높고
쓰기·지우기가 빨라 대용량 저장에 적합한 **NAND Flash**로 나뉘는데, 스마트폰과 SSD에 들어가는
낸드플래시가 바로 이 NAND Flash예요.

| 구분 | 종류 | 특징 |
|---|---|---|
| 휘발성 메모리 | DRAM | 트랜지스터+커패시터 구조, 재충전(refresh) 필요, 컴퓨터 메인 메모리 |
| 휘발성 메모리 | SRAM | 플립플롭 구조, 재충전 불필요, 빠르지만 비쌈, 캐시 메모리 |
| 비휘발성 메모리 | NOR Flash | 빠른 읽기 속도, 펌웨어·부트로더 저장 |
| 비휘발성 메모리 | NAND Flash | 높은 저장 밀도, SSD·USB 등 대용량 저장 |

<div className="text-xs italic text-slate-500">출처: NCS 학습모듈 메모리 반도체 제조 공정 개발 — 1-1. 수행 내용 (메모리 종류와 특성, 발췌 재구성)</div>

## 2. 트랜지스터가 들어설 자리부터 만든다 — 웰과 격리 구조

### 가. 도핑으로 짓는 두 개의 자리 — p-well과 n-well

메모리 셀 하나를 세우려면 먼저 트랜지스터가 들어설 자리부터 파야 해요. **웰(well)**은
웨이퍼의 특정 영역에 불순물을 <Term id="doping">도핑</Term>해 만든 자리로, 붕소를 넣은
**p-well**에는 NMOS가, 인이나 비소를 넣은 **n-well**에는 PMOS가 들어서요. 이온 주입 장비로
도핑 물질을 밀어 넣은 뒤 고온에서 열처리(어닐링)하면 불순물이 웨이퍼 안으로 고르게 퍼지면서
원하는 전기적 특성을 지닌 자리가 완성돼요. DRAM은 이 p-well 위에 셀 트랜지스터를 세워 데이터를
저장·읽기·쓰기 하고, NAND Flash는 n-well 또는 p-well 위에 전하를 저장하는 플로팅 게이트
트랜지스터를 세워요.

웰의 도핑 농도와 깊이를 얼마나 정밀하게 맞추느냐가 전류 누설과 기생 커패시턴스를 얼마나
줄이느냐로 직결돼요.

### 나. 셀과 셀 사이에 담장 쌓기 — LOCOS·STI

자리를 만들었으면 이제 옆 셀과 전기적으로 섞이지 않도록 담장을 쌓아야 해요. 이를
**격리(isolation)**라고 하는데, 실리콘 표면에 두꺼운 산화막을 태워 넣는 오래된 방식인
**LOCOS**는 공정이 간단하지만 산화막이 옆으로 파고드는 '버즈비크(Bird's Beak)' 현상 때문에
면적 손해를 봐요.

<ImageFigure

그래서 요즘 고밀도 메모리는 실리콘을 얕게 파낸 뒤 산화막으로 채우고
<Term id="cmp">CMP</Term>로 평탄화하는 **STI(shallow trench isolation)**를 주로 써요. 공정은
더 복잡하지만 면적 효율이 높고 정밀한 격리가 가능해서 DRAM처럼 셀을 촘촘히 박아 넣어야 하는
메모리에 유리해요.

  DRAM은 셀 트랜지스터와 커패시터 사이의 격리로 데이터 보존 성능을 지키는 게 중요하고, NAND
  Flash는 촘촘히 직렬로 이어진 셀 사이·비트라인 사이의 격리로 데이터 무결성을 지키는 게
  중요해요. 같은 격리 기술이라도 무엇을 지키려는지는 메모리 종류마다 달라요.
</Callout>

### 다. 자리 위에 소자 완성하기 — MOSFET와 커패시터

자리와 담장이 준비되면 그 위에 진짜 소자를 쌓아요. **MOSFET**는 게이트(폴리실리콘 또는
금속)·소스·드레인·게이트 산화막으로 이뤄진 스위치 소자로, 데이터를 읽고 쓸 때 전류를 여닫는
역할을 해요.

<ImageFigure
  src="/source-images/ncs/memory-process-development/_page_36_Figure_2.jpeg"
  alt="게이트 산화막 위에 폴리실리콘을 증착해 게이트를 형성하는 공정 단면도"
  caption="[그림 1-19] POLY SILICON 형성"
  source="NCS 학습모듈 「메모리 반도체 제조 공정 개발」(LM1903060115_23v7) · 교육부·한국산업인력공단"
/>

**커패시터(capacitor)**는 두 개의 도전성 플레이트 사이에 SiO2나 HfO2 같은 유전체를 끼운
구조로, 전하를 저장해 논리 상태(0과 1)를 유지해요. MOSFET가 스위치라면 커패시터는 그 스위치가
열고 닫는 데이터 저장고인 셈이에요.

## 3. 같은 부품, 다른 집 — DRAM과 NAND Flash 셀 구조

### 가. DRAM 셀 = 트랜지스터 1개 + 커패시터 1개

<SourceQuote section="NCS 학습모듈 — 메모리 반도체 제조 공정 개발: 1-1. 수행 내용 (DRAM 셀 구조)">
  <p>DRAM 메모리 셀은 1개의 MOSFET와 1개의 capacitor로 구성된다.</p>
</SourceQuote>

<ImageFigure
  src="/source-images/ncs/memory-process-development/_page_36_Figure_7.jpeg"
  alt="게이트 양옆에 이온을 주입해 소스·드레인 영역을 형성하는 단면도"
  caption="[그림 1-21] source, drain implant"
  source="NCS 학습모듈 「메모리 반도체 제조 공정 개발」(LM1903060115_23v7) · 교육부·한국산업인력공단"
/>

워드 라인(word line)이 MOSFET의 게이트에 연결돼 셀을 켜고 끄는 스위치 역할을 하고, 비트
라인(bit line)이 MOSFET의 드레인에 연결돼 데이터가 오가는 통로가 돼요. 워드 라인이 켜지면
MOSFET가 열리면서 비트 라인의 데이터가 커패시터에 저장되고(쓰기), 반대로 커패시터에 저장된
전하 상태가 비트 라인으로 전달돼요(읽기). 이 단순한 1트랜지스터-1커패시터(1T1C) 구조 덕분에
DRAM은 셀 하나가 아주 작아 대용량·고밀도로 만들기 유리해요.

### 나. NAND Flash 셀 = 직렬로 이어진 플로팅 게이트 트랜지스터

<SourceQuote section="NCS 학습모듈 — 메모리 반도체 제조 공정 개발: 1-1. 수행 내용 (NAND Flash 셀 구조)">
  <p>NAND Flash 메모리 셀은 여러 MOSFET가 직렬로 연결된 구조를 가지며, 플로팅 게이트를 통해 전하를 저장한다.</p>
</SourceQuote>

NAND Flash는 절연체로 둘러싸인 **플로팅 게이트(floating gate)**가 전하를 가둬 두는 저장소
역할을 하고, 그 위의 **컨트롤 게이트(control gate)**가 쓰기·읽기 동작을 제어해요. 높은
전압을 걸어 플로팅 게이트에 전하를 밀어 넣으면 쓰기, 컨트롤 게이트에 전압을 걸어 채널의
전도 여부를 읽으면 읽기, 전하를 다시 빼내면 지우기 동작이에요. 절연체에 완전히 둘러싸여
있어서 전원이 꺼져도 전하가 새지 않는다는 점이 DRAM의 커패시터와 결정적으로 달라요.

<Callout type="tip" title="왜 DRAM만 계속 충전해야 할까">
  DRAM의 커패시터는 얇은 유전체 막 하나로만 전하를 가둬서 시간이 지나면 조금씩 새요. 반면
  NAND의 플로팅 게이트는 절연체로 완전히 둘러싸여 있어 전하가 빠져나갈 길이 없어요. 이 구조
  차이 하나가 "계속 충전해야 하는 메모리"와 "전원을 꺼도 그대로인 메모리"를 가르는 핵심이에요.
</Callout>

## 4. 완성된 소자, 진짜 기준을 만족하는지 확인하기

### 가. 소자 특성 재보기 — Vth부터 데이터 유지 시간까지

메모리 셀을 다 쌓았다고 끝이 아니에요. 파라미터 애널라이저 같은 장비로 프로브를 대고 전압을
흘려 게이트-소스 전압에 따른 드레인 전류(Ids-Vgs 커브)를 측정해 트랜지스터가 켜지기 시작하는
문턱 전압(Vth)을 확인해요. DRAM은 특히 **데이터 유지 시간(data retention time)**이 핵심
기준이에요.

<SourceQuote section="NCS 학습모듈 — 메모리 반도체 제조 공정 개발: 2-1. 수행 내용 (DRAM 소자의 특성 항목과 기준)">
  <p>데이터 유지 시간(data retention time): 전원이 켜져 있을 때 데이터를 유지할 수 있는 시간이며 일반적으로 몇 밀리초(ms)이다.</p>
</SourceQuote>

데이터 유지 시간이 겨우 몇 밀리초밖에 안 되기 때문에 DRAM은 이 시간이 다 되기 전에 쉬지 않고
모든 셀을 다시 채워 줘야 해요. 검증할 때도 메모리 종류마다 쓰는 패턴이 달라요. DRAM은
(0쓰기→0읽기→1쓰기→1읽기)를 반복하는 **마치 테스트(march test)**로 셀 결함을 찾고, NAND
Flash는 (010101…)처럼 인접 셀 간섭을 확인하는 **체커보드 패턴(checkerboard pattern)**과
프로그램·소거를 반복하는 내구성 테스트를 함께 써요.

<Callout type="warning" title="고전압·고자기장 측정, 항상 조심해야 해요">
  소자 측정 장비는 고전압·고전류·고자기장을 다루기 때문에 매뉴얼을 충분히 숙지한 뒤에
  사용해야 하고, 측정 장비의 그라운드가 서로 어긋나면(커먼 그라운드 불량) 엉뚱한 값이 나올 수
  있어 주기적으로 기준 소자로 점검해야 해요.
</Callout>

### 나. 소재도 성적표가 있다 — 커패시터의 유전체가 특히 중요

완성된 소자뿐 아니라 그 재료가 된 웨이퍼·<Term id="photoresist">감광액</Term>·가스·금속까지도
정해진 규격을 만족해야 공정에 투입될 수 있어요. 그중 메모리, 특히 DRAM에서 유독 중요한 항목이
커패시터에 쓰이는 유전체의 **유전 상수(dielectric constant)**예요.

<SourceQuote section="NCS 학습모듈 — 메모리 반도체 제조 공정 개발: 3-1. 수행 내용 (전기적 특성 항목과 기준 — 유전 상수)">
  <p>(가) 특성 항목: 유전체 소재의 전기적 절연 특성</p>
  <p className="mt-2">(다) 기준: 기대되는 유전 상숫값과 일치해야 함. 유전 상수가 높을수록 커패시터의 저장 능력이 커짐.</p>
</SourceQuote>

유전 상수가 높은 소재를 쓰면 같은 면적에서 더 많은 전하를 저장할 수 있어서, 셀 면적이 점점
작아지는 고집적 DRAM일수록 이 소재 선택이 성능을 좌우해요. <Term id="etching">식각</Term>·
<Term id="deposition">증착</Term> 공정 하나하나도 이런 소재의 물성을 해치지 않는 조건으로
관리돼야 해요.

## 이 일을 하는 사람은

웰과 격리 구조를 설계하는 사람은 **메모리 공정 개발 엔지니어**, 완성된 DRAM·NAND 소자의
Vth·데이터 유지 시간·프로그램/소거 내구성을 재고 검증 패턴을 적용하는 사람은 **소자 특성
평가 엔지니어**, 웨이퍼·유전체·가스 같은 소재 하나하나의 규격을 관리하는 사람은 **소재
엔지니어**라고 불러요. 이들은 나노미터 단위의 웰 깊이와 밀리초 단위의 전하 누설까지 함께
들여다보며, 같은 트랜지스터로 전혀 다른 두 종류의 기억을 만들어 내는 사람들이에요.
