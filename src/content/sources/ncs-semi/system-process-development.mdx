## 한 줄 요약

시스템 반도체 제조 공정 개발 = 회로도를 실제 웨이퍼 위에 쌓아 올릴 순서표(공정 흐름도)를
짜고, 그 순서표대로 만들어진 트랜지스터 하나하나가 설계대로 동작하는지 재고, 그 재료가 된
웨이퍼·화학약품까지 성적을 매기는 일이에요. 「반도체 산업의 유해인자」<ChapterRef order={3} />가
"공정이 무엇인가"의 큰 그림을 보여준다면, 이 모듈은 **"그 공정 하나하나를 어떤 순서로 설계하고
검증하나"**를 다뤄요.

## 1. 공정 흐름도 읽기 — 웨이퍼 한 장이 칩이 되기까지

### 가. 큰 그림 — 11단계로 보는 시스템 반도체 공정

시스템 반도체는 마이크로프로세서·DSP·MCU·FPGA처럼 계산과 신호 처리를 담당하는 반도체를
통틀어 부르는 이름이에요. 만드는 제품은 저마다 다르지만, 고순도 실리콘 <Term id="ingot">잉곳
(ingot)</Term>을 얇게 썰어 <Term id="wafer">웨이퍼</Term>를 만드는 것부터 시작해 칩이 완성되기
까지 거치는 큰 골격은 비슷해요. 공정 개발 엔지니어가 가장 먼저 하는 일은 이 골격을 순서대로
정리한 **공정 흐름도**를 그리는 것이에요 — 어떤 공정을 몇 번째에 넣을지 잘못 정하면 뒤 공정에서
되돌릴 수 없는 손실이 나기 때문이에요.

| 단계 | 주요 내용 |
|---|---|
| 1. 웨이퍼 제조 | 단결정 성장 → 웨이퍼 절단 → 웨이퍼 연마 |
| 2. 웨이퍼 세정 | 화학 세정(RCA 세정 등)으로 표면 유기물·금속 이온 제거 |
| 3. 산화 공정 | 고온에서 실리콘 표면에 산화막(SiO2) 형성 |
| 4. 포토리소그래피 | 감광액 도포 → 노광 → 현상 |
| 5. 에칭 | 건식(플라즈마) 또는 습식(화학 용액)으로 불필요한 부분 제거 |
| 6. 이온 주입 | 이온 주입기로 불순물을 넣어 도핑 |
| 7. 금속 증착 | 물리적 증착(PVD)·화학적 증착(CVD)으로 금속막 형성 |
| 8. 리소그래피·에칭 반복 | 다중 패터닝으로 복잡한 회로 패턴 완성 |
| 9. 평탄화 | 화학 기계적 연마(CMP)로 표면을 평평하게 |
| 10. 패키징 | 다이싱 → 본딩 → 캡슐화 |
| 11. 테스트 | 전기적 테스트·신뢰성 테스트 |

<div className="text-xs italic text-slate-500">출처: NCS 학습모듈 시스템 반도체 제조 공정 개발 — 1-1. 필요 지식 [그림 1-1] 시스템 반도체 공정 흐름도 다이어그램(요약 재구성)</div>

「반도체 산업의 유해인자」<ChapterRef order={5} />가 다루는 웨이퍼 제조는 이 표의 1번에 해당하고,
세정·산화·포토·에칭·이온 주입은 각각 2~6번에 해당해요. 공정 개발이라는 일은 이 낱개 공정을
"어떤 순서로 몇 번 반복할지"까지 촘촘하게 설계하는 일이에요.

### 나. 트랜지스터 하나에도 이 순서가 여러 번 반복돼요

실리콘 기판 위에 트랜지스터 하나를 세우려면 표의 3~7번 단계가 그 안에서만 대여섯 번
되풀이돼요. 소자와 소자 사이를 갈라놓는 **소자 분리(STI)** 부터 시작해서, p형·n형 영역을
나누는 **Well 구조**, 전류를 여닫는 **게이트**, 전류가 드나드는 **소스·드레인**까지 — 단계마다
<Term id="mask">마스크</Term>에 그려진 패턴을 포토 공정으로 옮기고 <Term id="etching">식각</Term>
으로 깎아내고 <Term id="deposition">증착</Term>으로 다시 채우는 과정이 반복돼요.

나란히 있어야 CMOS 회로가 완성되기 때문에, 이온의 종류와 깊이를 정확히 맞추는 게 중요해요.

인 이온을 그만큼 더 깊이 밀어 넣어야 하기 때문이에요.

## 2. 단위 소자 개발 — 만든 트랜지스터를 하나하나 검증하기

공정 흐름도대로 웨이퍼를 다 쌓았다고 끝이 아니에요. 실제로 만들어진 MOSFET·커패시터·저항기가
설계한 대로 동작하는지 재고 확인하는 단계가 뒤따라야 해요.

### 가. 무엇을 재나 — 다섯 가지 성적표

MOSFET을 예로 들면 재는 항목이 정해져 있어요. **임계 전압(Vth)**은 트랜지스터가 켜지기
시작하는 전압, **온 저항(Rds(on))**은 켜졌을 때 저항 없이 전류를 얼마나 잘 흘리는지, **누설
전류(Ioff)**는 꺼져 있어야 할 때 얼마나 새는지, **전류 구동 능력(Idsat)**은 최대로 흘릴 수
있는 전류량, **전하 이동도**는 전자·정공이 얼마나 빨리 움직이는지를 나타내요. 자동차로 치면
연비·최고속도·가속력을 재는 것과 같아요 — 설계할 때 목표로 잡은 숫자와 실제로 만들어진 소자의
숫자가 얼마나 가까운지를 확인하는 거예요.

### 나. 어떻게 확인하나 — 검증 패턴과 분석 장비

<SourceQuote section="NCS 학습모듈 — 시스템 반도체 제조 공정 개발: 2-1. 필요 지식(검증 패턴의 정의)">
  <p>
    시스템 반도체 단위 소자 개발을 위해서는 각 소자의 검증 패턴을 해석하고 이를 실제 소자
    개발에 적용할 수 있는 능력이 필요하다. 검증 패턴은 소자의 성능, 신뢰성, 품질을 평가하기
    위해 설정된 테스트 절차와 기준이다.
  </p>
</SourceQuote>

**프로브 스테이션(probe station)**이라는 장비로 웨이퍼 위 소자에 미세한 탐침을 대고 전류·전압을
흘려보며 측정해요. 구조 자체에 결함이 있는지 봐야 할 때는 전자현미경을 써요 — 표면은
**SEM(주사전자현미경)**으로, 내부 단면은 **TEM(투과전자현미경)**으로 들여다봐요. 이렇게 모은
측정값은 평균과 표준편차로 정리하고, 히스토그램과 관리도로 공정이 안정적인지 살펴봐요. 정해둔
사양 범위를 벗어나면 불량으로 판정하고, 그 원인을 찾아 공정 조건을 다시 조정해요.

<Callout type="tip" title="만들기 전에 미리 검증한다 — TCAD 시뮬레이션">
  실제 웨이퍼를 깎기 전에 **TCAD(기술 컴퓨터 지원 설계)**라는 도구로 소자의 동작을 컴퓨터 안에서
  먼저 시뮬레이션해요. 도핑 농도나 산화막 두께를 바꿔가며 가상의 웨이퍼로 미리 실험해 보고,
  실제 공정에 넣을 조건을 좁혀 나가는 거예요.
</Callout>

<Callout type="warning" title="정전기 하나로도 소자가 죽어요">
  트랜지스터의 검증 항목에는 **정전기 방전 내성(ESD tolerance)**도 포함돼요. 눈에는 아무 일도
  없어 보여도 순간적인 정전기가 산화막을 뚫어 소자를 망가뜨릴 수 있기 때문에, 소자를 만지고
  옮기는 모든 과정에서 정전기 방지 장비와 손목 접지 밴드를 쓰는 게 원칙이에요.
</Callout>

## 3. 공정 소재 평가 — 웨이퍼도 재료마다 성적표가 있다

공정과 소자만 검증하는 게 아니에요. 그 재료가 되는 <Term id="wafer">웨이퍼</Term> 자체,
<Term id="photoresist">감광액</Term>, 금속, 절연막, 화학약품까지도 정해진 기준을 만족해야
공정에 투입될 수 있어요.

<SourceQuote section="NCS 학습모듈 — 시스템 반도체 제조 공정 개발: 3-1. 필요 지식(공정 소재 특성의 중요성)">
  <p>
    시스템 반도체 공정에 사용되는 소재는 고도의 성능과 신뢰성을 요구하며, 이들 소재의 특성은
    소자의 성능에 직접적인 영향을 끼친다.
  </p>
</SourceQuote>

실리콘 웨이퍼 하나만 봐도 크기·두께·전기 저항·결정 방향까지 미리 정해둔 값 안에 들어와야
공정에 쓸 수 있어요.

| 특성 항목 | 값·기준 |
|---|---|
| 직경(diameter) | 200mm 또는 300mm |
| 두께(thickness) | 725μm(200mm 웨이퍼) 또는 775μm(300mm 웨이퍼) |
| 저항율(resistivity) | 1-10 Ω·cm |
| 결정 방향(crystal orientation) | `<100>` 또는 `<111>` |
| 결함 밀도(defect density) | 낮을수록 좋음 — 기준을 초과하면 불량으로 판정 |

<div className="text-xs italic text-slate-500">출처: NCS 학습모듈 시스템 반도체 제조 공정 개발 — 3-1. 수행 내용(실리콘 웨이퍼 특성 항목과 평가 기준)</div>

이 기준은 재료마다 따로 있어요. 감광액은 빛에 얼마나 민감한지(감광성)와 얼마나 작은 패턴까지
그릴 수 있는지(해상도)로, 금속은 저항이 얼마나 낮은지로, 절연막은 얼마나 높은 전압까지 버티는지
(파괴 전압)로 성적을 매겨요. 공정 조건도 재료의 성적표에 그대로 영향을 줘요 — 예를 들어 산화
온도가 높을수록 산화막은 두꺼워지지만, 너무 높으면 웨이퍼 표면에 스트레스가 생겨 오히려
결함이 늘어나요.

## 이 일을 하는 사람은

공정 흐름도를 설계하는 사람은 흔히 **공정 개발 엔지니어(PE, Process Engineer)**라 불려요. 단위
소자를 측정하고 분석하는 사람은 **소자 특성 평가 엔지니어**, 컴퓨터로 미리 시뮬레이션하는
사람은 **TCAD 엔지니어**, 웨이퍼·화학약품 같은 소재 자체를 관리하는 사람은 **소재 엔지니어**
라고 불러요. 이들은 회로 설계자가 그린 도면과 실제 웨이퍼 사이를 오가며, 도면이 실제로 구현
가능한지, 구현된 소자가 도면대로 동작하는지를 끝없이 확인하는 사람들이에요.
