도착하는 과정 — 수변전 설비, 전압 등급, 전기가 말썽을 부리는 순간들 — 을

## 1. 전기가 팹까지 오는 길 — 전력설비

한전에서 보낸 전기가 웨이퍼 옆 장비까지 오려면 여러 설비를 거쳐요. 전기는 가스·
화학약품·초순수와 함께 팹을 도는 '유틸리티' 중 하나로, 전체 그림은{' '}
<SourceRef source="ncs-semi" section="utility-operation" label="NCS · 반도체 유틸리티 운영" />에서
볼 수 있어요. 여기서는 전기 계통만 자세히 봐요.

| 설비 | 역할 |
|---|---|
| 지중 케이블 | 절연체(가교폴리에틸렌·XLPE)로 감싸 땅속에서 전기를 안전하게 옮겨요 |
| 가스절연개폐장치(GIS) | SF6 가스로 절연해 사고·단락 같은 이상 상태에서도 선로를 안전하게 끊어요 |
| 변압기 | 한쪽 권선의 교류를 전자유도로 다른 쪽에 같은 주파수·다른 전압으로 옮겨요 |
| 무정전 전원장치(UPS) | 정류기·축전지·인버터·절체스위치로 정전·전원 이상에도 끊김 없이 공급해요 |
| 비상 발전기 | 상용 전원이 끊기면 조명·엘리베이터·급배수·공조·주요 장비를 지키는 최후의 예비 전력이에요 |

각 **차단기**가 사고 전류를 얼마나 빨리 끊어내는지도 중요해요. 소호(아크를 끄는)
방식에 따라 네 가지로 나뉘어요.

| 차단기 | 소호 방식 | 특징 |
|---|---|---|
| 진공차단기(VCB) | 진공의 높은 절연내력 + 아크의 급속 확산 | 소형·경량, 화재 위험 적음, 서지전압 발생은 단점 |
| 기중차단기(ACB) | 자연 공기 중 접촉자 분리로 자연소호 | 교류 저압·직류용, 배선용은 MCCB(노퓨즈차단기)라 불러요 |
| 유입차단기(OCB) | 절연유가 기화하며 만드는 가스로 소호 | 저렴하고 넓은 전압대에 적용, 기름 때문에 화재 위험 |
| 가스차단기(GCB) | SF6 가스를 고압(약 12~15kg/cm²·g)에서 저압(약 2kg/cm²·g)으로 분사해 소호 | 보수 적고 성능 좋음, 고가·대형이라 초고압에 주로 사용 |

여기까지가 공장 단위의 전기 인프라라면, 장비 한 대 안에서 안정된
전기가 정밀도를 어떻게 지키는지(장비 전원과 접지)는{' '}
<SourceRef source="hs-equipment-maintenance" section="element-power" label="「반도체 장비 유지 보수」 전원 공급 기술" />에서
이어서 볼 수 있어요.

## 2. 전압에도 등급이 있다 — 저압·고압·특별고압

같은 '전기'라도 크기에 따라 다루는 방법이 완전히 달라요. 전압을
세 등급으로 나눠요.

| 등급 | 직류 | 교류 |
|---|---|---|
| 저압 | 1,500V 이하 | 1,000V 이하 |
| 고압 | 1,500V 초과 ~ 7,000V 이하 | 1,000V 초과 ~ 7,000V 이하 |
| 특별고압 | 7,000V 초과 | 7,000V 초과 |

<Callout type="tip" title="시험 포인트 — 저압 기준, 직류와 교류가 달라요">
  저압의 경계선이 직류는 1,500V, 교류는 1,000V로 서로 달라요. 두
  숫자를 바꿔서 헷갈리게 내는 문제가 나오니, "저압은 교류 쪽 숫자가
  더 낮다"로 기억해 두세요. 한국전기설비규정(KEC)이 개정되며
  옛 기준(직류 750V·교류 600V)에서 지금 기준으로 상향됐다는 점도
  알아두면 좋아요.
</Callout>

전압 등급은 실제 배선에서 **배전방식**으로 이어져요.

| 간선 | 방식 | 대표 전압 |
|---|---|---|
| 저압간선 | 단상 3선식 / 3상 3선식 / 3상 4선식 / 직류식 | 220/110V, 220V, 440/254·380/220·208/120V, 직류 100V |
| 고압간선 | 3상 3선식 | 6kV급, 3kV급 |
| 특별고압간선 | 3상 3선식(비접지) / 3상 4선식(다중접지) | 22kV급, 22.9kV급 |
| 초고압간선 | 3상 3선식 | 154kV급, 345kV급 |

전압을 높이면 같은 전력에 필요한 전류가 줄어 전선을 가늘게 쓸 수
있어요. **220/110V 단상 3선식**은 전류를 줄이려 회로 전압을 올리며
낮은 전압도 함께 꺼내 쓰고, **208/120V 3상 4선식**은 무정전 장치를
단 컴퓨터 전원용으로도 쓰여요.

## 3. 전기가 말썽부릴 때 — 전기적 장애와 위험성

전기 자체는 끊기지 않아도 품질이 흐트러지는 문제가 있고, 사람과
설비를 직접 다치게 하는 문제도 있어요. 성격이 다른 두 그룹이에요.

| 전기적 장애 | 무엇이 문제인가 | 대응 |
|---|---|---|
| 정전 | 순간적인 정전·전압강하로 정전압·정주파수가 흔들림 | UPS·축전지 설비로 정전압·정주파수 유지 |
| 노이즈(Noise) | 케이블·장비의 전자유도 작용으로 잡음이 실림 | 전력선과 신호선을 분리 공사, 차폐 와이어 사용 |
| 고조파 | 정류기·전자부품 장비에서 기본 주파수 외 성분이 섞임 | 여과기(필터), 역고조파 방지용 변압기 리액터 사용 |

| 전기적 위험성 | 원인 | 대책 |
|---|---|---|
| 누전 | 절연 불량·피복 손상·접촉 불량으로 전기가 샘 → 감전·화재·전력 손실 | 공사 시 피복 보호, 연결 상태·절연저항 수시 점검 |
| 스위치 조작 | 부하측 상황을 모른 채 조작 → 감전·단락 | 조작 전 부하측에 사람·장애물 없는지 확인 |
| 과부하 | 허용전류 초과 → 발열 → 절연 파괴 → 단락·화재 | 전류·전압 점검, 연결 부위 발열·조임 상태 관리 |

차단기가 만드는 순간적인 **서지전압**(앞서 본 진공차단기 VCB의
단점)도 전기적 장애의 하나예요 — 정전·노이즈·고조파처럼 전기
품질을 흔들지만, 발생 원인이 차단기의 개폐 동작이라는 점이 달라요.

<Callout type="tip" title="시험 포인트 — 장애와 위험성, 분류를 헷갈리지 마세요">
  정전·노이즈·고조파는 전기 '품질'이 흔들리는{' '}
  <strong>전기적 장애</strong>고, 누전·스위치 조작·과부하는 사람과
  설비를 직접 다치게 하는 <strong>전기적 위험성</strong>이에요. 이
  여섯 가지를 섞어서 어느 쪽인지 묻는 문제가 나오니 두 그룹으로
  나눠 외워 두세요.
</Callout>

## 4. 보이지 않는 불꽃 — 정전기

정전기는 두 가지 방식으로 생겨요. 대전되지 않은 물체가 이미 대전된 물체의
전기장에 노출돼 양쪽이 다른 극성으로 갈라지는 **유도성 대전**과, 두 물체가
접촉·마찰·분리되며 한쪽은 전자를 잃고 다른 쪽은 얻어 +, -로 갈라지는
**접촉성 대전**이에요. 작업자·의복·작업 의자·작업대·바닥·부품함·포장재·
제조 기계·제조 공정 — 사실상 팹 안의 거의 모든 것이 정전기원이 될 수 있어요.

| 정전기가 만드는 문제 | 내용 |
|---|---|
| 오염 | 대전된 표면에 미소 입자가 정전기적으로 붙어 쌓여요 |
| 소자·시스템 파손 | 정전기 방전(ESD)에 노출된 소자나 시스템이 고장 나요 |
| 시스템 교란 | 디지털 시스템의 동작이 흐트러져요 |
| 정보 유실 | 저장된 정보가 지워지거나 손실돼요 |

대책은 크게 두 방향이에요 — 불필요한 접촉·물체를 치우고 공구를
접지하며 손목 접지 밴드(Wrist Strap)를 쓰는 것, 그리고 전기장
유도물체 근처에 부품을 두지 않고 이오나이저(제전기)를 설치하는
것이에요.

<Callout type="tip" title="시험 포인트 — 정전기 방지, 접지가 항상 답은 아니에요">
  접지·본딩은 <strong>도전성</strong> 물체가 대전됐을 때 전하를
  흘려보내는 대책이에요. 하지만 <strong>부도체</strong>는 접지해도
  전하가 흐르지 않아 대전이 그대로 남아요 — 이때는 도전성 재료나
  가습, 제전기(이오나이저)처럼 다른 방법이 필요해요. "정전기
  대책은 무조건 접지"로 외우면 걸리기 쉬운 함정이에요.
</Callout>
