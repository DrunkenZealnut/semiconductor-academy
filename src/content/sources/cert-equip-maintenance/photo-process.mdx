## 1. 사진공정이란 — 회로를 '인화'하는 네 단계

리소그래피(Lithography)라는 말은 원래 돌(Lithos)에 그림(Graphy)을
새기는 석판화 기술을 가리켰어요. 반도체에서는 빛에 반응하는 화학물질인
감광물질(PR; Photo Resist)을 웨이퍼에 발라 정밀한 회로 패턴을 실수
없이 반복해서 복사해 내는 공정을 뜻하고, 우리말로는
**사진(Photo)공정**이라고 불러요. 눈에 보이지도 않는 미세한 배선을
똑같이 찍어내는 첫 관문이라, 반도체의 설계도가 실제 물건이 되는
출발점이에요.

사진공정은 아래 네 단계를 순서대로 거쳐요.

| 단계 | 하는 일 | 담당 장비 |
|---|---|---|
| ① 도포(PR Coating) | 웨이퍼 전면에 감광물질(PR)을 고르게 바른다 | 트랙(Track) |
| ② 노광(Exposure) | 마스크를 통과한 빛으로 PR을 반응시켜 패턴을 새긴다 | 스테퍼(Stepper)·스캐너(Scanner) |
| ③ 현상(Develop) | 반응한(또는 반응하지 않은) PR 중 필요 없는 부분을 현상액으로 녹여낸다 | 트랙(Track) |
| ④ 검사(Inspection) | 패턴이 설계대로 만들어졌는지 확인한다 | 전용 검사 장비 |

검사에서 문제가 발견되면 어떻게 될까요? 사진공정은 아직 PR이
유기용제에 녹는 상태이기 때문에, 잘못 만들어진 패턴을 통째로 씻어내고
처음부터 다시 진행하는 **재작업(Rework)**이 가능해요. 반면 뒤에 오는
식각·증착 공정은 한 번 웨이퍼가 깎이거나 막이 쌓이면 되돌릴 수 없어서,
사진공정에서 패턴을 확실히 맞혀 두는 일이 특히 중요해요. 더 미세한
회로를 그리기 위해 사진공정이 다중 패턴·EUV 같은 기술로 어떻게
진화해 왔는지는{' '}
<SourceRef source="daegu-hs-process" section="photo" label="「반도체 공정기초」 포토 공정" />에서
더 볼 수 있어요.

  "도포→노광→현상→검사" 순서를 뒤섞어 놓고 올바른 순서를 고르는 문제가
  정말 자주 나와요. "PR을 바르고(도포) → 빛을 쬐고(노광) → 씻어내고
  (현상) → 확인한다(검사)"처럼 동작 순서로 외우면 헷갈리지 않아요.
  재작업(Rework)이 가능한 공정은 8대 공정 중 사진공정 하나뿐이라는
  점도 단골로 나오는 포인트예요.
</Callout>

## 2. 도포공정 — 감광물질을 입히다

도포공정은 크게 HMDS 처리 → PR 도포 → EBR → 소프트 베이크 순서로
세분돼요.

HMDS(Hexamethyldisilazane)는 PR을 바르기 전에 먼저 처리하는
화학물질이에요. 풀칠하듯 웨이퍼 표면과 화학반응을 일으켜 PR이 잘
달라붙도록 접착력을 높여주는 역할을 해요. 압력을 가한 질소(N2) 가스가
HMDS 증기를 웨이퍼까지 실어 나르는 기상 도포 방식을 써요.

PR은 빛에 반응하는 방식에 따라 두 종류로 나뉘어요.

| 종류 | 빛을 받은 부분 | 현상 후 남는 부분 |
|---|---|---|
| 양성(Positive) PR | 조직이 붕괴돼요(약해져 씻겨 나가요) | 빛을 받지 않은 부분 |
| 음성(Negative) PR | 조직이 강화돼요(단단해져 남아요) | 빛을 받은 부분 |

국내 반도체 공정에서는 주로 양성 감광액을 사용해요. 이 PR은 다시
세 가지 성분으로 이뤄져요.

| 성분 | 역할 |
|---|---|
| 감광 성분(PAC; Photo Active Compound) | 빛과 반응해 폴리머 결합을 끊는 이온 물질을 만들어요 |
| 수지(Resin) | 사슬처럼 이어진 폴리머 — PR의 뼈대예요 |
| 솔벤트(Solvent) | PAC·수지의 농도(점도)를 조절해요 |

<Callout type="tip" title="시험 포인트 — PR 성분과 종류 구분">
  PR 성분 중 "농도(점도)를 조절하는 물질"을 고르는 문제는 정답이
  솔벤트(Solvent)예요 — 초순수(DI Water)나 수지(Resin)를 헷갈려서
  고르지 않게 주의하세요. 양성/음성 PR은 "빛을 받은 부분이 없어지면
  양성, 남으면 음성"으로 짝지어 기억하면 헷갈리지 않아요.
</Callout>

PR 도포는 회전하는 웨이퍼 위에 감광액을 직접 분사하는
**회전도포(Spin Coating)** 방식이 대표적이에요. 균일한 두께를
얻으려면 회전 속도와 PR의 점도, 이 두 변수를 잘 맞춰야 해요. 도포와 동시에 웨이퍼
가장자리에 남은 PR은 오염원이 될 수 있어 시너 같은 용제로 제거하는데,
이를 **EBR(Edge Bead Removal)**이라고 해요. 마지막으로 트랙 장비의
오븐에서 비교적 낮은 온도로 구워 PR과 웨이퍼의 결합력을 높이는 과정이
**소프트 베이크(Soft Bake)**예요.

## 3. 노광공정 — 빛으로 패턴을 옮기다

노광은 마스크(패턴이 새겨진 원판)를 통과한 빛으로 PR에 회로 모양을
새기는 단계예요. 마스크는 흔히 레티클이라고도 부르는데, 투명한
유리판 위에 회로 패턴을 크롬(Chrome)으로 그린 원판이에요 — 빛이
크롬 부분은 막히고 투명한 부분은 통과하면서 그림자처럼 패턴이
만들어져요. 반도체가 얼마나 미세한 회로(선폭)를 만들 수 있는지가
여기서 갈리기 때문에, 업계에서 가장 공들이는 기술이기도 해요.

노광 방식은 크게 세 가지로 발전해 왔어요.

| 방식 | 특징 | 한계 | 장비명 |
|---|---|---|---|
| 접촉(Contact)형 | 마스크와 웨이퍼를 맞붙여 1:1로 노광해요. 장비가 저렴해요 | 맞닿는 과정에서 PR이 상하고 마스크가 오염돼요 | 얼라이너(Aligner) |
| 근접(Proximity)형 | 마스크와 웨이퍼 사이를 살짝 띄워요 | 렌즈 없이 상을 옮기다 보니 빛이 퍼지고 꺾여요(회절·발산) | 얼라이너(Aligner) |
| 투영전사(Projection)형 | 렌즈로 마스크의 상을 축소해 투영해요(5:1, 4:1 등) | 앞의 두 단점을 해결했지만 초점(Focus) 관리가 중요해져요 | 스테퍼·스캐너(다음 문단) |

  "접촉형은 PR 손상·마스크 오염, 근접형은 회절·발산, 투영형은 이 둘을
  렌즈로 해결"이라는 짝을 순서대로 기억해 두세요. 발전 순서
  (접촉→근접→투영)를 묻는 문제도 자주 나와요.
</Callout>

투영전사 방식은 다시 한 번에 전체를 노광하는 **스테퍼(Stepper)**와,
슬릿으로 빛을 쪼개 가며 훑는 **스캐너(Scanner)**로 나뉘어요. 스캐너는
렌즈 전체를 쓰지 않아도 되기 때문에 스테퍼보다 상이 더 선명하고 더
넓은 면적을 노광할 수 있어요. 빛의 파장(λ)이 짧아질수록 더 가는
선(미세 패턴)을 그릴 수 있는데, 파장이 짧아지면 초점이 맞는 세로
범위, 즉 초점심도(DOF; Depth of Focus)도 함께 얕아져서 초점을
맞추기가 더 까다로워져요 — 그래서 반도체 미세화의 역사는 곧 노광
광원의 파장을 줄여 온 역사이기도 해요. 얼라이너부터 최신 스캐너까지
노광 장비가 이 파장을 줄여 온 흐름은{' '}
<SourceRef source="hs-photo-etch" section="exposure-equipment" label="「반도체 포토·에칭」 노광 장비의 개요" />에서
이어서 볼 수 있어요.

노광 능력은 두 값으로 요약돼요 — 해상력(Resolution)은 K₁×λ/NA로
작을수록 좋고, 초점심도(DOF)는 K₂×λ/NA²로 클수록 좋아요. 여기서
NA는 렌즈 성능을, λ는 빛의 파장을 나타내요. 파장이 짧아지면 해상력은
좋아지지만 DOF는 함께 얕아지니, 미세화와 초점 관리는 늘 맞바꿈
(trade-off) 관계예요. 그래서 노광 장비를 고를 때는 원하는 패턴
크기(디자인 룰)에 맞는 파장의 광원을 고르는 일 자체가 핵심 설계
결정이 돼요 — 회로가 미세해질수록 더 짧은 파장의 광원이 필요해지는
식이에요.

## 4. 현상과 검사 — 남길 것만 남기고, 확인한다

노광이 끝난 PR 단면에는 빛이 간섭하며 생긴 물결 모양의 굴곡이 남아요.
노광 직후 한 번 더 가열해 이 굴곡을 완만하게 펴 주는 단계가
**PEB(Post Exposure Bake)**예요. 이어지는 **현상(Develop)**은
웨이퍼를 돌리면서 현상액을 뿌려 필요 없는 PR을 녹여내는
**회전분사현상(Spin Spray Develop)** 방식이 널리 쓰이고, 반응이
끝나면 초순수(DI Water)로 헹궈 마무리해요. 산업 현장에서는 현상액으로
흔히 TMAH(테트라메틸수산화암모늄) 같은 알칼리성 수용액을 써요.
마지막으로 **하드 베이크(Hard Bake)**는 남은 PR을 웨이퍼 표면에
단단히 고정하는 마무리 열처리예요.

현상까지 끝나면 패턴이 제대로 만들어졌는지 세 갈래로 검사해요.

| 검사 종류 | 확인하는 것 |
|---|---|
| 육안검사(Visual) | 눈이나 광학현미경으로 도포 불량 등을 확인해요 |
| 오버레이(Overlay) | 이전 막 위에 지금 패턴이 정확히 겹쳤는지, 샷 귀퉁이의 정렬 표시로 확인해요 |
| CD 측정 | 전자현미경(CD-SEM)으로 패턴의 실제 크기·형태를 확인해요 — 광학현미경보다 훨씬 고배율(최대 약 20만 배)이에요 |

오버레이가 어긋나면 층과 층이 제대로 연결되지 않아 원하는 전기적
흐름을 만들 수 없고, CD(Critical Dimension, 패턴의 임계 치수)가
기준을 벗어나면 소자 성능 자체가 달라져요. 그래서 검사는 사진공정의
마지막 관문이자, 다음 공정으로 넘어가도 좋다는 통과증과 같아요.

<Callout type="tip" title="시험 포인트 — 검사 종류와 통과 기준">
  검사 종류(육안·오버레이·CD)를 헷갈려 하는 문제가 잘 나와요. "도포
  불량은 육안, 정렬은 오버레이, 크기는 CD"로 짝지어 기억하세요. 여기서
  걸러지지 않으면 이후 식각 같은 공정에서는 되돌릴 수 없다는 점도
  함께 기억해 두세요.
</Callout>

## 5. 사진공정 장비, 한눈에 정리

| 장비 | 담당 공정 | 기억할 포인트 |
|---|---|---|
| 트랙(Track) | 도포, 현상(+베이크) | 노광 장비와 나란히 붙어 웨이퍼를 주고받아요 |
| 스테퍼(Stepper)·스캐너(Scanner) | 노광 | 트랙 장비와 연결돼 한 세트처럼 움직여요 |
| 오버레이·CD-SEM 계측기 | 검사 | 정렬 상태와 패턴 크기를 재는 전용 장비예요 |
