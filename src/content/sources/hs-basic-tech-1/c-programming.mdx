## 1. 함수와 문장 — C 프로그램의 뼈대

C로 프로그램을 짠다는 건 결국 <strong>함수를 만들고, 그 함수의 실행 순서를 정하는 일</strong>이에요. 수학 함수가 입력을 받아 출력을 내놓듯, C의 함수도 입력(인자)을 받아 특정 작업을 처리한 뒤 결과를 반환하거나 실행해요.

- <strong>함수의 정의</strong>: 입력값을 받아 특정 작업을 수행한 뒤 결과를 반환하거나 실행하도록 짜인 코드 블록.
- <strong>함수의 호출</strong>: 그 함수를 실행하라고 명령하는 행위.
- <strong>인자의 전달</strong>: 호출할 때 함수에 넘겨주는 입력값.

모든 C 프로그램은 가장 먼저 <strong>main</strong>이라는 이름의 함수가 자동으로 호출되면서 시작돼요. 함수가 하는 일은 중괄호로 감싼 영역 안에 적는데, 그 안의 문장 하나하나는 반드시 <strong>세미콜론(;)</strong>으로 끝나야 해요. C는 줄바꿈이 아니라 세미콜론을 문장의 끝으로 인식하기 때문에, 문장 하나가 여러 줄에 걸쳐 있어도 되고 한 줄에 문장 여러 개가 있어도 상관없어요. 다만 보기 좋게 한 줄에 문장 하나씩 쓰는 것이 관례예요.

<strong>주석</strong>(comment)은 코드에 남기는 메모예요. // 뒤(한 줄) 또는 /* */ 사이(여러 줄)에 적으면 컴파일 대상에서 제외돼요. 나중에 코드를 다시 읽을 자신과 동료를 위해 꼭 필요한 습관이죠. 표준 입출력 함수를 쓰려면 코드 맨 위에 #include &lt;stdio.h&gt;처럼 필요한 헤더 파일을 불러오는 문장도 적어야 해요 — printf 같은 <strong>표준 함수</strong>들의 정보가 그 헤더 파일 안에 들어있거든요.

## 2. 화면에 값 내보내기 — printf와 서식 문자

값을 화면에 찍는 대표 함수가 <strong>printf</strong>예요. 문자열과 변수 값을 함께 출력할 수 있고, 문자열만 출력하고 싶다면 더 단순한 <strong>puts</strong> 함수를 써도 돼요.

문자열 안에 <strong>%d</strong>처럼 %로 시작하는 표시를 <strong>서식 문자</strong>라 불러요. 서식 문자는 그 자리에 값을 어떤 형태로 넣을지 지정하는 표시이고, 문자열 뒤에 콤마로 구분해 나열한 값들이 순서대로 그 자리를 채워요. 서식 문자 개수와 나열한 값의 개수는 항상 같아야 해요.

| 서식 문자 | 출력 형태 |
|---|---|
| %d | 부호 있는 10진수 정수 |
| %ld | long형 10진수 정수 |
| %u | 부호 없는 10진수 정수 |
| %o | 8진수 |
| %x, %X | 16진수(소문자, 대문자) |
| %f | 실수(float·double) |
| %e, %E | 지수 표기 실수 |
| %c | 문자 하나 |
| %s | 문자열 |

문자열 속 \n은 <strong>이스케이프 시퀀스</strong>라 부르는 특수 표기로, 커서를 다음 줄로 옮기라는 뜻이에요.

```c
#include <stdio.h>

int main(void)
{
    printf("안녕, 반도체고!\n");
    printf("%d\n", 2026);
    printf("가로 %d, 세로 %d\n", 10, 20);
    return 0;
}
```

## 3. 변수와 대입·산술 연산자

계산 결과나 나중에 다시 쓸 값을 담아두려면 <strong>변수</strong>가 필요해요. 변수는 값을 저장하는 메모리 공간에 붙인 이름이고, 변수를 선언하면 그만큼의 메모리 공간이 확보돼요.

변수 이름 규칙은 이래요.

- 알파벳·숫자·언더바(_)로만 구성한다.
- 대문자와 소문자를 구분한다(Num과 num은 다른 변수).
- 숫자로 시작할 수 없고, 예약어는 이름으로 쓸 수 없다.
- 이름 중간에 공백을 넣을 수 없다.

선언한 위치에 따라 <strong>전역 변수</strong>(함수 밖에서 선언, 프로그램 전체에서 접근 가능, 프로그램이 끝날 때까지 유지)와 <strong>지역 변수</strong>(함수 안에서 선언, 그 함수 안에서만 쓰이고 함수가 끝나면 사라짐)로 나뉘어요.

변수에 값을 넣고 계산하려면 다음 연산자들을 써요.

| 연산자 | 기능 | 예 |
|---|---|---|
| = | 오른쪽 값을 왼쪽 변수에 대입 | num = 20; |
| + | 두 값을 더함 | num = 4 + 3; |
| - | 왼쪽에서 오른쪽을 뺌 | num = 4 - 3; |
| * | 두 값을 곱함 | num = 4 * 3; |
| / | 왼쪽을 오른쪽으로 나눈 몫 | num = 7 / 3; |
| % | 나눈 나머지 | num = 7 % 3; |

```c
#include <stdio.h>

int main(void)
{
    int a = 9, b = 4;

    printf("%d + %d = %d\n", a, b, a + b);
    printf("%d - %d = %d\n", a, b, a - b);
    printf("%d * %d = %d\n", a, b, a * b);
    printf("%d / %d = %d (몫)\n", a, b, a / b);
    printf("%d %% %d = %d (나머지)\n", a, b, a % b);
    return 0;
}
```

## 4. 비교하고 판단하는 연산자 — 증감·관계·논리·비트

값을 1씩 늘리거나 줄이는 상황이 잦다 보니, C는 전용 연산자를 따로 둬요. <strong>전위형</strong>(++num)은 먼저 값을 바꾼 뒤 그 문장에 사용하고, <strong>후위형</strong>(num++)은 그 문장에 먼저 사용한 뒤에 값을 바꿔요.

```c
#include <stdio.h>

int main(void)
{
    int n = 5;

    printf("후위 증가로 전달되는 값: %d\n", n++);
    printf("증가 후 n: %d\n", n);

    n = 5;
    printf("전위 증가로 전달되는 값: %d\n", ++n);
    return 0;
}
```

조건이 맞는지 따지는 <strong>관계 연산자</strong>는 참이면 1, 거짓이면 0을 돌려줘요. C는 0이 아닌 값을 모두 참으로 보고, 1을 참의 대표값으로 써요.

| 연산자 | 의미 |
|---|---|
| &lt; | 작다 |
| &gt; | 크다 |
| &lt;= | 작거나 같다 |
| &gt;= | 크거나 같다 |
| == | 같다 |
| != | 다르다 |

여러 조건을 조합할 때는 <strong>논리 연산자</strong>를 써요.

| 연산자 | 의미 |
|---|---|
| &amp;&amp; | 둘 다 참이어야 참(AND) |
| \|\| | 둘 중 하나만 참이어도 참(OR) |
| ! | 참·거짓을 뒤집음(NOT) |

값을 0과 1의 비트 단위로 다루고 싶을 때는 <strong>비트 연산자</strong>를 써요. 반도체 장비 제어 코드에서 특정 신호 핀 하나만 켜고 끄는 데 실제로 이런 연산이 쓰여요.

| 연산자 | 의미 | 예 |
|---|---|---|
| &amp; | 비트 단위 AND | 1100 &amp; 1010 → 1000 |
| \| | 비트 단위 OR | 1100 \| 1010 → 1110 |
| ^ | 비트 단위 XOR | 1100 ^ 1010 → 0110 |
| ~ | 모든 비트를 반전(단항 연산자) | ~1100 → 0011 (4비트 기준) |
| &lt;&lt; | 왼쪽으로 비트를 이동 | num &lt;&lt; 2 |
| &gt;&gt; | 오른쪽으로 비트를 이동 | num &gt;&gt; 2 |

연산자를 섞어 쓸 때는 우선순위가 낮아지는 순서를 알아야 해요. 괄호 → 단항 연산자(!, ++, --) → 곱셈·나눗셈·나머지(*, /, %) → 덧셈·뺄셈(+, -) → 비트 이동(&lt;&lt;, &gt;&gt;) → 관계 연산자 → 등가 연산자(==, !=) → 비트 AND → 비트 XOR → 비트 OR → 논리 AND(&amp;&amp;) → 논리 OR(\|\|) → 대입(=) 순으로 낮아져요. 같은 순위끼리는 대부분 왼쪽부터 계산하지만, 단항 연산자(!, ++, --)와 대입(=)은 예외적으로 오른쪽부터 계산해요. 헷갈릴 때는 괄호로 순서를 명확히 묶어주는 게 가장 안전해요.

## 5. 입력받기와 흐름 제어 — scanf, 반복문, 조건문

지금까지는 코드 안에 값을 직접 적어 넣었지만, 사용자에게 값을 입력받고 싶다면 <strong>scanf</strong> 함수를 써요. 사용법은 printf와 비슷하지만 정반대 방향(입력)이고, 변수 이름 앞에 반드시 <strong>&amp;</strong>(번지 연산자)를 붙여야 해요 — 값을 저장할 메모리 주소를 알려주는 표시예요. 공백을 포함한 문자열을 통째로 입력받고 싶을 때는 scanf 대신 <strong>fgets</strong> 함수를 써요 — `fgets(buffer, sizeof buffer, stdin)`처럼 버퍼 크기를 함께 지정해야 안전해요(과거 흔히 쓰던 gets는 버퍼 크기 제한이 없어 위험해서 C11부터 표준에서 제외됐어요).

```c
#include <stdio.h>

int main(void)
{
    int a, b;

    printf("정수 두 개를 입력하세요: ");
    scanf("%d %d", &a, &b);
    printf("두 수의 합은 %d입니다.\n", a + b);
    return 0;
}
```

같은 작업을 여러 번 반복하거나 조건에 따라 다르게 실행하고 싶을 때는 <strong>제어문</strong>을 써요.

| 제어문 | 동작 |
|---|---|
| for(초깃값; 조건식; 증감식) | 조건을 만족하는 동안 정해진 횟수만큼 반복 |
| while(조건식) | 조건이 참인 동안 반복(처음부터 거짓이면 한 번도 실행하지 않음) |
| do ∼ while(조건식) | 먼저 한 번 실행한 뒤 조건을 검사(최소 한 번은 실행) |
| if ∼ else | 조건이 참인지 거짓인지에 따라 다른 코드 실행 |
| switch ∼ case | 정숫값 하나를 여러 case와 비교해 맞는 곳으로 분기 |
| break | 감싸고 있는 반복문·switch를 즉시 빠져나옴 |

## 6. 실습 예제로 감 잡기

배운 내용을 짧은 예제 네 개로 정리해 볼게요.

<strong>(1) 문자 하나의 아스키 코드값 출력하기</strong>

```c
#include <stdio.h>

int main(void)
{
    char ch = 'Z';

    printf("문자 '%c'의 아스키 코드 값은 %d입니다.\n", ch, ch);
    return 0;
}
```

<strong>(2) 10진수를 16진수·8진수로 바꾸기</strong>

```c
#include <stdio.h>

int main(void)
{
    int num = 250;

    printf("10진수 %d → 16진수 %x, 8진수 %o\n", num, num, num);
    return 0;
}
```

<strong>(3) 비트 단위 AND·OR·XOR 연산하기</strong>

```c
#include <stdio.h>

int main(void)
{
    int x = 20, y = 6;
    int a, b, c;

    a = x & y;
    b = x | y;
    c = x ^ y;

    printf("%d & %d = %d\n", x, y, a);
    printf("%d | %d = %d\n", x, y, b);
    printf("%d ^ %d = %d\n", x, y, c);
    return 0;
}
```

<strong>(4) 화씨 온도를 섭씨 온도로 바꾸기</strong> — 공식 C = 5/9 × (F − 32)를 반복문으로 여러 번 계산해요.

```c
#include <stdio.h>

int main(void)
{
    int fahrenheit;
    float celsius;

    for (fahrenheit = 90; fahrenheit <= 95; fahrenheit++) {
        celsius = (5.0 / 9.0) * (fahrenheit - 32.0);
        printf("화씨 %d도는 섭씨 %.1f도입니다.\n", fahrenheit, celsius);
    }

    return 0;
}
```
