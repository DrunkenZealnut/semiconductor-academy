## 1. 전류와 전압 — 강물과 높이 차

자유전자가 도선을 따라 이동하는 것이 전류인데, 방향 표기는 조금 독특해요.
전자가 발견되기 전 과학자들은 (+)전하가 움직인다고 생각해 전류의 방향을
전지의 (+)극에서 (−)극으로 정했어요. 나중에 실제로 움직이는 건 (−)전하인
전자라는 게 밝혀졌지만, 관습대로 지금도 (+)에서 (−) 방향을 전류의 방향으로
써요.

전류의 크기는 전기량 Q가 1초 동안 이동한 양으로 정해요.

**I = Q / t [A]** (1초 동안 1[C]의 전하가 이동하면 전류는 1[A])

전압은 물의 위치 에너지 차이에 해당해요. 전하량 Q가 이동해 W만큼의 일을
했을 때, 그 에너지가 전압이에요.

**V = W / Q [V]**

## 2. 세 가지 전류 — 직류·교류·맥류

| 종류 | 특징 | 예시 |
|------|------|------|
| 직류(DC) | 방향·크기가 항상 일정 | 건전지, 축전지, 정류기 |
| 교류(AC) | 일정 주기로 방향·크기가 바뀜 | 가정용 전원(정현파) |
| 맥류(PC) | 방향은 일정, 크기만 변함 | 반파·전파 정류기 출력 |

## 3. 옴의 법칙과 저항의 연결

<strong>옴의 법칙</strong>은 전류가 전압에 비례하고 저항에 반비례한다는
원리예요.

**I = V / R [A]**

실제 측정 회로에서는 <strong>전류계를 부하와 직렬로, 전압계를 부하와
병렬로</strong> 연결해야 정확히 잴 수 있어요.

### 직렬 회로

저항을 순서대로 하나씩 이으면, 전체 저항(합성 저항 R_T)은 각 저항을 그냥
더한 값이에요.

**R_T = R₁ + R₂ + R₃**

길이가 늘어나는 셈이니 저항이 커지는 거죠. 원하는 전류·전압 조건에 맞춰
저항값을 골라 직렬 회로를 설계할 수도 있어요 — 이때는 시중에 파는 표준
저항값(색띠로 표시된 그 값들이에요) 중에서 적절히 골라야 해요.

### 병렬 회로

저항 여러 개를 나란히 이으면, 각 저항에 흐르는 전류(I₁, I₂, I₃)를 모두
더한 것이 전체 전류(I_T)예요.

**I_T = I₁ + I₂ + I₃ = V(1/R₁ + 1/R₂ + 1/R₃)**

여기서 합성 저항의 역수를 구하면:

**1/R_T = 1/R₁ + 1/R₂ + 1/R₃ (+ ⋯)**

병렬 연결은 물길이 여러 갈래로 나뉘는 셈이라, 저항이 하나 늘수록 전체
저항은 오히려 작아져요 — 직렬과 정반대죠.

## 4. 키르히호프의 법칙 — 접합점과 폐회로의 균형

옴의 법칙만으로 풀기 어려운 복잡한 회로는 <strong>키르히호프의
법칙</strong> 두 가지로 분석해요.

**전류 법칙(KCL)**: 회로의 한 접합점(node)으로 들어오는 전류의 합과 나가는
전류의 합은 같아요. 예를 들어 I₁이 들어오고 I₂, I₃가 나간다면 I₁ = I₂ + I₃,
즉 접합점에서 전류의 총합은 항상 0이에요(들어오는 방향을 +, 나가는 방향을
−로 잡으면).

**전압 법칙(KVL)**: 하나의 폐회로를 한 바퀴 돌면서 만나는 전압들을 전부
더하면 0이 돼요. 공급 전압 V가 각 소자에서 V₁, V₂, V₃만큼 나눠 소모된다면
V = V₁ + V₂ + V₃라는 뜻이에요.
