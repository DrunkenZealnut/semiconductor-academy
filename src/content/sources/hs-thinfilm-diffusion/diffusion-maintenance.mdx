## 1. 조정단말기 — 레시피를 보여주고 고르는 화면

확산 장비의 조작 화면은 크게 <strong>오퍼레이션 화면</strong>과{' '}
<strong>텐키(ten key)</strong>로 나뉘어요. 오퍼레이션 화면은 레시피와 알람
로그, 가스, 온도, T-BAWL 상태 등을 한자리에서 다루는 창구인데, 그중에서도
가장 자주 쓰는 기능은 셋이에요 — 레시피를 새로 만들고 고치는{' '}
<strong>편집</strong>, 지금 실행 중인 레시피의 스텝과 시간을 보여주는{' '}
<strong>스텝·시간 확인</strong>, 그리고 다음에 돌릴 레시피를 고르는{' '}
<strong>선택</strong>. 확산로를 조작한다는 건 결국 대부분 이 세 가지 사이를
오가는 일이에요.

텐키는 커서를 옮기고 값을 입력하는 이동·숫자 키 묶음과, 그 아래 놓인
하드웨어 버튼 한 줄로 이뤄져요. 화면 속 메뉴와 달리 이 버튼들은 눌렀을 때의
동작이 분명해서, 알람이나 비상 상황에 곧장 손이 가는 자리예요.

| 버튼 | 하는 일 |
|---|---|
| START | 설정된 레시피로 공정을 시작한다 |
| END RESET | 레시피가 끝나 부저가 울리면 점등되고, 누르면 꺼진다 |
| ALARM RESET | 알람이 울리면 부저를 멈춘다 — 램프는 알람 원인이 실제로 풀려야 꺼진다 |
| EMG ABORT | 실행 중인 레시피를 강제로 즉시 중단시킨다 |
| HOLD | 진행 중인 스텝의 시간을 멈춰 둔다 |
| SKIP | 지금 스텝을 건너뛰고 다음 스텝으로 강제 이동한다 |
| MANUAL | 스텝 시간을 멈추고 수동으로 개입한다 |
| POWER | 조정단말기의 메인 컨트롤러에 전원을 넣는다 |

화면 메뉴를 몇 단계씩 눌러 들어가야 하는 기능들과 달리, 이 물리 버튼들은
화면이 먹통이 되어도 살아있는 마지막 안전판이에요. ALARM RESET을 눌러도 램프가 꺼지지 않는다면, 그건 소리만 멈췄을 뿐 원인은
아직 그대로라는 뜻이에요 — 알람 대응의 첫 번째 원칙은 "조용해졌다고 끝난
게 아니다"예요.

## 2. T-BAWL — 웨이퍼가 보트에 오르기까지

확산로에서 웨이퍼를 나르는 자동화 시스템에는{' '}
<strong>T-BAWL(Tube-Boat Auto Wafer Loading)</strong>이라는 이름이 붙어
있어요 — 이름 그대로, 튜브(공정관)와 보트 사이에서 웨이퍼를 자동으로 실어
나른다는 뜻이에요. 카세트 한 개가 보트 위 웨이퍼로 자리 잡기까지, 웨이퍼는
정해진 길을 그대로 따라가요.

| 순서 | 위치 | 하는 일 |
|---|---|---|
| 1 | I/O 포트 | 카세트가 장비에 처음 놓이는 자리 |
| 2 | 카세트 트랜스퍼 | 카세트를 I/O 포트에서 들어 옮기는 손 |
| 3 | 카세트 스토커 | 옮겨진 카세트가 대기하는 자리 |
| 4 | 트랜스퍼 스테이지 | 카세트 트랜스퍼에서 웨이퍼 트랜스퍼로 바통을 넘기는 중간 지점 |
| 5 | 웨이퍼 트랜스퍼 | 카세트에서 웨이퍼를 한 장씩 꺼내 보트로 옮기는 손 |
| 6 | 보트 | 웨이퍼 수십 장이 최종적으로 자리 잡는 곳 |

언로딩은 이 순서를 그대로 거꾸로 밟아요. 보트가 다 차면{' '}
<strong>보트 엘리베이터</strong>가 보트를 들어 올려 히터챔버 안으로 밀어
넣고(로드), 공정이 끝나면 다시 내려요(언로드) — 이때 챔버 입구를 여닫는
문이 <strong>오토셔터</strong>예요. 카세트를 옮기는 손과 웨이퍼 한 장을
옮기는 손이 이렇게 따로 있는 이유는 간단해요 — 카세트 하나의 무게와
웨이퍼 한 장의 무게·크기가 크게 달라서, 서로 다른 정밀도로 다뤄야 하기
때문이에요. 정리하면 확산로의 자동화는 오토도어·카세트 I/O 포트·카세트
트랜스퍼·카세트 스토커·트랜스퍼 스테이지·웨이퍼 트랜스퍼·보트 엘리베이터·
오토셔터, 이 여덟 요소가 맞물려 돌아가요.

## 3. 낱개 점검에서 실전 생산까지 — DIAG·EVALUATION·RUN

T-BAWL을 실제로 움직이기 전에는 세 단계를 거쳐요. 먼저{' '}
<strong>DIAG(진단) 모드</strong>에서 구동부를 하나씩 따로 움직여 보며
낱개로 점검해요 — 앞서 본 자동화 요소들을 기능별로 묶으면 이렇게
정리돼요.

| 점검 대상 | 하는 일 |
|---|---|
| 카세트 로더 도어 | 카세트를 넣는 출입문을 여닫는다 |
| 카세트·웨이퍼 트랜스퍼 | 카세트와 웨이퍼를 층층이 손으로 옮기듯 이동시킨다 |
| 보트 엘리베이터 | 보트를 히터챔버 안팎으로 오르내리고 돌린다 |
| 오토셔터 | 히터챔버 입구를 여닫는다 |

이렇게 낱개로 이상이 없는지 확인한 다음은{' '}
<strong>EVALUATION(평가) 모드</strong> — 실제 생산 없이 카세트와 웨이퍼의
이동 흐름 전체를 시험 삼아 돌려 보는 단계예요. 마지막이{' '}
<strong>RUN(운전) 모드</strong>, 실제 로트를 흘리는 생산 단계고요. 낱개 점검
→ 흐름 시험 → 실전 생산, 이 사다리를 거꾸로 오르는 법은 없어요.

구동부가 여러 축으로 나뉘어 있다 보니, 축끼리 부딪히지 않게 서로 다른
축의 움직임을 조건으로 거는 장치가 필요해요. 이걸{' '}
<strong>인터락(interlock)</strong>이라 불러요. 예를 들어 보트 엘리베이터는
오토셔터가 열려 있어야만 올라갈 수 있어요 — 셔터가 닫힌 채로 올리려 하면,
장비는 조건이 채워지지 않았다는 메시지만 띄우고 움직이지 않아요. 어느 한
축의 실수가 다른 축의 충돌로 번지지 않도록 막아 주는 셈이에요.

RUN 모드로 실제 로트를 흘릴 때도 순서가 있어요. 웨이퍼를 보트에 실을
때는 <strong>더미(dummy) → 프로덕션(production) → 모니터(monitor)</strong>{' '}
순으로 채우고, 꺼낼 때는 <strong>모니터 → 프로덕션</strong> 순으로 반대로
비워요. 생산용이 아닌 더미·모니터 웨이퍼를 앞뒤에 배치해 두면, 보트 양
끝처럼 조건이 흔들리기 쉬운 자리를 실제 제품 대신 먼저 맡아 주는 셈이에요.

## 4. 배치식 장비의 무게중심 — 보트 하나에 수십 장

박막 공정에서 만난 클러스터형 CVD 장비 — 예컨대 <strong>P-5000</strong> 같은
멀티 챔버 장비 — 는 챔버 하나에 웨이퍼를 한 장씩 넣는{' '}
<strong>매엽식</strong>이었어요. TEL α-8 같은 수직형 퍼니스는 정반대예요 —
보트 하나에 웨이퍼 수십 장을 실어 통째로 굽는 <strong>배치식</strong>이죠.
T-BAWL이 애써 카세트·트랜스퍼·보트 사이의 자동 반송 경로를 갖춘 이유도
결국 여기 있어요 — 한 장이 아니라 수십 장을 동시에, 정확한 자리에 실어야
하니까요.

보트가 히터챔버로 들어갈 때 <strong>회전(rotate)</strong>하며 진입하는
기능도 있어요. 수십 장이 통 안에서 고르게 조건을 받게 하려는, 배치식
장비다운 배려예요. 이런 배치식 장비는 로딩부터 언로딩까지 준비 시간이
상대적으로 길지만, 한 번 공정을 돌리면 웨이퍼 수십 장을 한꺼번에
처리하니 웨이퍼 한 장당 처리 시간으로 보면 오히려 유리해요.

## 5. 가스라인, 새는 곳부터 잡는다

확산로에는 여러 갈래의 가스 라인이 몰려 있어요. 라인을 새로 연결했거나
새는 게 의심될 때는, 진공이 아니라 거꾸로 <strong>압력을 넣어</strong>
확인해요.{' '}
<SourceRef source="hs-photo-etch" section="etcher-maintenance" label="「반도체 포토·에칭」 TE8500 장비의 유지·보수" />에서
본 에칭 장비의 리크 체크가 진공 챔버를 막아 두고 압력이 얼마나 올라오는지
지켜보는 방식이었다면, 확산로의 가스 라인 점검은 정반대예요 — 라인에
질소(N₂)를 채워 압력을 <strong>3kgf/cm² 이상</strong>까지 올린 뒤 공급
쪽 밸브를 잠그고, 10분 동안 안정시켜 그 압력을 기록해요. 그리고{' '}
<strong>12시간 이상</strong> 그대로 두었다가 다시 압력을 재요. 이렇게 오래
기다리는 이유는 간단해요 — 아주 미세한 틈은 새는 속도도 느려서, 짧게 보면
멀쩡해 보이기 쉽거든요. 두 값을 비교해서 압력이 떨어져 있으면 어딘가 새고
있다는 뜻이고, 그러면 이음매(피팅)를 다시 살펴 같은 과정을 반복해요.

이 라인에는 점검할 때는 안전한 질소만 흐르지만, 실제 공정 중에는 위험한
반응 가스가 지나가요 — 그래서 라인을 손보기 전에는 반드시 가스를 비우는{' '}
<strong>퍼지(purge)</strong> 절차가 먼저예요. 확산 공정에서 다루는 가스가
어떤 위험을 갖는지는 <ChapterRef order={7} />에서 자세히 다뤄요.

## 6. 소모품을 갈아 끼우는 순서 — MFC와 밸브

가스 라인의 소모품을 갈아 끼울 때도 원칙은 같아요 — 손대기 전에 반드시
질소로 퍼지부터 해요.

| 작업 | 핵심 절차 | 잊지 말아야 할 것 |
|---|---|---|
| MFC 교체 | 신호 연결단자를 분리하고, 앞뒤 피팅(VCR)을 풀어 MFC를 갈아 낀다 | 사용한 개스킷은 반드시 새것으로 교체 |
| 밸브 교체 | 에어 튜브를 분리하고, 피팅을 풀어 밸브를 갈아 낀다 | 교체 후 밸브를 직접 열고 닫아 가스 흐름과 동작을 확인 |

개스킷을 매번 새것으로 바꾸는 이유도 리크 체크와 같은 맥락이에요 — 한
번 눌려 찌그러진 개스킷을 재사용하면 겉보기엔 멀쩡해도 미세한 틈이 남을
