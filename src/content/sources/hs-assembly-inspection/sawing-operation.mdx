쏘잉 머신은 사람이 임의로 순서를 바꿔 조작하는 장비가 아니에요. 이번
모듈에서는 실제 조작 화면의 버튼 하나하나보다, <strong>왜 이 순서로
움직이는지</strong>를 따라가 볼게요.

## 1. 준비 작업 — 시작하기 전에 맞춰야 하는 것들

절삭을 시작하기 전, 장비는 크게 세 가지를 먼저 확인해요.

먼저 냉각수와 공기 밸브를 열어 절삭 중 쓸 물과 압축 공기부터
준비해요. 이어서 AC 전원을 켜고 장비를 초기화하는데, 이때도 순서가
있어요 — 공기와 냉각수 공급을 먼저 확인한 뒤에 전원을 넣어야, 정작
절삭이 시작될 때 물도 공기도 없는 상태로 블레이드만 도는 상황을 막을
수 있어요.

마지막으로 <strong>척 테이블의 기준 높이(0점)</strong>를 다시 잡아요.
블레이드와 척 테이블이 맞닿는 지점을 정확히 0.0으로 잡아 둬야 절삭
깊이가 항상 일정하게 유지되거든요. 이 기준점은 아무 때나 다시 잡는 게
아니라, 아래 세 경우에만 다시 맞춰요.

| 언제 다시 맞추나 | 왜 |
|---|---|
| 전원을 껐다가 다시 켰을 때 | 꺼져 있는 동안 기준점이 흐트러졌을 수 있어서예요 |
| 절단면에 칼날 자국이 남지 않을 때 | 블레이드가 척 테이블에 닿는 깊이가 어긋났다는 신호라서예요 |
| 블레이드를 교체했거나 척 테이블을 재가동했을 때 | 새 블레이드·재가동된 테이블의 실제 높이가 이전과 달라져서예요 |

기준점을 맞추는 동안에는 앞면 덮개를 닫아 두고, 블레이드와 척 테이블이
닿아 화면에 0.0mm로 표시되면 절삭 준비가 끝나요. 이후 척 테이블에 남은
물기를 에어건으로 반드시 제거하는데 — 물기가 남으면 다음 단계인 웨이퍼
장착과 진공 고정이 제대로 되지 않기 때문이에요. 스핀들이 멈춰 있는
것을 확인하면 준비 작업이 마무리돼요.

## 2. 본 작업 — 자동 절삭이 이루어지는 순서

### 레시피부터 부른다

쏘잉 머신은 제품마다 조건을 매번 새로 입력하지 않아요.{' '}
<strong>레시피(Recipe)</strong> — 요리의 조리법처럼, 장비가 그대로
따라갈 절삭 조건 한 벌 — 를 미리 저장해 두고, 작업할 제품에 맞는
레시피를 불러오는 것으로 시작해요. 아래는 이런 유형의 장비가 레시피에
담는 대표 조건이에요.

| 조건 | 대표값(예시) | 의미 |
|---|---|---|
| 스핀들 회전수 | 30,000rpm 안팎 | 블레이드가 웨이퍼를 파고드는 속도 |
| 제품 형상 | 원형 또는 사각 | 자를 웨이퍼·기판의 모양 |
| 가공 사이즈 | 약 200mm(8인치급) | 절삭할 제품의 대표 지름 |
| 웨이퍼 두께 | 0.700 안팎 | 절삭 대상의 두께 |
| 절입 깊이 | 0.060 안팎 | 척 테이블 위로 블레이드가 파고드는 깊이 |
| 이송 속도 | 10.0 안팎 | 블레이드가 지나가는 속도 |
| 테이프 두께 | 0.07 안팎 | 마운트에 쓰인 테이프의 두께 |

### 웨이퍼를 장착하고 정렬한다

레시피를 불러온 뒤에는 마운트된 웨이퍼를 척 테이블에 올리고 — 이때도
물기가 없는지 먼저 확인해요 — 진공으로 고정해요. 그다음이 정렬이에요.
카메라가 절단선을 알아볼 수 있도록 먼저 조명과 초점을 자동으로
맞추고, 화면에 나타나는 <strong>Hair Line</strong>(칩과 칩 사이의
절단 기준선을 표시하는 선)에 실제 절단할 위치를 맞춰요. 이 정렬을
가로축(CH1)에서 한 번, 제품을 90도 돌린 세로축(CH2)에서 한 번 더 —
이렇게 두 번에 걸쳐 하는 이유는 절단선이 가로·세로 격자 모양으로 나
있어서예요. 한쪽만 맞고 다른 쪽이 어긋나면 칩이 비뚤게 잘려요.

### 자동 절삭과 반자동 절삭

정렬이 끝나면 절삭을 시작해요. 이때 두 가지 방식 중 하나를 골라요.

| 방식 | 진행 방법 | 언제 쓰나 |
|---|---|---|
| 자동 절삭 | 설정된 라인을 처음부터 끝까지 한 번에 절삭해요 | 정렬 조건이 안정적으로 잡혀 있을 때 |
| 반자동 절삭 | 절삭할 라인 수(전체·1개·2개)를 지정해 나눠 진행하고, 도중에 정지해 정렬 상태를 다시 확인할 수 있어요 | 중간중간 절단 상태를 눈으로 확인하며 진행하고 싶을 때 |

반자동 절삭 중 멈추면, 칼날이 지나간 자국과 화면의 십자선을 맞춰
보는 방식으로 정렬을 다시 확인할 수 있어요. 절삭이 끝나면 진공
고정을 풀고 에어건으로 가공물을 꺼낸 뒤, 스핀들이 멈춘 것을
확인해요.

## 3. 종료 작업 — 안전하게 장비를 재우는 순서

작업이 끝나면 준비 작업의 역순으로 장비를 정리해요. 순서가 뒤집히면
안 되는 이유가 있어요 — <strong>회전이 완전히 멈춘 것을 확인하고
나서야 전원을 내리고</strong>, 전원을 내린 뒤에야 공기·냉각수 밸브를
잠가요. 회전 중에 전원부터 끊으면 관성으로 블레이드가 불규칙하게
멈추면서 날이 상하거나 다치는 사고로 이어질 수 있거든요.

## 4. 장비 조작 안전 수칙

쏘잉 머신은 고속으로 도는 블레이드와 절삭 중 튀는 미세 분진을 함께
다루는 장비예요. 그래서 아래 수칙은 예외 없이 지켜야 해요.

| 수칙 | 이렇게 하는 이유 |
|---|---|
| 정해진 안전 규칙과 조작 순서를 지킨다 | 순서를 벗어나면 예상치 못한 오작동으로 이어질 수 있어서예요 |
| 인터록(Interlock)이 정상 작동하는지, 강제 해제 시 경고 신호가 뜨는지 확인한다 | 인터록은 위험한 상태에서 장비가 스스로 멈추게 하는 마지막 안전장치라서예요 |
| 비상 스위치가 정상 작동하는지 확인한다 | 위급 상황에서 가장 먼저 손이 가는 장치이기 때문이에요 |
| 안전장치 이상 시 즉시 정지·정비하고, 해제 상태로는 절대 작업하지 않는다 | 안전장치 없이 도는 블레이드는 사람에게 그대로 위험이 되기 때문이에요 |
| 정비 중 위급 상황이 생기면 비상 스위치나 메인 차단기로 멈춘다 | 정비자가 가장 빠르게 회전을 멈출 수 있는 방법이라서예요 |
| 전기 장치를 다룰 때는 전원을 차단하고 무전압을 확인한 뒤 작업하며, 소자를 만질 때는 정전기 방지 장갑을 따로 쓴다 | 감전 예방과 정전기 손상 방지는 서로 다른 보호가 필요하기 때문이에요 — 정전기 방지 장갑은 감전을 막아 주지 않아요 |

고속으로 도는 블레이드와 그 주변의 절삭 분진은 조립·검사 공정 전체를
관통하는 물리적 위험이에요. 이 공정 라인의 유해인자는{' '}
<ChapterRef order={13} />에서 자세히 정리해요.

## 5. 실습으로 확인하기

이 모듈에서 배운 논리를 실습 두 가지로 직접 확인해요.

**실습과제 1 · 웨이퍼 테이프 마운트하기** — 테이프 마운터로 웨이퍼를
고정하는 실습이에요. 목표는 테이프의 용도를 설명하고 실제로 마운트를
해내는 것. 실습기기는 테이프 마운터, 재료는 웨이퍼와 UV 테이프예요.
프레임과 웨이퍼를 스테이지에 올려 진공으로 고정한 뒤, 테이프를 당겨
덮고 롤러로 눌러 기포 없이 밀착시켜요. 남은 테이프 끝단을 자르고
덮개를 닫은 다음, 회전 칼로 테이프를 웨이퍼 모양대로 다듬어 마운트된
웨이퍼와 프레임을 꺼내면 끝나요. 이때 웨이퍼가 손상되지 않게 다루고
장비에 충격을 주지 않으며, 테이프를 붙일 때 칼날에 무리한 힘을 주지
않는 것이 핵심 유의사항이에요. 평가는 마운터의 구조·기능을
이해했는지, 진공이 고르게 밀착됐는지, 작업 순서를 지켰는지를
확인해요.

**실습과제 2 · 웨이퍼 쏘잉 작업하기** — 실제 쏘잉 머신(DAD640 등)으로
웨이퍼를 절삭하는 실습이에요. 목표는 웨이퍼 재질에 맞는 블레이드를
고르고, 회로 도면을 보며 절삭을 해내는 것. 재료는 웨이퍼와
카본(다이아몬드) 블레이드예요. 진행 순서는 이 모듈에서 다룬 흐름
그대로예요 — 냉각수·공기 밸브를 열고 전원을 켜 초기화한 뒤 척 테이블
위치를 맞추고, 레시피를 불러와 웨이퍼를 장착하고 절삭 위치·조건을
세팅해 자동·반자동 절삭을 진행한 다음, 절삭을 종료하고 전원과
밸브를 차례로 잠가요. 스핀들이 도는 동안에는 방수 커버를 절대 열지
않고, 블레이드 외경에 맞는 회전수로만 장비를 쓰며, 칼날·척 테이블
주변과 전기 장치를 다룰 때 항상 안전에 유의하는 것이 핵심이에요.
평가는 블레이드 재질과 장비 구조를 설명할 수 있는지, 조작 순서를
정확히 지키는지를 확인해요.

두 실습 모두 조작은 반드시 지도 교사의 지시에 따라 진행하고, 이상이
생기면 즉시 실습을 멈추고 지도 교사에게 알려야 해요.

<Callout type="warning" title="안전 수칙 한눈에">
  쏘잉 장비를 다룰 때는 아래 사항을 모두 지켜야 해요.

  - 스핀들이 도는 동안에는 블레이드 회전부의 방수 커버를 절대 열지 않는다.
  - 장착된 블레이드의 외경에 맞는 회전수로만 장비를 사용한다.
  - 칼날 근처·척 테이블 주변, 전기 장치를 다룰 때 항상 안전에 유의한다.
  - 웨이퍼·테이프를 다룰 때 무리한 힘을 주지 않고, 장비에 충격을 주지 않는다.
  - 인터록·비상 스위치가 정상 작동하는지 확인하고, 안전장치를 해제한 상태로는 절대 작업하지 않는다.
  - 기기 조작은 지도 교사의 지시에 따르고, 이상이 생기면 즉시 실습을 멈추고 알린다.
</Callout>
