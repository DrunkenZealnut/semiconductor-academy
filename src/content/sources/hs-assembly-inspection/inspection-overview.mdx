조립 공정 지도를 다시 떠올려 볼까요. 다이 본딩 단계에서 "테스트로 양품 판정된
칩만 골라 붙인다"고 했었죠. 그 양품을 무엇으로, 어떻게 가려내는지가 바로 이
단원부터 이어지는 <strong>검사(Inspection)</strong> 이야기예요. 검사는 조립의
앞과 뒤 모두에 자리 잡고 있어요 — 조립하기 <strong>전</strong> 웨이퍼 상태에서
한 번, 조립을 마친 <strong>후</strong> 완제품 상태에서 또 한 번요.

## 1. 검사가 반도체 공정에 놓인 자리

검사(Inspection)라는 발상은 뜻밖에도 우주에서 왔어요. 인공위성으로 지상의
변화를 관측하던 기술이, 반도체 제조 상태를 진단하는 기술로 옮겨 온 거예요.
지금은 그 기술이 웨이퍼 위 칩 하나하나의 전기적 특성을 재고, 완제품이 제대로
동작하는지 가리는 데 쓰이고 있어요.

반도체 제조공정의 마지막 단계인 검사는 <strong>언제 검사하느냐</strong>를
기준으로 크게 둘로 나뉘어요. 다음 절에서 그 둘을 나란히 놓고 비교해 볼게요.

## 2. 왜 두 번 검사하는가 — 웨이퍼 레벨과 패키지 레벨

| 구분 | 웨이퍼 레벨 검사 (프로브 테스트) | 패키지 레벨 검사 (패키지 테스트) |
|---|---|---|
| 검사 시점 | 전공정 직후, 칩을 낱개로 자르기 전 | 조립(패키징)까지 마친 완제품 상태 |
| 가려내는 것 | 불량 다이를 조립 전에 미리 걸러냄 | 조립 과정에서 새로 생긴 결함까지 포함해 최종 품질 확인 |
| 판정 단위 | 웨이퍼 위 칩(다이) 하나하나 | 완제품(패키지) 하나하나 |

두 검사가 따로 존재하는 이유는 간단해요. 조립(패키징)에는 리드 프레임·와이어·
EMC 같은 재료비와 공정 시간이 들어가요. 애초에 불량인 칩을 조립까지 마치고
나서야 걸러낸다면 그 재료와 시간을 통째로 낭비하는 셈이죠. 그래서 조립 <strong>
전</strong> 웨이퍼 상태에서 한 번 걸러내는 게 프로브 테스트예요. 그런데 조립
과정 자체에서도 본딩이 어긋나거나 몰딩이 불완전하게 되는 등 새로운 불량이
생길 수 있어요. 그래서 조립을 <strong>마친 뒤</strong>에 완제품을 다시 검사하는
패키지 테스트가 한 번 더 필요해요.

## 3. 프로브 테스트 — 웨이퍼 상태에서 가려내기

<SourceRef source="ncs-semi" section="wafer-level-test" label="NCS · 반도체 웨이퍼 레벨 테스트 장비 운영" />에서
현업의 능력단위로도 다뤄지는 이 공정은, 웨이퍼 한 장에 붙어 있는 수백 개의 칩을
아래 다섯 단계로 훑어가요.

| 단계 | 이름 | 하는 일 |
|---|---|---|
| 1 | EPM(Electrical Parameter Monitor) | 트랜지스터 특성·접촉저항 등 전기적 특성을 측정해 제조 상태를 추정한다 |
| 2 | WFBI(Wafer Burn-In) | 웨이퍼 상태에서 전압·온도 스트레스를 가해 초기 불량을 미리 유도한다 |
| 3 | PT1 | 각 셀에 전기 신호를 인가해 양품·보정 가능·불량을 구분한다 |
| 4 | L/R(Laser Repair) | 레이저로 불량 셀의 퓨즈를 끊고 여분의 셀로 교체한다 |
| 5 | PT2 | 레이저 보정이 제대로 됐는지 다시 검사한다 |

2단계 WFBI가 특히 알뜰한 아이디어예요. 완제품이 된 뒤에 번인(Burn-in) 검사를
하려면 시간이 오래 걸리는데, 웨이퍼 상태에서 미리 스트레스를 줘 약한 칩을
걸러내면 훨씬 짧게 끝나거든요. 실제로 이 방식을 도입한 사례에서는 패키지
번인에 드는 시간을 12시간 이상에서 2~4시간 수준으로 줄이고, 수율을 1~2퍼센트
포인트 끌어올리는 효과가 보고되기도 했어요.

이 밖에 두 가지 공정이 더 있어요. <strong>베이크(Bake)</strong>는
120~350℃ 정도의 열을 가해 웨이퍼 표면의 코팅막을 단단하게 만드는 공정인데,
원래는 조립 단계의 일이었다가 비용 절감을 위해 프로브 단계로 옮겨 왔어요.
<strong>잉킹(Inking)</strong>은 불량으로 판정된 다이에 잉크로 표시를 남겨,
이후 조립 공정에서 양품만 골라 포장하도록 돕는 공정이에요.

프로브 테스트는 <strong>무엇을 확인하느냐</strong>에 따라서도 나뉘어요.

| 종류 | 확인하는 것 |
|---|---|
| DC Test | 개방·단락 여부, 이물질, 소비 전력 |
| Function Test | 셀에 읽기·쓰기를 반복해 기능이 제대로 동작하는지 |
| Application Test | 실제 사용 시스템에 장착한 것과 같은 조건에서 확인 |
| 신뢰성 Test | 겉으로 드러나지 않는 잠재적 불량 여부 |

## 4. 패키지 테스트 — 완제품이 되어 다시 한번

<SourceRef source="ncs-semi" section="package-level-test" label="NCS · 반도체 패키지 레벨 테스트 장비 운영" />로도
이어지는 이 단계는, 조립을 마친 완제품을 대상으로 진행돼요.

| 단계 | 내용 |
|---|---|
| TDBI | 고온에서 장시간 전기 스트레스를 가해 초기 불량 제품을 미리 걸러낸다 |
| TEST | 고객이 요구하는 스펙에 맞춰 전기적 기능이 제대로 발휘되는지 확인한다 |
| Marking | 제품명·로트 번호를 새겨 생산 이력을 남긴다 |
| Visual | 장비(LIS)와 육안(FVI)으로 외관·리드 상태를 검사하고, 리드 불량은 재생(LCS)한다 |
| Packing | 테이프&릴 포장 또는 진공 포장으로 출하를 준비한다 |

패키지 테스트도 조건에 따라 여러 종류로 나뉘어요.

| 종류 | 확인하는 조건 |
|---|---|
| Function Test | 시험 패턴을 넣고 출력 패턴이 기댓값과 같은지 비교 |
| DC Test | 입출력 회로·전원계의 직류 전기 특성 |
| AC Test | 스위칭 시간 등 동적 특성 |
| Cold Test | 액체 질소를 이용한 저온(약 영하 40℃~영하 5℃) 환경 |
| Hot Test | 70℃ 이상 고온 환경 |
| Room Test | 상온에서 특성을 안정화 |

테스트를 거치지 않은 반도체로 완제품(휴대전화·PC 등)을 만들면, 숨어 있던
불량 하나가 제품 전체의 신뢰를 무너뜨릴 수 있어요. 반도체를 잘 설계하고
조립하는 일 못지않게, 제 기능을 하는지 끝까지 확인하는 일이 중요한 이유예요.

<Callout type="tip" title="함께 보면 좋아요">
  프로브 테스트의 다섯 단계(EPM~PT2)가 실제로 어떤 장비 위에서, 어떤 순서와
  논리로 벌어지는지는 다음 단원 <strong>프로브 테스트 장비</strong> 편에서
  뜯어봐요. 웨이퍼 위 칩과 탐침을 정확히 맞대는 장비, 프로버(Prober)가
  주인공이에요.
</Callout>
