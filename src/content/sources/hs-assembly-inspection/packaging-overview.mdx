  반도체 조립(패키징)이 전체 공정 어디에 놓이는지 설명하고, 패키지가 맡는 네 가지
  기능을 구분하며, 조립 공정 8단계를 순서대로 짚고, TSOP·FBGA 같은 패키지 종류의
  차이를 설명할 수 있어요.
</Callout>

이 교과서는 반도체 <strong>후공정</strong> — 완성된 웨이퍼를 자르고 붙여 제품으로
만드는 <strong>조립</strong>과, 만든 것이 제대로 작동하는지 가려내는{' '}
<strong>검사</strong> — 의 공정과 장비를 장비 기술자의 눈으로 다뤄요. 웨이퍼 위에
회로를 만드는 전공정의 전체 흐름은
<SourceRef source="daegu-hs-process" section="process-overview" label="「반도체 공정기초」 반도체 공정의 이해" />에서
다졌으니, 이 권은 그 <strong>다음 이야기</strong>부터 시작해요.

## 1. 웨이퍼에서 검은 칩까지 — 조립이 놓인 자리

반도체 만들기를 크게 나누면 네 토막이에요 — 웨이퍼 표면에 막을 쌓고 깎기를
되풀이해 미세 회로를 새기는 <strong>전공정(fabrication)</strong>, 웨이퍼 위의 칩을
낱개로 잘라 포장하는 <strong>패키지(조립)</strong>, 제대로 작동하는지 가려내는{' '}
<strong>검사(test)</strong>, 그리고 여러 칩을 한 기판에 모아 조립하는{' '}
<strong>모듈(module)</strong>.

조립(packaging)은 전공정이 끝난 웨이퍼의 칩을 개개로 잘라{' '}
<strong>리드 프레임(lead frame)</strong>과 결합해 완제품으로
만드는 과정이에요. 요즘은 <strong>어셈블리(assembly)</strong>라는 말로도 많이
불러요. 완성된 패키지의 속을 들여다보면 구조가 한눈에 들어와요 — 알루미늄·구리로
만든 리드 프레임 위에 웨이퍼 칩을 붙이고, 전기 신호가 다닐 금선(gold wire)을
연결한 뒤, 바깥 충격에서 소자를 지키기 위해 에폭시 수지로 감싼 구조예요.

## 2. 패키지의 네 가지 일

포장(패키지)은 장식이 아니라 기능이에요. 패키징 기술이 반드시 해내야 하는 일은
네 가지로 정리돼요.

        { label: '외부 보호', note: '물리·화학·열 충격에서 — 기계적 신뢰성 구조 설계' },

| 기능 | 하는 일 | 걸린 기술 |
|---|---|---|
| 전력 공급 | 칩이 일할 전기를 넣어 준다 | 패키징 구조와 맞물린 재료·공정 설계 |
| 신호 연결 | 칩과 바깥, 칩과 칩 사이 신호를 잇는다 | 신호보전(signal integrity)·회로 설계·접속 기술 |
| 열 방출 | 칩에서 나는 열을 밖으로 뺀다 | 열이 성능·신뢰성을 갉지 않게 하는 방열 설계 |
| 외부 보호 | 물리·화학·열 충격에서 소자를 지킨다 | 기계적 신뢰성을 보장하는 구조 설계 |

여기에 더해 패키지는 <strong>작아져야</strong> 해요. 크기를 줄여야 패키지 효율이
오르고, 시스템 안정성은 부품 하나하나의 결함률이 좌우하니 열적·전기적 신뢰성을
높이는 설계와 재료 선택이 함께 가야 하죠. 스마트폰 한 대가 게임기·카메라·
내비게이션 노릇까지 하게 된 바탕에는 이 "작고 믿음직한 포장" 기술의 발전이
있어요.

## 3. 조립 공정 8단계 지도

조립의 뼈대는 <strong>쏘잉 → 다이 본딩 → 와이어 본딩 → 트림 폼</strong> 네
공정이고, 앞뒤로 보조 공정이 붙어 전체 흐름이 완성돼요. 순서대로 걸어 볼게요.

<FlowSteps
  caption="조립 공정 8단계 — 웨이퍼에서 검은 칩까지"
  orientation="column"
  steps={[
    { id: 'a1', label: '1 백 그라인딩', sub: '다이아몬드 휠로 뒷면을 갈아 패키지 두께에 맞춘다' },
    { id: 'a2', label: '2 웨이퍼 쏘잉', sub: '다이아몬드 블레이드 고속 회전으로 낱개 칩(다이)으로 분리' },
    { id: 'a3', label: '3 다이 본딩', sub: '양품 칩만 골라 접착제로 리드 프레임·기판에 붙인다', tone: 'accent' },
    { id: 'a4', label: '4 와이어 본딩', sub: '칩 단자와 기판 단자를 가는 금선으로 잇는다' },
    { id: 'a5', label: '5 몰딩', sub: '금형과 수지(EMC)로 전극만 남기고 밀봉' },
    { id: 'a6', label: '6 마킹', sub: '레이저로 제품명·로트 번호를 새긴다' },
    { id: 'a7', label: '7 솔더 볼 마운트', sub: 'PCB와 연결할 단자 구실의 볼을 붙인다' },
    { id: 'a8', label: '8 싱귤레이션', sub: '여러 유닛이 붙은 기판을 낱개로 자른다' },
  ]}
/>

| # | 공정 | 하는 일 |
|:-:|---|---|
| 1 | 백 그라인딩(back grinding) | 다이아몬드 휠로 웨이퍼 뒷면을 갈아 패키지 크기에 맞는 두께로 만든다 |
| 2 | 웨이퍼 쏘잉(wafer sawing) | 다이아몬드 블레이드의 고속 회전으로 웨이퍼를 낱개 칩(다이)으로 분리한다 |
| 3 | 다이 본딩(die bonding) | 테스트에서 양품으로 판정된 칩만 골라 접착제로 리드 프레임·기판에 붙인다 |
| 4 | 와이어 본딩(wire bonding) | 칩의 단자와 기판 단자를 가는 금선으로 이어 전기 통로를 만든다 |
| 5 | 몰딩(molding) | 금형과 수지(EMC)로 전극만 남기고 밀봉 — 충격·진동·습기·이물질을 차단한다 |
| 6 | 마킹(marking) | 레이저로 제품명·로트 번호를 새겨 생산 이력을 추적하게 한다 |
| 7 | 솔더 볼 마운트(solder ball mount) | PCB와 연결할 단자 구실의 솔더 볼을 기판에 붙인다 |
| 8 | 싱귤레이션(saw singulation) | 다이아몬드 블레이드로 여러 유닛이 붙은 기판을 낱개 유닛으로 자른다 |

낯선 말이 많지만 걱정하지 않아도 돼요 — 이 가운데 <strong>쏘잉</strong>과{' '}
<strong>다이 본딩</strong>은 다음 단원부터 장비 구조와 조작·정비까지 통째로
파고들 주인공이에요. 3단계에서 "양품만 골라 붙인다"고 했는데, 그 양품을 가려내는
웨이퍼 검사(EDS 테스트)가 바로 이 책 후반부 <strong>검사</strong> 편의 주제예요.

## 4. 패키지의 종류와 진화

칩이 작아지고 빨라질수록 포장도 얇아지고 촘촘해져요. 대표 선수 둘을 비교하면
이래요.

<CompareCards
  caption="리드 프레임 기반이냐 기판 기반이냐"
  columns={[{ title: 'TSOP' }, { title: 'FBGA', tone: 'accent' }]}
  rows={[
    { aspect: '방식', values: ['리드 프레임 기반, 두께 1.0mm 이하의 얇은 패키지', '기판 전면에 볼을 붙인 CSP(칩 스케일 패키지)'] },
    { aspect: '재료', values: ['프레임은 Alloy-42(니켈 42%·철 58%) 주력, Cu·Pd도 사용. 와이어는 금(Au)', '기판 기반'] },
    { aspect: '강점', values: ['가격이 매우 저렴 — 현재 가장 널리 쓰임', '공정이 단순·저비용, 열·전기 특성 좋고 가볍고 얇고 작다'] },
  ]}
  note="Alloy-42는 20~300℃에서 열팽창이 낮고 일정해 열을 가하는 공정에서도 뒤틀리지 않는다."
/>

| | TSOP | FBGA |
|---|---|---|
| 방식 | 리드 프레임 기반, 두께 1.0mm 이하의 얇은 패키지 | 기판(substrate) 전면에 볼을 붙인 CSP(칩 스케일 패키지) |
| 재료 | 프레임은 Alloy-42(니켈 42%·철 58% 합금 — 20~300℃에서 열팽창이 낮고 일정)가 주력, Cu·Pd도 사용. 와이어는 금(Au)이 주력 | 기판은 FR-4·FR-5·BT 레진·폴리이미드 필름 |
| 강점 | 가격이 매우 저렴 — 현재 가장 널리 쓰임 | 제조 공정이 단순하고 비용이 적으며, 열·전기 특성이 좋고 가볍고 얇고 짧고 작음 |

밀봉재 <strong>EMC(Epoxy Molding Compound)</strong>는 에폭시 수지에 필러를 섞은
재료로, 필러 입자가 둥근 것(구상)과 모난 것(각상) 두 갈래가 있어요.

패키지 형태의 역사는 "핀을 어디에 어떻게 낼 것인가"의 역사예요 — 양옆에 핀이
달린 초창기 SIP·DIP·ZIP에서, 핀 많은 프로세서용 PGA(pin grid array)로, 다시
소형화 흐름을 타고 QFP·CSP·BGA로, 최근에는 여러 칩을 한 패키지에 쌓는{' '}
<strong>MCM(Multi-Chip Module)</strong> 같은 고속·고밀도 시스템 패키지로 발전하고
있어요.

## 5. 포장 재료의 다른 얼굴 — 유해인자와 만나는 곳

이 단원에 나온 재료들은 유해인자 공부와 정면으로 만나요. 다이 본딩의 접착제와
몰딩의 EMC는 <strong>에폭시 수지</strong> — 피부에 닿으면 알레르기성 접촉 피부염을
일으킬 수 있는 감작성 물질이고, 몰딩·마킹·솔더 공정에는 가열 흄과 분진 이슈가
따라와요. 조립·검사 라인 전체의 유해인자 지도는{' '}
<ChapterRef order={13} />
에서 같은 공정 순서 그대로 다루니, 이 권으로 장비를 익히고 그 챕터로 위험을
겹쳐 읽으면 후공정이 입체로 보여요.
