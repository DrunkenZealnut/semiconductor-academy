다뤘어요 — 이 단원은 그 실린더와 밸브를 <strong>전기 신호로 정확한 순서에 맞춰
조종하는 법</strong>을 다뤄요. 반도체 장비 자동화의 가장 밑바닥 원리가 바로 여기서
시작돼요.

## 1. 전기로 공압을 조종하는 이유

공압 실린더를 움직이는 방법은 크게 두 가지예요. 하나는 손으로 조작하는 밸브의 신호를
다시 압축 공기로 다음 밸브에 전달하는 <strong>전공압 방식</strong>이에요. 예를 들어
사람이 수동 조작 밸브를 누르면 그 파일럿 신호가 마스터 밸브를 전환시켜 압축 공기가
실린더 헤드 쪽으로 흘러 들어가고, 실린더가 끝까지 밀려 나가는 순간 리밋 밸브가 눌리며
다시 마스터 밸브에 신호를 보내 실린더를 후진시켜요 — 신호도 동작도 전부 공기로만
이뤄지는 '1회 왕복' 회로예요.

다른 하나가 이 단원의 주제인 <strong>전기 제어 방식</strong>이에요. 접점과 전자
밸브(솔레노이드 밸브)로 액추에이터를 움직이고, 나머지 제어는 모두 전기 회로가 맡아요.
전공압 방식보다 응답 속도가 빠르고, 회로를 작게 구성할 수 있고, 동작이 확실하며, 가는
전선 하나로 멀리 떨어진 곳까지 원격 조작할 수 있다는 장점이 있어요. 장비가 빼곡히 들어찬
반도체 팹에서 전기 제어 방식이 널리 쓰이는 이유이기도 해요.

## 2. 접점 3형제 — a·b·c접점

전기 제어의 가장 작은 단위는 <strong>접점</strong>이에요. 회로를 잇거나 끊는
역할을 하는데, 평소 상태와 동작 후 상태가 어떻게 바뀌는지에 따라 세 가지로 나뉘어요.

| 접점 | 평소 상태(초기) | 조작력이 가해지면 | 다른 이름 |
|---|---|---|---|
| a접점 | 열림(통전 안 됨) | 닫힘(통전) | NO(Normally Open), 메이크 접점 |
| b접점 | 닫힘(통전) | 열림(통전 끊김) | NC(Normally Closed), 브레이크 접점 |
| c접점 | 공통단자(COM)가 NC와 연결 | COM이 NO로 갈아탐 | 전환 접점(Change-over, SPDT) |

a접점은 평소엔 꺼져 있다가 눌러야 켜지는 초인종 버튼과 같고, b접점은 반대로 평소엔
이어져 있다가 누르면 끊어지는 구조예요. c접점은 이 둘을 한 몸에 담아, 공통 단자 하나를
상황에 따라 b접점 쪽에서 a접점 쪽으로 넘겨주는 스위치예요.

접점은 조작 방식으로도 나뉘어요. 누름버튼처럼 힘을 빼면 스프링으로 저절로 돌아오는
<strong>자동 복귀 접점</strong>, 가정용 전등 스위치처럼 다시 손대야만 원래대로 돌아오는
<strong>수동 복귀 접점</strong>, 손으로 조작하는 <strong>수동 조작 접점</strong>과
릴레이처럼 전기 신호로 움직이는 <strong>자동 조작 접점</strong>, 그리고 리밋
스위치·마이크로 스위치처럼 기계적인 움직임과 맞닿아 작동하는 <strong>기계적
접점</strong>이 있어요.

## 3. 스위치와 센서 — 손으로 누르는 것부터 비접촉 감지까지

접점을 실제로 여닫는 부품이 스위치예요. 사람이 직접 조작하는 <strong>조작
스위치</strong>와, 사람 대신 상태를 감지하는 <strong>검출 스위치</strong>(센서)로
나뉘어요.

조작 스위치 중 <strong>누름버튼 스위치</strong>는 손을 떼면 내장 스프링으로 자동
복귀하고, <strong>유지형 스위치</strong>(셀렉터·토글·로터리 스위치)는 반대로 조작하기
전까지 상태를 그대로 유지해요 — 자동↔수동 전환처럼 모드를 바꿔 두는 용도로 쓰여요.

검출 스위치는 제어 장치의 눈과 귀 역할을 해요. 대상과 직접 맞닿아 검출하는 접촉식과,
닿지 않고 검출하는 비접촉식으로 나뉘어요.

| 종류 | 검출 방식 | 특징 |
|---|---|---|
| 마이크로 스위치 | 접촉식 | 소형·경량, 계측기나 소형 기계장치에 사용 |
| 리밋 스위치 | 접촉식 | 마이크로 스위치를 밀봉 케이스에 담아 내수·내유·방진 — 생산설비·자동화 설비에 사용 |
| 근접 스위치(유도형) | 비접촉식 | 코일의 인덕턴스 변화로 감지 — 금속만 검출 가능 |
| 근접 스위치(정전 용량형) | 비접촉식 | 전극-대지 사이 정전 용량 변화로 감지 — 나무·종이·플라스틱·물 등 대부분 검출 |
| 광전 스위치 | 비접촉식 | 빛의 변화로 감지 — 검출 거리가 수 mm부터 수십 m로 가장 길고, 크기·형상·색상 판별도 가능 |

리밋 스위치는 특히 실린더가 정한 위치까지 왔는지 확인하는 용도로 자주 쓰여요 — 다음
절의 순차 작동 회로에서 "다음 단계로 넘어가도 좋다"는 신호를 만드는 것이 바로 이
리밋 스위치예요.

## 4. 기본 논리 회로 일곱 가지

접점 몇 개를 어떻게 잇느냐에 따라 완전히 다른 동작을 하는 회로가 만들어져요.

| 회로 | 동작 | 비유하자면 |
|---|---|---|
| AND(직렬 회로) | 입력이 모두 켜져야 출력이 켜짐 | 작업자 여럿이 동시에 버튼을 눌러야 움직이는 프레스의 안전장치 |
| OR(병렬 회로) | 입력 중 하나만 켜져도 출력이 켜짐 | 여러 초인종 버튼 중 아무거나 눌러도 울리는 벨 |
| NOT(부정 회로) | 입력을 뒤집어 출력함(0→1, 1→0) | 문이 닫히면 꺼지고 열리면 켜지는 경고등 |
| 자기유지 회로 | 버튼을 눌렀다 떼도 스스로 만든 접점으로 전류를 계속 흘려 동작을 유지 | 손을 떼도 눌린 채로 남는 엘리베이터 버튼 |
| 인터록 회로 | 한쪽이 동작 중이면 상대 릴레이의 b접점으로 다른 쪽 동작을 막음 | 두 열차가 동시에 같은 선로에 못 들어가게 막는 신호 체계 |
| 온 딜레이 회로 | 입력이 켜진 뒤 설정 시간이 지나야 출력이 켜짐 | 신호등이 초록으로 바뀌기 전의 짧은 대기 |
| 오프 딜레이 회로 | 입력이 꺼진 뒤에도 설정 시간 동안 출력이 유지되다 꺼짐 | 스위치를 꺼도 잠시 더 켜져 있는 계단 조명 |

이 중 <strong>자기유지</strong>와 <strong>인터록</strong>은 다음 절의 순차 회로 설계를
떠받치는 뼈대예요. 자기유지는 누름버튼(PB₁)을 눌러 릴레이가 동작하면, 그 릴레이 자신의
a접점이 버튼과 나란히 붙어 있어 손을 떼도 전류가 끊기지 않는 구조예요. 정지 버튼(PB₂)을
눌러야 비로소 회로가 끊어지고 릴레이가 떨어져요. 인터록은 한 릴레이가 동작 중일 때
관련된 다른 릴레이의 동작을 막는 안전장치로, 상대 릴레이의 b접점을 자기 회로에 직렬로
끼워 넣어 구현해요 — 먼저 동작한 쪽이 우선권을 갖고, 다른 쪽은 절대 켜지지 않도록
원천 차단하는 거예요.

온 딜레이와 오프 딜레이는 모두 <strong>타이머</strong>를 이용한 지연 회로예요. 온
딜레이는 입력이 들어온 순간부터 시간을 재기 시작해 설정 시간이 끝나야 출력이 켜지고,
오프 딜레이는 반대로 입력이 꺼진 순간부터 시간을 재서 그 시간이 다 지나야 출력이
꺼져요 — 입력이 사라진 뒤에도 한동안 동작을 붙잡아 두는 셈이에요.

## 5. 움직임을 기록하는 다섯 가지 언어

시퀀스 회로에 따라 움직이는 자동화 기기의 동작을, 사람이 알아보기 쉽게 적는 방법에는
여러 가지가 있어요. 컨베이어로 온 상자를 실린더 A가 들어 올리고 실린더 B가 다음
컨베이어로 밀어내는 장치가 있다면, 다섯 가지 방법은 이렇게 표현돼요.

① <strong>서술적 표현법</strong>: 문장으로 순서를 적어요. "상자가 도착하면 실린더
A가 올라가 들어 올린다 → 실린더 B가 전진해 다음 컨베이어로 민다 → A가 내려온다 → B가
후진한다."

② <strong>테이블 표현법</strong>: 작업 단계와 실린더를 표로 정리해요.

| 작업 단계 | 실린더 A | 실린더 B |
|---|---|---|
| 1단계 | 전진 | - |
| 2단계 | - | 전진 |
| 3단계 | 후진 | - |
| 4단계 | - | 후진 |

③ <strong>벡터적 표시법</strong>: 화살표 →(전진)와 ←(후진)로 나타내요.

④ <strong>기호에 의한 표시법(간략적 표시법)</strong>: 전진을 +, 후진을 -로 써서 A+B+A-B-처럼
한 줄로 압축해요. 순서 표현법으로 가장 널리 쓰여요.

⑤ <strong>그래프에 의한 표시법(변위-단계 선도)</strong>: 가로축은 작업 단계, 세로축은
실린더의 변위예요. 선이 맨 아래면 완전히 후진한 상태, 맨 위면 완전히 전진한 상태,
수평이면 그 위치에서 정지해 있다는 뜻이에요. 실린더 여러 대의 선도를 나란히 쌓아
그리면 장치 전체의 작동 순서를 한눈에 볼 수 있어요.

## 6. 회로도를 그리는 규칙

여러 사람이 봐도 같은 뜻으로 읽히려면 회로도에는 공통 규칙이 필요해요. 회로도는 가로로
그리는 <strong>횡서</strong> 방식과 세로로 그리는 <strong>종서</strong> 방식 중 하나를
정해 도면 전체에서 통일해서 써요 — 그리기도 읽기도 편한 횡서가 더 널리 쓰여요.

기기를 배치하는 순서도 정해져 있어요. 회로도 아래쪽부터 위쪽으로, 에너지가 공급되는
곳에서 실제로 일을 하는 곳까지 다섯 단계로 쌓아 올려요.

| 실행 단계 | 처리 요소 | 대표 공압 기기 |
|---|---|---|
| 에너지 공급 | 동력 발생 장치 | 공기 압축기 |
| 신호 입력 | 신호 입력 요소 | 압력 스위치, 공기압 센서, 푸시버튼 스위치 |
| 신호 처리 | 신호 처리 요소 | 압력 제어 밸브, 유량 제어 밸브, 방향 제어 밸브 |
| 신호 출력 | 최종 제어 요소 | 방향 제어 밸브 |
| 명령 실행 | 작업 요소 | 공기압 실린더, 공기압 모터 |

실제로 회로를 그릴 때는 최종 제어 요소와 액추에이터 사이에 <strong>유량 제어
요소</strong>(속도를 조절하는 밸브)를 하나 더 끼워 넣는 것이 기본이에요.

기기의 기호는 언제나 <strong>동작을 시작하기 전 상태</strong>로 그려요. 스프링으로
자동 복귀하는 밸브는 복귀된 상태로, 신호가 사라져도 마지막 상태를 계속 기억하는
<strong>플립플롭(FF)형 메모리 밸브</strong>는 무신호 상태로 그리고요. 대부분의 공압
실린더는 전진하며 일을 하기 때문에 후진 상태를 초기 상태로 삼는 경우가 많은데, 이때
마스터 밸브는 실린더 로드 쪽에 압력이 걸리는 상태로 표시해요. 반대로 전진한 상태가
초기 상태라면 헤드 쪽에 압력이 걸리는 상태로 그려요.

배선에도 규칙이 있어요. 선은 교차점이 되도록 생기지 않게 직선으로 긋고, 압축 공기가
흐르는 주관로는 실선으로, 파일럿 신호 같은 제어선은 점선으로 구분해요(회로가 아주
복잡할 때는 제어선도 실선으로 그려도 괜찮아요). 배선 실수를 줄이기 위해 접속구(포트)에도
국제 규격(ISO 1219, ISO 5599)에 따른 번호나 기호를 붙여요.

| 접속구 기능 | ISO 5599 표기 | ISO 1219 표기 |
|---|---|---|
| 공급 포트 | 1 | P |
| 작업 포트 | 2, 4 | A, B, C |
| 배기 포트 | 3, 5 | R, S, T |
| 제어 포트 | 10, 12, 14 | X, Y, Z |

## 7. 실린더 여러 대를 순서대로 — 순차 작동 회로 설계

입력이 시간 순서대로 들어올 때, 미리 정해진 순서에 맞춰 정해진 동작을 하도록 짜인
회로를 <strong>시퀀스 회로</strong>라고 해요. 반도체 장비 자동화 설비 대부분이 이
시퀀스 회로 위에서 움직여요.

회로를 설계하기 전에는 먼저 <strong>타임 차트</strong>를 그려요. 시간이 흐르는 축을
따라 리밋 스위치·릴레이·솔레노이드 같은 신호들이 언제 켜지고 꺼지는지를 나타낸 표예요.
신호들이 어떤 순서로 겹치는지 눈으로 미리 확인하면 회로 설계 실수를 줄일 수 있어요.

<strong>방법 1 — 주회로 차단법</strong>은 편측(스프링 복귀형) 전자 밸브로 실린더를
제어할 때 쓰는 방식이에요. 절차는 이래요.

1. 동작 순서를 기호로 정리한다(예: A+B+A-B-, +는 전진·-는 후진)
2. 공압 회로를 그리고 리밋 스위치를 배치한다
3. 제어 회로를 작성한다 — 제어 모선 두 줄 사이에 스텝 수만큼 릴레이(R₁∼R₄)를 배치하고,
   각 릴레이를 <strong>리밋 스위치 신호와 이전 단계 신호</strong>로 여자시켜
   자기유지시킨다. 전진 신호는 릴레이의 a접점으로 솔레노이드를 켜고, 복귀 신호는 다음
   릴레이의 b접점으로 그 솔레노이드를 끈다. 마지막 스텝이 끝나면 마지막 릴레이의
   b접점이 첫 릴레이의 자기유지를 풀어 전체가 처음 상태로 돌아간다.

A+B+A-B- 순서라면, 시동 신호와 마지막 스텝 완료 신호(LS₃)가 함께 R₁을 켜 A를
전진시켜요. A 전진 완료 신호(LS₂)와 R₁이 함께 R₂를 켜 B를 전진시키고요. 이런 식으로
각 스텝은 리밋 스위치가 "완료"를 알려야만 다음으로 넘어가니, 정확히 계주에서 배턴을
넘기듯 진행돼요.

<strong>방법 2 — 레지스터 방식</strong>은 양쪽에 솔레노이드가 있는 전자 밸브로 제어할
때 주로 쓰는 방식이에요. 운동 스텝마다 릴레이를 하나씩 배정하는 것은 방법 1과 같지만,
리밋 스위치 신호와 이전 스텝 릴레이의 a접점을 AND로 묶어 다음 스텝 릴레이를 동작시키고,
그 릴레이의 b접점으로 이전 스텝의 자기유지를 끊어낸다는 점이 달라요. A+A-B+B- 순서라면,
시동 스위치로 R₁이 켜져 A가 전진하고, A 전진 완료(LS₂)와 R₁이 AND로 R₂를 켜 A를
후진시키는 식으로, 각 스텝의 자기유지와 인터록이 사슬처럼 이어지며 순서를 확정 지어요.

두 방법 모두 핵심은 같아요 — <strong>리밋 스위치가 "여기까지 왔다"를 알리고, 릴레이가
그 신호를 기억했다가 다음 릴레이에 넘겨주는 것</strong>. 이 원리 하나로 실린더 두 대,
세 대, 그 이상도 정해진 순서대로 반복 작동시킬 수 있어요.
