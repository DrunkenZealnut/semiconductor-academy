## 1. 아두이노란 — 누구나 쓰는 오픈소스 보드

아두이노(Arduino)는 마이크로컨트롤러를 사용해 전자·전기 프로젝트를 쉽게
만들 수 있도록 설계된 오픈소스 하드웨어 플랫폼이에요. 초보자도 쉽게
시작할 수 있고, 활발한 커뮤니티가 예제 코드와 문제 해결법을 공유하며,
가격이 저렴하다는 점이 널리 쓰이는 이유예요.

활용 분야도 다양해요. 교육용으로는 프로그래밍·전자공학 기초 수업이나
메이커 커뮤니티에서, IoT 분야에서는 조명 제어·온도 모니터링 같은 스마트 홈
기기나 원격 제어 장치로, DIY 분야에서는 로봇 제작이나 인터랙티브 아트로,
연구·개발 분야에서는 아이디어를 빠르게 검증하는 프로토타이핑 도구로
쓰여요.

오픈소스라 대부분 저작권 문제없이 쓸 수 있지만, 다음 사항은 유의해야

## 4. 디지털 신호와 아날로그 신호

<strong>디지털</strong> 신호는 0(LOW, 보통 0V)과 1(HIGH, 보통 5V 또는
3.3V) 두 값만 가져요. 우노 기준 D0∼D13이 디지털 핀이고, 버튼·스위치 값을
읽는 입력이나 LED·릴레이를 켜고 끄는 출력으로 쓰여요. 이 가운데 물결표(∼)
표시가 있는 D3·D5·D6·D9∼D11 여섯 개 핀은 <strong>PWM</strong> 방식으로
아날로그 출력처럼 쓸 수 있어요.

<strong>아날로그</strong> 신호는 연속적으로 변하는 값이에요 — 바늘시계의
회전이나 0V∼5V 사이를 매끄럽게 오가는 전압 변화가 그 예죠. 우노 기준
A0∼A5가 아날로그 핀이고, 온도·빛·거리 센서처럼 연속된 값을 읽어 들일 때
주로 써요.

## 7. 실습① — LED 5개 순차 점등

준비물은 아두이노 우노, USB 케이블, 브레드보드, 330Ω 저항 5개, LED 5개,
점퍼선이에요. 목표는 LED 5개를 정해진 순서로 하나씩 늘려가며 켜는
프로그램을 만드는 거예요. 핀 배열과 반복문을 함께 쓰면 digitalWrite를
5번씩 따로 늘어놓지 않고도 같은 동작을 만들 수 있어요.

```cpp
const int ledPins[] = {2, 4, 6, 8, 10}; // 순서대로 켤 LED 핀 5개
const int ledCount = 5;

void setup() {
  for (int i = 0; i < ledCount; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < ledCount; i++) {
    digitalWrite(ledPins[i], HIGH); // 핀을 하나씩 추가로 켠다
    delay(800);
  }
  for (int i = 0; i < ledCount; i++) {
    digitalWrite(ledPins[i], LOW);  // 전부 끄고 처음부터 다시
  }
  delay(800);
}
```

이 실습에서 확인하는 것: 배열과 반복문으로 여러 개의 핀을 한꺼번에 다룰 수
있다는 것, delay 간격이 점등 속도를 결정한다는 것이에요.

## 8. 대표 실습② — 초음파 센서로 거리에 따라 3색 LED 켜기

준비물은 아두이노 우노, USB 케이블, 브레드보드, 초음파 센서, 3색(RGB)
LED, 점퍼선이에요. 목표는 초음파 센서로 잰 거리에 따라 LED 색을 바꾸는
것 — 입력을 받아 판단하고 출력을 바꾸는 흐름 전체가 담긴 실습이에요.

초음파 센서는 Trig 핀으로 초음파를 아주 짧게 쏘고, Echo 핀에 반사파가
돌아오기까지 걸린 시간을 pulseIn() 함수로 재요. 그 시간을 거리(cm)로
환산한 뒤, 조건문으로 구간을 나눠 RGB LED의 각 색 핀을 analogWrite로
켜요.

```cpp
#define TRIG_PIN 2   // 초음파 센서 Trig(발신)
#define ECHO_PIN 3   // 초음파 센서 Echo(수신)
#define LED_RED   9
#define LED_GREEN 10
#define LED_BLUE  11

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(LED_RED, OUTPUT);
  pinMode(LED_GREEN, OUTPUT);
  pinMode(LED_BLUE, OUTPUT);
  Serial.begin(9600); // 거리 값을 모니터링하기 위한 시리얼 통신 시작
}

void loop() {
  // 초음파를 짧게 한 번 쏜다
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  // 반사파가 돌아오는 시간을 재서 거리(cm)로 환산
  long duration = pulseIn(ECHO_PIN, HIGH);
  long distanceCm = duration / 58;
  Serial.println(distanceCm);

  analogWrite(LED_RED, 0);
  analogWrite(LED_GREEN, 0);
  analogWrite(LED_BLUE, 0);

  if (distanceCm < 15) {
    analogWrite(LED_RED, 255);   // 가까우면 빨강
  } else if (distanceCm < 25) {
    analogWrite(LED_GREEN, 255); // 중간이면 초록
  } else if (distanceCm < 35) {
    analogWrite(LED_BLUE, 255);  // 멀면 파랑
  }

  delay(100); // 0.1초 간격으로 반복 측정
}
```

회로는 팅커캐드 같은 시뮬레이터로 먼저 구성해 보면 좋아요 — 초음파 센서의
Trig·Echo 핀과 RGB LED의 세 색 핀을 각각 정해진 디지털·PWM 핀에 연결하면
돼요.

이 실습에서 확인하는 것: 센서로 읽은 값(거리)이 조건문을 거쳐 출력(LED
색)으로 이어지는 전체 흐름, pulseIn으로 시간을 재서 거리로 바꾸는 계산,
analogWrite로 색을 단계별로 제어하는 법이에요.

## 9. 나머지 실습 여섯 가지 — 무엇이 달라질까

같은 뼈대(센서 읽기 → 조건·계산 → 출력) 위에서 센서와 출력 장치만 바뀌는
구조예요. 준비물과 회로는 실습마다 다르지만, 프로그램을 짜는 순서는
비슷해요.
