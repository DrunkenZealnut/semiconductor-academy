## 1. 코드가 칩에 들어가기까지 — 개발 사이클 네 단계

실습용 Kit는 컴퓨터와 <strong>ISP(In-System Programming)</strong> 케이블로
연결해요. 칩을 보드에서 떼어내지 않고도 그 자리에서 몇 번이고 새 프로그램을
구워 넣을 수 있다는 뜻이에요. 이후 과정은 네 단계로 정리돼요.

| 단계 | 하는 일 |
|---|---|
| ① 연결 | ISP 케이블로 실습 Kit와 컴퓨터를 연결 |
| ② 작성 | 에디터로 예제 프로그램(소스 코드)을 작성 |
| ③ 빌드 | 컴파일러가 소스 코드를 검사해 기계어를 담은 HEX 파일로 변환 |
| ④ 다운로드·확인 | ISP 프로그램이 HEX 파일을 칩의 플래시 메모리에 기록하고 즉시 실행해 동작을 확인 |

1권에서 배운 컴파일 과정 뒤에, 실제 하드웨어에 구워 넣고 눈으로 확인하는
두 단계가 이번 실습에서 새롭게 더해지는 셈이에요.

## 2. 포트를 열고 첫 신호 내보내기

모든 실습은 같은 첫 동작으로 시작해요 — 사용할 포트의 방향 레지스터(DDRx)를
출력으로 설정하고, 값 레지스터(PORTx)에 신호를 한 번 써 보는 거예요. 레지스터
값 하나가 8개의 핀을 한꺼번에 결정한다는 감각을 확인하는 단계예요.

```c
#include <avr/io.h>

int main(void)
{
    DDRA = 0xFF;  // Port A 전체를 출력으로 설정
    DDRB = 0xFF;
    DDRC = 0xFF;
    DDRD = 0xFF;

    PORTA = 0x03; // 하위 2비트에 신호를 한 번 내보내고 멈춤

    while (1) {
        ; // 무한 대기 — 프로그램이 끝나지 않게 붙잡아 둔다
    }
}
```

이 코드는 값을 딱 한 번만 내보내고 멈춰요. 다음 실습부터는 이 뼈대에 반복과
지연을 더해 "점멸"이라는 시간의 흐름을 만들어요.

## 3. 대표 실습 — 두 패턴을 번갈아 켜기

목표는 두 가지 점등 패턴을 일정한 간격으로 번갈아 반복 출력하는
프로그램이에요. 원리는 간단해요 — 무한 반복문 안에 "값 출력 → 지연 → 다른
값 출력 → 지연"을 담아 두면, 그 네 줄이 영원히 순서대로 되풀이돼요.

```c
#include <avr/io.h>
#include <util/delay.h>

int main(void)
{
    DDRB = 0xFF; // Port B 전체를 출력으로 설정

    while (1) {
        PORTB = 0x0F; // 하위 4비트 점등
        _delay_ms(300);

        PORTB = 0xF0; // 상위 4비트 점등
        _delay_ms(300);
    }
}
```

이 실습에서 확인하는 것: 레지스터 값이 바뀌는 순간 해당 LED가 실제로
반응하는지, 지연 시간을 줄이거나 늘리면 점멸 속도가 어떻게 달라지는지,
무한 루프가 다운로드 이후에도 전원이 꺼지기 전까지 계속 반복되는지예요.

## 4. 변형 비교 — 흐르는 불빛 만들기

점등 패턴을 매번 새로 쓰는 대신, 이전 값을 <strong>비트 시프트</strong>로
한 칸씩 밀면 불빛이 옆으로 흐르는 것처럼 보여요. 값을 왼쪽으로 미는
변형과 오른쪽으로 미는 변형은 코드 한 줄과 리셋값만 다를 뿐, 나머지 구조는
대표 실습과 같아요.

```c
#include <avr/io.h>
#include <util/delay.h>

int main(void)
{
    unsigned char pattern = 0x01;
    DDRB = 0xFF;

    while (1) {
        PORTB = pattern;
        _delay_ms(200);

        pattern = pattern << 1;  // 켜진 자리를 한 칸 왼쪽으로 민다
        if (pattern == 0x00) {
            pattern = 0x01;      // 맨 끝까지 밀렸으면 처음 자리로 되돌림
        }
    }
}
```

| 실습 변형 | 코드에서 달라지는 부분 | 새로 배우는 것 |
|---|---|---|
| 첫 신호 내보내기 | PORTx에 값을 한 번만 쓰고 끝 | 레지스터 설정만으로 하드웨어가 즉시 반응한다는 감각 |
| 패턴 반복 점등(대표 실습) | while(1)과 지연 함수로 두 값을 번갈아 출력 | 반복문과 지연으로 "점멸"이라는 시간 동작을 만드는 법 |
| 왼쪽 시프트 | pattern을 왼쪽으로 밀고, 0이 되면 0x01로 되돌림 | 비트 연산 하나로 "흐르는 불빛" 효과를 구현하는 법 |
| 오른쪽 시프트 | pattern을 오른쪽으로 밀고, 0이 되면 0x80으로 되돌림 | 시프트 방향과 리셋값의 관계 — 최상위·최하위 비트가 뜻하는 자리 |
