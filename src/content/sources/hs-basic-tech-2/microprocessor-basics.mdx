메모리, 입출력 창구가 모두 들어있는 것이 바로 <strong>마이크로프로세서</strong>예요.

그 문법을 다시 확인할 수 있어요.

## 1. 여러 입력 중 하나를 고르고, 부호를 새기는 기본 회로

CPU 안에는 몇 가지 기본 회로 블록이 반복해서 쓰여요. <strong>멀티플렉서</strong>는
여러 개의 선택 신호 조합으로 수많은 입력선 가운데 하나를 골라 출력선 하나에
연결하는 회로예요 — 채널이 수십 개라도 버튼 몇 개로 하나를 골라내는 셈이죠.
<strong>인코더</strong>는 정보를 정해진 규칙의 부호로 바꾸는(부호화) 회로이고,
<strong>디코더</strong>는 그 부호를 다시 원래 정보로 되돌리는(복호화) 회로예요.
CPU는 이런 기본 블록들을 레지스터·ALU와 함께 표준화된 하나의 칩으로 묶어 놓은
결과물이에요.

## 2. 마이크로프로세서, 반백 년의 역사

마이크로프로세서가 널리 쓰이기 시작한 건 인텔의 8비트 칩 <strong>8080</strong>부터예요.
CP/M이라는 운영체제와 함께 개인용 컴퓨터의 CPU로 널리 퍼졌고, 자일로그가 8080을
개량해 만든 <strong>Z80</strong>은 지금까지도 쓰이는 대표적인 8비트 칩이 됐어요.
같은 시기 모토로라의 6800·6809, 모스텍의 6502도 널리 쓰인 8비트
마이크로프로세서예요.

| 칩 | 제조사 | 비고 |
|---|---|---|
| 8080 | 인텔 | CP/M과 함께 초기 개인용 컴퓨터의 CPU로 확산 |
| Z80 | 자일로그 | 8080을 개량, 지금도 쓰이는 8비트 칩 |
| 6800·6809 | 모토로라 | 8080과 경쟁한 8비트 계열 |
| 6502 | 모스텍 | 초기 개인용 컴퓨터·게임기에 널리 채택 |

## 3. 마이크로프로세서를 마이크로프로세서답게 만드는 것들

- <strong>비트 단위 입출력</strong>: 필요한 신호선 하나하나를 자유롭게 켜고 끌 수 있어요.
- <strong>인터럽트 처리</strong>: 하던 작업과 별개로 내외부 상태 변화를 즉시 알아챌 수 있어요.
- <strong>특수 기능 내장</strong>: A/D 컨버터, 카운터, LCD 제어기, PWM 발생기, 직렬
  통신기, 버스 제어기 같은 기능을 칩 안에 갖추고 있어요.
- <strong>타이머 내장</strong>과 <strong>저전력 동작</strong>도 빼놓을 수 없는 특징이에요.

## 4. 마이크로컴퓨터의 3대 부품 — CPU·메모리·입출력 포트

마이크로프로세서에 기억장치와 입출력장치가 더해지면 <strong>마이크로컴퓨터</strong>가
돼요. "마이크로(Micro)"는 부품 크기가 물리적으로 작다는 뜻이고, "프로세서
(Processor)"는 중앙처리장치를 줄인 말이에요.

| 구성 요소 | 역할 |
|---|---|
| CPU | 레지스터(값 임시 저장)·ALU(산술·논리 연산)·제어장치(명령 해석과 흐름 제어)로 구성, 전체 데이터 흐름을 지휘 |
| 메모리 | 프로그램과 데이터를 보관 — 잘 바뀌지 않는 ROM 계열과 자유롭게 읽고 쓰는 RAM으로 나뉨 |
| I/O 포트 | 마이크로프로세서와 외부 장치 사이에서 정보를 주고받는 인터페이스 |

CPU와 메모리, CPU와 I/O 포트는 <strong>버스(bus)</strong>라는 규격화된 통로로
연결돼 데이터를 주고받아요. 그리고 전원이 끊기거나(Power Fail), 하드웨어가
고장 나거나(Machine Check), 정해진 시간을 넘기거나(External), 입출력 도중
문제가 생기거나(I/O), 0으로 나누는 것처럼 금지된 연산을 하거나(Program
Check), 운영체제 호출이 필요할 때(Supervisor Call) — 이런 사건들이 각각 CPU에
<strong>인터럽트</strong> 신호를 보내요.

## 5. 기억장치 — RAM과 ROM, 그리고 용량 단위

RAM은 저장 방식에 따라 둘로 나뉘어요.

| 종류 | 저장 원리 | 특징 |
|---|---|---|
| SRAM | 플립플롭 논리 게이트 | 회로는 복잡하지만 고속, 재생(refresh) 불필요, 소용량에 적합 |
| DRAM | 커패시터의 전하 축적 | 스스로 방전되어 주기적 재생 필요, 저전력·고밀도로 대용량에 적합 |

ROM도 기록·소거 방식에 따라 여러 종류로 나뉘어요.

| 종류 | 특징 |
|---|---|
| MASK ROM | 공장에서 대량 생산 시 미리 기록, 이후 변경 불가 |
| PROM | 사용자가 전용 장치로 1회 기록, 이후 변경 불가 |
| EPROM | 여러 번 기록 가능, 지울 때는 자외선 사용 |
| EEPROM | 전기 신호로 지우고 다시 쓸 수 있음 |
| Flash 메모리 | 읽기는 바이트 단위, 쓰기는 페이지·섹터 단위 — EEPROM의 변형 |

메모리 용량은 다음 순서로 커지고, 한 단계마다 1024배씩 뛰어요.

**bit(비트) &lt; Byte(바이트) &lt; KB &lt; MB &lt; GB &lt; TB**

## 6. ATmega8535 뜯어보기 — AVR, 레지스터, 포트

교육용 보드에 흔히 올라가는 칩이 <strong>AVR</strong> 계열이에요. Atmel사가 만든
RISC 구조의 고속 8비트 마이크로프로세서로, 칩을 기판에 붙인 상태에서 내부
Flash·EEPROM을 여러 번 다시 프로그래밍할 수 있는 <strong>ISP</strong>(In
System Programming) 기능이 특징이에요. 클록 1MHz마다 약 1MIPS(초당 100만
명령)의 처리 성능을 내고, C 언어 처리를 강력하게 지원해요.

그중 <strong>ATmega8535</strong>는 118개 명령어를 대부분 단일 클록 사이클에
실행하고, 32×8 범용 레지스터를 갖추고 10MHz에서 최대 10MIPS로 동작해요.
프로그램은 8KB 플래시 메모리(약 10만 번 쓰기·지우기 가능)에 담기고, 512Byte
SRAM과 512Byte EEPROM(역시 약 10만 번 가능)을 함께 내장하며, 저장된 내용을
함부로 못 건드리게 지키는 Lock 기능도 갖추고 있어요.

칩 안의 동작은 <strong>레지스터</strong>라는 스위치판을 설정해서 제어해요.
예를 들어 상태 레지스터(SREG)는 직전 연산 결과가 0이 됐는지, 자리 올림이
생겼는지, 부호가 음수인지 같은 정보를 8개의 비트 깃발로 기억해 둬요 — 이후
조건문이나 반복문이 바로 이 깃발을 보고 판단해요. 이 밖에도 인터럽트 방식이나
타이머 동작을 세밀하게 정하는 레지스터가 여러 개 있는데, 공통점은 하나예요 —
<strong>레지스터에 값을 써넣는 것으로 하드웨어의 동작 방식을 바꾼다</strong>는 것.

칩의 다리(핀)는 여덟 개씩 묶여 <strong>포트(Port A∼D)</strong>라는 입출력
창구를 이뤄요. 포트마다 방향을 정하는 레지스터(DDR)와 값을 내보내는
레지스터(PORT), 값을 읽어 들이는 레지스터(PIN)가 한 세트예요 — 방향 레지스터의
비트를 0으로 두면 입력, 1로 두면 출력이에요. 포트 A는 아날로그 신호를 입력받는
겸용 핀, 포트 B는 아날로그 비교기·타이머·SPI 프로그래밍 겸용, 포트 C는 시리얼
통신(TWI)과 타이머 발진 겸용, 포트 D는 UART 송수신과 외부 인터럽트 겸용으로
쓰여요. 이 밖에 전원(VCC·GND·AVCC), 리셋, 외부 클럭(XTAL1·XTAL2), ADC 기준
전압(AREF) 핀이 있어요. 각 포트는 20mA까지 흘려받을 수 있어 LED를 직접 켤 수
있는데, 이 칩은 <strong>Logic 'L'을 출력해야 LED가 켜지고 'H'를 출력해야
꺼지는</strong> 배선을 쓰는 경우가 많아요 — 다음 실습 단원에서 직접 확인해요.

```c
#include <avr/io.h>

int main(void)
{
    DDRA = 0xFF;   // Port A의 8개 핀을 모두 출력으로 설정
    PORTA = 0x0F;  // 하위 4개 핀에 신호를 내보냄(레지스터 값 하나로 4개 핀이 한꺼번에 바뀜)

    while (1) {
        // 이후 실습에서 이 자리에 점등·센서 로직을 채워 넣는다
    }

    return 0;
}
```

입력 핀을 그냥 비워 두면(open 상태) 값이 흔들려 오작동할 수 있어서, 높은
저항을 전원선에 연결하는 <strong>풀업 저항</strong>이나 접지선에 연결하는
<strong>풀다운 저항</strong>으로 핀 상태를 고정해요. 그리고 이 모든 걸 지휘하는
시계 신호는 <strong>오실레이터</strong>(발진기)가 만들어요 — 증폭 회로의 출력
일부를 입력으로 적당한 위상과 크기로 되먹임하면 일정한 진동이 계속 발생하는
원리예요. ROM과 RAM 회로까지 한 칩에 담아 사실상 초소형 컴퓨터 역할을 하는
이런 칩을 <strong>MCU</strong>(Micro Controller Unit) 또는 "원칩 컴퓨터",
"마이콤"이라고도 불러요.
