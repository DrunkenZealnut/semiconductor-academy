# 소개 & 출처

## 이 사이트는요

**반도체 아카데미**는 반도체 산업과 그 안의 유해인자를 누구나 이해할 수 있도록 풀어주는 학습 사이트예요.

- **대상**: 중·고등학생부터 일반인까지
- **방법**: 비유, 일러스트, 인터랙티브 다이어그램으로 어려운 내용을 풀어요
- **목적**: '알 권리의 민주화' — 산업 위험 정보를 누구나 접근 가능하게

## 재구성 원칙

1. **3단 레이어 구조** — 한 줄 요약 → 비유 → 학술 원본 (선택)
2. **출처 명시** — 모든 본문은 원본 페이지를 명시해 추적 가능
3. **정확성 유지** — 쉽게 풀어도 사실 왜곡 없도록 검수
4. **사전주의 원칙** — 입증이 어려운 위험도 가능한 범위에서 안내
